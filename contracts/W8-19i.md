## Semantics (C# is the spec)
Texts `text_fn(tr::<snake_case>)` (D-W8B5-802), pattern D-W8B5-803. `context` = `self.context.context()`. The page holds `marked: Rc<RefCell<BTreeSet<String>>>`, which the label providers share.
1. **`key()`** `"Shortcuts"`. The three row tables and `all_rows()` are given (27 rows, 14 with `clear_tip`; the optional rows are exactly `ShortcutMappings::OPTIONAL_NAMES`, a test checks it).
2. **`declare`**, in this order (ids follow): `page.note(Some(text_fn(tr::settings_group_shortcuts_hint)), false)`; `warning = page.warning(None)`; `reset_keys = first(page.buttons(false, &[text_fn(tr::settings_shortcuts_reset_keys)]))`; `page.group(text_fn(tr::settings_group_navigation), |g| add_grid(g, &NAVIGATION_ROWS))`; `page.group(text_fn(tr::settings_group_view), |g| add_grid(g, &VIEW_ROWS))`; `page.group(text_fn(tr::settings_group_actions), |g| { add_grid(g, &ACTION_ROWS); g.note(Some(text_fn(tr::settings_edit_action_profiles_hint)), false); edit_actions = first(g.buttons(false, &[text_fn(tr::settings_edit_action_profiles)])); })`.
3. **`add_grid(group, rows)`**: `specs` = per row `SettingsKeyCellSpec { label: text_fn(move || label_text(&marked, property, label)), clearable: row.clear_tip.is_some() }`; `cells = group.key_grid(&specs)`; for each `(row, cell)` (zip) push `(row.property.to_owned(), cell)` to `self.cells` (clear `self.cells` in `declare` first). `label_text(marked, property, label)` = `MARKER` + `label()` when `property` is in `marked`, else `label()` (the `RefCell` borrow ends before `label()` is called).
4. **`attach(context)`**: store; for each row of `all_rows()` with a `clear_tip`: if the page has a cell for the property and `cell.clear != 0` -> `set_tooltip_text(cell.clear, &tip())` (the text evaluated now, as C# `tip()`).
5. **`load(state)`**: for each `(property, cell)` in `cells` order: `set_text(cell.box_id, state.shortcut_texts.get(property).map_or("", String::as_str))`; then `refresh()`.
6. **`collect(state)`**: for each `(property, cell)`: `state.shortcut_texts.insert(property.clone(), context.text(cell.box_id))` (the typed text as is; the presenter canonicalizes at Save).
7. **`on_command(id, n)`**: (a) `n == EN_CHANGE && is_box(id)` -> `refresh()`, `true`. (b) `n != BN_CLICKED` -> `false`. (c) `id == reset_keys` -> `reset_keys()`, `true`. (d) `id == edit_actions` -> `edit_actions()`, `true`. (e) the first cell with `cell.clear != 0 && cell.clear == id`: `set_text(cell.box_id, "")` then `refresh()` (D-W8B5-805: the C# relied on the `EN_CHANGE` echo, Rust calls `refresh` itself), `true`. (f) `false`. `is_box(id)` = some cell has `box_id == id`.
8. **`reset_keys()`**: `defaults = ShortcutMappings::default()`; for each `property` of `settings_field_map::shortcut_properties()` (27, C# `SettingsFieldMap.Shortcuts` order) with a cell: `set_text(cell.box_id, shortcut_get(&defaults, property))`; then `refresh()`. Actions and every other page are untouched; nothing is saved.
9. **`edit_actions()`**: `json = context.collect_actions_json()`; `actions = SettingsPresenter::actions_for_editor(&json, &EnglishSettingsTexts)` (D-W8B5-806); `Err(_)` -> `show_warning(&tr::dialog_open_editor_failed_title(), &tr::dialog_open_editor_failed_message())` and return (the C# `catch`); `edited = context.edit_action_profiles(&actions)` (the context itself warns when the editor is unavailable and answers `None`; a cancelled editor is `None` without a warning); `None` -> return; `Some(list)` -> `context.commit_actions_json(&SettingsPresenter::actions_to_text(&list), self.key())` then `refresh()`.
10. **`refresh()`**: `texts` = `BTreeMap` of `property -> context.text(cell.box_id)` over `cells`; `actions_json = context.actions_json()` (read BEFORE the presenter is borrowed); `message = context.presenter().borrow_mut().duplicate_shortcut_warning(&texts, &actions_json).unwrap_or_default()`; if `message != self.warning_text` -> `self.warning_text = message.clone()`, `set_text(warning, &message)`, `relayout()`; then `update_markers(&texts)`.
11. **`update_markers(texts)`**: `problems = find_problems(texts)`; `*marked.borrow() == problems` -> return. Else `changed = problems ∪ old marked` (BTreeSet, sorted); replace `marked` by `problems` (borrow released); for each `property` in `changed` that is in `all_rows()` and has a cell: `set_text(cell.label, &label_text(&marked, property, row.label))`; then `relayout()`.
12. **`find_problems(texts)`**: for each `(property, raw)`: `canonical = canonicalize(Some(raw))` (`pr_core::settings::shortcuts`: trims, aliases, case); empty canonical -> a problem iff `!ShortcutMappings::is_optional(property)`, then next; `shortcut_key_name::try_parse(Some(&canonical)).is_none()` -> a problem, next; else group the property under `canonical.to_ascii_lowercase()`. Afterwards every group with two or more properties adds all its properties. Returns the sorted set.
13. **`on_language_changed()`**: `warning_text = String::new()`; `refresh()` (so the warning is written again in the new language, and the marks re-evaluated). The labels follow through the builder providers.
14. **Accessors**: `ids()`, `cell(property)` (linear search, a copy of the cell), `marked_properties()` (sorted).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (string comparison): shortcut names are compared after `canonicalize`; the group key is ASCII-lowercased (canonical names are ASCII by construction: `try_parse` accepted them), never `to_lowercase()` of arbitrary text; property names compare ordinally (`BTreeMap`, `is_optional`).
- T8 (null vs empty): an empty optional box is valid and absent from every group (two empty optional boxes are NOT a conflict); `shortcut_texts.get(property)` missing = `""`.
- T9: the C# `catch (Exception) when not OperationCanceledException` around `EditActionProfiles(...)` is `actions_for_editor` returning `Err` (this page) plus the context's own unavailable branch (19a).
- T10 (order): `cells` in `all_rows()` order (C# dictionary insertion order, D-W8B5-815); `load`/`collect` iterate in that order; the order of the label rewrites in `update_markers` is sorted (C# `HashSet` order is unspecified): tests must not depend on it.
- D-W8B5-805: no reliance on `EN_CHANGE` echo; D-W8B5-706: no `RefCell` borrow (presenter or `marked`) across a `context` write.
- D-W8-4: the only literal is `MARKER` (a symbol); all names are `tr::`.
- R0003: no `unwrap`/`expect`/indexing; the detached context and a page that was never declared do nothing.
