## Semantics
- `suggest`: ProductName then FileDescription, each tested with `string.IsNullOrWhiteSpace`, the winner `Trim()`med. Read the version resource of the file WITHOUT loading it as code (`GetFileVersionInfoSizeW`/`GetFileVersionInfoW`/`VerQueryValueW`; translation = the first entry of `\VarFileInfo\Translation`, else `040904B0`; `Win32_Storage_FileSystem` is already a feature of the crate, no `Cargo.toml` change). Every failure is `None`, never a panic, never an error dialog.
- Text prompt: label, edit box (text `initial`, whole text selected at open), Cancel, Apply (default). `on_ok`: `get_item_text(EDIT_ID).trim()`; empty -> focus the box and stay open **without a message**; else `value = Some(text)`. Preferred size: `width = max(dx(220), button_row_width + 2*dx(12))`, `height = dy(10) + label + dy(4) + h + dy(10) + h + dy(10)` with `h = max(dy(14), line_height + dy(6))`.
- Choice list: `for_choice(title, intro, lines, selected)` = no heading, intro in `Dark.TextSecondary`, confirm `dialog.externalEditor.setDefaultConfirm`, 260 x 150 dialog units; with `0 <= initial_selected_index < lines.len()` that row is selected right after the list is filled (after `LB_SETHORIZONTALEXTENT`); `on_ok` stores `LB_GETCURSEL` (or `-1` when there is no list control) in `selected_index`, and returns `initial_selected_index < 0 || selected_index >= 0`. Existing dialogs (`initial_selected_index = -1`) keep their behaviour: `on_ok` returns `true`.
