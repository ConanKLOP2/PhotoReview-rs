## Scope and decisions

The plan row is `ViewModels/ViewerState` (450 C# lines, zoom/fit/fullscreen/stretch state machine). The unit ports that one class.
`ViewerStretchMode` (11 lines) is ported by W8-01a, `ViewRefreshOutcome` by W8-01d, `FitViewer` (the seam the Fit driver uses) by W8-01d.
Everything in `ViewerStateTests.cs` that is not about `ViewerState` belongs to another unit (see "NOT here").

- **D-06a-1 Change set instead of `INotifyPropertyChanged`.** Every C# `[ObservableProperty]` setter and every `[NotifyPropertyChangedFor]`
  dependent becomes one bit of `ViewerChanges`. The two types `ViewerChanges` (bit set of `ViewerProperty`) and `ViewerUpdate`
  (`changes` + `zoom_mode_changed`) are declared in `viewer_state.rs` by this unit. Open question OQ-2 says where they live if W8-08a
  wants them shared.
- **D-06a-2 Events become return values.** C# `ZoomModeChanged` becomes `ViewerUpdate::zoom_mode_changed`. C# `SourceSizeSwapping`
  becomes the `on_swapping: &mut dyn FnMut(&ViewerState)` argument of `swap_source_size`, called with the state BEFORE the size changes.
  No stored listener, no `Rc<RefCell>` (D-W8-1).
- **D-06a-3 Raw setters are public** (C# generated setters are public): `set_zoom_raw`, `set_stretch`, `set_dpi_scale`,
  `set_max_image_width`, `set_max_image_height`, `set_scaling_quality`, `set_force_high_quality_scaling`, `set_fullscreen`,
  `set_zoom_step`. They are not wrappers of the command methods: they do not clamp, do not touch the Fit axis and do not raise
  `zoom_mode_changed`. The C# public setters of `SourcePixelWidth`/`SourcePixelHeight` are NOT exposed: nothing outside
  `SetSourceSize`/`SwapSourceSize` writes them (traces and tests go through those two). A note in the PARITY row, not a `Different` row
(nothing observable changes).
- **D-06a-4 `FitViewer` seam.** `impl FitViewer for ViewerState` exists so W8-01d's Fit driver can call `reset_fit`. The trait method
  returns `()`, so the impl stores `zoom_mode_changed` in `pending_fit_zoom_mode_changed` and the shell drains it with
  `take_pending_zoom_mode_changed()` (OQ-1).
- **D-06a-5 The default click level is a parameter.** C# `ApplyInitialViewMode` has default arguments
  (`clickZoomPercent = AppSettings.DefaultClickZoomPercent`, `keepZoomAcrossImages = false`). The Rust method takes all five arguments;
  the caller passes `pr_core::settings::app_settings::DEFAULT_CLICK_ZOOM_PERCENT` (100) where C# used the default.
- **D-06a-6 Zoom step is plain data.** C# `ZoomStep` is a public auto-property without notification. Rust: `set_zoom_step` / `zoom_step`,
  no change set, no clamp (C# has none).
- **D-06a-7 `DisplayZoomPercent` uses ties-to-even** (C# `Math.Round(double)` default), not Rust's `f64::round` (ties away from zero).
  This is trap T9.

## Semantics

### 1. Change-set rule (applies to every mutating method)
A setter's bits are added only when the stored value changes. The comparison is `f64_same` for doubles (NaN equals NaN, `-0.0` equals
`0.0`, as C# `EqualityComparer<double>.Default`) and `==` for the other types. The dependents are added whenever the source bit is
added, with no comparison of the dependent's value. The table is the C# attributes, checked line by line:

| Source (setter)                        | Bits added with it (when the source changed)                                  |
|----------------------------------------|--------------------------------------------------------------------------------|
| `Zoom` (`set_zoom_raw`, and every zoom command) | `Zoom`, `IsFit`, `ImageWidth`, `ImageHeight`, `DisplayZoomPercent`    |
| `Stretch`                              | `Stretch`, `IsFit`, `ImageWidth`, `ImageHeight`, `DisplayZoomPercent`          |
| `SourcePixelWidth` / `SourcePixelHeight` | the source, `ImageWidth`, `ImageHeight`, `DisplayZoomPercent`                 |
| `DpiScale`                             | `DpiScale`, `ImageWidth`, `ImageHeight`, `DisplayZoomPercent`                  |
| `MaxImageWidth` / `MaxImageHeight`     | the source, `DisplayZoomPercent`                                               |
| `ScalingQuality`                       | `ScalingQuality`, `EffectiveScalingQuality`                                   |
| `ForceHighQualityScaling`              | `ForceHighQualityScaling`, `EffectiveScalingQuality`                           |
| `IsFullscreen`                         | `IsFullscreen`                                                                 |

`ImageWidth` is NOT a dependent of `MaxImageWidth` (C# attribute list), and `IsFit` is NOT a dependent of anything but `Zoom` and
`Stretch`. A method that sets two sources (for example `SetSourceSize` with a new width and height) returns the union.

### 2. Derived values (C# computed properties)
- `IsFit = stretch == Uniform && |zoom - 1.0| < 0.001` (strict `<`).
- `normalize_dpi(d) = d` when `0.25 <= d <= 16.0` (NaN fails the test), else `1.0`.
- `calculate_display_size(w, h, zoom, dpi)`: `scale = zoom / normalize_dpi(dpi)`; result `(w as f64 * scale, h as f64 * scale)`.
- `display_size()` (private): NaN pair when `is_fit()` or `source_pixel_width <= 0` or `source_pixel_height <= 0`; else
  `calculate_display_size(source_pixel_width, source_pixel_height, zoom, dpi_scale)`. `image_width()`/`image_height()` read it.
- `fit_zoom()`: 0 when `source_pixel_width <= 0` or `source_pixel_height <= 0`; 0 unless both `max_image_width` and
  `max_image_height` are finite AND both are `> 1`; `dpi = normalize_dpi(dpi_scale)`;
  `fit = math_min((max_image_width * dpi) / source_pixel_width, (max_image_height * dpi) / source_pixel_height)`; result `fit` when
  finite and `> 0`, else 0.
- `fit_width_zoom()`: 0 when `source_pixel_width <= 0` or `max_image_width` not finite or `<= 1`; `fit = (max_image_width * dpi) /
  source_pixel_width`; `fit` when finite and `> 0`, else 0. `fit_height_zoom()` is the height twin (uses `max_image_height` and
  `source_pixel_height`).
- `step_base()` (private): `fit_zoom()` when `is_fit() && fit_zoom() > 0`, else `zoom`.
- `display_zoom_percent()`: `value = if is_fit() { if fit_zoom() > 0 { fit_zoom() } else { 1.0 } } else { zoom }`;
  result `(value * 100.0).round_ties_even() as i32` (trap T9; a NaN zoom is not golden-covered, OQ-5).
- `effective_zoom()`: `None` when `is_fit()`, else `Some(zoom)`.
- `effective_scaling_quality()`: `HighQuality` when `force_high_quality_scaling`, else `scaling_quality`.

### 3. Source size
- `set_source_size(w, h, new_image)`: `w = max(0, w)`, `h = max(0, h)`. When `new_image` OR `(w, h) != (source_pixel_width,
  source_pixel_height)` (after clamping) clear the Fit axis (`fit_axis = None`, `fit_axis_viewport = 0`). Then set width, then height
  (each through the source-setter rule of section 1).
- `swap_source_size(w, h, on_swapping)`: clamp both as above. If `(w, h)` equals the current size: return the empty update (no
  callback). If `source_pixel_width <= 0 || source_pixel_height <= 0 || w <= 0 || h <= 0 || is_fit()`: call
  `set_source_size(w, h, false)` and return its update (no callback). Otherwise:
  1. call `on_swapping(&*self)` (the listener reads the OLD size, trap T5);
  2. save `(fit_axis, fit_axis_viewport)`; call `set_source_size(w, h, false)` (which clears the axis because the size changed);
     restore the saved pair;
  3. `fit_zoom = match axis { Width => (axis_viewport * normalize_dpi(dpi_scale)) / w as f64, Height => (axis_viewport *
     normalize_dpi(dpi)) / h as f64, None => 0.0 }`, where `w`/`h` are the NEW clamped sizes;
  4. when `fit_zoom` is finite and `> 0`: `set_zoom_raw(clamp(fit_zoom, MIN_ZOOM, MAX_ZOOM))` (raw: `Stretch` stays `None`,
     no `zoom_mode_changed`). Union the bits. Callback count is exactly 1 in the zoomed branch, 0 otherwise.

### 4. Zoom commands
- `set_zoom(value)` (C# `SetZoom` -> `SetZoomCore(value, None, 0)`): `NaN` returns the empty update (no bit, no event). Otherwise, in
  this order (the order matters for the change set only through bit union, but the fit axis must be set before `Zoom` for the
  listener, which the C# comment states): `Stretch = None` (raw), `max_image_width = +Infinity` (raw), `max_image_height = +Infinity`
  (raw), `fit_axis = axis`, `fit_axis_viewport = axis_viewport`, `zoom = clamp(value, MIN_ZOOM, MAX_ZOOM)` (raw), and
  `zoom_mode_changed = true`. `clamp(+Inf)` is 8.0, `clamp(-Inf)` is 0.10.
- `zoom_to_actual_size()` = `set_zoom(ACTUAL_SIZE_ZOOM)`.
- `zoom_to_fit_width()`: `z = fit_width_zoom()` computed FIRST; when `z > 0`: `set_zoom_core(z, Width, max_image_width)` where
  `max_image_width` is read BEFORE the call (trap T4). Otherwise the empty update. `zoom_to_fit_height()` is the twin.
- `zoom_in()` = `step_zoom(zoom_step)`; `zoom_out()` = `step_zoom(-zoom_step)`; `wheel_zoom(d)` = `step_zoom(if d > 0 { zoom_step }
  else { -zoom_step })` (trap T6: delta 0 steps DOWN).
- `step_zoom(step)`: `next = calculate_step_zoom(step_base(), step)`; `Some(v)` -> `set_zoom(v)` (returns its update); `None` -> empty.
- `calculate_step_zoom(current, step)` (C#, exact order):
  - if `step > 0`: if `current >= MAX_STEP_ZOOM - 0.0005` -> None; else `Some(math_min(current + step, MAX_STEP_ZOOM))`.
  - else (`step <= 0` or NaN step): if `current <= MIN_STEP_ZOOM + 0.0005` -> None; if `current > MAX_STEP_ZOOM` -> `Some(4.0)`;
    else `Some(math_max(current + step, MIN_STEP_ZOOM))`.
  - Comparisons with NaN are false, so a NaN `current` reaches `math_min`/`math_max`, which return NaN (trap T3). A NaN step takes the
    `else` branch.

### 5. Viewport bound and Fit axis
- `reset_fit(w, h)`: `fit_axis = None` (set directly, not `clear_fit_axis`, same effect); `zoom = 1.0` (raw); `stretch = Uniform`
  (raw); `update_viewport(w, h, true)` (its bits and no event); then `zoom_mode_changed = true` ALWAYS. The returned bits are the union.
- `update_viewport(w, h, force)`:
  1. if `fit_axis != None && w > 1 && h > 1 && w.is_finite() && h.is_finite()`: `fit_axis_viewport = if fit_axis == Width { w } else { h }`;
  2. if `!force && stretch != Uniform`: return the empty update;
  3. if `w > 1 && h > 1 && both finite`: `max_image_width = w` and `max_image_height = h` (raw, bits as section 1). Otherwise the
     limits keep their old values (trap T7).
  `zoom_mode_changed` is never set here.
- `apply_initial_view_mode(mode, w, h, click, keep)`: `keep` -> `None`. Else `Some(update)` of the table:

  | mode | action (union of the bits of the calls) |
  |---|---|
  | `Fit` | `reset_fit(w, h)` |
  | `FitWidth` | `update_viewport(w, h, true)`, then `zoom_to_fit_width()` (the viewport refresh MUST come first, trap T8) |
  | `FitHeight` | `update_viewport(w, h, true)`, then `zoom_to_fit_height()` |
  | `ClickZoomLevel` | `set_zoom(click as f64 / 100.0)` (float division, trap T10) |
  | `Percent200`, `Percent400` | `set_zoom(2.0)` (Percent400 is legacy, kept defensively) |
  | `Percent100` and any other value | `set_zoom(1.0)` |

  `zoom_mode_changed` is the OR of the calls. `None` for `keep`: the state is untouched (test 18).
- `toggle_fullscreen()` (`is_fullscreen = !is_fullscreen`, bit `IsFullscreen` when it changed), `exit_fullscreen()` (set false).

### 6. FitViewer seam
`impl FitViewer for ViewerState::reset_fit(&mut self, w, h)` calls the inherent `reset_fit(w, h)` and sets
`pending_fit_zoom_mode_changed |= update.zoom_mode_changed`. `take_pending_zoom_mode_changed()` returns the flag and clears it.
No other method touches the flag.

## Traps (write these into the porter's tests before the bodies)

- **T1 Default stretch.** C# `_stretch = ViewerStretchMode.Uniform`; the enum's `#[default]` is `None`. `new()` sets `Uniform`
  explicitly. Test `default_state_is_fit_and_uniform` fails on the wrong default.
- **T2 `IsFit` tolerance is strict.** `|zoom - 1.0| < 0.001`: a zoom of 1.001 is not Fit. Test with 1.0009 and 1.001.
- **T3 NaN in `Math.Min`/`Math.Max`.** C# propagates NaN; Rust `f64::min`/`f64::max` return the non-NaN operand. Use
  `math_min`/`math_max` (NaN if either is NaN). Golden `viewer-step-zoom` has `current = NaN` (both branches) and `step = NaN`.
  `f64::clamp` does propagate NaN and is fine where the value is finite anyway.
- **T4 Argument captured before `SetZoomCore` clears the limit.** `ZoomToFitWidth` passes the CURRENT `MaxImageWidth` as
  `axisViewport`; `SetZoomCore` sets the limit to `+Infinity` before storing the axis. Read it into a local first. Golden trace case
  `fit width then step continues from the fitted zoom` and the `swap` cases pin it: a swap after `zoom_to_fit_width` refits to
  `viewport / new_width`.
- **T5 Listener sees the old size.** `on_swapping` runs before `set_source_size`; the mutation-gap test checks width 50 at the event.
- **T6 Wheel delta 0 steps down** (`delta > 0 ? +step : -step`).
- **T7 Unusable viewport readings keep the old limits.** Only `> 1` and finite readings write; `1.0` exactly is unusable. Also the
  fit-axis memory uses the same rule, but it is updated even outside Uniform (step 1 of `update_viewport`).
- **T8 Order in `ApplyInitialViewMode` FitWidth/FitHeight.** The viewport refresh (`force: true`) comes before the zoom so
  `fit_width_zoom()` sees the new `max_image_width`.
- **T9 Ties to even.** `DisplayZoomPercent` uses C# `Math.Round(double)` (ties to even): `zoom 0.125` -> 12, `0.375` -> 38, `0.625`
  -> 62. Rust `f64::round()` gives 13, 38, 63. Use `round_ties_even()`. Golden trace `display zoom percent rounds half to even` pins it.
- **T10 `clickZoomPercent / 100.0`** is a double division. `150 / 100` as integers would be 1; use `f64::from(click) / 100.0`.
- **T11 `ZoomStep` is not clamped.** A negative step reverses `zoom_in`/`zoom_out` (golden trace `negative zoom step`).
- **T12 `ResetFit` always raises `zoom_mode_changed`**, even when nothing changes (test `reset_fit` twice at the same viewport: both
  updates have the flag; the trace pins it).
- **T13 `set_zoom(NaN)` is a full no-op**: no `Stretch` bit, no limits, no axis change, no flag. A raw `set_zoom_raw(NaN)` is stored
  as NaN (C# has no guard on the raw setter) but its `DisplayZoomPercent` is not golden-covered (OQ-5).
- **T14 Equality by `f64_same`.** Setting `max_image_width` to `+Infinity` when it already is `+Infinity` returns no bit. Example: the
  first `set_zoom` of a fresh state (trace `set_zoom leaves fit`) reports no `MaxImageWidth` bit, because the limit is already
  `+Infinity`. A second `set_zoom` with `Stretch` already `None` reports no `Stretch` bit.
- **T15 Negative source sizes are clamped to 0**, then compared (a `-5` change from 2000 is a change to 0).

## Open questions (each has a recommended default; the stub already follows the default)
- **OQ-1 `FitViewer::reset_fit` returns `()`.** The C# `ResetFit` raises `ZoomModeChanged`, which the view model listens to. The
  trait (W8-01d) cannot carry it, so this unit keeps a pending flag. Recommended (used): keep the trait, drain the flag in the shell.
  Alternative: W8-01d changes the trait to return `ViewerUpdate` (the type would move to `viewport::types` first, no cycle). That is
  cleaner and removes the flag, but it edits a stub that is already written. The lead decides before the 01d merge.
- **OQ-2 Home of `ViewerChanges`/`ViewerUpdate`.** Recommended (used): here, in `viewmodels::viewer_state`. W8-08a (`MainViewModel`)
  and W8-04a may import them from here. Alternative: `viewmodels::change_set`, a lead-owned module created with the D-W8-1 decision.
  Moving it later is a rename of one `use` line per consumer.
- **OQ-3 Raw setters public.** Recommended (used): public, because the C# generated setters are public and the golden drives them.
  Alternative: `pub(crate)` if no consumer needs raw writes; the golden would then need `ViewerState` test hooks. The porter keeps the
  public form unless the wave's consumer review says otherwise.
- **OQ-4 `set_source_size` raw `SourcePixelWidth` setter not exposed.** Recommended (used): not exposed (D-06a-3). Alternative: expose
  `set_source_pixel_width` raw. Nothing in the C# code calls it outside `SetSourceSize`/`SwapSourceSize`.
- **OQ-5 `DisplayZoomPercent` of a NaN zoom.** C# `(int)Math.Round(NaN)` is platform-defined (0 on .NET 9+ x64 by saturation, but
  not guaranteed). Recommended: not golden-covered; the Rust cast `as i32` gives 0 (saturating), which matches .NET 9+. Lead may ask
  the oracle to pin it later.
- **OQ-6 Math.Round ties-to-even.** Recommended (used): `round_ties_even()` because C# `Math.Round(double)` defaults to ties-to-even;
  golden cases pin it (`0.125` -> 12). If the oracle shows otherwise, the golden wins and the rounding changes (T9).
