## Semantics notes
1. **Preconditions** (lines 733 to 742): operation not Move/Copy -> `Err(operation)`; catalog empty, no executor or `is_busy()` -> `Ok(Done(false))`; `get_source()` is called live; `source = compare.or(current)`, empty -> Done; `photo_folder = get_directory_name(source)`, empty -> Done.
2. **Destination** (lines 744 to 775): `action_name` = `action.moveToFolder.name` / `action.copyToFolder.name`; `last_folder` from the settings (`last_move_to_folder` / `last_copy_to_folder`); `last_usable = validate_picked_folder(last_folder, photo_folder, directory_exists) == Ok`;
   when `move_copy_reuse_last_folder && !force_picker && last_usable` the last folder is used WITHOUT a picker; else a picker is required (`None` -> Done); `initial_folder` = `last_folder` if it exists, else the parent of `photo_folder`, else `photo_folder`;
   `folder_before = clock.current_folder()`; `picker.pick_folder(dialog.moveToFolder.title | dialog.copyToFolder.title, Some(initial))`; `None` -> Done (cancel is a no-op); then `get_source()` AGAIN: folder generation changed OR executor busy OR
   `compare_after.or(current_after)` differs from `source` (OrdinalIgnoreCase) OR the source left the catalog -> status `status.moveCopyTo.stateChanged(actionName)` and Done(false).
3. **Validation** (lines 777 to 790): `validate_picked_folder(destination, photo_folder, directory_exists)`: `Ok` -> continue; `SameAsPhotoFolder` -> `status.moveCopyTo.sameFolder`; `Missing` -> `status.moveCopyTo.folderMissing(actionName, destination)`;
   anything else (Empty, NotAbsolute) -> `status.moveCopyTo.notAbsolute`; `Err(PathError)` -> `notAbsolute` too (D-07e-1). `directory_exists` = `file_system.directory_exists` when a file system was given, else `Path::is_dir` (C# `Directory.Exists`).
   A fake file system that says "missing" wins over the disk (test `..ReportsMissingEvenWhenItExistsOnDisk`).
4. **Core** (lines 792 to 813): `folder = trim_ending_directory_separator(get_full_path(destination))`; `execute_core(.., AfterCore::MoveCopyTo(MoveCopyTail{ operation, folder, last_folder, file_name }))`. The tail runs only when the core returned true (succeeded and the folder is still current):
   `rememberFolder(operation, folder)` when `folder` differs from `last_folder` (OrdinalIgnoreCase); then, once the present of the next photo finished (`present` state), if the folder is still `last_action_folder_gen`: when `catalog.count() > 0`, status
   `status.movedToFolder(fileName, folder)` or `status.copiedToFolder(fileName, folder)`, followed by `" " + last_partner_missing_warning` when the core wrote one. Moving the only photo keeps `AllImagesProcessed` (no final status).
5. **`restores_outside_folder(result, current_folder)`** (lines 821 to 826): true iff `result` is `Some`, `succeeded`, the source is non-empty, the operation is Recycle or Move, and: `restored_paths` non-empty -> any restored path is NOT in `current_folder`; otherwise the source is not in it.
   `None`, failed, Copy, empty source -> false. A `current_folder` that is `None`, empty, or fails `get_full_path` makes every path "outside".
6. **`reload_path_after_undo(result)`** (lines 833 to 839): no restored paths -> `result.source`; the source is among `restored_paths` (OrdinalIgnoreCase) -> `result.source` (its own spelling, not the restored one: test `..KeepsTheSourceSpelling`);
   else the first restored path that `is_supported_with(path, true, true)` (sidecars never qualify), else `result.source`. Returns `Option<String>`: `None` only when the source is empty and nothing qualifies (C# returns the `string?` source).
7. **`is_in_folder(path, folder)`** (lines 841 to 857): empty `folder` -> false; `get_directory_name(path)` empty -> false; compare `trim_ending_directory_separator(get_full_path(parent))` with the same for `folder`, `eq_ignore_case`; `PathError` -> false (test `..InvalidCharacters_CountsAsOutsideInsteadOfThrowing`).

## Traps checklist (concrete)
- **Modal picker** (R7-4): `pick_folder` runs a nested loop in the shell; `get_source` is re-read afterwards and the FOUR conditions of note 2 are checked in one `if`. The status for a changed state is `stateChanged`, not a silent return.
- **RV-A09**: the final "Moved to ..." status is written after the next photo's present finished, otherwise the presenter's "Ready" replaces it (test `MoveToFolder_NextPresentStillRunning_FinalStatusIsMovedTo`). If the folder changed meanwhile write NOTHING.
- Destination comparison with `last_folder` is OrdinalIgnoreCase (`eq_ignore_case`); do not call `remember_folder` for the same folder spelled in another case.
- `get_full_path`/`trim_ending_directory_separator` of the destination: a drive root keeps its separator (`E:\`).
- Operation precedence in the C# helpers (`x is A or B`) is the pattern `is (A or B)`; do not port as `(x is A) || B`.
- `IFolderPicker::pick_folder(&mut self, title, initial)` takes `&mut`: the picker is passed per call, never stored.
- No `async`, no `unsafe`, no `windows` crate; texts only through `TextSource`.
