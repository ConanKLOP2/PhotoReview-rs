## Semantics notes (C# is the spec)
1. **Cache state** is one `RefCell<State<N>>`; entries are `Rc<TextLayoutEntry<N>>` with `Cell` counters (`ref_count`, `evicted`) and `RefCell<Option<N>>` for the native payload (`None` = released). No lock (D-W8B3S-10): the C# `lock` guarded a lease disposed from another thread, which a `!Send` Rust lease cannot be.
   Recency: `HashMap<key, (stamp, entry)>` + `BTreeMap<stamp, key>`: a hit or a new entry takes the next, larger stamp ("moved to head"); eviction removes the SMALLEST stamp ("tail").
2. **`acquire(key, build)`**: disposed -> `Err(Disposed)`. Hit: `hits += 1`, new stamp, `ref_count += 1`, return the same `Rc`. Miss: `misses += 1` FIRST (so a failing `build` still counts), then `build(&key)` WITHOUT any borrow of the state held (build may read the cache; it cannot mutate it), `Err(e)` -> `Err(Build(e))` with nothing cached;
   `Ok(parts)` -> entry with `ref_count = 1`, inserted at the newest stamp, then `while map.len() > capacity { evict(oldest) }` (the new entry is the newest, so it is never the victim while `capacity >= 1`).
3. **`evict(entry)`**: remove from both maps, `evicted = true`; `ref_count == 0` -> drop the native payload now, else `pending += 1`.
4. **`release(entry)`**: `ref_count <= 0` -> return (idempotent, guards a double release); `ref_count -= 1`; if `evicted && ref_count == 0 && !is_released()` -> drop the native payload, `pending -= 1`. Works after `dispose` (leases outlive the renderer).
5. **`clear`** evicts everything (leased entries become pending); **`dispose`** evicts everything, then sets `disposed` (idempotent). **`new(capacity)`**: `capacity < 1` -> `Err(InvalidCapacity(capacity))`.
6. **`TextLayoutKey`**: equality and hash over (text, family, size bits, bold, width bits, trimming). The two `f32` are compared by BITS, which is correct because they are never NaN and never `-0.0` (size validated finite and positive; width normalised: negative zero becomes `0.0`).
   The same bit pattern <=> C# `float.Equals` for these values. Text and family are ordinal and case-sensitive (`"abc"` and `"ABC"` are different keys; C# record equality uses `string.Equals` ordinal).
7. **`normalize_width(w)`** = `if w.is_nan() || w >= 1_000_000.0 { UNBOUNDED } else if w <= 0.0 { 0.0 } else { w as f32 }` (positive zero for `-0.0`, `-inf` and negatives; `as f32` rounds to nearest like the C# cast; a positive `f64` below the smallest `f32` becomes `0.0`, still a valid key). `is_valid_font_size(s)` = `s > 0.0 && s.is_finite()`.
8. **`create_layout`** order (C#): renderer disposed -> `Err(Disposed { object: RENDERER_OBJECT_NAME })`; `!is_valid_font_size` -> `Err(InvalidFontSize { value_bits: size.to_bits() })`; family = `effective_font_family` (`str::trim().is_empty()` -> `"Segoe UI"`, otherwise the string UNTRIMMED; .NET `IsNullOrWhiteSpace` and Rust `trim` both use Unicode White_Space);
   key = (`text`, family, `font_size_dip as f32`, `bold`, `normalize_width(max_width)`, `trimming`). A size such as `1e300` passes validation but is `+inf` as `f32`, `1e-300` is `0.0`: DirectWrite rejects both with `E_INVALIDARG` -> `Err(Device(..))` (same as C#); never a panic.
9. **`build(key)`** (closure passed to `acquire`): `gfx::dwrite::create_text_format(&factory, family, bold, size, &locale)?`; `gfx::dwrite::create_text_layout(&factory, text, &format, max_width)?` (UTF-16 length is taken from the string by the helper; height `UNBOUNDED`); for `CharacterEllipsis`: `layout.SetWordWrapping(DWRITE_WORD_WRAPPING_NO_WRAP)`
   (mapped with `.gfx("IDWriteTextLayout::SetWordWrapping")`) THEN `gfx::extras::set_character_ellipsis_trimming(&factory, &layout)?` (T4); `metrics = gfx::dwrite::layout_metrics(&layout)?`; `is_trimmed = ellipsis && metrics.line_count >= 1 && gfx::dwrite::first_line_is_trimmed(&layout)`;
   `NewLayoutEntry { native: layout, width: metrics.width as f64, height: metrics.height as f64, line_count: metrics.line_count as i32, is_trimmed }`. The text format and the sign are dropped when `build` returns (RAII replaces the C# `finally` releases).
10. **Locale** (`resolve_locale`): `Some(l)` with `!l.trim().is_empty()` -> `l`; else `ui_culture_name` if `!ui_culture_name.is_empty()` (NOT trimmed, C# `Name is { Length: > 0 }`); else `"en-us"`. The caller supplies the UI culture name from the localization service (the C# app sets `CurrentUICulture` in `LocalizationService`, line 74).
11. **Lease**: copies `text`, `width`, `height`, `line_count`, `is_trimmed` from the entry at creation; `native_layout()` clones the `IDWriteTextLayout` (`AddRef`) while the entry is not released (always true for a live lease); `Drop` calls `cache.release(entry)` once (the field is an `Option` taken in `drop`).
12. **Thread affinity**: `DWriteTextRenderer` and `DWriteTextLayoutLease` hold `Rc` and a `PhantomData<*const ()>`: `!Send`. windows-rs 0.62.2 marks `IDWriteFactory`/`IDWriteTextLayout` `Send`, so the marker, not the compiler default, enforces the UI-thread rule (D-W8B3G-9 d). The factory is the shared one (`DWRITE_FACTORY_TYPE_SHARED`).
13. **Device independence**: a layout is measured in DIP and carries no D2D device; a lost Direct2D device (`DeviceRecreated`) never touches this cache (test `Layouts_SurviveDeviceRecreation`).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (float equality): the key stores `f32` bits; `-0.0` and NaN must never reach it. A porter who derives `Hash` on a struct with `f32` fields will not compile; one who uses `f64` for the size/width changes the cache identity (`12.0` and `12.0000001` would be separate C# keys only after the `f32` cast).
- T2 (miss counted before build): a failing build still increments `misses`; no entry is stored.
- T3 (new entry never the victim): with `capacity == 1`, acquiring `b` evicts `a`, not `b`. The stamp scheme makes this automatic; a `BTreeMap::pop_first` on the wrong end does not.
- T4 (ellipsis order): `NoWrap` -> sign -> `SetTrimming`. With wrapping on, a narrow layout wraps instead of cutting (11f T8). `is_trimmed` is only evaluated for `CharacterEllipsis`.
- T5 (`width` is the ink-box width): `layout_metrics().width` (the `DWRITE_TEXT_METRICS::width`), not `widthIncludingTrailingWhitespace`; the C# tests compare `Size.Width <= 120.01` for a 120 wide ellipsis layout and equality with the unconstrained width for short text.
- T6 (UTF-16): lengths and DirectWrite offsets are UTF-16 code units; Vietnamese text with combining marks and emoji (surrogate pairs) must not be measured by `chars().count()` or `len()`. The helper encodes with `encode_utf16`; this unit never indexes text.
- T7 (release after dispose): leases outlive the renderer and the cache; `release` must still work, and `dispose` must not drop leased native layouts.
- T8 (double release): the `ref_count <= 0` guard; also `pending` must never go negative.
- T9 (check order): disposed before font size. A disposed renderer with a bad size reports `Disposed`.
- T10 (locale is not trimmed for the UI culture): only the explicit `locale_name` is tested with white space.
- T11 (`!Send`): the `PhantomData<*const ()>` markers are part of the contract; remove them and a lease could be dropped on another thread (releasing into a `RefCell` from there).

## Safety rules (every `unsafe` block gets a `// SAFETY:` comment; the lint `undocumented_unsafe_blocks` is on)
`layout_cache.rs`: ZERO `unsafe`. `renderer.rs`: exactly ONE `unsafe` block, the call `layout.SetWordWrapping(DWRITE_WORD_WRAPPING_NO_WRAP)` (`pub unsafe fn` in windows 0.62.2; no 11h/11f helper wraps it). SAFETY comment: `layout` is a live owned `IDWriteTextLayout` created a few lines earlier,
the argument is a plain enum constant, no pointer escapes, UI thread. Every other DirectWrite call goes through the safe helpers of `gfx::dwrite` / `gfx::extras` (11f, 11h). No raw pointers are stored. No `mem::forget`, no `ManuallyDrop`.
Thread affinity: UI thread only (note 12). No locks, no threads, no environment access. The renderer never calls into the cache while a state borrow is held (T2: `build` runs unborrowed).

## Error mapping
`TextError::Device(GfxError)` carries the failing DirectWrite call (`"DWriteCreateFactory"`, `"CreateTextFormat"`, `"CreateTextLayout"`, `"IDWriteTextLayout::SetWordWrapping"`, `"IDWriteFactory::CreateEllipsisTrimmingSign"`, `"IDWriteTextFormat::SetTrimming"`, `"IDWriteTextLayout::GetMetrics"`); `GetLineMetrics` failure is NOT an error (`is_trimmed = false`).
After the layering PR it converts field for field into `RenderError::Device { hresult, operation }`. `AcquireError::Disposed` is mapped by the renderer to its own `Disposed { object: RENDERER_OBJECT_NAME }` (C# `ThrowIf(_disposed, this)` in the renderer comes first; the cache's own check is a second line of defence and unreachable through the renderer).

## Open questions
1. **Allocation per `create_layout`** (key = two `String` clones on every call, hit or miss). Overlay layout creates a handful of layouts per frame, so it is negligible; recommended: accept for the first port. Alternative (if a profile shows it): look up with a borrowed key (`HashMap::raw_entry` is unstable; use `hashbrown::HashMap` with `Equivalent`, a new dependency: lead decision) or intern the strings.
2. **Locale source.** Recommended (taken): the caller passes the UI culture name (the `pr_l10n` current language tag mapped to a BCP-47 name). Alternative: `GetUserDefaultLocaleName` (needs the `Win32_Globalization` feature); rejected, the C# app uses the app language, not the OS locale.
3. **Where the placeholders disappear.** Recommended: in the layering PR's follow-up commit by the 12i porter. Alternative: take `style: &TextStyle` etc. directly and wait for the layering PR; rejected, it would serialize the batch.
4. **`native_layout()` returning an owned clone vs a borrow guard.** Recommended (taken): clone (`AddRef`) because the payload sits in a `RefCell<Option<N>>`; the draw call holds it only for one `DrawTextLayout`. Alternative: `Ref<'_, IDWriteTextLayout>`; rejected, it leaks the `RefCell` into 12e.
5. **Cache capacity.** The C# default is 256 and the overlay is the only user; recommended: keep 256, expose `cache_capacity` for tests. No evidence for another number.
