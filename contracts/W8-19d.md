## Semantics (C# is the spec)
Texts: `text_fn(tr::<snake_case of the Tr name>)` (D-W8B5-802); `context` below is `self.context.context()` (a cheap clone; detached before `attach`, D-W8B5-705). Declaration pattern: D-W8B5-803.
1. **Diagnostics `declare`**: `page.group(text_fn(tr::settings_nav_diagnostics), |g| { logging = g.check(text_fn(tr::settings_logging_label), 0); open_log = first(g.buttons(false, &[text_fn(tr::settings_open_log_location)])); })`. `key()` is `"Diagnostics"`. `attach` stores the context in the slot. `load`: `context.set_checked(logging, state.logging_enabled)`. `collect`: `state.logging_enabled = context.is_checked(logging)` (nothing else of `state` is touched).
2. **Diagnostics `on_command(id, n)`**: `id != open_log || n != BN_CLICKED` -> `false`. Else `context.run_explorer(&SettingsPresenter::prepare_log_location())` and `true`. The presenter call creates the log directory (it is a file system call; the Rust test accepts both outcomes, see the test).
3. **Performance `declare`**: one group `tr::settings_nav_performance`, in this order (ids are allocated in this order, so the golden fixes them): `decoder = g.combo(text_fn(tr::settings_decoder_backend_label), Some(vec![text_fn(tr::enum_decoder_backend_wpf), text_fn(tr::enum_decoder_backend_wic_direct), text_fn(tr::enum_decoder_backend_turbo_jpeg)]), 0).control`; `turbo_note = g.note(None, true)`; `let s = g.slider(text_fn(tr::settings_ram_cache_label), MIN_IMAGE_CACHE_RAM_PERCENT, MAX_IMAGE_CACHE_RAM_PERCENT)` -> `ram_slider = s.slider`, `ram_value = s.value`; `ram_hint = g.note(None, true)`; `forward = g.edit(text_fn(tr::settings_preload_forward_label), 45).control`; `backward = g.edit(text_fn(tr::settings_preload_backward_label), 45).control`; `g.note(Some(text_fn(|| with_field_context(|c| SettingsPresenter::preload_window_hint(c)))), true)`.
4. **Performance `attach(context)`**: store the context; `turbo_available = SettingsPresenter::is_turbo_jpeg_available(context.decoder_factory().as_deref())` (`None` factory = available); `context.set_visible(turbo_note, !turbo_available)`; `update_turbo_note()`.
5. **`update_turbo_note()`**: only when `!turbo_available`: `set_text(turbo_note, &tr::settings_decoder_backend_turbo_jpeg_unavailable())`.
6. **`load(state)`**, exactly this order (the recorded calls are compared): `set_combo_index(decoder, state.decoder_backend_index)`; `last_decoder = combo_index(decoder)` (READ BACK: a control clamps an out-of-range index); `set_text(forward, &state.preload_forward_text)`; `set_text(backward, &state.preload_backward_text)`; `update_range()`; `set_slider_value(ram_slider, state.ram_cache_percent.round_ties_even() as i32)` (C# `(int)Math.Round`, ties to even, T4; `as` saturates and maps NaN to 0 where C# is unspecified); `update_ram_texts()`.
7. **`collect(state)`**: `decoder_backend_index = combo_index(decoder)`, `ram_cache_percent = f64::from(slider_value(ram_slider))`, `preload_forward_text = text(forward)`, `preload_backward_text = text(backward)`. Nothing else.
8. **`on_command(id, n)`**: (a) `id == decoder && n == CBN_SELCHANGE as u32`: `chosen = combo_index(decoder)`; if `chosen == TURBO_JPEG_INDEX && !turbo_available && last_decoder != TURBO_JPEG_INDEX` then `set_combo_index(decoder, last_decoder)` (refuse) else `last_decoder = chosen`; return `true`. (b) `(id == forward || id == backward) && n == EN_CHANGE`: `update_range()`, `update_ram_texts()`, `true`. (c) otherwise `false`. A saved TurboJpeg on a machine without it stays selectable: `last_decoder` is 2 after `load`, so choosing 2 again passes the `last_decoder != 2` test.
9. **`on_scroll(id)`**: `id == ram_slider` -> `update_ram_value()`. **`on_language_changed()`**: `update_turbo_note()`, `update_ram_texts()`. **`focus_target(field)`**: `PreloadForward` -> `Some(forward)`, `PreloadBackward` -> `Some(backward)`, any other field `None`.
10. **`update_range()`**: read both texts FIRST (`let f = context.text(forward); let b = context.text(backward);`), then `let (min, max) = context.presenter().borrow().ram_cache_range(Some(&f), Some(&b));` (the borrow ends at the semicolon), then `context.set_slider_range(ram_slider, min, max)`. **`update_ram_texts()`**: the same `(min, max)`; `hint = with_field_context(|c| presenter.borrow().ram_cache_hint_text(min, max, c))`; `set_text(ram_hint, &hint)`; `update_ram_value()`; `context.relayout()`. **`update_ram_value()`**: `v = slider_value(ram_slider)`; `text = with_field_context(|c| presenter.borrow().ram_cache_value_text(v, c))`; `set_text(ram_value, &text)`. No `RefCell` borrow of the presenter is alive across a `context` write (D-W8B5-706).
11. **Registration**: the golden pins the ids: with `id_base` 7000 Diagnostics uses 7001 (group box), 7002 (check), 7003 (button); with 4000 Performance uses 4001 (group box) .. 4013 (decoder label 4002 and combo 4003, turbo note 4004, slider label/trackbar/value 4005/4006/4007, RAM hint 4008, forward label/edit 4009/4010, backward label/edit 4011/4012, preload hint 4013).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T3/T4 (arithmetic, rounding): `round_ties_even` for the slider value (40.5 -> 40, 41.5 -> 42); no `+`/`-` on ids in the page.
- T8 (null vs empty): `ram_cache_range(Some(&text), ..)` always `Some` (C# passes strings, never null); `note(None, true)` registers no text provider (the page writes the text later); a missing decoder factory is `None` = TurboJpeg available.
- T10 (order): the `load` statement order and the declaration order are the contract (golden item order = Tab order; the call-list test).
- D-W8-4: no language text in production code (every caption is `tr::`).
- R0003: no `unwrap`/`expect`/indexing; `first().copied().unwrap_or(0)`; nothing panics if `declare` was never called (ids 0, the detached context ignores the writes).
- D-W8B5-706: do not hold `presenter().borrow()` across a `context` write or `relayout`.
