## Semantics notes
1. **Construction.** Nothing touches the disk. Defaults: durability provider = always `Fast`; retry delay = `std::thread::sleep`; live registry = a NEW
   `InProcessLiveOperationRegistry` per journal (two journals built without a registry do NOT see each other's markers); compaction files = none
   (`try_compact` = `NotSupported(0, 0)`); log = `FileLog::default_instance()` (only W3-03 writes to it); texts = English; flush-to-disk = `File::sync_all`.
2. **Append (`AppendLines`), exact order** (counting tests and the `journal-ops` golden `append_opens` pin it): (a) [C# surrogate check, vacuous: T19];
   (b) gate; (c) `get_directory_name(path)`, `Some(non-empty)` -> `create_directory` on EVERY append (no cache); (d) text = `to_line() + "\r\n"` per entry,
   concatenated; (e) provider called ONCE -> `durable`; (f) `open_append(path, durable)` with retry: attempt `n` (1..=5) failing with
   `is_sharing_or_lock_violation` and `n < 5` -> `append_retry_delay(APPEND_RETRY_STEP * n)` then retry; any other error or the 5th failure is returned
   (4 delays max); (g) torn-tail check UNDER the open append handle: `file_exists(path)` false -> no repair; else `open_read_shared(path, 16)`, length 0 ->
   no repair, else seek to `len - 1`, read one byte; not `b'\n'` -> prepend `"\r\n"` (a tail ending in `\r` IS repaired, a bare `\n` is not); an error of
   this probe is returned (the append handle is dropped, nothing written); (h) ONE `write_all`; (i) durable and a real file -> flush-to-disk seam, else
   `flush()`. An error anywhere leaves the gate released and returns `Err`.
3. **Full reader (`read_entries`)**: gate; `file_exists` false -> `Ok(())`; `open_read_shared(path, 65536)`; read all bytes ONCE; lines =
   [`decode_stream_reader_lines`]; each line -> `journal_line::try_parse(&line)`; accepted ones to `handle` in file order. Consequences that differ from the
   tail reader (golden-pinned): a UTF-8 BOM at file start is skipped; invalid UTF-8 inside a string becomes U+FFFD and the line is ACCEPTED (path with
   U+FFFD); a lone `\r` (also inside JSON whitespace) splits a line, so `{\r"Id":..}` is rejected; a UTF-16/32 BOM switches the whole file's decoding.
4. **Latest entry per Id** (C# `ComputeLatestEntries`, used by `dismiss` and `read_pending_and_failed_operations`): one pass; for each entry
   `if !journal_rules::is_stale_reconcile_after_committed(&entry, latest.get(&id)) { latest[id] = entry }`. The map preserves FIRST-insertion order
   (C# `Dictionary` without removals); re-assigning keeps the position (use `Vec<(String, JournalEntry)>` + `HashMap<String, usize>`, never iterate a
   `HashMap`). Id comparison is ORDINAL (case-sensitive) everywhere in this unit.
5. **`read_pending_and_failed_operations`**: latest values with state Prepared (map order), then those with state Failed (map order). Dismissed/Committed
   never appear.
6. **`dismiss`**: `now = clock.utc_now()` BEFORE the gate. Under the gate: latest map (note 4); for each input in order: `latest.get(&e.id) == Some(e)`
   (full value equality; `JournalDateTime` compares ticks only) -> push `JournalEntry { state: Dismissed, timestamp_utc: JournalDateTime::utc(now),
   error: None, error_code: None, ..e.clone() }` (the other fields, including `last_write_utc`'s Unspecified kind and the members, come from the CALLER's
   entry), else push `e.clone()` to skipped. Non-empty -> ONE append of all dismissed lines (one write, one open). The map is not updated during the loop,
   so a duplicated input is dismissed twice. Files named by entries are never touched; the live marker is never consulted (RV-T05).
7. **`read_committed_moves`**: gate; missing -> empty; `open_read_shared(path, 65536)`; length via `seek(SeekFrom::End(0))` (no bytes read);
   `>= FULL_SCAN_THRESHOLD_BYTES` -> reverse reader on THAT stream, under the gate; else drop the stream, RELEASE the gate, then `read_entries` keeping
   `op_type == Move && state == Committed` (all of them, no limit). Reverse reader (copy C# 324-367 exactly; `u64` offsets, `usize` buffers):
   `boundary = len; window = 256 KiB; collected = []` loop { `start = len.saturating_sub(window)`; read EXACTLY `boundary - start` bytes at `start`;
   `line_start = 0; new_boundary = boundary`; if `start > 0` { first `\n` in the buffer: none -> `window *= 2; continue` (same prefix re-read wider);
   `line_start = idx + 1; new_boundary = start + line_start` }; parse `buffer[line_start..]`: split at `\n` (the last piece may lack it), strip ONE trailing
   `\r`, `journal_rules::try_parse_tail_committed_move(piece)`; prepend the chunk's results to `collected`; if `collected.len() >= 200 || start == 0` ->
   return the LAST `min(200, len)` of `collected`; `boundary = new_boundary; window *= 2` }. A read error is returned. Each byte is read once except in the
   "no newline in the window" case.
8. **`append_if_unchanged_since(anchor, own_since, entry)`**: gate; `history` = every accepted line with `id == anchor.id` (raw: NO FA-01 skipping);
   `at` = last index with `history[i] == *anchor` (none -> the whole history is "since"); require `history.len() - (at + 1) == own_since.len()` and
   element-wise equality; then `append(entry)` -> `Ok(true)`; else `Ok(false)` with nothing created or opened (a missing journal and an empty
   `own_since` APPENDS: the whole empty history equals `[]`).
9. **`read_latest_entry(id)`**: gate; over the lines of `id` in order: `if !is_stale_reconcile_after_committed(&e, current.as_ref()) { current = Some(e) }`.
10. **`append_if(id, decide)`** (W3-03 primitive): gate held across the read, `decide` and the append; lines = raw lines of `id`; `Some(entry)` -> `append`.
11. **`try_compact`**, exact order (the boundary tests and the `journal-compact` golden pin every byte count):
    1. no compaction files -> `NotSupported(0, 0)` (nothing else is touched, not even the stale-file sweep);
    2. stale sweep: `dir = get_directory_name(path)`; `None`/empty or `!directory_exists(dir)` -> skip; else `enumerate_files(dir,
       "<file name>.*.compact.tmp")?` (collected first); for each: skip unless its name ends with `.compact.tmp` ignoring case (`text::eq_ignore_case` on
       the suffix); `get_file_stat` `None` -> skip; `now.ticks() - last_write.ticks() < STALE_COMPACTION_FILE_AGE_TICKS` -> skip (clock read per file);
       `delete(file)`, ANY delete error ignored;
    3. `!file_exists(path)` -> `BelowThreshold(0, 0)`;
    4. snapshot = all bytes via `open_read_shared(path, 65536)`; `cut` = index after the last `\n` (0 when none); `cut < 1 MiB` ->
       `BelowThreshold(snapshot.len, snapshot.len)` (FULL length incl. a partial last line);
    5. `plan = compaction::build(&snapshot[..cut])` (W3-02); `((cut - plan.kept.len()) as f64) < (cut as f64) * 0.25` -> `NotWorthIt(snapshot.len, snapshot.len)`;
    6. `temp = format!("{path}.{}{COMPACTION_FILE_SUFFIX}", io::physical::new_guid_n())`; `replacement = files.create_staged_replacement(temp)?`;
       `write(&plan.kept)?`; `flush_to_disk()?`;
    7. gate; `open_read_deny_writers(path)`: `Err` with `is_sharing_or_lock_violation` -> `Busy(snapshot.len, snapshot.len)`; other `Err` -> step 9;
    8. `current` = all bytes of that stream; `current.len() < cut` or `current[..cut] != snapshot[..cut]` -> `Changed(current.len, current.len)`;
       `delta = &current[cut..]`; `new_len = kept.len + delta.len`; non-empty delta -> `write(delta)`, and when it does not end in `\n` also
       `write(b"\r\n")` and `new_len += 2`, then `flush_to_disk()`; `replace_atomically(path)?` (the deny-writers stream is STILL open) ->
       `Compacted(current.len, new_len)`;
    9. any `io::Error` in steps 2-8 -> `JournalCompactionResult::failed(&err)` (`Failed(0, 0, Some(err.to_string()))`).
    The deny-writers stream is dropped before the gate is released, and the staged replacement after the gate (declare it before taking the gate), as C#
    `using` does; dropping a non-replaced replacement deletes the temp file (W3-02).
12. **Transaction** (`transaction.rs` doc comments give each step): marker taken lazily in `try_begin` before the Prepared append and kept until the
    outcome append attempt; released on a Prepared append error, on a superseded begin, after the outcome append (success or not) and on drop.
    `commit` appends unconditionally (also for a retry) and keeps every field of `prepared` but `state`/`timestamp_utc` (a retry's prepared carries the
    old `error`/`error_code`: the Committed line keeps them; golden `retry-commit-is-unconditional-and-keeps-the-error`). Every outcome timestamp is
    `JournalDateTime::utc(self.clock.utc_now())` with the TRANSACTION's clock, never the journal's. `fail` gets `(code, text)` from
    `errors::for_journal(failure, &|k| journal.texts().english(k))`: a coded error -> its code + English text; `Canceled` -> `CancelledByUser`;
    anything else -> no code, `failure.to_string()`.

- §7 items: 1 (Id comparisons are ORDINAL; the only ignore-case compare is the `.compact.tmp` suffix), 2 (journal text invariant: English from `texts().english`),
  3 (`u64` file lengths vs C# `long`, `i64` result fields; `saturating_sub` for the window start; a stat length above `i64::MAX` never equals `size`),
