- Semantics notes:
  1. **Sizes.** `size = max(1, size_of(&value))`: an empty value still costs 1 (golden scenario with `""` values). `size_of` is called ONCE per `set`,
     BEFORE the lock is taken, never while holding it (R0003: no callbacks under a lock; C# does the same).
  2. **set(key, value)** under the lock, in this order (matches C# exactly; the golden scenarios pin each step):
     (a) remove the existing entry for `key` if any (subtracting its size);
     (b) if `size > capacity` -> return without storing (so an oversize replacement DELETES the old value; `count` and `current_size` shrink);
     (c) while `current_size + size > capacity` and the cache is not empty: remove the least recently used entry (subtract its size);
     (d) insert the new entry as the most recently used, add `size`.
     Postcondition: `current_size <= capacity`. Use `saturating_add` for `current_size + size` (capacity may be `i64::MAX`; C# would wrap, never meant).
  3. **try_get** moves a hit to most-recently-used and returns a clone of the value; a miss changes nothing (no recency change, no counts).
  4. **Recency order.** Suggested layout: `items: HashMap<K, Slot<V>>` + `order: BTreeMap<u64, K>` keyed by a monotonically increasing stamp
     (`next_stamp += 1` on every insert and every hit; on a hit remove the old stamp from `order` and insert the new one). The LRU entry is
     `order.first_key_value()`. Keep `items` and `order` in sync in every path (`remove`, `remove_where`, `clear`, eviction).
  5. **remove(key)**: true iff present; subtracts the size. **remove_where(pred)**: evaluates `pred` on every key (while locked), removes the matches,
     returns the number removed (0 when none). **clear**: empties everything, `current_size` 0. `count()` = number of entries.
  6. **Thread safety:** one `std::sync::Mutex` around the state; recover poisoning with `unwrap_or_else(std::sync::PoisonError::into_inner)` (never `unwrap()` a lock).
     `BoundedLruCache<K, V>` must be `Send + Sync` when `K, V: Send` (assert in a test with a function `fn assert_send_sync<T: Send + Sync>() {}`).
     `remove_where`'s predicate runs under the lock and must not call back into the same cache (documented in the stub).
  7. **Keys:** the C# optional `IEqualityComparer` is replaced by `K: Eq + Hash`. Case-insensitive path caches pass keys through
     `pr_core::text::ignore_case_key` / `path_key` (trap 1) -- nothing to do in this WU except a doc sentence (already in the stub).
  8. **Capacity validation:** `capacity <= 0` -> `Err(InvalidCapacity(capacity))` (zero too). `i64::MAX` is fine.
  9. **Value cloning:** `try_get` clones `V` (callers store `Arc<...>` for big values). Do not require `V: Copy`. Do not return references into the lock.
- Traps checklist: §7 items 3 (no overflow in size sums: `saturating_add`/`saturating_sub`; never `as` casts that can wrap), 10 (eviction order is by recency, never by `HashMap` order).
