## Semantics (C# is the spec)
1. **`show(point)`**: if `is_open` -> return. `is_open.set(true)`; `chosen = match self.build_model() { Ok(items) if items.is_empty() => None, Ok(items) => match host.show(&items, point) { Ok(c) => c, Err(e) => { report_menu_failed(&*e); None } }, Err(e) => { report_menu_failed(&e); None } }`; `is_open.set(false)` (also on every error path); then `if let Some(id) = chosen { self.execute_guarded(&id) }`. `menu_host` is cloned out of its `RefCell` BEFORE the call and no borrow is held while the modal host runs (D-W8B4I-1: the window procedure is re-entered during `TrackPopupMenuEx`). A `MenuBuildError` is a menu failure (C# threw `InvalidOperationException` from `Build`, caught by the same `catch`).
2. **`build_model()`**: `ContextMenuBuildContext { settings: &*settings, has_image, can_undo, is_fit: effective_zoom.is_none(), effective_zoom, can_open_in_external_editor, can_copy_path, is_compare_visible }`; every flag is read from the actions AT CALL TIME (the settings Arc is fetched again at each open: a settings change shows at once).
3. **`execute(id)`** returns the command's result; `execute_guarded(id)` = `guarded(id, || execute(id))`. `guarded(name, f)`: `Err(e)` -> `log.error(&format!("Context menu command {name} failed"), Some(&*e))` and `actions.report_action_failed(name, &*e)`; returns `()`.
4. **The id switch** (names are `ContextMenuItemId::<X>.name()`): `Undo` -> `execute(UNDO)`; `MoveToRecycleBin` -> `execute(RECYCLE)`; `Fit` -> `fit()`; `ZoomToLevel` -> guarded(`zoom_action_name()`, `zoom_to_configured_level`); `ZoomFitWidth` / `ZoomFitWidth2` / `ZoomFitHeight` -> guarded(zoom name, `execute(FIT_WIDTH / FIT_WIDTH2 / FIT_HEIGHT)`); `Refresh` -> `execute(REFRESH)`; `OpenFolder` / `NextFolder` / `PreviousFolder` -> `execute(OPEN_FOLDER / NEXT_FOLDER / PREVIOUS_FOLDER)`; `ExternalEditor` / `CopyFileName` / `CopyFullPath` / `Settings` -> run the action method, guarded with the EMPTY name (C# `Run(action)` = `GuardedAsync(string.Empty, ..)`); `"Zoom.Custom"` -> guarded(zoom name, `custom_zoom`); `"Zoom.AlsoSetClickLevel"` -> `set_zoom_also_sets_click_level(!settings().set_zoom_also_sets_click_level)`; `"Zoom.SetCurrentAsClickLevel"` -> `zoom_rules::calculate_click_level_from_effective_zoom(effective_zoom())` `Some(p)` -> `set_click_zoom_percent(p)`, `None` nothing; an id with `try_parse_preset` `Some(p)` -> guarded(zoom name, `apply_zoom_preset(p)`); anything else (separators, `ZoomSubmenu`, unknown) -> `Ok(())`. The unguarded arms (`Undo`, `MoveToRecycleBin`, `Fit`, `Refresh`, folder items) return their `Err` to `execute_guarded`, which reports with the id as the name (C# `ExecuteGuardedAsync(id)`).
5. **`try_parse_preset(id)`**: `id.strip_prefix("Zoom.Preset.")` (ordinal, case-sensitive), the rest non-empty and `bytes().all(is_ascii_digit)` (`NumberStyles.None`: no sign, no space, no thousands separator), `parse::<i32>()` (overflow gives `None`, as `int.TryParse`). `"Zoom.Preset."` alone, `"Zoom.Preset.+5"`, `"Zoom.Preset. 5"`, `"zoom.preset.5"` are `None`.
6. **`ContextMenuMessageHandler::try_handle`** as the C# table: only `WM_CONTEXTMENU`; `(x, y) = (signed_low_word(lparam), signed_high_word(lparam))`; `(-1, -1)` -> `client_center_screen_pixel()`; else `client = window.screen_to_client_dip(PointD { x, y })` (the host-contracts twin type), `size = window.client_size_dip()`; `client.x < 0 || client.y < 0 || client.x >= size.width || client.y >= size.height` -> `None`. `scale = if window.dpi_scale() > 0.0 { dpi_scale } else { 1.0 }`; `controller.show(PointD { x: screen.x / scale, y: screen.y / scale })`; `Some(0)`. The (-1, -1) test is on the signed words, so a keyboard invocation on a monitor left/above the primary at exactly (-1, -1) is indistinguishable from the keyboard case: C# parity.
7. **`mapping`**: `display_text`: `text = item.text.replace('&', "&&")`; no shortcut (`None` or empty) -> `text`; else `text + "\t" + shortcut.replace('&', "&&")`. `item_flags`: `MF_STRING` (0) `| MF_GRAYED` when `!is_enabled` `| MF_CHECKED` when `is_checked` (`MF_DISABLED` is NOT used). `id_for_command(ids, command)`: `1 <= command <= ids.len()` -> `Some(&ids[command - 1])` else `None`.
8. **`owner_draw_style`**: every function as in the C# summary above. `scale(px96, dpi)` = `max(1, (f64::from(px96) * scale).round_ties_even() as i32)` with `scale = if dpi == 0 { 1.0 } else { f64::from(dpi) / 96.0 }`. `item_height(t, dpi) = max(t + scale(10, dpi), scale(28, dpi))`. `separator_height = scale(9)`. `item_width(t, s, dpi) = scale(32) + t + (if s > 0 { scale(32) + s } else { 0 }) + scale(32)`. `left_gutter = scale(32)`, `right_pad = scale(16)`. `color_ref(key)`: `palette::get(key)` `None` -> `0`; `Some(c)`: `channel(v) = (f64::from(v * 255.0_f32)).round_ties_even().clamp(0.0, 255.0) as u32` (the `v * 255f` is an `f32` product, as in C#); `r | g << 8 | b << 16`. Constants: `background() = color_ref("Dark.Panel")`, `separator() = color_ref("Dark.Border")`, `item_background(state) = if state & ODS_SELECTED != 0 { color_ref("Dark.ButtonPressed") } else { background() }`, `item_text(state) = if state & (ODS_GRAYED | ODS_DISABLED) != 0 { color_ref("Dark.TextFaint") } else { color_ref("Dark.Text") }`.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (re-entrancy): `show` is modal (14f's `TrackPopupMenuEx` pumps messages of this very window); no `RefCell` borrow and no `Cell` guard is held across `host.show`; `is_open` is a `Cell` precisely so the nested `WM_CONTEXTMENU` can read it. A test host calls `controller.show` again from inside `show` (second call returns at once).
- T2 (commands after the menu): the command of the chosen id runs after `is_open` is cleared and after the menu closed (test `TheCommand_RunsAfterTheMenuHasClosed`); a command that opens a modal dialog or closes the window therefore never runs inside the menu loop.
- T3 (integer words): `signed_low_word` of an `lparam` with high bits (a 64-bit negative) must mask first; screen coordinates are signed (secondary monitor left of the primary).
- T4 (DPI): the point given to the controller is in DIP of the OWNER window's DPI (divided by `dpi_scale`), the host multiplies by the same DPI again; never mix in the monitor DPI.
- T5 (text): action names for the failure report come from `zoom_action_name()` (localized at call time); no English literal in production code (D-W8-4). The log text `"Context menu command {name} failed"` is a diagnostic literal, as in C#.
- T6 (float): `Math.Round` is ties-to-even (`round_ties_even`); `v * 255f` is `f32`; `Math.Clamp` order of C# (`Clamp(int, 0, 255)`) is applied after the conversion to `int`; an `f32` NaN channel gives 0.
- T7 (no async): `ShowAsync`'s `Task` is `show` returning `()`; the guarded commands are synchronous (D-W8B4I-8).

## Error mapping
| C# | Rust |
|---|---|
| exception from `Build`/`Show` | `MenuBuildError` / the host's `Err` -> `report_menu_failed` |
| exception from a command (not cancel, not OOM) | `Err` -> `log.error` + `report_action_failed(name, e)` |
| `OperationCanceledException` | no twin |
| `ArgumentNullException` | unrepresentable |
| `KeyNotFoundException` of `DarkPalette.Get` | `color_ref` returns 0 (constant keys) |
