- Semantics notes (every item is read from `CompareViewModel.cs`):
  1. **Setters are `SetProperty`.** An equal value changes nothing and notifies nothing. Strings and paths compare ordinally and case-SENSITIVELY (`EqualityComparer<string>.Default`);
     the images compare by reference (`Arc::ptr_eq`; two `None` are equal). Only the *selection* flags compare ignoring case.
  2. **Derived flags.** `IsLeftSelected = !LeftPath.is_empty() && eq_ignore_case(SelectedPath, LeftPath)`; a `None` or empty `LeftPath` is never selected; `None == non-empty` is false.
     `LeftPath` set notifies `LeftPath` + `IsLeftSelected` (and only when the text changed); `SelectedPath` notifies `SelectedPath`, `IsLeftSelected`, `IsRightSelected`;
     `LeftSizeText` / `RightSizeText` also notify `SizeText`; `RightPath` the twin of `LeftPath`.
  3. **`Clear`.** Resets all ten fields, `_hashText` to `CompareHashText(null)` of the CURRENT language, and raises 13 notifications unconditionally (the list at lines 147-159),
     so `clear` returns `CompareChanges::all()` even from the default state.
  4. **`LoadAsync` order.** Token check first (false: nothing touched). Then `LeftPath`, `RightPath`, `SelectedPath = initialSelectedPath` (else `Left`), `IsVisible = true`, both images `null`.
     Both preview loaders are STARTED before either is awaited (`Task.WhenAll`), hence one `CompareWork::LoadImages` for both paths and the contract line "run concurrently".
  5. **Token checks (INV-1) exist at exactly four places:** at entry, after the preview await, after the `Task.Run` stat (only when no `getFileSize` was injected), after the hash await.
     There is NO check after an injected `getFileSize` and none before the final status. A superseded load returns `false` and applies nothing of the later stages;
     what it already applied (paths, `IsVisible`, images) stays (the next load overwrites it).
  6. **Sizes.** Disabled: both suffixes empty. Enabled with `getFileSize`: both values read on the UI thread. Enabled without: both stat'ed in ONE worker task. A known size is
     `CompareSizeSuffix(bytes)`, unknown is empty. `LeftSizeText` / `RightSizeText` are set even when empty. The suffix fragments also go into the status line (not the property text round trip).
  7. **Hash.** `HashText` starts as `CompareHashText(null)`. With `compareHashEnabled && getHashAsync != null`: `IsRawPath(left) != IsRawPath(right)` gives `CompareHashText(false)` and NO hashing
     (two whole-file reads saved); otherwise both hashes run concurrently. A hash that fails with anything but cancellation is logged and counts as null: if either is null the text is
     `CompareHashUnknown()`, else `CompareHashText(eq_ignore_case(h0, h1))`. `compareHashEnabled` with no hash function, or a disabled flag, keeps `CompareHashText(null)` and never calls the function.
  8. **Cancellation.** A cancelled hash propagates (not swallowed) and wins over the token check: `WhenAll` throws before `isTokenCurrent` is read. A failing preview loader propagates too
     (the caller clears the comparison; the left error is rethrown first when both fail).
  9. **Status.** `StatusFormatter.Compare(currentIndex, totalFiles, GetFileName(left), leftSize, GetFileName(right), rightSize, HashText)`; the formatter adds 1 to the index.
  10. **Default state** (test): hidden, all paths/images/selection `None`, size and status texts empty, hash text `CompareHashText(null)`. The C# tests run under the Vietnamese catalog (they pin the
      `vi` texts of `compare.hash.off`, `compare.sizeSuffix` ("byte") and `status.compare`); the Rust twins build the `FormatContext` over `en` and assert the English values of `assets/languages/en.json`
      (`" | hash off"`, `" ({bytes} B)"`, `"{position}/{count} | Compare | .. | click to select"`), or over `vi` when they want the C# text; they must always compare with the `status::*` function, not a literal, where the test is not about the text.

- Traps checklist:
  - **T1 (INV-1).** The generation token is checked at the four places of note 5, not more. An extra check after the injected-size path would change which loads win.
  - **T2 Concurrency.** `LoadImages` and `ComputeHashes` carry BOTH paths so the caller starts both before waiting. Do not turn them into two sequential steps.
  - **T3 Cancellation vs failure.** `HashOutcome::Cancelled` ends the load as `Cancelled` before the token is read; `Failed` keeps previews and sizes. A cancelled preview is `CompareError::Cancelled`.
  - **T4 Case rules.** Selection and hash equality ignore case (`pr_core::text::eq_ignore_case`, ordinal); `SetProperty` on paths does not. Never lower-case with locale rules.
  - **T5 `SetProperty` on images.** Two different `Arc`s holding equal pixels are different values; do not compare pixels.
  - **T6 Notification set.** `clear` returns all 13 even at the defaults; `set_left_path` with an equal path returns the empty set.
  - **T7 UI thread.** `try_get_file_size` and `hash_outcome` BLOCK (file stat, whole-file hash): the caller runs them on workers. The view model itself does no I/O (the stat is the caller's work), has no clock and no thread.
  - **T8 Hash cost.** Never ask for hashes when exactly one of the two paths is RAW (note 7). The hasher is `misc::file_hash::FileHasher` (SHA-256 upper-case hex, shared LRU), so the same file is not re-read.
  - **T9 Log text.** `"Compare hash failed path={path}"` and `"Compare file size unavailable path={path}"` are diagnostics (invariant, not catalog text, D-W8-4 does not apply).
  - **T10 Swallowed errors.** C# `TryGetFileSize` swallows four exception types and lets a bug (`InvalidOperationException`) escape. `FileSystem::try_get_file_stat` returns `io::Result`, so EVERY `Err` is
      swallowed in Rust; the "does not hide a bug" assertion of the C# test has no twin (record it in the test file as a comment, not a test).

## Open questions (each with a recommended default; the stub already follows the default)
- **O1 Staged load instead of `async`.** D-W8-2 forbids futures, so `LoadAsync` is `begin_load` + `resume_load` with a `CompareLoad` continuation (the pattern of `viewport::fit::FitContinuation`).
  Alternative: one blocking `load(...)` that runs the workers itself with `std::thread::scope`; rejected because the view model would own threads and the INV-1 checks between workers would need the UI thread.
  W8-07j drives it. Recommended: as stubbed.
- **O2 Preview type.** `Arc<DecodedImage>` (the type of `IPresentationSink::set_current_image`). C# is `object?` because the WPF view model could not name the bitmap type. If W8-07j needs a platform wrapper,
  it wraps the `Arc` in its own cache; this module stays free of it. Recommended: as stubbed.
- **O3 `compare.sizePair` has no formatter yet.** `status.rs` (W8-02b) lacks `compare_size_pair`. Recommended (used): this module formats it with `Localizer::format_with`. If 02b adds the function before
  this unit is ported, call it instead (same key and arguments). No B1 change is required.
- **O4 Swallowing every `io::Error` in `try_get_file_size`** (T10). Recommended: accept; the C# list of four types is exactly the set `FileInfo` raises for expected failures.
- **O5 Default hash text needs a context.** `new(ctx)` replaces C#'s parameterless constructor (the text depends on the current language). The shell passes its `FormatContext`; a `Default` impl is deliberately absent.
