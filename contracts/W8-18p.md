## Semantics (C# is the spec)
1. **Texts are the ambient language** (`pr_l10n::tr::*`, the C# `Tr`, D-W8-4) read AT CALL TIME for `title()`, `label_text`, `value`-independent strings; the item LISTS are built ONCE in `new` (the C# constructor / list initialiser), so a language change after construction does not change an open dialog's captions (D-W8B5-508). Never embed English or Vietnamese literals.
2. **Zoom items** exactly as the C# list above, in this order (the order is the Tab order: box, Cancel, Apply). The error line has `WS_CHILD | SS_NOPREFIX` only: it becomes visible when `on_ok` calls `show_item(ERROR_ID, true)`.
3. **Zoom `on_ok`**: reads the box text BEFORE borrowing the presenter (`dialog.get_item_text(EDIT_ID)`), calls `presenter.borrow_mut().try_accept(&Localizer::current(), Some(&text))`, releases the borrow, then acts (D-W8B4I-1). A refusal never closes the dialog and always re-selects the box text and focuses the box. `value` is `Some(presenter.value())` only on accept. `error_message` keeps the LAST refusal even after a later accept.
4. **Zoom layout** (worked example below). `preferred_client_size` is the size the window gets at creation AND after an error appears (`resize_client`); `layout_controls` ignores `client_height`. `error_visible` adds `dy(4) + error height` between the box and the buttons.
5. **Diagnostics rows**: `label_text(r)` = (0) `diagnostics.label.cacheHits`, (1) `cacheMisses`, (2) `cacheHitRate`, (3) `sourceBytesRead`, (4) `sourceFileReads`, (5) `decodeTime`, (6) `keyToPresentLatency`, (7) `explorerOrder`, (8) `explorerSortGroup`, (9) `sourceOpens`, (10) `metadataQueries`, (11) `sessionWrites`, (12) `decoderFallbacks`, (13) `presentLatencyHistogram`, (14) `crossThreadPresents` (the `tr::diagnostics_label_*` functions). `value_text` is the matching `DiagnosticsDisplay` field in the order: `cache_hits, cache_misses, hit_rate, source_bytes, source_reads, decode_time, present_latency, explorer_order, explorer_metadata, source_opens, stat_count, session_writes, decoder_fallbacks, present_histogram, cross_thread_presents` (note: row 8 is `explorer_metadata` although its label is "explorer sort group", row 10 is `stat_count` for "metadata queries"; the C# pairing is the spec). `build_copy_text` ends every line with `"\r\n"`, no escaping of tabs or line breaks in values.
6. **Diagnostics copy**: `on_command(COPY_ID, BN_CLICKED)` is handled whether or not a copy function was given; with one, `copy(&build_copy_text(&display))` returning `true` adds one to `copy_count`; the dialog stays open. The close routes (Close button, Esc, Enter anywhere, the X button, Alt+F4) all end with `ID_CANCEL` because `DefaultButtonId` is `CLOSE_ID`.
7. **Diagnostics layout** (worked example below): values wrap, so each row is as tall as the taller of its label (at `dx(125)`) and its value (at the remaining width).
8. **Arithmetic** is `i32` wrapping with truncating division like the C# unchecked context (D-W8B5-312); use `wrapping_add/mul/sub` in the layout functions.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- 3 (arithmetic): wrapping layout maths, `/` truncates; the dialog-unit helpers are the base class's (`dx`, `dy`), do not re-derive them.
- 8 (None vs empty): `value()` is `None` until an accept; `error_message()` stays `Some` after a later accept; the error line text is `""` until the first refusal; `label_text(row)` out of range is `None`, not `""`.
- 9 (exception to Result): the C# `ArgumentOutOfRangeException` becomes `None`; nothing else throws.
- T-re-entrancy (D-W8B4I-1): `on_ok` calls `set_item_text`, `run_layout`, `set_focus` which re-enter the dialog procedure (`WM_SIZE` -> `layout_controls`): the presenter `RefCell` and the `Cell`/`RefCell` state are never borrowed across those calls.
- T-panic (R0003): no `unwrap`/`expect` outside tests; a hook must not panic; `EM_SETSEL` is one `unsafe` `send_message` with a SAFETY comment (message with two integers, no pointer).
- T-language: lists frozen at construction, titles read at call time; a test that sets a language holds `serial()`.
- T-style: the error line is created WITHOUT `WS_VISIBLE`; the Apply button is `BS_DEFPUSHBUTTON` and `ID_OK`; Close of Diagnostics is `BS_DEFPUSHBUTTON` and `ID_CANCEL`.
