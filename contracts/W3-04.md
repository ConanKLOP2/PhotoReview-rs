Rust methods are infallible. `string` paths stay `&str`/`String` (D1) and cross the trait boundary as `Path::new(&s)`. `long Size` stays `i64`;
`DateTime.MinValue` is `DateTimeUtc::MIN`; journal timestamps are `JournalDateTime::utc(..)`. Private helper signatures in the stub are suggestions.

## Semantics notes
Every number in brackets is a C# line of `FileActionService.cs`. "error(X)" = the action fails with an `io::Error` whose `to_string()` is X; "coded(C)" =
`self.coded_error(C)` (message = journal's localized text of C). All texts in the examples are the English catalog.

**Gate (INV-4) [36-49].** `AtomicI32` 0/1, all `SeqCst`. `try_begin` = `compare_exchange(0, 1)`; `end` = `store(0)` (unconditional); `is_busy` = `load != 0`.
Both execute methods take the gate FIRST and, when refused, return at once (rejected result; nothing read, nothing journaled, `end` NOT called). After the gate
is taken, every path releases it exactly once (an RAII guard whose `Drop` calls `end`, so a panic in a fake also releases it), AFTER the transaction is
dropped (C# `finally { tx?.Dispose(); End(); }` [278-282, 727-731]: drop the `JournalTransaction` first, then the guard).

### Single action: `execute` (C# `ExecuteAsync` [482-732])
- **S1 refused gate** [486-497]: `FileActionResult { rejected: true, ..new(false, op, source, None, 0, DateTimeUtc::MIN, Some(busy)) }`. No id is generated.
- **S2 state** [499-513]: `operation_id` = `crate::io::physical::new_guid_n()` (W2-14's `Guid.NewGuid().ToString("N")`: 32 lowercase hex; no new crate); `destination_path = None`, `source_size = 0`, `source_last_write = MIN`, `permanent = false`,
  a fresh `CopyCreationProof`, `copied_stat = None`, `created_folders = []`, `tx = None`.
- **S3 Move/Copy pre-checks, in this order, before anything is created or journaled** [517-563]:
  1. `destination` is `None` or `trim().is_empty()` => error(`core_file_action_no_destination`). (C# `IsNullOrWhiteSpace`; Rust `char::is_whitespace`
     agrees with `char.IsWhiteSpace` for every code point.)
  2. `destination_policy::validate(Some(dest)) != Ok` => coded(`DESTINATION_OUTSIDE_SOURCE`) [525] (drive-relative `D:x`, rooted-without-drive `\x`,
     `..` segments, invalid chars all land here, r7).
  3. `destination_folder = get_full_path(if is_path_rooted(dest) { dest } else { combine(get_directory_name(source).unwrap_or_default(), dest) })`;
     `source_folder = get_full_path(get_directory_name(source).unwrap_or_default())` — in THIS order (a source without a folder fails on the second call:
     golden `single-move-source-without-folder`, trap T7).
  4. `is_same_path(destination_folder, source_folder)` => error(`core_file_action_same_folder`) (`.`, `C:\PHOTOS`, `C:\photos\` all hit it).
  5. relative destination AND `!ignore_case_key(destination_folder).starts_with(ignore_case_key(source_folder.trim_end_matches('\\') + "\\"))` => coded
     (`DESTINATION_OUTSIDE_SOURCE`) [539-541]. Note `TrimEnd('\\')` trims ALL trailing backslashes (not `trim_ending_directory_separator`).
  6. `destination_path = combine(destination_folder, get_file_name(source))`.
  7. relative destination AND `validate_no_escape_via_reparse_point(source_folder, destination_path, fs) != Ok(Ok)` => coded(`DESTINATION_OUTSIDE_SOURCE`)
     [549-551] (SEC-01; an `Err(ArgumentError)` cannot happen here — both paths are full — but map it to the same coded error, fail closed).
     Absolute destinations skip 5 and 7 (an explicit user choice may leave the folder).
  8. `file_exists(destination_path)` => error(`core_file_action_destination_exists(destination_path)`) [553].
  9. `get_file_stat(source)` `None` => error(`core_file_action_source_missing(source)`) with kind `NotFound` [556]. `source_size = i64::try_from(len)`
     (saturate at `i64::MAX`, trap T3), `source_last_write = stat.last_write_utc`.
  10. ONLY NOW `created_folders = create_destination_folder(destination_folder)?` [563] (a missing source never leaves an empty folder:
      `ExecuteAsync_MissingSource_DoesNotCreateDestinationFolder`).
- **S4 Move/Copy journal + mutation** [565-603]: `prepared = JournalEntry { id, op_type, state: Prepared, source, destination: Some(destination_path),
  size: source_size, last_write_utc: utc(source_last_write), timestamp_utc: utc(clock.utc_now()), error: None, error_code: None, permanent: None, undo: None,
  group_id: None, group_members: None }`; `tx = JournalTransaction::new(&journal, &*clock, prepared, None)`; `tx.begin()?` (an append failure is the action's
  failure; the transaction released its marker). Then:
  - the hand-off check: `cancel.is_canceled()` => error(`TASK_CANCELED_MESSAGE`) carrying `Canceled` (C# `Task.Run(.., ct)` refuses to start). It applies to
    Copy and to a Move WITHOUT override only: the override is awaited directly with no token [588-591], so a pre-cancelled Move with an override still
    moves (golden `single-move-pre-cancelled-with-override-still-moves`).
  - Copy [576-585]: `fs.try_copy_new_with_proof(source, destination_path, &proof)?`; `Ok(false)` => error(`core_file_action_destination_exists(destination_path)`);
    then `copied_stat = fs.get_file_stat(destination_path)` (ONE stat, reused for the verify and the cleanup identity).
  - Move [588-595]: the override (`(source, destination_path)`) or `fs.move_file`.
  - verify [599-602]: Move => `tx.verify_moved(fs, source, destination_path, VERIFY_SIZE_CHANGED)?`; Copy => `tx.verify_destination_stat(copied_stat, VERIFY_SIZE_CHANGED)?`.
  - `(_, journal_error) = tx.commit()`; result `new(true, op, source, Some(destination_path), source_size, source_last_write, None)` with
    `journal_persisted = journal_error.is_none()`, `journal_error` [604-619].
- **S5 Recycle** [621-683]: `get_file_stat(source)` `None` => error(source missing, `NotFound`); sizes as in S3.9; `permanent = !recycle_bin.can_recycle(source)`;
  `permanent && !allow_permanent_delete` => error(`core_recycle_unsupported_drive(get_file_name(source))`); `!permanent && !fits_in_recycle_bin(source,
  stat.length)` => error(`core_recycle_bin_cannot_hold(name)`) (capacity is NOT asked for a permanent delete: `Recycle_NoRecycleBin_DoesNotAskCapacity`;
  `allow_permanent_delete` does not bypass the capacity rule on a drive WITH a bin). Prepared as S4 with `op_type: Recycle`, `destination: None`,
  `permanent: if permanent { Some(true) } else { None }`. `tx.begin()?`; hand-off check (always: no override here); `delete_permanently(source)?` or
  `send_to_recycle_bin(source)?`; `file_exists(source)` => coded(`SOURCE_STILL_EXISTS_AFTER_RECOVERY`) (B-06); `tx.mark_mutation_completed()`; commit; result
  with `destination_path: None`, `permanently_deleted: permanent`.
- **S6 unsupported operation** [684-687]: unreachable (closed enum); keep no code for it (the text exists in `FileActionTexts` for catalog parity).
- **S7 failure** [689-726], for ANY error `err` of S3-S5 (C# `catch (Exception ex)`), in this order:
  1. `tx` absent or `!tx.is_prepared()` => `remove_created_empty_folders(created_folders)` [693].
  2. `proof.destination_created() && destination_path.is_some() && copied_stat.is_some()` => `remove_partial_copy(dest, source_size, &copied_stat)` [697-698]
     (W3-08 deletes only a strictly shorter file that is still the observed one).
  3. `mutation_completed = tx.map_or(false, |t| t.mutation_completed())`.
  4. `is_canceled(&err) && tx.is_prepared() && !mutation_completed && is_untouched(source, source_size, source_last_write, destination_path)` =>
     `(_, journal_error) = tx.dismiss_rolled_back()` (RV-C02); otherwise `tx.fail(&err)` when `tx` exists (it writes nothing when not prepared).
     `is_untouched` reads the REQUEST's `source` (same as `source` above) with an EXACT stamp compare [744-756].
  5. `source_removed = !mutation_completed && op == Move && tx.is_prepared() && is_source_gone(request.source)` (F3, INV-3) [711-712].
  6. result: `succeeded: mutation_completed`, `operation`, `source: request.source`, `destination_path`, `size: source_size`, `last_write_utc: source_last_write`,
     `error: if mutation_completed { None } else { Some(message(err)) }`, `journal_persisted: journal_error.is_none()`, `journal_error`,
     `permanently_deleted: permanent && mutation_completed`, `source_removed`, `rejected: false`.
     `message(err)` = `err.to_string()`, except a cancellation: `TASK_CANCELED_MESSAGE` at the hand-off check, `OPERATION_CANCELED_MESSAGE` for a `Canceled`
     coming from a fake/override (C# `OperationCanceledException()`); carry the text next to the error from the moment it is created, do not guess later
     (trap T5). The stub's private `ActionFailure { error, message }` does exactly that: the `error` half of a cancellation must stay a bare
     `io::Error::other(Canceled)`, because `errors::for_journal` recognizes only `Canceled` directly inside the `io::Error` (a wrapper carrying the .NET
     text would be journaled with no code instead of `CancelledByUser`).
- **S8** journal Error text: `tx.fail` stores `errors::for_journal(err)`: coded errors => code + ENGLISH text; a cancellation => `CancelledByUser` + English;
  anything else => no code, `err.to_string()`. The result's `error` and the journal's `Error` therefore differ for coded errors in a non-English UI
  (`FileAction_SizeChangedAfterMove_JournalsCode_ResultShowsUiLanguage`).

### Capture group: `execute_group` (C# `ExecuteGroupAsync` [61-283])
- **G1** [67-71]: `group_id` = `new_guid_n()` FIRST, then the gate; refused => `CaptureGroupActionResult::new(false, true, op, group_id, None, vec![],
  Some(busy))`.
- **G2 validation** [90-113]: fewer than 2 paths => error(`group_needs_two_paths`) (unreachable: `CaptureGroup` always has >= 2; keep the check). Move/Copy:
  no destination => error(no destination); `validate` => coded(outside); `first_source_folder = get_full_path(get_directory_name(paths[0]).unwrap_or_default())`;
  `destination_folder = get_full_path(rooted ? dest : combine(first_source_folder, dest))` (NOTE: combined with the FULL first folder, unlike S3.3);
  same folder => error(same folder); relative and not under `first_source_folder + "\"` => coded(outside).
- **G3 preflight per path, in `group.paths()` order** [115-151]: `cancel.check()` at the top of EACH iteration => error(`OPERATION_CANCELED_MESSAGE`, `Canceled`).
  `get_file_stat(source)` `None` => push to `missing` and `continue` (stale partner). Move/Copy: relative destination and this member's full folder !=
  the first member's full folder (OrdinalIgnoreCase) => coded(outside); `destination = combine(destination_folder, get_file_name(source))`;
  `file_exists(destination)` => error(destination exists(destination)); relative and reparse escape => coded(outside) — NOTE the order differs from the
  single path (exists BEFORE the reparse check). Recycle: `permanent = !can_recycle(source)`; `permanent && !allow` => error(unsupported drive(name)).

- **G4** [153-158]: no member is one of `group.image_paths()` (OrdinalIgnoreCase) => error(source missing(gone)) kind `NotFound`, where `gone` = the first
  `missing` path that is an image path, else `paths[0]`.
- **G5 capacity** (Recycle) [160-166]: `errors::first_overflow(recycle_bin, &members)` `Some(m)` => error(`core_recycle_bin_cannot_hold(get_file_name(m.source))`).
  Then `manifest = members` [167] (from here on the failure path inspects the manifest).
- **G6** [169-177]: Move/Copy: `created_folders = create_destination_folder(destination_folder)?`. Prepared = the FIRST manifest member's source, destination,
  size, last write; `permanent: Some(true)` only when EVERY member is permanent (and there is one), else `None`; `group_id: Some(group_id)`;
  `group_members: Some(manifest.clone())`; `id` = a second `new_guid_n()` (different from `group_id`). `tx.begin()?`.
- **G7 members, in manifest order** [179-221]: `cancel.check()` (OPERATION_CANCELED); `in_flight = Some(member)`; a fresh proof; then the hand-off check
  (TASK_CANCELED — in practice unreachable right after the loop check, keep it for the order) before every mutation EXCEPT a Move through the override
  (C# awaits `_moveOverride(..)` directly, no token [203-204], same rule as the single path);
  Copy: `try_copy_new_with_proof(source, destination, &proof)?`, `Ok(false)` => error(destination exists(destination)); `copied = get_file_stat(destination)`;
  `Some` => `created_copies.insert(ignore_case_key(destination), copied)`; `verify_group_destination(member, copied)?`.
  Move: override or `move_file`, then `verify_group_move(member)?` (source still there => coded(`MOVE_SOURCE_NOT_REMOVED`) BEFORE the size check).
  Recycle: `delete_permanently` (member.permanent) or `send_to_recycle_bin`, then `file_exists(source)` => coded(`SOURCE_STILL_EXISTS_AFTER_RECOVERY`).
  `done.push(member)`; `in_flight = None`.
  After the loop: `tx.mark_mutation_completed()`; `(committed, journal_error) = tx.commit()`; members = every manifest member as
  `CaptureGroupMemberResult::new(m, true, false)`; result `new(true, false, op, group_id, Some(Box::new(committed)), members, None)` with
  `journal_persisted`, `journal_error`, `permanently_deleted: op == Recycle && any member permanent`, `skipped_missing: (!missing.is_empty()).then_some(missing)`.
- **G8 failure** [231-265] for ANY error `err` of G2-G7:
  1. `tx` absent or not prepared => `remove_created_empty_folders(created_folders)`.
  2. `stuck = 0`; prepared AND Move/Copy => `stuck = remove_created_copies(&done, in_flight, proof.destination_created(), &created_copies)` (Copy) or
     `restore_moved_members(&done, in_flight)` (Move). Recycle is never compensated.
  3. `states = manifest.map(|m| inspect_group_member(op, m, &message(err)))` (empty when the failure came before G5 ended).
  4. user message: `stuck > 0 => core_group_action_rollback_failed(message(err), stuck)`, else `message(err)`. The journal still gets the ORIGINAL `err`
     (`ExecuteGroupAsync_MoveRollbackIncomplete_JournalsOriginalCodedFailureNotLocalizedRollbackText`).
  5. `rolled_back = stuck == 0 && !states.is_empty() && prepared && op is Move|Copy && every state is { state_known, !completed, !conflict, source_exists,
     !destination_exists }` => `tx.dismiss_rolled_back()`, else `tx.fail(&err)` (when `tx` exists).
  6. result `new(false, false, op, group_id, entry.map(Box::new), states, Some(user message))`, `journal_persisted: journal_error.is_none()`, `journal_error`,
     `permanently_deleted: op == Recycle && any state completed && member.permanent`, `skipped_missing` as in G7.
- **G9 the "unexpected exception" arm** [266-276]: see open question 2. Under option A it returns every manifest member as `{ completed: false, conflict:
  true, error: Some(message(err)), state_known: false }`, `entry: None`, message `rollback_failed(message(err), manifest.len())`, `permanently_deleted: false`,
  `journal_persisted: true`, and writes NO outcome line (Prepared stays for startup reconcile).
- **Compensation, Copy** [332-382]: for `done` in REVERSE: stat (P1 seam; `Err` => stuck); `None` => skip; not in `created_copies`, or `length != size`, or

- **Compensation, Move** [394-433]: candidates = in-flight (`was_done = false`) then `done` reversed (`true`). Per candidate: stat source and destination;

  `types::matches_moved_destination(&dest, size, member.last_write_utc.value)` (tolerant ±2 s, RV-C01) => stuck (ALSO for the in-flight one); else
  `fs.move_file(destination, source)` (NEVER the override), then stat source: `None` or length != size, or `file_exists(destination)` => stuck. Any
  `Err` => stuck.
- **Inspection** [447-477]: Recycle: source stat `s`: `completed = s.is_none()`, `conflict = s.is_some_and(|s| len != size || s.last_write_utc !=

### Cancellation
| C# point | Rust | message |
|---|---|---|
| `ThrowIfCancellationRequested()` at the top of each preflight / member iteration (group only) | `cancel.check()` | `OPERATION_CANCELED_MESSAGE` |
| `await Task.Run(mutation, ct)` (single Copy, single Move without override, single Recycle, every group mutation) | `cancel.is_canceled()` right before the call | `TASK_CANCELED_MESSAGE` |
| the move override, the compensation, the journal appends, `CreateDestinationFolder` | no check | — |
| an `OperationCanceledException` returned by a fake/override | `io::Error::other(Canceled)` passes through | `OPERATION_CANCELED_MESSAGE` |
A cancellation is journaled as `CancelledByUser` (by `tx.fail`), or Dismissed when untouched (single) / fully rolled back (group).

## Traps checklist (MULTI-AGENT-PLAN §7 + unit specific)
- T1 (INV-4) gate: take it first, release it once on every path after taking it (RAII), never release a gate you did not take (the busy path returns
  BEFORE the guard exists). `TryBegin_And_End_ManageBusyGate`, `SecondCallWhileFirstRuns_*_GateIsReleasedOnce`.
- T2 (INV-3/F3) `source_removed` is computed from the disk AFTER the failure, only for a prepared Move; never assumed.
- T3 (§7.3) `FileStat.length` is `u64`, journal `size` is `i64`: convert with `i64::try_from` (saturating), compare `i64::try_from(len) == Ok(size)`, never
  `as i64`. `fits_in_recycle_bin` takes the stat's `u64` directly (single) — no round trip through `i64`.
- T4 (§7.1) every path comparison is OrdinalIgnoreCase via `crate::text` (`is_same_path`, "same first folder", image-path set, `created_copies` key, the
  `StartsWith` containment check). Never `to_lowercase`.
- T5 (§7.9) one C# `catch (Exception)` per method, but the RESULT message depends on what was thrown: keep the C# `ex.Message` per source (coded =>
  localized text; cancellation => the two .NET texts; `io::Error` => `to_string()`). Rust `Canceled`'s own Display ("operation canceled") must never reach
  a result.
- T6 (§7.8) `None` vs `Some("")`: `destination: Some("")` is "no destination" (whitespace check), `skipped_missing` is `None` when nothing is missing (never
  `Some(vec![])`), `permanent` on the Prepared line is `None` unless ALL members are permanent.
- T7 (§7.7) `get_full_path` failures (a source without a folder, a too-long path) are failures of the action, not panics; the message is the .NET text the
  golden pins (`path_error_to_io`; expected `"The path is empty. (Parameter 'path')"` for `GetFullPath("")`, NOT `PathError`'s own Display); if the golden
  shows a text `PathError` cannot reproduce, record a `Different` row instead of guessing. The group path computes the first source folder BEFORE the
  destination folder (G2), the single path AFTER it (S3.3): both orders are observable only through which error wins, keep each.
- T8 (data safety, R01/D-06) never delete a destination without the proof AND the observed identity; never delete the in-flight MOVE destination; the Move
  compensation uses `move_file` (no overwrite) and never the override; nothing in this unit calls `delete` on a source or touches the bin outside
  `send_to_recycle_bin`/`delete_permanently` of the member being processed. Tests: `HookRecycleBin`/`FakeRecycleBin` only (AGENTS.md: never the real bin).
- T9 cleanup can never mask the original failure: `remove_created_empty_folders` and `remove_partial_copy` swallow everything; the folder list is
  deepest-first and stops at the first folder that stays.
- T10 (§7.10) member order is the manifest order everywhere (journal `GroupMembers`, result `members`); `created_copies` is a lookup only (a `HashMap` is
  fine because nothing iterates it into output).
- T11 the Prepared line's TimestampUtc is read from the SERVICE clock (`self.clock`), not the journal's; `JournalTransaction` gets `&*self.clock` too.
- T12 a cancellation at the single hand-off happens AFTER Prepared: the outcome line is Dismissed (untouched) — never "nothing journaled".
