## Semantics and wrapper rules (C# is the spec; D-W8B3-4, written for every function)
1. **Handle conversion.** `Hwnd = isize`; the body builds `HWND(h as *mut c_void)` (and back with `.0 as isize`). `0` is the null handle; the pseudo handles `HWND_TOP`/`-1`/`-2` and the DPI contexts (`-4`) are passed as integers. No wrapper dereferences a handle.
2. **Error mapping.** A C# `SetLastError = true` function that returns `bool`/null on failure becomes `Result<_, Win32Error>`: on failure `Win32Error::last()` is read **immediately**, before any allocation or other call (the windows-rs `Result` already did
   `GetLastError`; the wrapper reads the code from it with `(e.code().0 as u32) & 0xFFFF` when the facility is `FACILITY_WIN32`, as `dark_title_bar::win32_error_code` does, else the raw code). A failure that left the last error `0`
   is `Err(Win32Error(0))`, never `Ok`. Functions without `SetLastError` in C# keep their plain return value (`ShowWindow` -> previous visibility, `IsWindowVisible`, `GetDpiFor*`, `GetSystemMetrics*`, `MonitorFrom*`, `SetCursor`, `SetCapture`, `ReleaseCapture`, `GetWindowLongPtr`...).
   `GetWindowLongPtr` returns `isize` without `Result` although C# has `SetLastError = true`: `0` is a legal value and no caller reads the error.
3. **`HRESULT` returns** (`GetDpiForMonitor`, `DwmSetWindowAttribute`, `OleInitialize`, `RegisterDragDrop`, `RevokeDragDrop`) become `Result<_, Hresult>`: negative = `Err(Hresult(hr))`. `OleInitialize` returns `S_FALSE` (1) when COM was already initialised: that is `Ok`
   and still needs one `ole_uninitialize` (C# `OleUninitialize` takes no result). `RPC_E_CHANGED_MODE` (0x80010106, COM already MTA) is `Err`.
4. **Safe vs `unsafe fn`.** `pub fn` only when no integer argument can make the callee read or write memory the caller did not hand over; `pub unsafe fn` for: `register_class_ex` (pointers in the struct, window procedure), `create_window_ex` (runs the
   window procedure with `param` during the call), `def_window_proc`, `post_message`, `dispatch_message` (message parameters interpreted as pointers), `set_window_long_ptr` (`GWLP_WNDPROC`, user data), `set_clipboard_data` (ownership of an `HGLOBAL`), `global_free`
   (a still-locked or foreign block). Each documents the exact obligation in a `# Safety` section (the stub text). A stale or wrong `HWND`/`HMENU`/`HDC` is not undefined behaviour: the OS validates handles and fails the call.
5. **Strings.** `&str` becomes NUL-terminated UTF-16 (`structs::to_utf16z`) that lives in a local until after the call. `class_name`/`window_name` may be empty; an embedded NUL ends the name for the OS.
6. **Out structures.** `get_monitor_info` / `get_monitor_info_ex` / `get_window_placement` / `set_window_placement` set the size field themselves (D-W8B3-6: 40 / 104 / 44 / 44) on the struct they pass (the caller's struct for `get_*`, a copy for `set_*`), so a forgotten
   `cbSize` cannot fail the call. `get_window_rect` / `get_client_rect` return the `Rect` by value. `get_dpi_for_monitor` returns `(dpi_x, dpi_y)`.
7. **`get_message`.** Calls `GetMessageW`: result `> 0` -> `Message`, `0` -> `Quit` (`msg.wParam` = exit code), `-1` -> `Failed(Win32Error::last())`. With `hwnd = 0` it retrieves for the whole thread; `WM_QUIT` is retrieved only when no other message is pending for the filter.
   `peek_message` returns `true` when a message was stored (`PM_REMOVE` removes it).
8. **`msg_wait_for_multiple_objects_ex`.** `handles.len()` is the count (at most 63; the OS fails for more with `WAIT_FAILED`); an empty slice passes a null pointer and count 0. The result is the raw `DWORD`: `WAIT_OBJECT_0 + i` for handle `i`, `WAIT_OBJECT_0 + count`
   when input is available, `WAIT_TIMEOUT` (0x102), `WAIT_ABANDONED_0 + i`, `WAIT_IO_COMPLETION` (0xC0), `WAIT_FAILED` (0xFFFF_FFFF). The caller reads `Win32Error::last()` after `WAIT_FAILED`. The C# `MessageLoop` converts a deadline to ms and caps it
   at `INFINITE - 1`; that is W8-13, not here.
9. **`load_system_cursor(id)`** is C# `LoadCursor(0, id)`: every C# caller passes instance 0, so the parameter is dropped (the resource name is `MAKEINTRESOURCE(id)`: `PCWSTR(id as usize as *const u16)`, a pointer that is never dereferenced as text because its high bits are zero).
   Cursors from `LoadCursor(0, ..)` are shared; never destroy them.
10. **`track_popup_menu_ex`** is C# `TrackPopupMenuEx(menu, flags, x, y, hwnd, 0)`: the `TPMPARAMS` argument is always null in C#. Modal: it returns after the menu closes; with `TPM_RETURNCMD` the chosen command id or `0`; on error `0` (the caller cannot tell cancel from error, like C#).
11. **`append_menu(menu, flags, item_id, Some(text))`**: `MF_STRING` text item; `None` + `MF_SEPARATOR` separator; `MF_POPUP` takes a sub-menu `HMENU` as `item_id` (ownership passes to the parent menu: destroying the parent destroys it). Bitmap and owner-draw items are not used by the shell.
12. **Clipboard.** The order is `open_clipboard` -> `empty_clipboard` -> `set_clipboard_data` -> `close_clipboard`; `set_clipboard_data` needs the memory from `global_alloc(GMEM_MOVEABLE | GMEM_ZEROINIT, bytes)` filled under `global_lock`/`global_unlock`; on `Ok` the system owns the handle
    (do not free it), on `Err` the caller still owns it and frees it with `global_free`. No clipboard service logic here (W8-04c).
13. **`global_unlock` returns `bool` "still locked".** `false` is **not** an error when the lock count reached zero (`GetLastError()` is `NO_ERROR`); it is an error only when `Win32Error::last() != 0`. The wrapper returns the bool as is (C# does).
14. **`dwm_set_window_attribute(hwnd, attribute, &value)`**: passes `size_of::<T>()` bytes. `DWMWA_USE_IMMERSIVE_DARK_MODE` and `DWMWA_BORDER_COLOR` take a 4-byte value (`BOOL` / `COLORREF`, pass `&1i32` / `&0x00FF_FFFFu32`), `DWMWA_CAPTION_COLOR` a `COLORREF` (`0xFFFFFFFF` = `DWMWA_COLOR_DEFAULT` -> reset), `DWMWA_WINDOW_CORNER_PREFERENCE` an `i32` enum.
    A size or attribute the OS rejects is `Err(E_INVALIDARG)` (0x80070057), not a crash. Windows older than the attribute returns `E_INVALIDARG` too: callers ignore the error as the C# `_ =` does.
15. **`enum_display_monitors(clip)`** (D-W8B3-7) calls `EnumDisplayMonitors(null, clip, Some(callback), lparam)` with an internal `unsafe extern "system"` callback that pushes `MonitorEnumItem { monitor, rect }` into a `Vec` reached through `lparam` (a `*mut Vec<_>` that lives on the
    wrapper's stack for the call); the callback returns `TRUE` (keep going). No panic may unwind through the callback (it only pushes). `Err(Win32Error::last())` when the API returns `FALSE`. The order is the OS order.
16. **Kernel32 loader.** `load_library_ex(name, flags)` calls `LoadLibraryExW(name, null, flags)`; `LOAD_LIBRARY_SEARCH_SYSTEM32` loads only from `%SystemRoot%\System32` (no app-directory DLL planting). The module is never freed (C# has no `FreeLibrary`). `get_proc_address_by_ordinal(module, ordinal)`
    passes `MAKEINTRESOURCE(ordinal)`; `None` when the export is missing. Calling the returned address is the caller's `unsafe` (cast to `unsafe extern "system" fn(..)` with the documented signature).
17. **`get_module_handle()`** is `GetModuleHandleW(null)` (the `.exe`), never `0` for a running process.
18. **`ole_initialize` / drag-drop** need the STA thread of the window (C# comment: "RegisterDragDrop needs `OleInitialize` on the window's STA"). `register_drag_drop` takes `&IDropTarget`; OLE `AddRef`s it, so the caller may drop its own reference after the call and must call `revoke_drag_drop` before destroying the window.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (item 3, integers): `msg_wait_for_multiple_objects_ex` returns `u32`; `WAIT_FAILED` is `0xFFFF_FFFF`: compare as `u32`, never as `i32 == -1` after a cast to a signed type.
- T2: `CW_USEDEFAULT` is `i32::MIN` (`-2147483648`), not `0x8000_0000u32`; `create_window_ex` takes `i32` x/y/width/height, so pass the `i32` constant.
- T3: `get_message` must not treat `-1` as "message": the C# idiom `while (GetMessage(..) > 0)` is the Rust `matches!(.., MessageOutcome::Message)`; a `Failed` loop that continues spins forever (known Win32 bug pattern).
- T4: `global_unlock` false-is-not-error (note 13) and `global_free` returning the handle on failure, `0` on success (inverted from what a reader expects).
- T5: `get_monitor_info_ex` needs `cbSize == 104`; with `MonitorInfo` (40) the OS returns `ERROR_INVALID_PARAMETER` (also T2 of 11a).
- T6 (item 8, null vs empty): `msg_wait_for_multiple_objects_ex(&[], ..)` must pass count 0 and a null pointer (an empty slice's dangling non-null pointer is harmless but `nCount = 0` with `INFINITE` and no input blocks for ever: that is the caller's job).
- T7: `PostQuitMessage` posts `WM_QUIT` to the **calling thread's** queue; the exit code arrives in `msg.wParam`, not in `lParam`.
- T8: do not call `destroy_window` from a thread other than the creator (`ERROR_ACCESS_DENIED`); the wrapper does not check, it reports the OS error.
- T9: `register_class_ex` returns the **atom** (`u16`); `0` means failure. A class name must be unique per process and `UnregisterClass` must run with the same `hInstance`; an unregistered-twice class is `ERROR_CLASS_DOES_NOT_EXIST` (1411).

## Safety rules (one `// SAFETY:` per `unsafe` block, naming the pointer and why it is valid)
- Struct pointers (`&mut Msg`, `&mut Rect`, `&mut MonitorInfoEx`, `&WndClassEx`, `&WindowPlacement`): "references to live, correctly sized (`cbSize` set) structures that outlive the call; the OS does not keep them" (except `register_class_ex`: the class name pointers are copied by the OS).
- String pointers: "pointer into a local `Vec<u16>` that ends in NUL and lives past the call".
- Handles: "a handle value; the OS validates it" (no unsafe for the value itself).
- Callbacks: `enum_display_monitors` documents that `lparam` is the address of the `Vec` on the wrapper's stack and the callback runs synchronously on the calling thread inside `EnumDisplayMonitors` (never after it returns).
- `global_lock`: "the returned pointer is valid until the matching `global_unlock`; the wrapper does not read it".
- `unsafe fn` wrappers state their obligation in `# Safety` and the inner block repeats "upheld by the caller of this function".

## Decisions taken in this contract (D-W8B3-n; the lead may overrule in `contracts/README.md`)
- **D-W8B3-4 Wrapper conventions** (items 1 to 5 above): `isize` handles, `Result<_, Win32Error>` for `SetLastError` functions, `Result<_, Hresult>` for `HRESULT` ones, `&str` strings, `unsafe fn` exactly where an integer argument can become a pointer dereferenced by the callee.
- **D-W8B3-6 Wrappers fill the size field of the structure they pass** (`cbSize`/`length`). A forgotten size cannot fail the call; it is a strict improvement over C# with the same observable result for correct callers.
- **D-W8B3-7 `enum_display_monitors` returns a `Vec`** instead of porting the unmanaged callback + `data` pointer; `GetMonitorInfo` per monitor stays a separate call. Reason: the callback form cannot be made safe, and the only consumer (W8-13k `Win32MonitorLayout`) wants the list.
- Wrappers the C# declares but no C# caller uses (0 call sites: `GetStockObject` only in tests, `DragAcceptFiles`, `GetDpiForMonitor`, `DwmSetWindowAttribute` once, `GetCurrentInputMessageSource` once) are ported anyway: they are 3 lines each and the plan asks for the whole file.

## Open questions
1. **Typed vs raw `send_message`.** Not in this unit (11d). Mentioned because 102 call sites each need `unsafe`; 11d recommends only the raw `unsafe fn` plus a few typed helpers in the dialogs (W8-18).
2. **`GetWindowLongPtr` failure.** Recommended: plain `isize`. Alternative `Result` clearing the last error first (`SetLastError(0)`): costs two extra calls on a hot path (the C# shell calls it 14 times, none per frame).
3. **Replace the dynamic binding in `dark_title_bar.rs` with `dwmapi::dwm_set_window_attribute`?** Recommended no, in this wave: `dark_title_bar` is a finished W6 unit with its own tests and tolerates a missing `dwmapi.dll` (Server Core); the new wrapper statically imports `dwmapi.dll`. Revisit when W8-13b needs the dark title bar.
4. **`register_drag_drop` argument type.** Recommended `&IDropTarget` (typed). Alternative raw `*mut c_void` like C# `nint`; rejected because W8-14 implements the target with `#[implement]` and gets an `IDropTarget` for free.
