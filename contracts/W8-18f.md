## Semantics (C# is the spec)
1. **Wrappers**: each function is the one or two messages listed above; return values narrow with `as i32` like the C# `(int)`; a message that fails is not an error (the OS answer is returned as is). Integer-only messages go through `send_int`; the pointer messages (`CB_ADDSTRING`, `CB_GETLBTEXT`, `LB_ADDSTRING`, `LB_GETTEXT`) use `dialog_native::user32::send_message` in a block of their own with the SAFETY text of the contract.
2. **Strings**: `add` sends a NUL-terminated UTF-16 buffer; `text_at` allocates `length + 1` units, reads `length` units back (the length from the `..TEXTLEN` message BEFORE the copy, as C#); a negative or zero length gives `""` without the second message.
3. **`select_all`**: `count > 0` only; `select_range_lparam(count) = (((count - 1) as u16 as u32) << 16) as i32 as isize`. The C# `(ushort)(count - 1) << 16` is an `int` shift: for `count - 1 >= 0x8000` the result is negative and is sign-extended into the `nint`. Keep it (a list that long ignores the range anyway).
4. **`item_from_point`**: `encode_item_from_point(x, y) = (((y as u32) << 16) | ((x as u32) & 0xFFFF)) as isize` (zero-extended: the C# `(nint)(uint)`); the answer is `result as u32`; `decode_item_from_point(packed)`: `packed >> 16 != 0` -> `-1`, else `(packed & 0xFFFF) as i32`.
5. **`ensure`**: `ensure_once(&DONE, |classes| common_controls::init_common_controls_ex(classes))`, `DONE` a `static AtomicBool`. `ensure_once` is `swap(true, SeqCst)`: runs `init` and returns `true` only for the call that saw `false`; the result of `init` is ignored.
6. **`draw_item`**: the order and every number of the C# text above. `itemID` is a `UINT` in the SDK: compare `draw.itemID as i32 < 0` (the OS passes `-1` for an empty list or the area below the last row). `font` of `0` selects nothing. A failed `get_text_extent_point32` (`None`) is `(0, 0)`. Create-then-delete of brushes and pens on every path (pen and brush are deleted AFTER they were selected out); the text rectangles come from `row_layout`. `DrawText` goes through `user32::draw_text` (it clears `DT_MODIFYSTRING`, D-W8B3-9). Colours: `DialogColors::from_key(..)` for the `Dark.*` keys (a missing key falls back to `0`), `DialogColors::input()`, `text_secondary()`, `text_strong()`.
7. **`row_layout`** is the pure geometry of item 6 (arithmetic in the stub doc); `draw_item` calls it, so the native test and the pure test share one truth.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (GDI leaks): in `draw_item` the brush/pen/old-object bookkeeping is the whole risk: every created object is deleted, every selected object is restored first, on every early return (`itemID < 0`). Test: 200 draws leave `GetGuiResources(GR_GDIOBJECTS)` flat.
- T3 (arithmetic): `rect.right - pad_x`, `height - 4`, `badge_top` can underflow for tiny rectangles: saturating, no panic; the C# wraps silently.
- T3 (allocation sizes): `text_at` sizes its buffer as `length as usize + 1` computed in `usize` (an OS answer of `i32::MAX` must not overflow an `i32` add; a negative or zero length never reaches the allocation).
- T4 (sign and width casts): `itemID as i32`, `select_range_lparam`, the zero-extended `encode_item_from_point`.
- T5 (integer ids): none in this file.
- T8 (null vs empty): `badge: Option<&str>` where C# tests `string.IsNullOrEmpty(badge)`: `Some("")` is NO badge; same for `subtitle`.
- T10 (order): text drawing order is badge, subtitle, title, focus; the focus rectangle is drawn last so it lies over the text.
- R0003: no `unwrap`/`expect`; a null `rcItem` cannot occur (value type).

## Safety rules (`// SAFETY:` per `unsafe` block)
`send_int`: "callers pass only messages whose wParam/lParam are plain values (this module tree)". Pointer messages: "pointer to a NUL-terminated UTF-16 buffer / to a `length + 1` unit buffer, both alive for the synchronous call; the control writes at most `length + 1` units". No other `unsafe` (the `&DRAWITEMSTRUCT` is a safe reference; the caller creates it).

## Error mapping
| C# | Rust |
|---|---|
| `GetComboBoxInfo` false | `list_window` = `0` |
| any message failing (`CB_ERR`/`LB_ERR` = -1) | returned as `-1` / `false`, never an error |
| `InitCommonControlsEx` false | ignored; the flag stays set |
