## Scope and decisions

The C# file `RecoveryPresentation.cs` is a static class of pure functions that turn a `RecoveryCheckResult` or a `JournalEntry` into
localized text and colour tones. `RecoveryFilter.cs` holds two enums (`RecoveryFilter`, `RecoveryTone`) and nothing else. Both go to
one Rust module pair. The window (`RecoveryWindowPresenter`, W8-10g) and the Win32 dialog are not here.

- **D-10f-1 Texts come from `pr_l10n::keys` through the `Localizer`, not from `pr_l10n::tr`.** `tr::` accessors read a global
  localizer; D-W8-4 and testability need the catalog passed in. Every key is a constant from the generated module `pr_l10n::keys`:
  the C# `Tr.X` maps to `keys::` `SCREAMING_SNAKE` of the catalog key's identifier (keygen `to_identifier` then `const_name`), e.g.
  `Tr.RecoveryVerdictCanRetry` -> `keys::RECOVERY_VERDICT_CAN_RETRY` (`"recovery.verdict.canRetry"`). Text is
  `loc.format(keys::X, &[LocArg::new("size", ..), ...])`.
- **D-10f-2 Time-dependent members are F, not G.** `FormatTime`, the time part of `NowText` and `JournalText`, `PathView` (through
  `JournalText`/`NowText`) depend on the local time zone and the culture of the machine that runs the oracle. The golden cannot pin
  them. The oracle leaves them out. The port takes the time text from the `RecoveryTimeFormatter` trait (D-10f-3), and the tests use a
  fake that returns a fixed string. Test `FormatTime_TreatsTheStampAsUtcAndShowsLocalTime` becomes: the trait gets the UTC value
  unchanged (`.value`, no offset). The real text (`SpecifyKind` Utc, `ToLocalTime`, "g", current culture) is a native check in
  `pr_platform_win` and is not claimed by this unit.
- **D-10f-3 `RecoveryTimeFormatter` is a trait in this unit** (`fn format_local_general(&self, utc: DateTimeUtc) -> String`). The
  implementation is in `pr_platform_win` and belongs to the Win32 foundation or dialog units (lead assigns; it is the Windows
  equivalent of `ToLocalTime().ToString("g", CurrentCulture)`). Until then tests use a fake.
- **D-10f-4 Digit grouping of `FormatSize` (`N0`).** `pr_l10n::template::NumberCulture` has no group-separator field (only
  negative sign, positive sign, decimal separator, NaN and infinity symbols). `N0` needs the group separator. This unit takes it as a
  parameter: `RecoveryTexts::group_separator: &str`. The golden and the default test use `","` (the oracle runs with
  `InvariantCulture`). The composition root supplies the current culture's separator. Grouping size is 3 (the invariant and en
  pattern; a culture with another pattern is out of scope and noted). **Lead:** add `group_separator` to `NumberCulture` in a later
  `pr-l10n` change if the Windows lookup wants it there (open question Q1).
- **D-10f-5 Names of enum variants and types are those of `pr_core`.** `RecoveryPathStatus`, `RecoveryVerdict` (11 variants,
  including `PermanentlyDeleted` and `PartiallyPermanentlyDeleted`), `RecoveryPathCheck`, `RecoveryCheckResult`,
  `RecoveryGroupMemberCheck` come from `pr_core::file_actions::recovery_check`; `JournalEntry`, `JournalGroupMember` from
  `file_actions::journal_line`; `FileOperationType`, `JournalState` (4 variants: `Prepared`, `Committed`, `Failed`, `Dismissed`) from
  `pr_core::model`. `CANCELLED_BY_USER` is `pr_core::file_actions::errors::CANCELLED_BY_USER` (`"CancelledByUser"`).
- **D-10f-6 Exceptions are not ported.** The C# `ArgumentNullException.ThrowIfNull` guards (`RetryConfirmText(null)`,
  `NearestExistingFolder(path, null)`) have no Rust equivalent: a reference cannot be null. The tests `RetryConfirmText_NullEntry_Throws`
  and `NearestExistingFolder_NullPredicate_Throws` are **not ported**; the PARITY note says so. The `try { GetDirectoryName } catch
  (ArgumentException)` in `NearestExistingFolder` maps to the `None` of `get_directory_name` (see Semantics 9).
- **D-10f-7 Count and integer arguments.** `Tr.X(int)` / `Tr.X(long)` pass the count as a plain integer. The Rust `LocArg` takes
  `i64` (`LocValue::from(i64)` renders the culture's negative sign and ASCII digits, no grouping). The golden has no count above
  999, so grouping never shows; a count of 1000 or more is not a golden case (noted, no difference is claimed).
- **D-10f-8 `RecoveryGroupMemberView` is defined here, produced by W8-10g.** The C# record is in this file. The struct is ported with
  three `String` fields; no function here returns it.

## Semantics (from the C# code; the stub doc comments repeat the order)

1. **Verdict and status maps are total.** Rust matches exhaustively (no `_` for the 11 verdicts and 4 statuses). The C# `_` branches
   (`VerdictText`, `ExplainText`, `ActionText` -> `*_UNKNOWN`; `PathStatusText`, `PathStatusTone` -> Unreadable/Bad; `VerdictTone` ->
   Neutral) are reproduced by listing the variants that go there, not by a wildcard. `Unknown` gets `*_UNKNOWN` and Neutral.
2. **`verdict_tone`:** CanRetry Good; AlreadyDone Info; Conflict, SourceChanged, DestinationChanged, NotRecycled,
   PartiallyPermanentlyDeleted Warn; PermanentlyDeleted, Lost Bad; RecycleUnverifiable and Unknown Neutral.
3. **`path_status_tone`:** Exists Good; Changed Warn; Missing Neutral; Unreadable Bad.
4. **`rgb`:** Good `(0x6C,0xCB,0x7A)`, Info `(0x6F,0xB1,0xFF)`, Warn `(0xF0,0xB0,0x40)`, Bad `(0xFF,0x6B,0x6B)`, Neutral `(0xB0,0xB0,0xB0)`.
5. **`allows_retry`:** `result.verdict == CanRetry && (op_type in {Move, Copy} || (result.is_group() && op_type == Recycle))`. `None`
   -> false. Note: a group Move or Copy with CanRetry is allowed by the first clause, even though the entry has members.
6. **`matches`:** All -> true. CanRetry / AlreadyDone -> `verdict == Some(x)`. Problems -> `verdict` is `Some(v)` and `v` is neither
   CanRetry nor AlreadyDone. `None` is never a Problems match (C# `verdict is not null and not (...)`).
7. **`format_size` (N0):** digits of the absolute value, grouped by `group_separator` every three digits from the right, a leading `-`
   for negative input, then `RECOVERY_DETAIL_BYTES` with `{size}`. **Trap:** use `bytes.unsigned_abs()`; `-i64::MIN` overflows
   (the golden `format-size-i64-min` covers it). Decimal digits only, no decimal part.
8. **`now_text`:** Missing -> `NOW_MISSING`; Unreadable -> `NOW_UNREADABLE`; any other status -> `NOW_PRESENT` with
   `size = current_size.unwrap_or(0)` and `time = current_last_write_utc.unwrap_or_default()` (C# `?? default` is `DateTime.MinValue`;
   `DateTimeUtc::default()` is ticks 0, the same value).
9. **`nearest_existing_folder`:** `current = get_directory_name(path)`; while `current` is `Some` and non-empty: if
   `directory_exists(current)` return it; `current = get_directory_name(current)`. Return `None` otherwise. The path itself is never
   tested (golden `nearest-folder-does-not-test-path-itself`). `get_directory_name` returns `None` for the root and for an unparsable path
   (`dotnet_path`, W2-00); the C# `try/catch (ArgumentException)` is that `None`. The predicate receives the exact string (no case
   folding; golden `nearest-folder-case-sensitive-predicate`).
10. **`group_status_text`:** state word first: AlreadyDone -> `RECOVERY_GROUP_EXISTS`; CanRetry -> `RECOVERY_GROUP_SOURCE_STATUS`;
    NotRecycled -> `RECOVERY_GROUP_ON_DISK` (the file is still at its original path: not "missing"); RecycleUnverifiable ->
    `RECOVERY_GROUP_MISSING`; SourceChanged and DestinationChanged -> `RECOVERY_GROUP_CHANGED`; Conflict -> `RECOVERY_GROUP_CONFLICT`;
    Lost -> `RECOVERY_GROUP_LOST`; Unknown -> `RECOVERY_GROUP_UNREADABLE`; the other verdicts -> `verdict_text(verdict)`.
    If `member.destination` is `None`, return the state word only. Otherwise append ` · {RECOVERY_DETAIL_SOURCE}: {path_status_text(source)}`
    and ` · {RECOVERY_DETAIL_DESTINATION}: {path_status_text(destination or Missing)}`. **Trap:** a `Some` destination in the member with
    `destination == None` in the check uses `Missing`, not the member's own text (golden `group-status-notrecycled-destination-null-check`).
11. **`retry_confirm_text`:** the branch order of the stub doc (first match wins). **Traps:** (a) `undo` is `Option<bool>`:
    the cancelled branch and the permanent branch test `undo != Some(true)`, the restore branch tests `undo == Some(true)`; (b) the
    cancelled count is `members.len()` of the entry, or 1 when the entry has no members (members `Some(vec![])` also gives 1: C#
    `Count > 0`); (c) the non-group text uses `get_file_name(source)` from `pr_core::text::dotnet_path` (C# `Path.GetFileName`:
    the part after the last `\` or `/`; empty for a trailing separator).
12. **`pending_permanent_count(members, check)`:** if `check` is `Some` and its `group_members` is `Some(list)` (even an empty list),
    count `list` entries whose `verdict == NotRecycled`, mapping each to its `member`; otherwise use the entry's `members`. Count the
    members with `permanent == true`. Golden `retry-cancelled-group-recycle-permanent-counts-only-notrecycled` (2 permanent members,
    one already recycled: count 1).
13. **`operation_text`:** Move, Copy, Recycle -> the `ENUM_FILE_OPERATION_*` text. **`state_text`:** Prepared, Committed, Failed -> the
    `ENUM_JOURNAL_STATE_*` text; `Dismissed` -> the literal `"Dismissed"` (C# has no case: `ToString()`). Golden
    `state-text-all-includes-dismissed` pins it.
14. **`path_view`:** `title` and `path` (`check.path`); `status_text` = `RECOVERY_DETAIL_STATUS` with `{status}` = `path_status_text`;
    `status_tone` = `path_status_tone`; `now_text`; `journal_text`; `note` = `Some(RECOVERY_DETAIL_FOLDER_MISSING)` when the flag is
    true, else `None`.
15. **`journal_text`:** `RECOVERY_DETAIL_JOURNAL` with `{size}` = `format_size(entry.size)` and `{time}` = `format_time(entry.last_write_utc.value)`.
    The journal's `Unspecified` flag is ignored: the C# `SpecifyKind(Utc)` does the same.
16. **Localized text function bodies** are one `loc.format(key, args)` each, with no string concatenation except the two `·` joins in
    rule 10 and the `Dismissed` literal. No English literal in the port (D-W8-4; tests may have them).
17. **No clock, no I/O, no logging, no `unsafe`, no `windows` crate** in either file.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- Enum discriminants and variant order (ComboBox index of `RecoveryFilter`) are kept.
- Option semantics: `undo` and `permanent` are `Option<bool>` in `JournalEntry`, `permanent` on `JournalGroupMember` is a `bool` (C#
  default false), so the golden `permanent` absent means `false`.
- The `·` separator is U+00B7 with a space on each side, as in the C# source (copy the bytes from `RecoveryPresentation.cs`).
- Localized placeholders: `{permanentCount}` is camel case (the keygen placeholder rule).
