# W6-01c: Explorer STA provider, timeouts, and prefetch lifecycle

- Color: 🔴 | Porter: **sonnet** (threading, cancellation, disposal races) | C# spec baseline: `d92d6aae`
- Rust crate: `pr-platform-win`
- C# source (baseline): `src/PhotoReview.Platform.Windows/Explorer/ExplorerOrderService.cs`, limited to `StaThreadPump`, provider construction/disposal, `PrefetchedQuery`, prefetch storage/joining, `TryGetSnapshot*`, timeout normalization, and cancellation resolution.
- C# tests (baseline): `tests/PhotoReview.Integration.Tests/ExplorerOrderServiceSeamTests.cs`; live-shell smoke cases in `ExplorerOrderServiceTests.cs` are listed below as native-only integration.
- Split rationale: the C# source file combines concurrency orchestration with native view reading. This contract owns the scheduling/lifecycle slice; W6-01d owns the synchronous native query/read slice. Keep a narrow internal query seam between them and do not duplicate provider policy.

## Scope and behavior

Provide one long-lived STA pump that serializes all Explorer queries. Enqueue must complete callers with the query result/error and remain usable after a query throws. Disposal is idempotent, closes queue resources only after a bounded thread join, and must not block shutdown indefinitely on a stuck COM call. Caller timeout, caller cancellation, provider disposal, and query self-cancellation map to the baseline statuses. `Timeout.InfiniteTimeSpan` stays infinite; other negative durations become zero; values above the `CancelAfter` timer limit become infinite. Calls after disposal and enqueue/disposal races must return a snapshot/error outcome without an uncaught race exception.

Prefetch is one-shot and folder-specific: a newer prefetch supersedes/cancels the previous one; stale or differently-spelled-but-not-equivalent requests discard it; an equivalent fresh prefetch is joined once. The joining caller still has its own timeout/cancellation, and giving up cancels the underlying query. Cleanup of the cancellation source must race safely with later cancellation. Preserve the baseline's maximum prefetch age, batch-size clamping, and monotonic elapsed-time semantics.

## Fake/native safeguards, hang guard, mutation expectations

- Default tests use injected query delegates, deterministic `TimeProvider`/clock seams, barriers/channels, and bounded waits. No fixed sleeps or timing assertions. Ensure every wait has a finite timeout so a regression fails rather than hangs.
- Real STA/shell tests are ignored with a `native` reason and external CI timeout. They may read shell state only; their temporary folders are unique and cleaned in `finally`/RAII. Never touch the real Recycle Bin.
- Time-box `cargo-mutants` to this unit. Mutations to cancellation precedence, timeout status, serialized execution, prefetch key/age/one-shot behavior, and idempotent disposal must be killed by focused tests. Report residual scheduler-equivalent mutants rather than broadening timeouts or adding sleeps.
