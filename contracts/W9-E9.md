## Work list for the porter
1. `ContextMenuController::execute`: after `"Settings"` and before `"Zoom.Custom"`: `EXTERNAL_EDITOR_ADD_ID => self.run(|| actions.add_external_editor())`, `EXTERNAL_EDITOR_SET_DEFAULT_ID => self.run(|| actions.choose_default_external_editor())`, and the prefix arm (`id.strip_prefix(EXTERNAL_EDITOR_OPEN_PREFIX)` -> `self.run(|| actions.open_in_external_editor_by_id(rest))`, `rest` verbatim, even empty or containing dots). Order matters only for ids that equal a constant: `ExternalEditor.Add` and `ExternalEditor.SetDefault` do NOT start with `ExternalEditor.Open.`.
2. `MainWindowMenuActions`: `open_in_external_editor_by_id` mirrors `open_in_external_editor` (a view-model `Err(ExternalEditorBug)` becomes the `Err` of the `ActionResult`, so `Run` reports it through the existing guarded path); `add_external_editor` and `choose_default_external_editor` call the W9-E5 view-model methods (`with_view_model`), `Ok(())`.
3. `shell_input/main_window.rs`: the `OpenInDefaultEditor` arm calls the view model's `open_in_external_editor()` (the DEFAULT editor, Settings when none is declared); an `Err(ExternalEditorBug)` is returned as the `Err` of `execute` (the C# line is the unguarded `_viewModel.OpenInExternalEditor()`: expected launch failures are shown by the view model itself, only a bug escapes, and `ShellInput` reports it like any other command failure).
4. A test compares `EXTERNAL_EDITOR_OPEN_PREFIX` / `_ADD_ID` / `_SET_DEFAULT_ID` with the constants of `pr_app::menus::external_editors` (the C# comment says the test matches both sides).

## Traps
- Never route an editor through a row index: the id after the prefix is the editor id and is passed on verbatim (ids contain anything the user's hand-edited config had: dots, spaces).
- All dispatch is synchronous on the UI thread; the controller's `is_open` guard and its `guarded`/`run` failure reporting stay as they are; non-editor ids behave exactly as before.
- `OpenInDefaultEditor` and the menu entry `ExternalEditor` do the same thing (default editor, Settings when none declared).
