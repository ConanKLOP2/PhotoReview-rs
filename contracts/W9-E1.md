## Traps
- `ExternalEditors::effective` returns the LIVE list in C# (callers never mutate it); Rust returns a copy, so a caller that wants to change the list edits `settings.external_editors`.
- `reconcile` returns `true` only when an EXISTING list was repaired: blank/over-cap/null entries dropped, a blank or repeated id replaced, an over-long `arguments` reset, an unknown non-empty default id replaced. The legacy migration and the `external_editor_path` mirror are silent. A default id that is non-empty while the list ends up empty counts as a repair.
- A repeated or blank id gets a fresh id (`new_id`, retried until unique); the default id then falls back to the first editor if it pointed at the replaced one.
- `build_arguments`: one left-to-right pass; the inserted path is never scanned again; `inQuotes` toggles on every `"` of the template (not of the path); a bare token gets the quoted path, a quoted token the bare escaped path; no token: the quoted path is appended after a space (no space for an empty result). The escape doubles trailing backslashes and turns `"` into `2n+1` backslashes plus the quote. The token is case-sensitive (`{FILE}` is not a token).
- No panic on user data: `config.json` is hand-editable (empty ids, 10 000 entries, `null`s, 100 KB arguments).

   211	    /// pass: the inserted path is never scanned again (a file literally named <c>{file}.jpg</c> cannot expand twice), and every
   212	    /// <c>{file}</c> in the template is replaced. A token inside double quotes receives the bare path (so the default
   213	    /// <c>"{file}"</c> yields one quoted argument); a bare token receives the path quoted. A template without <c>{file}</c> gets
   214	    /// the quoted path appended. Windows file names cannot hold <c>"</c>, but one is backslash-escaped anyway.

   221	        var result = new StringBuilder(text.Length + filePath.Length + 8);
   222	        var inQuotes = false;
   223	        var replaced = false;

   235	            result.Append(c);
   236	            i++;
   237	        }
   238	        if (!replaced) result.Append(result.Length > 0 ? " " : string.Empty).Append('"').Append(escaped).Append('"');

   242	    private static string EscapeForQuotes(string path)
   243	    {
   244	        var sb = new StringBuilder(path.Length + 2);
   245	        var backslashes = 0;
   246	        foreach (var c in path)
   247	        {
   248	            if (c == '\\')
   249	            {
   250	                backslashes++;
   251	                sb.Append(c);
   252	                continue;
   253	            }
   254	            if (c == '"') sb.Append('\\', backslashes + 1).Append('"'); // 2n+1 backslashes then the quote
   255	            else sb.Append(c);
   256	            backslashes = 0;
   257	        }
   258	        sb.Append('\\', backslashes); // trailing backslashes are doubled so they cannot swallow the closing quote
