## Semantics (C# is the spec)
1. **Structures**: the `windows` structs `LVCOLUMNW`, `LVITEMW`, `HDITEMW`, `NMCUSTOMDRAW`, `NMLVCUSTOMDRAW` replace the byte buffers; their x64 layout equals the C# offsets (tests assert `size_of::<LVCOLUMNW>() == LVCOLUMNW_SIZE (56)`, `LVITEMW == 88`, `HDITEMW == 72`, `NMCUSTOMDRAW == 80`, and `offset_of!` for `mask 0, fmt 4, cx 8, pszText 16, iSubItem 28`; `LVITEMW`: `mask 0, iItem 4, iSubItem 8, state 12, stateMask 16, pszText 24, cchTextMax 32, lParam 40`; `HDITEMW`: `mask 0, pszText 8, cchTextMax 24, fmt 28`; `NMCUSTOMDRAW`: `dwDrawStage 24, hdc 32, rc 40, dwItemSpec 56, lItemlParam 72`; `NMLVCUSTOMDRAW`: `clrText 80, clrTextBk 84`). Do NOT use `control_constants::NMLVCUSTOMDRAW_SIZE` (104, wrong C# value, D-W8B3-13 c): the real size is 136.
2. **Messages** use `basic::send_int` for integer-only ones (`LVM_SETCOLUMNWIDTH`, `GETCOLUMNWIDTH`, `GETITEMCOUNT`, `DELETEALLITEMS`, `GETNEXTITEM`, `ENSUREVISIBLE`, `GETITEMSTATE`, `GETHEADER`, `SETEXTENDEDLISTVIEWSTYLE`, `SETBKCOLOR`, `SETTEXTCOLOR`, `SETTEXTBKCOLOR`, all `PBM_*`, `TBM_*`, `BM_*` of this file) and `dialog_native::user32::send_message` (`unsafe`, SAFETY text below) for the ones that pass a structure (`LVM_INSERTCOLUMN`, `LVM_SETCOLUMNW`, `LVM_INSERTITEM`, `LVM_SETITEMTEXT`, `LVM_GETITEMTEXT`, `LVM_GETITEM`, `LVM_SETITEMSTATE`, `HDM_GETITEM`). The `COLORREF` parameters are zero-extended (`u32 as isize`).
3. **`add_row`** and **`select_row`** keep the C# edge behaviour, documented in the stub: a failed insert (`-1`) is passed on to `set_cell` (harmless), and `select_row(lv, -1)` sends `LVM_SETITEMSTATE(-1)` (the OS applies it to every item). Do not "fix" either; a test pins the first (a row of cells with more cells than columns still returns the index).
4. **`cell_text`**: the returned length is the number of units the control copied; clamp to `0..=511` and take that many units from the buffer (the buffer is zero-initialised; never read past it).
5. **`custom_draw`**: pure, exactly the three cases; the colours are written only in the item stage; `dwItemSpec as i32` is the visible row index; the callback is `FnMut` and is called once per item stage.
6. **`draw_header_item`**: as the C# text; the header text is taken from the pointer in `HDITEMW.pszText` AFTER the message (it may differ from the local buffer). That read is the one non-trivial `unsafe` of the file: bounded by `HEADER_TEXT_CAPACITY` when the pointer is the local buffer, a NUL-terminated read when the control repointed it (SAFETY: the control owns that string for the duration of the notification). All GDI objects created (two brushes) are deleted on every path; the selected font is restored.
7. **`position_for_fraction(f)`**: `NaN -> 0`; `clamp(f, 0.0, 1.0) * 1000.0`; `round_ties_even()`; `as i32`. **`range_lparam(min, max)`** = `(((max as u32) << 16) | (min as u16 as u32)) as isize` (zero-extended; `max > 0xFFFF` loses the high bits, as C#). **`fraction`** = `PBM_GETPOS as f64 / 1000.0`.
8. **`is_checked`** is `result == BST_CHECKED (1)`; `BST_INDETERMINATE (2)` is not checked.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (GDI leaks): `draw_header_item` creates two brushes per call; delete both on every path. Test: 200 header draws keep `GR_GDIOBJECTS` flat.
- T3 (arithmetic): `rc.right - pad_x * 3`, `rc.bottom - 1` and the `+`/`-` of the layout are saturating; padX can be large at high DPI.
- T4 (rounding and casts): `round_ties_even` for the progress position (golden-free: rows 0.0625 -> 62, 0.1875 -> 188, 0.5 -> 500); zero-extended colours; `range_lparam` casts.
- T8 (null vs empty): `cells[0]` empty gives `""`; a glyph is `Option`.
- T9 (exception to Result): none; `HDM_GETITEM == 0` leaves `text = ""`, `fmt = 0` (the cell is still drawn).
- T10 (order): `add_column`s are inserted at the given index; `add_row` inserts at the end (`count`).
- Handles: `Hwnd` as `isize`, `0` is "none"; a destroyed list view makes every message a no-op returning `0`.
- R0003: no `unwrap`/`expect`/indexing on the UI thread (use `get`).

## Safety rules (`// SAFETY:` per `unsafe` block)
Structure messages: "pointer to a live local struct (`LVCOLUMNW`/`LVITEMW`/`HDITEMW`) with its size field or mask set; the control reads/writes at most its documented size during the synchronous call; any `pszText` points into a buffer alive across the call". The header-text read: see item 6. `custom_draw` has no `unsafe` (references).

## Error mapping
| C# | Rust |
|---|---|
| a message returns 0 / -1 | returned as is, never an error |
| `HDM_GETITEM` returns 0 | `text = ""`, `fmt = 0`, drawing continues |
| `(ushort)`/`(uint)` casts | the `as` forms of the semantics |
