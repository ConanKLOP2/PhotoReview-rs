## Semantics notes

### `nearest_rank(sorted, p)`
- empty slice or `p.is_nan()` -> `f64::NAN`.
- `rank = (p.clamp(0.0, 100.0) * n as f64 / 100.0).ceil() as i64` — evaluate `(clamp(p) * n) / 100.0`: multiply FIRST, divide last (C# comment: `p / 100.0 * n` turns `0.07 * 100` into 7.000000000000001 and picks rank 8). `f64::clamp` keeps ±inf out of the cast. Then `rank = rank.clamp(1, n)`; result `sorted[rank - 1]`. `n` is a count, never overflow-prone here.
- Golden `nearest_rank_sweep`: `ranks_by_n[n-1][p]` is the expected value for `sorted = [1.0 ..= n as f64]`, `p = 0..=100` (a value equals its rank).

### `slowest_decile_phase_share(complete_navs)`
1. `eligible` = navs with `final_visual_ms` `Some(v)` and `v > 0.0` (NaN fails), then sorted ascending by `final_visual_ms` with a STABLE sort (`sort_by` + `partial_cmp`/`total_cmp`; ties keep the input order — golden case with three equal finals checks which one is "slowest"). Empty -> empty map.
2. `slice_count = max(1, ceil(eligible.len() as f64 * 0.10) as usize)` — keep the `* 0.10` double multiplication (for n <= 1000 it equals `ceil(n/10)`, but do not "simplify"). `slow` = the LAST `slice_count` of `eligible`.
3. For each `(name, get)` of `phase_getters()` in order: skip the phase if NO nav of `slow` has `get(n).is_some()` (not even a zero); else `ratios = slow.map(|n| get(n).unwrap_or(0.0) / n.final_visual_ms.unwrap())` and the entry is `sum(ratios) / ratios.len()` with the sum accumulated left to right starting from `0.0` (this is what LINQ `Average` does; checked: no vectorised/pairwise summation). A negative phase value gives a negative share (golden has one). Phases are inserted in getter order.

### `GroupSummary::build(key, navs)`
`summary = GroupSummary::new(key)`; `summary.navs = navs.to_vec()`; `count = navs.len() as i32`; `incomplete = number with incomplete == true`. `complete` = navs with `incomplete == false`, in input order. Then:
- `firsts` = `first_visual_ms` of complete navs that have one, `finals` likewise for `final_visual_ms`, `frames` for `t_render_frame_ms`; each sorted ascending (finite values only in practice: `total_cmp` is fine). For each non-empty list: `*_p50 = nearest_rank(list, 50.0)`, `*_p95 = nearest_rank(list, 95.0)`, `*_max = last element`. Empty list -> the three stay NaN. (An INCOMPLETE nav's values never count: golden/C# test `IncompleteNavsAreExcluded...`.)
- `kind_counts[kind] += 1` for every complete nav (first-seen order, `IndexMap`).
- `slowest_phase_share` = `slowest_decile_phase_share(&complete)` copied in order.
- `hit_rate` (only if `complete` is not empty) = `(complete navs whose kind CONTAINS the case-sensitive text "RamHit") as f64 / complete.len() as f64` (so `Thumbnail+RamHit` counts, `ramhit` does not); otherwise NaN.
- All other fields stay at `GroupSummary::new` values.
`low_sample_warning()` = `count - incomplete < 20` (i32 arithmetic; exactly 20 complete navs is NOT low).

### `GroupKey` `Display`
`format!("{scenario}/{mode}/{cond}/workers={w}")` where `w` is the decimal `i32` or `?` for `None`. Golden `group_summary.key_string`: `S2/Preview/warm/workers=?`, `S3@F1/x/Preview/cold-app/workers=0`, `S4//unknown/workers=-1` (empty mode stays empty). Note this text is later `Escape`d by the report.

### `RunFileMeta::load(file)` — exact algorithm
Directory: `dir` = parent of `file.path` as a path string, or `""` when there is none (`perf-1.csv` has parent `""`; a drive root has none). `session.json` / `process.json` live at `dir/session.json` etc. (with `dir == ""` the relative name alone; `Path::join` does that). Initial values: `scenario = "unknown"`, `mode = ""`, `cond = "unknown"`, `workers = None`, `gc = None`, `frame = None`.

**session.json** (only if the path exists and is a file; read as bytes -> `csv::decode_bytes` (BOM dropped, invalid bytes replaced); any `io::Error` -> treat as absent; parse with `serde_json::from_str::<Value>`; parse error or root not an object -> use nothing from this file). Helper `str_of(name)` = the value if the property exists AND is a JSON string, else `None` (numbers, bools, null, objects -> `None`). Duplicate property names: the last one wins (`serde_json` does that). Then, in this order:
1. `scenario = str_of("scenario") ?? str_of("alias") ?? scenario` (an empty string is a value: `{"scenario":"","alias":"A1"}` gives `""`).
2. if `str_of("folderAlias")` is `Some(a)` with `a` non-empty -> `scenario = format!("{scenario}@{a}")` (works even when `scenario` was missing: `unknown@F1`).
3. `mode = str_of("mode") ?? mode`; `cond = str_of("cond") ?? str_of("condition") ?? cond` (a non-string `cond` is skipped in favour of `condition`).
4. `preloadWorkers`:
   - property absent -> go to the env lookup (5);
   - present and NOT a JSON number (string, `null`, bool, array, object) -> **ABORT**: steps 5 and all later session steps are skipped, but `scenario`/`mode`/`cond` set in 1-3 stay (C# `TryGetInt32` throws `InvalidOperationException`, caught by the `catch`). The directory fallback and header fallback below still run;
   - present and a number: if it is an integer token that fits `i32` (`value.as_i64()` and `i32::try_from`) -> `workers = Some(v)`; a number like `4.0`, `1E2`, `2147483648` is NOT an `i32` -> go to the env lookup (no abort).
5. env lookup (only reached from 4): for `name` in `["diag", "env"]`: `root[name]` must be an object that has the property `PHOTOREVIEW_DIAG_PRELOAD_WORKERS`, else try the next name; its value: a JSON number that is an `i32` integer -> `workers = Some(v)`, stop; a JSON string for which `parse_integer_i32(s)` is `Some` -> `workers`, stop; anything else (`true`, `8.5`, `"x"`, `"2147483648"`) -> try the next name. First match wins, so `diag` beats `env`.
Then (outside the JSON handling, always executed):
6. **cond from the directory**: if `cond == "unknown"`: `cell` = file name of the PARENT of `dir` (`""` if none); for `known` in `["cold-diskcache", "cold-app", "cold-os", "warm"]` in this order: if `cell` ends with `format!("-{known}")` ignoring case (`pr_core::text` has no `ends_with`; compare the last `known.len()+1` chars with `eq_ignore_case`, all ASCII) -> `cond = known` (the lower-case literal, not the directory's spelling); stop at the first. `cell == "warm"` alone does not match (needs the `-`). Runs after session.json, so a session `cond` of the literal text `unknown` still gets replaced.
7. **header fallback**: if `workers.is_none()` and `file.diag_flags.get("PHOTOREVIEW_DIAG_PRELOAD_WORKERS")` is `Some(v)` with `parse_integer_i32(v)` `Some` -> `workers`. (A session `preloadWorkers` always wins; a session abort leaves `workers` unset so the header value is used — golden pins this.)

**process.json** (same reading rules; root must be an object else nothing). `num(name)` = property exists and is a JSON number -> its `f64`; exists and is NOT a number -> **ABORT** this file (everything not yet assigned is skipped); absent -> `None`. Steps:
1. if `gcTimePercent` exists: non-number -> ABORT (so `frameTimeP95Ms` is not read either); number -> `gc = Some(v)`. If it does not exist go to 2.
2. only when `gcTimePercent` is absent: if `gcPauseDeltaMs` exists: non-number -> ABORT; number `gp`: then if `elapsedMs` exists: non-number -> ABORT; number `el` with `el > 0.0` -> `gc = Some(gp / el * 100.0)` (divide first, then multiply). A missing `elapsedMs`, or `el <= 0`, assigns nothing and does not abort.
3. if `frameTimeP95Ms` exists: non-number -> ABORT (`gc` from 1-2 stays); number -> `frame = Some(v)`.
Golden examples: `{"gcTimePercent":5,"frameTimeP95Ms":"x"}` -> gc 5, frame None; `{"gcTimePercent":null,"frameTimeP95Ms":20.1}` -> both None; `{"gcPauseDeltaMs":3,"elapsedMs":7}` -> 42.857142857142854; `{"elapsedMs":1000,"frameTimeP95Ms":16.7}` -> gc None, frame 16.7.
Implement the aborts with a small private `fn read_x(...) -> Result<(), Abort>` that writes into `&mut` locals before it returns `Err`, not with early `return`s that lose the already assigned values.

`RunFileMeta::load` never fails and never panics on file content.

## Golden `perf-stats` (how to compare)
- `nearest_rank`: `sorted` is an array of numbers or `{"range": N}` (= `1.0..=N as f64`); `p` is a number or the string `"NaN"`/`"Infinity"`/`"-Infinity"`; `value` null <-> NaN.
- `decile` / `group_summary`: `navs` is an array of nav specs or `{"seq": {...}}`. Nav spec keys (all optional): `nav` (default 1), `mode`, `t_input t_pre t_stat t_thumb t_join t_disk t_read t_decode t_verify t_assign t_render t_render_frame`, `lookup_result`, `has_thumbnail`, `post_ms` (object), `first_visual`, `final_visual`, `incomplete` (default **false** in the golden spec, unlike `NavRecord::default()`), `kind` (default `"Unknown"`). `seq` = navs `i = 1..=count` with `final_visual = i as f64 * final_step`; optional `first_step` (`first_visual = i * first_step`), `frame_step` (`t_render_frame`), `incomplete_after` k (navs `i > k` incomplete), `kinds` (kind = `kinds[(i-1) % len]`), `t_decode_last` K + `t_decode_value` V (the last K navs get `t_decode = V`). Write one helper `nav_from_spec(&Value) -> NavRecord` and one `expand_seq` in the test file; keep them in sync with `golden.md` (the C# versions are `NavFromJson` / `Navs`).
- `group_summary` outputs: `key_string, count, incomplete, low_sample_warning, first_p50..rendered_max, hit_rate, kind_counts` (ordered pairs), `slowest_phase_share` (ordered pairs); null <-> NaN.
- `run_meta`: `files` maps a relative path to a text (or `{"content":..,"bom":true}`); write them under a `TempRoot`; the CSV path is `root/<csv>`; `diag` (optional object) becomes `DiagFlags`. Expected `scenario, mode, cond, preload_workers, gc_time_percent, frame_time_p95_ms`. The directory-name cases rely on the parent of the TempRoot not ending in `-warm`/`-cold-*` (`%TEMP%\pr-rs-tests`, fine).
- `phase_names`: equals `phase_getters()` names.

## Traps checklist (docs/MULTI-AGENT-PLAN.md §7)
1 (`ends_with` ignoring case via `eq_ignore_case`), 2 (all numbers are invariant), 4 (rank formula multiplies first; averages are left-to-right sums), 6 (JSON property types: string vs number vs null decide skipped steps; case-sensitive property names; duplicate keys: last wins), 8 (`""` is a value for scenario/mode; absent is `None`), 9 (no `?` on file errors in `load`: every `io::Error` / parse error means "absent"), 10 (`IndexMap` for `kind_counts` and `slowest_phase_share`; `sort_by` is stable).
