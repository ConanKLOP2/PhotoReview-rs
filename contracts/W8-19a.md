## Semantics (C# is the spec)
1. **`SettingsPageView`**: the defaults of the trait are the defaults of `SettingsPageBase` (`on_command` false, `focus_target` None, `focus_external_editor` false, the rest empty); `title()` defaults to `page_title(key())`. `declare`/`attach`/`load`/`collect` are required. Order of the frame calls (documented, not enforced here): `declare` once, then (window created) `attach`, `load`, `on_activated` when shown.
2. **`page_title(key)`** = `with_field_context(|ctx| SettingsPresenter::page_title(key, ctx))`: the localized `settings.nav.*` heading, `""` for an unknown key (the lookup is case sensitive).
3. **`with_field_context`**: `let texts = Localizer::current(); let numbers = number_culture(); f(&FieldContext { texts: &texts, numbers: &numbers })` (D-W8B5-710).
4. **`PageContextSlot`**: `new()` is empty; `attach(ctx)` stores it (a second attach replaces it); `context()` is a clone of the stored one, or `SettingsPageContext::detached()` when empty; `is_attached()` is `context.is_some()`.
5. **`SettingsPageContext::detached()`**: a context over a private no-op host: `presenter()` is one shared `Rc<RefCell<SettingsPresenter>>` per thread (a `thread_local!`) built with `SettingsPresenter::new(&AppSettings::new(&EnglishSettingsTexts), SettingsPresenterOptions::new(0, Arc::new(EnglishSettingsTexts), Arc::new(InertShellIntegration)))`, where `InertShellIntegration` is a private unit struct of `context.rs` implementing `pr_core::abstractions::ShellIntegration` with a neutral `ShellMenuState` and `Ok(())` (no store, no localization, no checker; the porter adapts the exact constructor names to `pr_core::settings::app_settings`), `hwnd()` 0, `files()`/`decoder_factory()`/`version()` `None`, `open_url`/`start_explorer` `Err("detached")` / `Some("detached")`, `show_action_profiles` `Err(ActionProfilesUnavailable)`, text `""`, checks false, combo `-1`, slider 0, enabled false, shortcut texts empty, `actions_json` `""`, `ui_post()` an `Arc` whose `post` drops the action, every write nothing.
6. **One-line forwarders** (`presenter`, `owner`, `files`, `decoder_factory`, `version`, `open_url`, `text`, `set_text`, `is_checked`, `set_checked`, `combo_index`, `set_combo_index`, `set_combo_items`, `slider_value`, `set_slider_value`, `set_slider_range`, `set_tooltip`, `current_shortcut_texts`, `set_enabled`, `is_enabled`, `set_visible`, `focus`, `relayout`, `show_warning`, `ui_post`, `post_to_ui`, `actions_json`, `collect_actions_json`, `commit_actions_json`) call the host method with the same arguments, once, and return its result. `owner()` = `host.hwnd()`; `set_tooltip_text(id, text)` = `host.set_control_tooltip(id, fixed_text(text))`; `post_to_ui(action)` = `host.ui_post().post(action)`; `relayout()` = `relayout_active_page()`; `show_warning` = `warn`.
7. **`radio_index(ids)`**: for `i` in `0..ids.len()`, the first `i` for which `host.is_control_checked(ids[i])` is true, as `i32`; `-1` when none (and for an empty group). Stops at the first checked radio (the host sees no later call).
8. **`set_radio_index(ids, index)`**: for `i` in `0..ids.len()` in order, `host.set_control_checked(ids[i], i as i32 == index)`: every radio of the group is written (`BM_SETCHECK` does not clear its siblings), an `index` outside `0..len` (also negative) checks none.
9. **`run_explorer(request)`**: `title = Localizer::current().get(keys::DIALOG_SETTINGS_OPEN_FAILED_TITLE)` read when needed. `error_message = Some(m)` -> `show_warning(title, m)`, return, no `start_explorer`. `arguments = None` -> return. `Some(args)` -> `host.start_explorer(args)`: `Some(error)` -> `show_warning(title, error)`; `None` -> nothing.
10. **`edit_action_profiles(actions)`**: `host.show_action_profiles(host.hwnd(), actions)`: `Ok(Some(list))` -> `Some(list)`; `Ok(None)` -> `None` with NO warning; `Err(ActionProfilesUnavailable)` -> `show_warning(get(DIALOG_OPEN_EDITOR_FAILED_TITLE), get(DIALOG_OPEN_EDITOR_FAILED_MESSAGE))` and `None`. (The C# `OperationCanceledException` exception is unrepresentable.)
11. **`catalog`**: `implemented_keys()` = the keys of `FACTORIES` in table order; `pending_keys_with(nav, f)` = the `nav` keys, in `nav` order, without a factory in `f`; `pending_keys()` = `pending_keys_with(PAGES keys, FACTORIES)` (as `&'static str`); `is_complete()` = `pending_keys().is_empty()`; `create_pages_with(nav, f)` = per `nav` key in order: the first factory of `f` with that key, called, else `Box::new(PendingSettingsPage::new(key))`; a factory key that is not in `nav` is never called. The real table has the seven alphabetical entries (D-W8B5-708), so `is_complete()` is `true` and `create_pages()` returns 7 pages in navigation order (General, Display, Mouse, Performance, Shortcuts, Files, Diagnostics) while `implemented_keys()` is alphabetical: do NOT sort one to look like the other.
12. **`PendingSettingsPage`**: `key()` is the given key (any text); `declare` = `page.note(Some(text_fn(|| Localizer::current().get(keys::SETTINGS_PAGE_PENDING))), false)` (ONE unaligned note); `attach` stores the context in its slot; `load` and `collect` leave the state untouched; every other method is the trait default.
