- Semantics notes:
  1. **Code strings are persisted in `operations.jsonl`: copy them exactly** (case-sensitive, no whitespace). `is_known` is an exact match; `"cancelledbyuser"`,
     `"CancelledByUser "` and `None` are not known (golden rows).
  2. **Texts.** The English text of each code is the `en.json` string behind its key (`CODE_KEYS`); the golden `journal-error-text.json` lists all eight, and your tests
     use them as the English catalog (a closure mapping `key -> text` built by inverting `CODE_KEYS` over the golden). `text(code, localize)` = `localize(catalog_key(code)?)`,
     unknown code -> `Err(UnknownJournalCode(code.to_owned()))` (C# `ArgumentException`). `describe(code, stored, localize)`: known code -> `Some(localize(key))`; otherwise `stored.map(String::from)`.
  3. **`for_journal`** (the C# `ForJournal`, internal): order matters. (1) a `JournalCodedError` with a KNOWN code -> `(Some(code), english text)`; (2) cancellation -> `(Some(CANCELLED_BY_USER), english text)`;
     (3) everything else -> `(None, err.to_string())`. Find the error inside an `io::Error` with `io::Error::get_ref()` + `downcast_ref` (and `err.downcast_ref::<io::Error>()` first). A coded error with an
     UNKNOWN code falls to (3), keeping its message. The returned code is the matching `&'static str` from `ALL_CODES` (not a clone of the input).
  4. **`JournalCodedError`**: `new(code, message)` keeps both; `with_inner(message, inner)` has `code == ""`; `Display` prints `message`; `source()` is the inner error. `into_io_error()` =
     `io::Error::other(self)` so `get_ref()` can recover it.
  5. **`is_destination_exists(&io::Error)`**: true when `raw_os_error()` is 80 or 183, or `kind() == AlreadyExists`. The pure `hresult_is_destination_exists` is the exact C# HRESULT test:
     `(h & 0xFFFF) in {80, 183}` and `(h & 0x7FFF0000) == 0x00070000` (work in `u32`: `let h = hresult as u32;`).
  6. **`get_path_root`** reproduces .NET `Path.GetPathRoot` on Windows; the algorithm is written in the doc comment of the stub and was checked against all 50 rows of the golden. Work on
     `Vec<char>` (all prefix chars are ASCII). Returned root is NORMALIZED (`"C:/"` -> `"C:\"`, `"//srv/sh/x"` -> `"\\srv\sh"`). `""`, `" "`, `"   "` -> `None`; a relative path (`"a\b"`) -> `Some("")`.
     `"\\?\unc\srv\sh\a"` (lower-case `unc`) is NOT a UNC device path (golden). No `std::path` APIs (they differ: trap 7).
  7. **`first_overflow`**: see the doc in the stub. Group key = `ignore_case_key(&get_path_root(&m.source).unwrap_or_default())`. Preserve first-appearance order of volumes with a
     `Vec<(String, Vec<&JournalGroupMember>)>` + `HashMap<String, usize>` (do not iterate a `HashMap`). Ask the recycle bin once per volume, with the FIRST member's path and the SUM of all
     non-permanent sizes of that volume; stop at the first volume that does not fit and return its first member. Sum with `saturating_add`; convert to `u64` with `u64::try_from(sum).unwrap_or(0)`.
     (C# `Sum` is checked and would throw on overflow; unreachable for real sizes, document it in a comment.)
  8. **Never** call the real Recycle Bin or any file-system API in this WU: everything is pure. Tests use the local `PerVolumeBin` only.

## Open questions
1. **Localization seam.** `pr-l10n` is an empty crate, so `text`/`describe`/`for_journal` take a `&dyn Fn(&str) -> String` instead of a `Localizer`. When `pr-l10n` lands (W1-11 + later) the call sites pass
   `|key| localizer.get(key)`. The English catalog (`assets/languages/en.json`) must be used for `english`; the Vietnamese half of `Code_IsDescribedInBothLanguages` is deferred to that unit.
2. **Message of non-coded failures.** C# stores `ex.Message` (e.g. `"Access to the path 'x' is denied."`); `io::Error::to_string()` for an OS error looks like `"Access is denied. (os error 5)"`. The journal text of
   such records therefore differs in wording from the C# app (it is free text, never parsed). Lead: accept, or have the file-system layer attach a .NET-style message.
3. **`get_path_root` home.** It is a generic `Path.GetPathRoot` that Wave 2 (`FileActionService`, `UndoService`, `RecoveryRetryService`) will also need. It sits in `errors.rs` only because this WU needs it first; hoist to a shared path module when convenient.
4. **Module wiring (lead):** `file_actions/mod.rs` must declare `pub mod errors; pub mod types;` (and `journal`, see W1-09).
