## Semantics (C# is the spec)
1. **`ShellServices::build(host, hub, log, options)`**, in this order (C# section 1 and `RegisterFeatures`): `ui_scheduler = Arc::new(host.dispatcher.clone())` and `ui_dispatcher` the same value as the other trait; `folder_dialog = options.folder_dialog.unwrap_or_else(|| Rc::new(NativeShellFolderDialog::new()))` (the `AddShellOverlay` line: the native dialog wins); `file_dialog = options.file_dialog.unwrap_or_else(|| Rc::new(NativeShellFileDialog::new()))`; `clipboard = Rc::new(Win32ClipboardService::new(host.owner_closure()))`; `folder_picker = Rc::new(FolderPicker::new(folder_dialog.clone(), host.owner_closure()))`; `graph_slot = Rc::new(OnceCell::new())`; the port factory (below) wrapped in `secondary_port = Rc::new(LazySecondaryPort::new(factory))`; `secondary_port_host = Rc::new(SecondaryWindowPortHost::new(secondary_port.clone()))`; `zoom_prompt = Rc::new(Win32ZoomPromptService::new(host.owner_closure(), secondary_port.clone()))`; `dialog_service = Rc::new(Win32DialogService::new(host.owner_closure(), FolderPicker::new(folder_dialog.clone(), host.owner_closure()), secondary_port.clone()).with_log(log.clone()))` (`FolderPicker` is not `Clone`: the service owns its own instance; both are stateless wrappers of the same dialog); `sink_factory = Rc::new(Win32PresentationSinkFactory::new(hub.clone()))`.
2. **The port factory** (`FnOnce`, runs on the FIRST `LazySecondaryPort::get`): `options.secondary_port` is `Some(port)` -> `Some(port)` (a port registered ahead wins over everything); else `dialogs = options.dialogs` or, when `None`, `graph_slot.get()` -> `Some(services)` -> `Rc::new(ProductionSecondaryWindowDialogs::new(services.clone(), host_parts, options.seams))`; no dialogs (graph not bound) -> `log.error("Secondary windows were requested before the service graph was bound", None)` and `None` (the answer `None` is KEPT by the lazy port: 17e must bind before the first window, trap T3); else `port = Win32SecondaryWindowPort::new(dialogs, log.clone(), PortOptions { ready: None, message_loop: host.message_loop.clone(), settings_enabled: None })`, `Some(Rc::new(SecondaryWindowRouter::new(port)))`. The `host_parts` of the `dialogs` line are built INSIDE the factory from clones captured before it (`clipboard`, `file_dialog`, `folder_dialog`, `log`, `options.version`) by ONE private free function `make_host_parts(..)` that `dialog_host_parts` also calls: `ShellServices` does not exist yet when the factory is created, and the factory must not capture it (T2). The closure captures `host.owner_window`/`message_loop` clones and `Weak`/clones as needed: NO `Rc` cycle may keep the port alive after `ShellServices` is dropped (D-W8B3H-18 rule: the port holds the dialogs, the dialogs hold `Rc<DialogServices>` and closures; none holds the `LazySecondaryPort`).
3. **`bind_dialog_services(services)`** = `graph_slot.set(services).is_ok()`. **`dialog_host_parts(version)`** = `DialogHostParts { clipboard: self.clipboard.clone() (as the trait), file_dialog, folder_dialog, log, version, localizer: Box::new(Localizer::current), numbers: Rc::new(WindowsNumberFormatting), time: Rc::new(WindowsRecoveryTimeFormatter), group_separator: locale::group_separator(), current_time_text: Arc::new(locale::local_long_time_text) }`.
4. **`ShellFolderPickerAdapter::pick_folder(title, initial)`** = `match picker.pick(title, initial) { Ok(v) => v, Err(hresult) => { log.error(&format!("Folder dialog failed (0x{:08X})", hresult.0 as u32), None); None } }` (D-W8B5-2: the COM failure is logged and answered as cancelled). `new_folder_picker()` = `Box::new(ShellFolderPickerAdapter::new(self.folder_picker.clone(), self.log.clone()))`.
5. **`owner_closure()`** = `let owner = self.owner_window.clone(); Box::new(move || owner())`: the provider is evaluated at USE time. 17e's provider holds a `Weak` of the main window and answers `0` once it is destroyed (D-W8B5-1, D-W8B3H-18).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (re-entrancy): a modal dialog runs a nested loop inside `LazySecondaryPort::get` consumers; no `RefCell` borrow and no `OnceCell` access is held across `show_modal`; the dialogs builders only read `Rc<DialogServices>` and never mutate it.
- T2 (`Rc` cycles and leaks): the lazy port, the port, the dialogs and `DialogServices` form a tree; `GraphSlot` is read once by the factory. A strong `Rc<ShellServices>` inside any closure of the dialogs is a cycle: forbidden. Test `shell_services_drop_frees_the_port` (a `Drop` counter on a fake `SecondaryWindowDialogs`).
- T3 (late binding): `LazySecondaryPort` keeps an absent answer forever; `bind_dialog_services` MUST run before the first window request. 17e binds right after it builds the graph and before any message is dispatched; the factory's `log.error` makes a violation visible.
- T4 (owner at use time): never cache the owner HWND; every service gets its own closure; a closure holds no strong reference to the window (17e's concern, tested here with a closure over a `Cell<Hwnd>`).
- T5 (panic on the UI thread): no `unwrap`/`expect`; every `Option`/`Result` has a defined answer above; a panic inside a dialog hook is the dialog base's concern (`pending_panic`).
- T6 (texts): UI text comes from the catalog only (`Localizer`); the only literals in this unit are log messages and the Win32 format strings.
- T7 (recycle bin and user data): the native tests use `TempRoot` and fakes; the Benchmark native test uses the benchmark's own fake recycle bin (`BenchmarkDialogSeams.sessions` with a fake session) and NEVER the real bin (`PHOTOREVIEW_RS_BENCH_REAL_RECYCLE_BIN` stays unset).
- T8 (warm-up cost on the start-up path): `warm_*` only spawn; they never block the caller; nothing is joined on the UI thread.
- T9 (locale): `locale.rs` calls are O(1) and run on the UI thread only when a dialog opens; the `unsafe` buffers are sized with the documented maximum (`LOCALE_NAME_MAX_LENGTH`, 80 characters for numbers and dates) and the return value (0 = failure) is checked: a failure answers the plain `to_string()` / ISO-like fallback, never panics.

## Safety rules (`// SAFETY:` per `unsafe` block)
`locale.rs` only: each FFI call states that its pointers are live local buffers of the stated length, the locale name is a NUL-terminated `u16` array (`to_utf16z`), and the returned length bounds the slice that is read. `warmup.rs` and the two `pr-shell` files have no `unsafe`.
