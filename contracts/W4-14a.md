- Semantics notes:
  1. **Constructor order (C#).** Required collaborators are fields, not checks. `disk_directory = config.disk_cache_directory` or
     `AppPaths::from_environment().preview_cache_dir` (R0002: the Rust app's directory, never `%LOCALAPPDATA%\PhotoReview\cache`). `log`
     default `NullLog`. Disk store: `DiskCacheStore::new(dir, "*.pv4", disk_cache_capacity_bytes, Some(log), Some(clock))` (W4-09; a blank
     directory is `Err(DiskDirectory)`). Then `disable_disk_cache` (note 3). Decoder: `decoder`, else `factory.create(current_backend())`
     (ONE call of the backend source and of the factory, even though the value is unused while a factory exists: C# does it), else
     `Err(NoDecoder)`. Original-dimension cache `BoundedLruCache::new(original_dimensions_capacity as i64, |_| 1)` (`<= 0` ->
     `Err(OriginalDimensionsCapacity)`). Capacity `resolve_capacity(capacity_bytes, cache_ram_percent, physical_memory_bytes,
     source_bytes_cache.map(capacity_bytes), preload_window)`, then exactly ONE `log.info(line)`. RAM cache `BoundedLruCache::new(capacity,
     |image| image.estimated_bytes())`. Last: `inner.start_background()` (W4-14c: 2 persist workers + startup cleanup); its `Err` is
     `Err(Spawn)`. No file is created by the constructor (the disk directory is created by the first write, W4-08a).
  2. **`resolve_capacity`** is pure and byte-identical (golden `preview-budget-line`, 49 cases): see the stub doc for both branches. The
     percent branch needs `ram_percent.is_some() && physical_bytes > 0`; a percent with unknown RAM takes the BYTE branch. Divisions are
     `i64 /` (truncate toward zero: `-1.5 MiB / MiB = -1`). `preview_bytes_for_percent` cannot fail there (physical > 0): map an impossible
     `Err` to the byte branch value rather than panicking. `max(1, ..)` only in the byte branch. The clamp text uses
     `MAX_IMAGE_CACHE_RAM_PERCENT` (90) from `pr_core::settings::perf_options`, not a literal. Never format with a locale.
  3. **Disk cache on/off (D10, F-IMG-4)** is resolved ONCE: `disable_disk_cache_override.unwrap_or(disk_cache_capacity_bytes <= 0 ||
     diag.disable_disk_cache)`. `diag` = `config.diag` or `DiagOptions::current()` (D4: `PHOTOREVIEW_RS_DIAG_DISABLE_DISKCACHE`). The decode
     and persist paths only read the stored bool (a mid-process environment change must not make them disagree).
  4. **Keys.** `get_current_cache_key_for_box`: read the mode ONCE; `ImageCacheKey::create(fs, path, is_original, if is_original
     {UNBOUNDED} else {box}, KeyOptions { orientation_applied: true, backend: (current_backend)(), source_kind: source_kind_for(path) })`.
     C# evaluation order: `get_current_cache_key(path)` reads the BOX FIRST (it is the argument of the box overload, so it is read even in
     Original mode), then mode, kind, backend inside; for the entry overload:
     mode, kind, then box (ONLY when not Original: the golden counts `box_calls`, `mode_calls`, `backend_calls`), backend. In both
     the backend source is called BEFORE `ImageCacheKey::create*` (it is an argument): a key that then fails (missing file) has
     still made one backend call. `source_kind_for`
     uses `pr_core::catalog::types::is_raw_path` (extension of the LAST segment, OrdinalIgnoreCase: `.NEF` is RAW, `x.dng.` and `x.dngx` are
     not). The width-only constructor's box source returns `DecodeBox::new(w(), 0)` on EVERY read.
  5. **RAM cache reads.** `try_get_cached_preview(key)` = `cache.try_get(key)` (makes the entry MRU; no metrics). The path overload builds the
     current key and returns `None` on ANY key error (C# catches `IOException` and `UnauthorizedAccessException`; `CacheKeyError` has only
     those two shapes plus `ArgumentException` for a blank path, which C# would let escape: see Open questions 3). `cached_preview_bytes` =
     `estimated_bytes()` of a hit. `has_inflight_preview(key)` looks up `(key.clone(), current_epoch())` in `in_flight` (W4-14b's table).
  6. **Epoch (INV-2).** `cache_epoch` is an `AtomicI64` written ONLY under `lifecycle_gate` with `wrapping_add(1)` (D3), read with `SeqCst`.
     `publish_if_current(key, image, epoch)`: lock the gate, compare, `cache.set`, unlock: the compare and the set are atomic against
     `clear_cache`'s bump+clear (and W4-14c's `clear_disk` bump). Never hold the gate across a decode or I/O.
  7. **`clear_cache`**: gate { epoch += 1; cache.clear() }; then `original_dimensions.clear()` (OUTSIDE the gate, like C#); then notify the
     `CacheCleared` listeners: snapshot the `Vec` under its mutex, release it, call each in subscription order on the calling thread. A
     listener may call `clear_cache` again or unsubscribe (no lock is held). `subscribe_cache_cleared` returns an id-based subscription; drop
     removes the id (a `Weak` to the inner state, so a subscription that outlives the service is harmless).
  8. **`evict_cached_path(path, also_invalidate)`**: `normalized = normalize_key_path(path)?` (W4-01a's own normalization, NOT a local
     `to_uppercase`: Unicode case mapping differs, trap 1); `source_bytes_cache.evict(Path::new(path))` with the ORIGINAL spelling (C#
     passes `path`); then gate { `cache.remove_where(|k| k.path() == normalized)` (ORDINAL equality, the key path is already upper-cased);
     `also_invalidate(&normalized)` }. No epoch bump (R2-F-02: an epoch bump would also drop every OTHER path's in-flight decode). The
     original-dimension cache is NOT touched (golden `evict-keeps-original-dims`).
  9. **`is_raw_full_decode_request(path)`**: `raw_full_decoder.is_some() && (is_raw_full_decode_enabled)() && is_raw_path(path)`; the enabled
     source is called only when a decoder exists (C# `&&` short-circuit).
  10. **`PreviewError`.** `is_canceled` = `Canceled | DiskEntry(PreviewCacheError::Canceled) | Decode(DecodeError::Canceled)`; `is_busy` = `Decode(Busy)`;
     `Display` texts in the stub. `PreviewError` is `Clone` (joiners share one outcome): inner errors that are not `Clone` sit behind `Arc`.
  11. **`StdThreadSpawner`**: `std::thread::Builder::new().name(..).spawn(job)`; map the builder's `io::Error` to `Err`; detach. Names:
     `PhotoReviewRs.PreviewDecode`, `.ViewerDecode`, `.OriginalDecode`, `.PreviewPersist`, `.PreviewCacheCleanup` (Process Explorer / perf
     traces show them).
  12. **`Drop for PreviewImageService`** only calls `self.inner.persist.complete()` (W4-14c); it never joins (a drop on the UI thread must not
     block on a disk write). `ServiceInner` stays alive while workers or handles hold it.
  13. **`IPreloadTarget` (W4-15a trait `pr_imaging::preload::target::PreloadTarget`).** W4-15a owns the trait; its shape is
     BLOCKING and differs from this service's inherent API, so the impl is an ADAPTER, not a pure delegation. It is NOT written in

## Open questions
1. **Default decoder.** C# defaults to `new WicDirectDecoder(codec, reader)` when neither `decoder` nor `decoderFactory` is given. That type is
   `pr_platform_win::wic` (W4-11c) and `pr-imaging` must stay OS-free (P-22), so the stub returns `Err(NoDecoder)` and the composition root
   (W8) always passes the factory. Alternative: a `default_decoder: Option<Arc<dyn Fn() -> Arc<dyn ImageDecoder>>>` hook. Recommended: keep
   the error (one explicit wiring, no hidden platform default); record `Different` only if a caller relies on the default (none at d92d6aae
   outside tests).
2. **`normalize_key_path`.** `evict_cached_path` must normalize exactly like `ImageCacheKey` (full path + `ToUpperInvariant`). W4-01a's stub
   keeps that private. Recommended: W4-01a exposes `pub fn normalize_key_path(path: &str) -> Result<String, PathError>` (and uses it
   itself); the lead adds it at wiring. Alternative: `ImageCacheKey::create_from_stat(path, Some(dummy stat), ..).path()`, a hack.
3. **Blank path in `try_get_cached_preview_path`.** C# `new FileInfo("")` throws `ArgumentException`, which the C# method does NOT catch (it
   escapes to the caller). Rust returns `None` for every key error. Recommended: accept (no caller passes a blank path; the PreloadScheduler
   uses catalog paths) and record it as a `// DIVERGENCE:` test comment; alternative: return `Result<Option<_>, CacheKeyError>`.
4. **PARITY row for `CacheCleared`.** No C# test covers the event; the new Rust tests above pin it. The lead may want an `I-07` note.
