## Semantics (C# is the spec)
Texts `text_fn(tr::<snake_case>)` (D-W8B5-802), pattern D-W8B5-803. `context` = `self.context.context()`.
1. **`key()`** `"Display"`. **`attach`** stores the context (nothing else).
2. **`declare`**: six groups in this order (the golden fixes every id). `ind` is the `indent_dlu` of `check`/`check_flow`, `w` the `width_dlu` of `edit`.
   | # | group title | controls in order |
   |---|---|---|
   | 1 | `settings_nav_display` | `show_info_overlay` = check(`settings_show_info_overlay_label`, 0); `show_file_info` = check(`settings_show_file_info_label`, 12); `show_folder_info` = check(`settings_show_folder_info_label`, 12); `font_size` = edit(`settings_info_overlay_font_size_label`, w 40).control; `show_zoom_indicator` = check(`settings_show_zoom_indicator_label`, 0) |
   | 2 | `settings_group_toolbar` | `toolbar_auto_hide` = check(`settings_toolbar_auto_hide_label`, 0); `toolbar_delay` = edit(`settings_toolbar_auto_hide_delay_label`, w 45).control; note(`settings_toolbar_auto_hide_hint`, aligned true); slider(`settings_toolbar_opacity_label`, `MIN_TOOLBAR_OPACITY_PERCENT`, `MAX_TOOLBAR_OPACITY_PERCENT`) -> `opacity` = `.slider`, `opacity_value` = `.value`; note(a provider that calls `SettingsPresenter::toolbar_opacity_hint(c)` inside `with_field_context`, true) |
   | 3 | `settings_group_info_overlay` | `info_auto_hide` = check(`settings_info_overlay_auto_hide_label`, 0); `info_delay` = edit(`settings_info_overlay_auto_hide_delay_label`, w 45).control; note(`settings_info_overlay_auto_hide_hint`, true) |
   | 4 | `settings_group_display_performance` | `loading_mode` = combo(`settings_loading_mode_label`, [`enum_loading_mode_fast`, `enum_loading_mode_preview`, `settings_loading_mode_original_with_hint`], 0).control; `scaling_quality` = combo(`settings_scaling_quality_label`, [`enum_scaling_quality_high_quality`, `enum_scaling_quality_linear`], 0).control |
   | 5 | `settings_group_exif` | `show_exif` = check(`settings_show_exif_info_label`, 0); note(`settings_group_exif_hint`, aligned false); `exif_checks` = check_flow([`settings_exif_field_file_name`, `_date_taken`, `_modified_date`, `_dimensions`, `_camera`, `_lens`, `_iso`, `_focal_length`, `_aperture`, `_shutter_speed`] (all with the prefix `settings_exif_field`), ind 12) |
   | 6 | `settings_group_title_bar` | note(`settings_group_title_bar_hint`, false); `title_checks` = check_flow([`settings_title_bar_field_folder_name`, `settings_title_bar_field_folder_path`, `settings_title_bar_field_index_count`, `settings_exif_field_file_name`, `settings_title_bar_field_file_size`, `settings_exif_field_dimensions`, `settings_exif_field_modified_date`, `settings_exif_field_date_taken`, `settings_exif_field_camera`, `settings_exif_field_lens`, `settings_exif_field_iso`, `settings_exif_field_focal_length`, `settings_exif_field_aperture`, `settings_exif_field_shutter_speed`], ind 0) |
   `declare` copies the ids and the two lists into the fields after the groups return.
3. **`load(state)`**, exactly this order: `set_checked(show_info_overlay, state.show_info_overlay)`; `set_checked(show_file_info, ..)`; `set_checked(show_folder_info, ..)`; `set_text(font_size, &state.info_overlay_font_size_text)`; `set_checked(show_zoom_indicator, ..)`; `set_checked(toolbar_auto_hide, ..)`; `set_text(toolbar_delay, &state.toolbar_auto_hide_delay_text)`; `set_checked(info_auto_hide, state.info_overlay_auto_hide)`; `set_text(info_delay, &state.info_overlay_auto_hide_delay_text)`; `set_slider_value(opacity, state.toolbar_opacity_value.round_ties_even() as i32)`; `set_combo_index(loading_mode, state.loading_mode_index)`; `set_combo_index(scaling_quality, state.scaling_quality_index)`; `set_checked(show_exif, state.show_exif_info)`; for each `(id, flag)` of `exif_checks` zip `EXIF_ORDER`: `set_checked(id, state.exif_info_fields.contains(flag))`; the same for `title_checks` and `TITLE_ORDER` with `state.title_bar_fields`; then `update_dependents()`; `update_opacity_value()`.
4. **`collect(state)`**: the mirror image, in the C# order: every check -> its `bool` field, edits -> the text fields, `state.toolbar_opacity_value = f64::from(slider_value(opacity))`, the two combo indices, `show_exif_info`; `exif` starts as `ExifInfoFields::NONE` and gets `exif.union(flag)` for each checked box (zip of `exif_checks` and `EXIF_ORDER`), then `state.exif_info_fields = exif`; the same for the title bar flags into `state.title_bar_fields`. Nothing else of `state` is touched.
5. **`on_command(id, n)`**: `n != BN_CLICKED` -> `false`. `id` in `{show_info_overlay, toolbar_auto_hide, info_auto_hide, show_exif}` -> `update_dependents()`, `true`. Otherwise `false`.
6. **`on_scroll(id)`**: `id == opacity` -> `update_opacity_value()`. **`on_language_changed()`** = `update_opacity_value()`. **`focus_target(field)`**: `InfoOverlayAutoHideDelay` -> `Some(info_delay)`, else `None`.
7. **`update_opacity_value()`**: `set_text(opacity_value, &with_field_context(|c| SettingsPresenter::toolbar_opacity_value_text(f64::from(slider_value(opacity)), c)))`.
8. **`update_dependents()`** (the call order is tested): `overlay = is_checked(show_info_overlay)`; `set_enabled(show_file_info, overlay)`; `set_enabled(show_folder_info, overlay)`; `set_enabled(toolbar_delay, is_checked(toolbar_auto_hide))`; `set_enabled(info_delay, is_checked(info_auto_hide))`; `exif = is_checked(show_exif)`; for each id of `exif_checks`: `set_enabled(id, exif)`. (The title bar checks are never disabled.)
9. **Accessors**: `ids()`, `exif_checks()`, `title_checks()` read the fields; both lists are empty before `declare`.
