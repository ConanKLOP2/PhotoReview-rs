## Required behavior

- Pipe name is `{prefix}.Forward.{UPPERCASE_SHA256_HEX(UTF8(mutex_name + "|" + SID + "|" + session_id))}`.
- Pipe security has a protected DACL with exactly one allow rule: current user SID with full control. Do not grant access
  through inherited entries or to other users/sessions.
- This class defines the paired pipe identity/security contract used by W6-03c/d; it does not accept requests or perform I/O.
- No behavior choice is unresolved in the C# baseline. If Rust APIs cannot express the exact DACL, preserve an equivalent
  current-user-only ACL and document the platform API mapping for review before widening access.

## Concurrency and safety

- ACL tests touch only a uniquely named test pipe, never user files or the Recycle Bin. Do not use the production pipe
  name in native tests. Native Windows checks must be `#[ignore = "native: ..."]` and bounded.
- Tests must inspect actual pipe security where supported, not merely assert that helper construction succeeds.
- Mutations expected to be killed: hash input order/delimiters, session/SID inclusion, prefix placement, inherited ACL
  protection, SID selection, and access mask/type.
- Gates: `cargo fmt --all --check`; `cargo clippy -p pr-platform-win --all-targets -- -D warnings`;
  `cargo test -p pr-platform-win`; final integration uses the workspace gates.
