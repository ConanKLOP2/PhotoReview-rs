# W6-04: Windows display clock (split under P-18)

The 323-line C# source `src/PhotoReview.Platform.Windows/WindowsDisplayClock.cs` contains three separable types. The
port is split into two implementation contracts:

- [W6-04a](W6-04a.md) owns the `WindowsDisplayClock` worker and deterministic fake-driven behavior tests.
- [W6-04b](W6-04b.md) owns `IVBlankDriver` and `NativeVBlankDriver`, including native D3DKMT/DWM calls and ABI tests.

Dependency: W6-04a consumes the driver interface from W6-04b; W6-04b is independently implementable on the existing
Core display abstractions. The split keeps unsafe platform calls out of the worker state machine and allows both
contracts to stay below the P-18 unit-size target. `DisplayTiming`, `DisplayClock`, and `VBlankEstimator` remain owned
by Core. PARITY row P-11 is updated by the integrator in the implementation change.
