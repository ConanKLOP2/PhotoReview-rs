## Semantics (C# is the spec)
1. **`ShellLaunch::parse(args, fs, log)`**, in this order: `smoke = args.iter().any(|a| a.as_ref() == "--smoke")` (exact, case-sensitive: `--SMOKE` is a path); `rest` = the other arguments in order (every `--smoke` is dropped, also a second one); `arguments` = for each of `rest`, `launch_args::normalize_one(fs, arg)` (same order and count; the empty and whitespace arguments stay as they are, W8-04d rule 1). A `PathError` keeps the raw argument and is counted; after the loop, if any failed, ONE `log.warn("Launch arguments could not be normalised and were kept as given: {count}")` (W8-04d open question 3). `initial_file` = the first `arguments` entry with `fs.file_exists`; `initial_folder` = the first with `fs.directory_exists`; `launch_folder` = with a file: `get_directory_name(&get_full_path(file))` (`get_full_path` failing: `get_directory_name(file)`, may be `None`), without: `initial_folder.clone()`. `existing_paths` = every `arguments` entry for which `file_exists || directory_exists`, mapped by `get_full_path` (a failing one keeps the entry as it is). `initial_path()` = `initial_file` else `initial_folder`.
2. **`ErrorDetails::from_error(error)`**: `type_name` `"std::io::Error"` when `error.downcast_ref::<io::Error>()` else `"Error"`; `hresult`: an `io::Error` with `raw_os_error() = Some(code)` gives `HRESULT_FROM_WIN32(code)` = `code` when `code <= 0` else `((code & 0xFFFF) | 0x8007_0000) as i32`, anything else `E_FAIL` (`0x8000_4005u32 as i32`); `message = error.to_string()`; `stack` = `Backtrace::force_capture().to_string()` split on `'\n'`, entries that are empty removed; `inner` = `error.source()` as `("Error", source.to_string())`.
3. **`format(utc_now, context, details)`** returns, with every line ended by `"\r\n"` (C# `AppendLine` on Windows): line 1 = `{timestamp} [{context}] {type_name} 0x{hresult as u32:08X}: {message}` where `timestamp` = the first 19 characters of `utc_now.to_json()` + `"Z"` (the C# format `yyyy-MM-dd'T'HH:mm:ss'Z'`, invariant culture, no fraction) and `message` = `details.message` with every line ending replaced by ONE space (.NET `ReplaceLineEndings(" ")`: `"\r\n"`, `"\n"`, `"\r"`, `\u{0C}`, `\u{85}`, `\u{2028}`, `\u{2029}`, each as one unit, `"\r\n"` as ONE) and then cut to at most 300 UTF-16 code units (a cut that falls between the two units of a surrogate pair writes `U+FFFD` for the lone unit: the C# `UTF8Encoding(false)` replacement); then, for the first 12 entries of `details.stack` (the C# `frames++ >= MaxStackFrames` check runs before each append): `"    "` + the entry TRIMMED of white space (an entry that is only `"\r"` is NOT removed: it trims to the empty string and prints `"    "`, the C# `RemoveEmptyEntries` ran before the trim); then, when `inner` is `Some`: `"  inner: {type_name}: {message}"` with the inner message line-ending-replaced and cut to `min(300, len)` the same way.
4. **`append_at(path, context, details, max_bytes, utc_now)`**: under the process-wide gate: create the parent folder when `path` has a non-empty parent; `if path.is_file() && len > max_bytes { truncate(path, max_bytes) }` (C# `File.Exists` is false for a directory); append `format(utc_now, ..)` as UTF-8 without BOM (`OpenOptions::append(true).create(true)`). Every `io::Error` is swallowed (the C# catches `IOException`, `UnauthorizedAccessException`, `ArgumentException` and `NotSupportedException`: the four map to `io::Error`; an invalid path in Rust is an `io::Error`). `truncate`: read all bytes; `keep = min(len, max_bytes / 2)`; `start = len - keep`; `while start < len && start > 0 && bytes[start - 1] != b'\n' { start += 1 }` (the C# `all[start - 1]` has no `start > 0` guard, which only matters for `max_bytes` below 2; the Rust guard stops at 0); write `bytes[start..]` back (`fs::write`). `append` = `append_at(.., DateTimeUtc::now())`.
5. **`configure`/`current_path`/`report`**: one `static` `Mutex<Option<PathBuf>>` (poison recovered with `PoisonError::into_inner`, never `unwrap`); `report_details` copies the path out under the lock, drops the guard, then calls `append` only when it is `Some` (so a slow disk never holds the gate while another thread configures). `append_at` takes the SAME gate for the file work (a second `Mutex<()>`, not the path mutex, so `report` can call it without a deadlock: D-W8B6-3).
6. **`ForwardedOpenHandler::handle(path)`**, in this order: `target.is_closing_or_closed()` -> `ignored += 1`, return (nothing else is called); then `is_minimized()?` / `restore()?` / `activate()?` as one block: an `Err(WindowGone)` anywhere in it -> `ignored += 1`, `log.warn(&format!("Forwarded launch: could not activate the main window: {}", error.message))`, return (the open does NOT happen); then `path == None` -> done; `Some(p)` -> `target.open_path(p)`: `Err(e)` -> `log.error("Forwarded open failed", Some(&*e))`.
7. **`ForwardedOpenRouter`** (C# `ShellStartup.OnForwardedOpen` and its three fields): `on_forwarded_open(path)`: with a handler -> `handler.handle(path.as_deref())`; without -> `pending`: `None` -> `Some(path)`; `Some(existing)` -> `existing` keeps its value unless it is `None`, then it takes `path` (`_pendingForwardPath ??= path`). `take_pending()` returns and clears `pending`. `attach_to_current_thread(self: &Rc<Self>)` stores a `Weak<ForwardedOpenRouter>` in a `thread_local!` of the CALLING thread; `deliver_on_current_thread(path)` upgrades it and calls `on_forwarded_open`; nothing when absent or dropped.
8. **`ui_open_callback(ui)`** returns `Arc::new(move |path: Option<String>| ui.post(Box::new(move || ForwardedOpenRouter::deliver_on_current_thread(path))))`. It runs on the coalescer's worker thread and NEVER touches the router directly (the router is `Rc`, `!Send`); the posted job runs on the UI thread, where the router was attached. `new_forward_coalescer(ui, log)` = `Arc::new(ForwardedOpenCoalescer::new(ui_open_callback(ui), FORWARD_COALESCE_WINDOW, Some(log), None, None))`; 17d passes `move |paths| coalescer.submit(paths)` to `InstanceScope::with_options`.
9. **`StartupTask`**: `spawn` uses `thread::Builder::new().name(name)`; an `Err` from `spawn` leaves `handle = None`; `join` = `handle?.join().ok()`.
10. **`ensure_per_monitor_v2(native)`**: `native = native.unwrap_or(&NativeDpiAwareness)`; `match api.is_per_monitor_v2() { Err(_) => false, Ok(true) => true, Ok(false) => match api.try_set_per_monitor_v2() { Err(_) => false, Ok(true) => api.is_per_monitor_v2().unwrap_or(false), Ok(false) => false } }`. `NativeDpiAwareness::is_per_monitor_v2` = `Ok(are_dpi_awareness_contexts_equal(user32::get_thread_dpi_awareness_context(), -4))`; `try_set_per_monitor_v2` = `Ok(set_process_dpi_awareness_context(-4).is_ok())` (`ERROR_ACCESS_DENIED` when already set is `false`, as in C#).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (hand-off): the coalescer callback runs on a worker thread; the router is `Rc`. The ONLY thing that crosses is `Option<String>` inside a `Send` job; test `ui_open_callback_posts_to_the_ui_scheduler_and_never_runs_inline` uses a recording scheduler and asserts that nothing ran before the recorded job is run.
- T2 (re-entrancy): `handle` calls into the window (`activate` may pump messages); no `RefCell` borrow of the router is held across `handler.handle`; `on_forwarded_open` clones the `Rc<ForwardedOpenHandler>` out of its cell first.
- T3 (error log never fails and never holds the gate across a slow call): see semantics 4 and 5; `format` allocates but never panics (no indexing: use `char_indices`/`encode_utf16`).
- T4 (line endings): the file is CRLF; `format` uses `"\r\n"` literally, not `\n`, so the golden text matches byte for byte.
- T5 (timestamp): `DateTimeUtc::to_json()` is `yyyy-MM-ddTHH:mm:ss[.fffffff]Z`; take the first 19 characters, NOT a trimmed fraction; a value at exactly a full second has no fraction and the 19 characters are still the date and time.
- T6 (smoke flag): exact ordinal match; a path argument that merely contains `--smoke` is a path.
- T7 (no panic on the UI thread): `parse`, `handle`, `on_forwarded_open` use no `unwrap`/`expect`; a poisoned lock is recovered.
- T8 (process-wide state in tests): `error_log::configure` (static), the current directory, `SetProcessDpiAwarenessContext`: each gets the guard or the own-executable rule above; no test sleeps or polls.

## Safety rules (`// SAFETY:` per `unsafe` block)
No `unsafe` in `pr-app`. `NativeDpiAwareness` only calls the safe wrappers `win32::startup::{set_process_dpi_awareness_context, are_dpi_awareness_contexts_equal}` and `win32::api::user32::get_thread_dpi_awareness_context` (their blocks already carry SAFETY): no new `unsafe` block is expected.

## Error mapping
| C# | Rust |
|---|---|
| `EntryPointNotFoundException`/`DllNotFoundException` in the DPI bootstrap | `Err(DpiApiMissing)` from the seam -> `false` |
| `InvalidOperationException` from `Restore`/`Activate`/`IsMinimized` | `Err(WindowGone)` -> warning, `ignored += 1` |
| exception from `OpenPathAsync` (not OOM) | `Err(Box<dyn Error>)` -> `log.error("Forwarded open failed", ..)` |
| `Path.GetFullPath` failing in `ShellLaunch` | the raw argument is kept; one warning (semantics 1) |
| `IOException` etc. in `ShellErrorLog.Append` | swallowed |
