## Semantics (W5-12b1)
1. **Construction.** `RawDecoderOptions::default()` = C# defaults: `PhysicalSourceReader`, `RawContainerReaderRegistry::new()`, no cache, no
   fallbacks, `EnglishRawDecoderTexts`. The container cache is `BoundedLruCache::new(CONTAINER_INFO_CACHE_CAPACITY, |_| 1)`; the `Err`
   is impossible for a positive constant: `expect("positive constant capacity")` is allowed here (no fs/user data) with a one-line comment.
2. **Blank paths.** `decode` with a blank `request.path` (`to_string_lossy`, all `char::is_whitespace` or empty) and `read_info("")`
   => `InvalidArgument` (.NET `ThrowIfNullOrWhiteSpace` text, param `request.Path` / `path`). Nothing is opened.
3. **`get_container_info(path, priority)`** in this exact order (C# comment: a file replaced at any point must never get its old
   identity cached for new bytes):
   a. `before = stat_file(path)` (`exists`, `stat_length`, `ticks`; not existing => length -1, ticks 0, no stat checks later);
   b. `SourceRawHeaderSource::open(Path::new(path), &*source_reader, priority)` (W5-12a takes `&Path`): its `io::Error` propagates as `DecodeError::from` (NotFound =>
      `FileNotFound`), NOT localized (C# constructor is outside the `try`);
   c. from here every error drops the header source (C# `catch { Dispose; throw; }`; Rust: it is a local, dropped on `?`);
   d. `exists && source.length() != stat_length` => changed-while-reading;
   e. `key = RawInfoKey { normalize_key_path(path)?, source.length(), ticks }` (`PathError` => `InvalidArgument`);
   f. cache hit => `throw_if_stat_changed` then return it (the header source is still open and returned: a hit costs one open, zero reads);
   g. miss: probe = `source.read(0, initial_probe_length(len))`; `find_reader(probe, get_extension(path))` (`pr_core::catalog::types::get_extension`,
      with the dot) - copy the probe out first (the borrow ends before `read`); none => `NotSupported` `"Unsupported RAW format: {ext}"`
      localized `raw_unsupported`; `reader.read(&mut source, &CancelToken::new())` (C# passes `CancellationToken.None`);
      reader `InvalidData` => localized `raw_corrupt`;
   h. `throw_if_stat_changed`, then `set(key, CachedRaw { info, exif: None, exif_read: false })`.
   **I/O unwrap (C# outer catch):** any `RawHeaderError::InvalidData { io: Some(e) }` raised in d-h (probe read or the reader) becomes
   `DecodeError::from(e)` - the real disk/share error, not "corrupt" (test `Decode_HeaderIoFailure_*`: same kind and message). Other
   header errors: `header_error_to_decode_error`.
4. **`read_info`:** lookup with `Viewer`; sensor size if both sides > 0, else `select_preview_resolved(source, previews, DecodeBox::UNBOUNDED,
   orientation)` + `remember_resolved_previews`, and the chosen preview's size if both sides > 0; else `InvalidData`
   `"RAW file declares no image size (no sensor size and no sized preview): {path}"` localized `raw_corrupt`. Returns
   `ImageInfo::with_orientation(w, h, info.orientation)`. A preview-walk I/O failure propagates as `InvalidData` (C# keeps the type here).
5. **`decode` composition** (C# `Decode`, keep the order):
   a. lookup with `request.priority`;
   b. EXIF: if `cached.exif_read` use `cached.exif`, else `try_read_exif(&mut source, &info)` (W5-11c `RawExifRead { summary, complete }`); when `complete`, store
      `CachedRaw { exif, exif_read: true, ..}` (`set`) - an incomplete read is never remembered;
   c. `select_preview_resolved(source, previews, request.decode_box(), orientation)` (W5-11b `PreviewSelection { chosen, resolved_previews }`), `remember_resolved_previews`, `info` = the entry's info;
   d. `chosen` is `None` or `length <= 0`: no preview fallback and no full decoder => `InvalidData` `"No embedded preview found in RAW file: {path}"`
      localized `raw_no_preview`; else `decode_without_preview` (12b2). Otherwise `decode_preview_with_fallbacks(request, &info, &key, &mut source, chosen)` (12b2);
   e. sensor = container size; if either side <= 0 => the decoded image's `original_width/height`; else if `request.apply_orientation &&
      is_transposed(info.orientation)` => swapped (stored vs visual size);
   f. `tiny = from_jpeg_preview && max(original_w, original_h) <= MAX_THUMBNAIL_LONG_SIDE`;
      `downscaled = image.downscaled() || tiny || pixel_w < sensor_w || pixel_h < sensor_h`;
   g. `source_bytes_read = if from_jpeg_preview || full <= 0 { header.total_bytes_read() + preview + fallback } else { full + preview }`
      with `checked_add` (overflow => `DecodeError::Overflow`, C# `checked`);
   h. wrapper: orientation = `info.orientation`; exif = container exif else `image.exif().cloned()`; backend = `image.actual_backend()`;
      embedded preview size = the image's `original_*` when `from_jpeg_preview`, else `(0, 0)`; degraded = `outcome.degraded || image.is_degraded_fallback()`;
      pixel size, estimated bytes and platform image delegate to the inner image.
6. **`decode_preview`:** `length > MAX_PREVIEW_BYTES` (compare in `i64`) => `InvalidData` "Embedded preview is too large: {len} bytes (limit
   134217728)." BEFORE any open or allocation; fresh `stat_file`: exists and (length != key.length or ticks != key.ticks) => `remove(key)` then
   changed-while-reading; cache path only when a cache exists, the file exists and `can_cache_range(len)`: `try_get_range(path, stat_len,
   stat_ticks, offset, len as i32)` hit => bytes, read count 0; miss => `get_or_read_range(..., priority)`, read count = len; else
   `read_preview_range(path, offset, len as i32, key.length, priority)`, read count = len. `AdobeRgb` => `ensure_adobe_rgb_profile(bytes.to_vec())`
   (copy only on this path; `Arc<[u8]>` otherwise). Every `InvalidData` of this block that is not localized gets `raw_corrupt`
   (cap, ICC "Adobe RGB preview is not a valid JPEG stream."). Inner request: `DecodeRequest { path, target_width/height = request box,
   apply_orientation, bytes: Some(preview), priority, source_orientation: Some(info.orientation) }`; the inner error is returned untouched.
7. **`read_preview_range`:** open via `source_reader.open_source(path, priority, SOURCE_READ_BUFFER_SIZE)` (W4-10a's 1 MiB constant = the C# default);
   C# order: length by `seek(End(0))`; `length != expected` => changed-while-reading (cache entry NOT removed here, unlike step 6); range check in
   `i64` without overflow (`count < 0 || offset < 0 || offset > length - count`) => `Io(UnexpectedEof)` "Embedded preview range is outside {path}";
   only then allocate and seek to `offset` (seeking first would turn a negative offset into a seek `InvalidInput` error); read loop until full
   or `Ok(0)` (`ErrorKind::Interrupted` retried, other read errors propagate as `Io`); short => `Io(UnexpectedEof)` "Truncated embedded preview in {path}".
8. **Changed while reading:** `DecodeError::Io(io::Error::other("RAW source changed while reading: {path}"))` + `file_changed_while_reading(path)`.
   This error is always `Io`, never `FileNotFound`, also when the re-stat finds the file gone (test `Decode_FileRemovedWhile...`: "exactly
   IOException"). A file that vanishes AFTER the container read is different: step 6 skips the identity check (`exists` false) and the
   preview open's `NotFound` surfaces as `FileNotFound` (C# `FileNotFoundException`, non-recoverable for 12b2).
9. **Messages** keep the C# text with the caller's path as given (no normalisation); goldens compare them with the path replaced by `{path}`.

## Semantics (W5-12b2)
1. **Classification** (C# whitelist, NOT W4-12b's `is_fallbackable`): see the doc comments in `fallback.rs`. `Io`, `FileNotFound`, `Canceled`,
   `OutOfMemory`, `Busy`, `MemoryAdmission`, `InvalidCast`, `Overflow`, `DllNotFound`, ... are NOT recoverable. `MissingCodec` IS (subclass of
   `NotSupportedException`). Classify `error.kind()` (wrappers transparent). HRESULTs compare as `u32` (`hresult as u32`).
2. **Fallback chain** (`decode_preview_with_fallbacks`): `tried: Vec<i64>` of offsets; `failed_bytes += min(len, MAX_PREVIEW_BYTES)` per
   failed attempt; `largest_failed_long_side = max(..)`; the next candidate comes from `next_preview_candidates` then
   `preview_selector::select_preview(header, &candidates, request box, orientation)` (its I/O error propagates). The next candidate is selected
   after EVERY recoverable failure, the 4th included, before the `tried.len() < MAX_PREVIEW_ATTEMPTS` test ends the loop (C# order: those header
   reads count in `total_bytes_read`, which the ORF-thumbnail and no-physical-file byte counts include); success after a failure =>
   `degraded_fallback = tried.len() > 1`, `preview_bytes_read = read + failed_bytes`. A non-recoverable failure leaves at once (no ORF, no full decode).
3. **ORF thumbnail step**: only `info.format == Orf`, a fallback present and the LAST failure `is_not_supported()`. Request = the caller's box,
   orientation flag and priority with `source_orientation = info.orientation`. Invalid size text = `raw_corrupt`. Success => `degraded = true`,
   `preview_bytes_read = failed_bytes`, `fallback_thumbnail_bytes_read = thumbnail len`. Recoverable failure => swallowed, counter back to 0;
   non-recoverable => propagates (the thumbnail's own error, test `..._ThePropagatedFailureIsTheThumbnailsOwn`).
4. **Full decode**: `no_preview_decoder.decode(request)` with the CALLER's request; `full_decode_bytes_read = stat_file length or 0`,
   `preview_bytes_read = failed_bytes`, `from_jpeg_preview = false`. No full decoder => `Err(first_failure)` (the first recoverable failure, moved;
   C# `ExceptionDispatchInfo.Throw`).
5. **No-preview path** (`decode_without_preview`): thumbnail first when a fallback exists (invalid size text = `raw_no_preview`); its recoverable
   failure falls through ONLY if a full decoder exists; then the full decode; returned counters already moved (semantics W5-12b1 5g).

## Traps checklist
- §7.3 integer widths: `EmbeddedPreview.length` is `i64`; the cap check precedes every `as i32`; byte counters `checked_add`; no `as usize` on an
  unchecked `i64`; negative offsets are data, never a panic (golden `range-negative-offset`).
- §7.9 every C# `catch ... when` is a branch: reader `InvalidData` (localize) / outer I/O unwrap / catch-all drop in `get_container_info`;
  the `DecodePreview` localize catch; the two `when IsRecoverable` catches; the no-preview catch with `_noPreviewDecoder is not null &&`.
- §7.8 `None` vs empty: C# `Bytes = ReadOnlyMemory.Empty` for the thumbnail request is overwritten by the thumbnail; inner requests always carry
  `Some(bytes)`; the full decode gets the caller's request (its `bytes` as given).
- §7.1 the cache key is `normalize_key_path` (full path, upper-invariant), not `to_uppercase` of the raw string; extension match in fakes is
  OrdinalIgnoreCase.
- §7.10 `tried` and candidate lists keep input order (`Vec`); no `HashMap` anywhere in the decision path.
- INV-1: a degraded answer must say so (`is_degraded_fallback`), the service never caches it; identity checks before every preview read.
- INV-8: the preview handle is closed before the inner decode; the header handle at the end of `decode` (C# `using` spans the inner decode too).
- `EmbeddedPreview` is `Clone` in W5-01b and `Copy` in W5-01a: write `.clone()` only where the type is not `Copy` at merge time (clippy
  `clone_on_copy` is a hard error under `-D warnings`); the stub signatures take `&EmbeddedPreview` / owned values to work with both.
- Never panic on hostile input (C# hardening): no `unwrap`/`expect` except the constant-capacity cache; no indexing without a bounds check.
- `RawHeaderSource::read` borrows the source: copy the probe (`to_vec`) before calling `find_reader`/`read`.
- A cache HIT still opens the header source once (C# constructs `SourceRawHeaderSource` before the lookup): golden `opens` pins it.
- `read_info` uses `Viewer`; `decode` uses `request.priority` for both opens.
- 12b2: keep `first_failure` by value and only a `last_is_not_supported: bool` for the ORF test; never clone a `DecodeError` (not `Clone`).

## Open questions
1. **Inner COM HRESULT (`IsRecoverablePreviewFailure`/`IsCorruptDataFailure` look at `ex.InnerException is COMException`).** The Rust
   `DecodeError` has no inner-exception slot; W4-11c's `icc_transform_failed(os_message)` keeps only the text, so a resource-exhausted ICC
   transform (E_OUTOFMEMORY wrapped in `NotSupported`) would be treated as recoverable and a SMALLER preview could be shown and cached.
   Options: **A (recommended)** add a transparent wrapper `DecodeError::WithInner { error: Box<DecodeError>, inner: Box<DecodeError> }` (or a field
   `inner_hresult: Option<i32>` on `NotSupported`) with `inner_com_hresult()`, and make W4-11c pass the COM error into `icc_transform_failed`;
   pros: exact C# parity, 3 C# tests portable; cons: touches merged W4-01c/W4-11c (small, additive). **B** accept the divergence (`Different`
   row, 3 golden cases skipped for good); pros: no change; cons: a transient OOM can degrade to a thumbnail. **C** map the ICC failure to
   `Com { hresult }` instead of `NotSupported`; cons: changes W4-12b fallback behaviour. Until decided `inner_com_hresult` returns `None`.
2. **Sibling APIs** (names in `mod-lines.txt`, signatures in `compile-check/src/lib.rs`, aligned at review with the W5-11b, W5-11c and W5-12a
   drafts): `preview_selector::select_preview_resolved -> Result<PreviewSelection { chosen, resolved_previews }, RawHeaderError>`,

   SourceReadPriority) -> io::Result<Self>` + `total_bytes_read()`, module names `registry`/`header_source`/`preview_selector`/`raw_exif`, and
   W5-01b's `RawHeaderError` enum (W5-01a drafts a different struct of the same name; the lead keeps one). The wiring step re-checks them
   against the merged stubs (D28).
2b. **W5-01b `RawPreviewFallback` doc** says the decoder classifies thumbnail errors "with the W4-12b whitelist". That is wrong for C#
   `RawDecoder` (its own `IsRecoverablePreviewFailure` whitelist, Semantics W5-12b2 1: `InvalidCast`/`Overflow`/`DllNotFound` are NOT recoverable
