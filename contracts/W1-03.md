## Semantics notes

* Values (persisted; numbers are accepted when reading config.json): `TitleBarFields`: None 0, FolderName 1, FolderPath 2, IndexCount 4, FileName 8, FileSize 16,
  Dimensions 32, ModifiedDate 64, DateTaken 128, Camera 256, Lens 512, Iso 1024, FocalLength 2048, Aperture 4096, ShutterSpeed 8192, All 16383, Default = FolderName = 1.
  `ExifInfoFields`: None 0, FileName 1, DateTaken 2, Dimensions 4, Camera 8, Lens 16, Iso 32, FocalLength 64, Aperture 128, ShutterSpeed 256, ModifiedDate 512,
  All 1023, Default = All minus (FileName, Dimensions, ModifiedDate) = 506 = DateTaken | Camera | Lens | Iso | FocalLength | Aperture | ShutterSpeed.
  Note the two types use different bit positions for the same names (`FileName` is 8 in the title bar and 1 in the EXIF line; `Camera` 256 vs 8).
* `Default::default()` is the C# `Default` alias, not C# `default(T)` (which is `NONE`). `AppSettings` and the JSON fallback use `Default`.
* The JSON text and the leniency rules are W1-02's (`deserialize_flags`, `format_flags`). Summary only: written as `"A, B"` in ascending bit order or `"None"`, never
  `All`/`Default`; read accepts names (any case, comma separated, unknown dropped), numbers (non-negative, unknown bits stripped, negative unreadable) and falls back to
  `Default` for unreadable input.
* `contains(other)` is `HasFlag`: `self & other == other` (so `contains(NONE)` is true). `difference(other)` is `self & !other`.
* No `Not` operator is provided on purpose (C# `~x` is a 32-bit complement; use `difference`).
