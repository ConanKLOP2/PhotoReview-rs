## Semantics (C# is the spec)
1. **`NativeTaskDialogPort::show`**: if `!comctl::task_dialog::is_available()` then `last_failure = "TaskDialogIndirect is missing (comctl32 v5)"` and return `IDCANCEL` (the EntryPointNotFound branch). Else build `TASKDIALOGCONFIG` with `new_task_dialog_config()` (sets `cbSize`, 160): `hwndParent = owner`, `dwFlags = TDF_ALLOW_DIALOG_CANCELLATION`, `dwCommonButtons = common_buttons(kind)`, `pszWindowTitle` and `pszContent` pointing into two `to_utf16z` buffers (locals that outlive the call; an embedded NUL ends the text early, as in C#), the main icon `main_icon(kind)` as `MAKEINTRESOURCE` (the 16-bit value as the pointer, 0 for none), `pfCallback = on_callback`, `lpCallbackData = self as *const Self as isize` (the address of the port itself, NOT of the `&self` reference; `show` is on the stack for the whole synchronous call, which replaces the C# `GCHandle`). `last_failure` is reset to `None` at the start of each `show` (deliberate difference: the C# property documents "null if it showed normally" but never clears it). `task_dialog_indirect(&config)`: `Ok(r)` -> `r.button`; `Err(hr)` -> `last_failure = hr.to_string()` (`"HRESULT 0x........"`, uppercase hex, 8 digits) and `IDCANCEL`. The struct is `packed(1)`: assign fields, never take a reference to one.
2. **`on_callback`** (`extern "system"`, `TDN_CREATED` only): reads the port through the data pointer, calls the hook inside `pending_panic::guarded(HRESULT(0), AssertUnwindSafe(|| ..))` (`guarded` needs `UnwindSafe`; the closure borrows the port, which holds a `RefCell` and a `dyn Fn`, so `AssertUnwindSafe` is required) and returns `S_OK` (`HRESULT(0)`) for every notification. After `task_dialog_indirect` returns, `pending_panic::rethrow_pending()` resumes a panic raised by the hook (D-W8B5-6; the C# swallowed it, the Rust hook is test-only and a panic in it is a test bug that must not vanish).
3. **`common_buttons`** and **`main_icon`**: the table in the C# summary (`Confirmation` = `TDCBF_YES_BUTTON | TDCBF_NO_BUTTON` = 6; `Information`/`Error` = `TDCBF_OK_BUTTON` = 1; icons `Information` -> `0xFFFD`, `Error` -> `0xFFFF` WARNING (the WPF `ShowError` used `MessageBoxImage.Warning`), `Confirmation` -> `0`).
4. **`Win32DialogService`**: `show_confirmation` = `task_dialogs.show(owner(), title, message, Confirmation) == IDYES` (only Yes: No, Cancel, X, Esc, Alt+F4 are `false`); `show_message` and `show_error` ignore the result. `pick_folder(initial)`: `title = localizer().get(keys::DIALOG_PICK_FOLDER_TITLE)` evaluated at call time; `initial` becomes `&str` with `Path::to_str` (a path that is not valid Unicode is `None`); `folder_picker.pick(&title, initial)`: `Ok(Some(text))` -> `Some(PathBuf::from(text))`, `Ok(None)` -> `None`, `Err(hr)` -> `log.error("Folder dialog failed", Some(&hr))` (when a log was given) and `None` (D-W8B5-2). The default localizer closure is `Localizer::current`.
5. **Secondary calls**: `port = secondary.get()` (lazy, once, the SAME `Rc<LazySecondaryPort>` as the zoom service). With a port: `port.show_x(owner(), ...)` where `owner()` is read at call time; without a port: `show_batch_review`/`show_settings`/`show_settings_at` return `false`, the others do nothing (D-W8B5-3; no fallback). `show_settings()` = `show_settings_at(SettingsTarget::Default)`. `show_benchmark(folder)` passes `Option<&Path>` through. `show_batch_review_paths(paths)` builds `BatchReviewItem { path, length: None }` per path and calls `show_batch_review`. NO RefCell borrow or other lock is held while the port runs a modal dialog.
6. **`LazySecondaryPort`**: the factory is taken out of its slot BEFORE it runs (`self.factory.borrow_mut().take()`, borrow released at the end of that statement). The answer is stored with `OnceCell::set`, NEVER with `get_or_init`: `get_or_init` panics on a re-entrant initialisation, which would be a panic on the UI thread. After the factory returned, `set` is tried and its `Err` (already set by a re-entrant call that cannot happen) is ignored (so a re-entrant `get` finds the slot empty and the value unset -> returns `None` without running the factory twice), the answer (port or `None`) is stored once and every later `get` returns a clone of it. `is_value_created` is true after the first completed `get` or after `from_value`. The Rust factory cannot fail (D-W8B5-3: the C# catch was for the WPF bridge load).
7. **`Win32ZoomPromptService::prompt_custom_zoom(p)`**: `secondary.get()` -> `None` gives `None`; `Some(port)` -> `port.prompt_custom_zoom(owner(), p)` (owner read at call time). No other filtering (the C# `catch` of load exceptions has no Rust twin).
8. **`SecondaryWindowPortHost::dispose`**: if `port.is_value_created()` then `if let Some(p) = port.get() { p.dispose() }`; otherwise nothing, and the factory is NEVER run by `dispose`. Calling it twice calls `dispose` on the port twice (the router's own dispose is idempotent; C# had the same).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (modal loops): `TaskDialogIndirect` and every port call run a nested message loop on the UI thread. The window procedure still runs (D-W8B3H-4/-8): no `RefCell` borrow, no `Cell` guard and no dispatcher lock is held across `task_dialogs.show` or a port call. `LazySecondaryPort` releases its factory borrow before running it.
- T2 (HWND lifetime): the owner may be destroyed while the factory runs; `owner()` returns 0 for a destroyed window (the closure's rule) and a task dialog with owner 0 still works (top-level).
- T3 (packed struct): `TASKDIALOGCONFIG` is `#[repr(C, packed(1))]` in windows-rs: no `&config.field`, no `println!("{:?}", config)`, build it by value; the size assert (160) exists in `structs.rs`.
- T4 (icon values): the C# passes the sign-extended `nint` -3/-1; the documented form (`MAKEINTRESOURCEW(-3)`) is the 16-bit value (comctl.rs note, D-W8B3-2). Use `main_icon` (`task_dialog_indirect` is `unsafe fn`: its SAFETY comment is the one in the rules below; `user32::post_message` of the native test is `unsafe fn` too) as the `PCWSTR` integer; the native test checks that an Information box still opens.
- T5 (strings, trap 8): `None`/empty handling of the folder: `pick_folder(None)` and `Some("")` both reach `FolderPicker` and become "no initial folder". Titles and messages are `&str`, converted with `to_utf16z` once per call; do not keep the buffers longer than the call.
- T6 (R0003): no `unwrap`/`expect`/`panic` on the UI thread. `TaskDialogIndirect` failing is a value (`IDCANCEL` + `last_failure`), not an error return; the service never throws.
- T7 (activation context): the comctl32 v6 manifest comes from the exe (W8-20a); in tests a process without it has no `TaskDialogIndirect`, so the native test activates the manifest through `ActivationScope` on its own thread and every pure test uses the fake port.
- T8 (localization, D-W8-4): the only user-visible text of this unit is the pick-folder title (catalog `dialog.pickFolder.title`); titles and messages of confirmations come from the callers.
- T9 (callback data): the data pointer is only valid during the synchronous call; the callback must not store it. `NativeTaskDialogPort` is not `Sync`; `show` may be called again from the hook only by nesting (not supported, not tested).

## Safety rules (`// SAFETY:` per `unsafe` block)
- the `task_dialog_indirect(&config)` call: "every pointer in `config` (title, content, callback, callback data) points into locals or into `self`, all alive until the call returns; the icon is the 16-bit resource value";
- the callback `unsafe extern "system" fn`: "`data` is the address of the `NativeTaskDialogPort` that `show` passed; `show` is still on the stack (the call is synchronous), so the reference is valid for the duration of the callback; only shared access";
- reading the packed config fields: not done.

## Error mapping
| C# | Rust |
|---|---|
| `hr != 0` from `TaskDialogIndirect` | `last_failure = "HRESULT 0x........"`, result `IDCANCEL` |
| `EntryPointNotFoundException` | `is_available() == false` -> `last_failure = "TaskDialogIndirect is missing (comctl32 v5)"`, `IDCANCEL` |
| exception in `onCreated` (swallowed) | `pending_panic::guarded` + `rethrow_pending` (D-W8B5-6) |
| `Port()` catches a failing `Lazy` factory | unrepresentable (infallible factory) |
| `PromptCustomZoom` catches ObjectDisposed/FileNotFound/FileLoad/BadImageFormat | unrepresentable (no bridge) |
| `COMException` from `PickFolder` reaching the caller | `log.error` + `None` (D-W8B5-2) |
| `ArgumentNullException` of the zoom ctor | unrepresentable |
