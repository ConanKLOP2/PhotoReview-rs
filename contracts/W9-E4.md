## Semantics
- The path box is a legacy-compatible mirror of the DEFAULT editor: when the user types a path, saving moves/creates/removes the default editor through `ExternalEditors::apply_legacy_path` (E1); the dialog's list and the box never disagree after "Manage editors...".
- The summary line is localized per language change (`on_language_changed`); `settings.externalEditors.summary {count, name}` uses the default editor's `display_name()` (the first editor when the stored default is unknown; empty when none).
- "Send RAW" is a plain check box bound to `external_editor_sends_raw_original` (default checked).
- Save validation: the shortcut conflict check is the existing `validate_shortcuts` (E1/E7 add the new name; no new rule here).
