## C# source (baseline `d92d6aae`)
`src/PhotoReview.Shell.Win32/Dialogs/SettingsUi/SettingsPageBuilder.cs`, lines 1-307 (this unit does not touch lines 309-645). Read it with `git -C ../PhotoReview show d92d6aae:<path>`. All dimensions are pixels; `Dx(n)` / `Dy(n)` are dialog units (n) converted by the surface; every element returns the height it used INCLUDING the gap below it (0 when hidden). Formulas (the C# is the spec; `max`/`min`/`clamp` are `Math.*`; division truncates toward zero; `h` = height, `w` = width):
- `SettingsLayoutElement.Place(s, x, y, width)`: if `!Visible`, `s.Hide(id)` for every id of `ControlIds` in order and return 0; else `PlaceVisible`.
- `LabelWidth(s, width) = clamp(width * 38 / 100, Dx(80), Dx(140))`.
- **Group** (`pad = Dx(8)`, `top = LineHeight + Dy(5)`): `innerX = x + pad`, `innerWidth = max(Dx(40), width - 2*pad)`, `cursor = y + top`; for each child `cursor += child.Place(s, innerX, cursor, innerWidth)`; `cursor += Dy(2)`; `s.Place(titleId, x, y, width, cursor - y)`; returns `(cursor - y) + Dy(8)`. `ControlIds` = `[titleId] + children's ids`.
- **Check**: if `s.IsHidden(id)`: `Hide(id)`, 0. `indent = Dx(indentDlu)`, `textWidth = max(Dx(20), width - indent - Dx(14))`, `h = max(LineHeight + Dy(2), TextHeight(id, textWidth) + Dy(1))`, `Place(id, x + indent, y, width - indent, h)`, returns `h + Dy(4)`.
- **Row** (`widthDlu`): if `IsHidden(controlId)`: `Hide(label)`, `Hide(control)`, 0 (a hidden LABEL alone does not matter). `labelWidth = LabelWidth`, `gap = Dx(6)`, `controlX = x + labelWidth + gap`, `available = max(Dx(30), width - labelWidth - gap)`, `controlWidth = widthDlu > 0 ? min(available, Dx(widthDlu)) : min(available, Dx(240))`, `ch = FieldHeight`, `lh = TextHeight(label, labelWidth)`, `rowH = max(ch, lh)`; `Place(label, x, y + (rowH - lh)/2, labelWidth, lh)`; `windowH = kind == Combo ? ch + ComboDropHeight(control) : ch`; `Place(control, controlX, y + (rowH - ch)/2, controlWidth, windowH)`; returns `rowH + Dy(5)`.
- **Slider**: no hidden check. `labelWidth`, `gap = Dx(6)`, `sliderX = x + labelWidth + gap`, `valueWidth = max(Dx(34), max(TextWidth(TextOf(value)), TextWidth("100 %")) + Dx(6))`, `sliderWidth = clamp(width - labelWidth - gap - valueWidth - gap, Dx(60), Dx(150))`, `sliderH = max(FieldHeight, LineHeight + Dy(8))`, `lh = TextHeight(label, labelWidth)`, `rowH = max(sliderH, lh)`; `Place(label, x, y + (rowH-lh)/2, labelWidth, lh)`; `Place(slider, sliderX, y + (rowH-sliderH)/2, sliderWidth, sliderH)`; `vh = TextHeight(value, valueWidth)`; `Place(value, sliderX + sliderWidth + gap, y + (rowH-vh)/2, valueWidth, vh)`; returns `rowH + Dy(5)`. The literal `"100 %"` is a layout constant (not localized).
- **Text** (`aligned`): if `IsHidden(id) || TextOf(id).Length == 0`: `Hide(id)`, 0. `indent = aligned ? LabelWidth + Dx(6) : 0`, `textWidth = max(Dx(30), width - indent)`, `h = TextHeight(id, textWidth)`, `Place(id, x + indent, y, textWidth, h)`, returns `h + Dy(5)`.
- **Buttons** (`aligned`): `indent = aligned ? LabelWidth + Dx(6) : 0`, `left = x + indent`, `right = x + width`, `gap = Dx(6)`, `h = FieldHeight`, `cursorX = left`, `cursorY = y`, `any = false`; for each id: hidden -> `Hide(id)`, continue; `bw = max(Dx(50), TextWidth(TextOf(id)) + Dx(16))`; if `cursorX > left && cursorX + bw > right` { `cursorX = left`; `cursorY += h + Dy(4)` }; `Place(id, cursorX, cursorY, bw, h)`; `cursorX += bw + gap`; `any = true`. Returns `any ? (cursorY - y) + h + Dy(5) : 0`.
- **Radio** (`hintId?`, `indentDlu`): if `IsHidden(id)`: `Hide(id)`, `Hide(hint)` when there is one, 0 (a hidden HINT alone is still placed). `indent = Dx(indentDlu)`, `textWidth = max(Dx(20), width - indent - Dx(14))`, `h = max(LineHeight + Dy(2), TextHeight(id, textWidth) + Dy(1))`, `Place(id, x + indent, y, width - indent, h)`, `used = h + Dy(2)`; with a hint: `hintIndent = indent + Dx(12)`, `hintWidth = max(Dx(30), width - hintIndent)`, `hh = TextHeight(hint, hintWidth)`, `Place(hint, x + hintIndent, y + used, hintWidth, hh)`, `used += hh + Dy(2)`. Returns `used + Dy(4)`. `ControlIds` = `[id, hint]` or `[id]`.
- **CheckFlow** (`indentDlu`): no hidden check (a hidden item is still placed). `left = x + Dx(indentDlu)`, `right = x + width`, `gap = Dx(10)`, `h = LineHeight + Dy(2)`; for each id: `itemWidth = TextWidth(TextOf(id)) + Dx(16)`; if `cursorX > left && cursorX + itemWidth > right` { `cursorX = left`; `cursorY += h + Dy(4)` }; `Place(id, cursorX, cursorY, min(itemWidth, right - left), h)`; `cursorX += itemWidth + gap`. Returns `(cursorY - y) + h + Dy(5)` (an empty list still returns `h + Dy(5)`).

## Semantics (C# is the spec)
1. **Arithmetic** (D-W8B5-703): every `+`, `-`, `*` is `saturating_*` on `i32`; `/ 2`, `/ 100` are plain integer divisions (the operand is a saturated value, the divisor a constant); `clamp(v, lo, hi)` is `v.max(lo).min(hi)` (never `i32::clamp`, which panics when `lo > hi`; a surface with a negative scale can invert them); `max` and `min` are the `i32` methods. The tests include `i32::MAX` and `i32::MIN` widths and positions and expect no panic.
2. **Order of surface calls** is part of the contract (the golden records the sequence): in each element the `place`/`hide` calls are made in the order of the formulas above (for example Row: label first, then control; Group: children first, then the group box itself; Radio: radio, then hint).
3. **`place` (trait provided method)**: as C#; the hide loop uses `control_ids()` order (a group hides its title first, then its children; a hidden child inside a visible group is hidden through the child's own `place`, so a group with a `visible = false` child makes the child call `hide` for its ids and contributes 0).
4. **`GroupElement::place_visible`** calls `child.place(...)` (the trait method), not `place_visible`, so the child's `visible` flag is honoured; `children_mut()` is how the frame reaches a nested group.
5. **`ControlIds`**: Row `[label, control]`; Slider `[label, slider, value]`; Text `[id]`; Buttons the given ids; Radio and Group as above; Check `[id]`; CheckFlow the given ids.
6. **`TextWidth` / `TextHeight` / `TextOf` come from the surface**; elements never measure text themselves. `text_of(id).is_empty()` for TextElement is the C# `Length == 0` (a text of only spaces is NOT empty).
7. **No `unsafe`, no OS call** in `rows.rs`/`groups.rs`.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T3 (arithmetic): saturating `i32`, the clamp helper, no `as` casts between widths; positions can be negative (scroll origin) and widths can be smaller than the indent.
- T4 (rounding): the divisions are `x / 2` and `x * 38 / 100` of values that are non-negative in practice but may be negative at the extremes; use plain `/` (truncation toward zero, as C#), never `div_euclid`, `>> 1` or float math.
- T8 (null vs empty): `hint_id: Option<i32>` (C# `int?`; `Some(0)` is a real id), the empty `ids` list of Buttons/CheckFlow is valid.
- T10 (order): `control_ids()` order, the `place` call order, the document order of the golden `calls`.
- UTF-16: the test fake's `text_width` counts `str::encode_utf16().count()` (the oracle uses `string.Length`; a non-BMP character counts 2). The golden has a row with five emoji.
- R0003: no `unwrap`/`expect`/indexing on the UI thread; this unit has no fallible call.
- Handles (native test only): every child window created by the test is destroyed on every path (a drop guard around the `HWND`s, children die with the owner but a failed assertion must not leak the owner); no font, DC or brush is created (metrics are fixed), so there is nothing to `DeleteObject`.

## Error mapping
| C# | Rust |
|---|---|
| `Math.Clamp` with `min > max` throws `ArgumentException` | `max` then `min` (no panic) |
| `int` overflow wraps (unchecked) | saturates |
| abstract `SettingsLayoutElement` | trait `SettingsLayoutElement` with the template method `place` |
