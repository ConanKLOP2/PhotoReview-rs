5. **`collect(state)`**: the mirror image in the same field order (texts via `text(id)`, bools via `is_checked`, indices via `combo_index`); then `state.context_menu_shown.clear()` and `insert(item)` for each `(item, id)` whose box is checked. Nothing else of `state` is touched.
6. **`on_command(id, n)`**: (a) `id == image_transition && n == CBN_SELCHANGE as u32` -> `update_dependents()`, `true`; (b) `n == BN_CLICKED` and the page has a check for `ContextMenuItemId::Settings` and `id` equals it -> `set_checked(that id, true)`, `true`; (c) otherwise `false`.
7. **`on_activated()`** and **`on_language_changed()`**: `set_summary(&context.current_shortcut_texts())`.
8. **`set_summary(texts)`**: `text = with_field_context(|c| SettingsPresenter::zoom_shortcut_summary(texts, c))`; only when `context.text(zoom_shortcuts_summary) != text` -> `set_text(zoom_shortcuts_summary, &text)` (a write that changes nothing is skipped, which the call list shows).
9. **`update_dependents()`**: `set_enabled(image_transition_ms, combo_index(image_transition) == 1)` (the fade duration matters only for Fade, index 1).
10. **`focus_target(field)`**: `ArrowPanStep` -> `arrow_pan_step`, `KeyboardZoomStep` -> `keyboard_zoom_step`, `ImageTransitionMs` -> `image_transition_ms`, `TouchpadSwipeDistance` -> `touchpad_distance`, any other `None`.
11. **Accessors**: `ids()`, `menu_checks()` (empty before `declare`); a private `menu_check(item) -> Option<i32>` by linear search.
