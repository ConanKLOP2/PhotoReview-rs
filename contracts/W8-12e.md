## Semantics notes (C# is the spec; trait notes 11 to 13 of W8-12a)
1. **Frame state.** `begin`: `active = true`, stacks cleared, `current_opacity = 1`, `clip_depth = 0`, `SetTransform(identity)` on the Direct2D context. `end`: `balanced = clip_depth == 0 && opacity empty && transform empty` is computed BEFORE the pops;
   then each dangling clip is popped (`PopAxisAlignedClip`; Direct2D `EndDraw` would fail otherwise); `active = false`. Opacity and transform stacks are NOT unwound on the context (the next `begin` resets them).
2. **Opacity is a multiplier, not a layer.** `push_opacity(o)`: push `current_opacity`, `current_opacity *= clamp(o, 0, 1)`. `PrepareBrush(color)` sets the shared brush to `(r, g, b, a)` straight alpha and `SetOpacity(current_opacity)` on EVERY primitive call
   (the brush is shared with the device); `Clear` ignores the pushed opacity and passes `(r, g, b, a * 1)`. `draw_image` alpha is `clamp(opacity, 0, 1) * current_opacity`.
3. **Transforms.** `push_transform(m)`: push the current matrix, new current = `m.multiply(current)` (row vectors: `m` is applied first, then the old matrix), then `SetTransform` with `(m11, m12, m21, m22, dx = m31, dy = m32)`.
   `pop_transform` restores the previous matrix and `SetTransform`s it. `transform()` returns the current matrix.
4. **Clip.** `push_clip(r)`: `PushAxisAlignedClip(to_d2d_rect(r), ALIASED)`, `clip_depth += 1`. `pop_clip` at depth 0 is `Err(InvalidOperation "PopClip without PushClip.")` and touches nothing.
5. **`draw_image`** (C# 62 to 107), exact order: (a) `image` not a `TiledGpuImage<ID2D1Bitmap1>` or not `is_drawable(resources.generation())` increments `skipped_image_draws` and returns (no error); (b) `bounds = (0, 0, width, height)`;
   `source = intersect(source_pixels.unwrap_or(bounds), bounds)`; (c) `rect_is_empty(source) || rect_is_empty(destination)` returns silently; (d) if a source was requested and `source != requested`, `destination = map_to_destination(requested, destination, source)`
   (only the intersection is drawn, in the right place); (e) mode = `to_d2d_interpolation(interpolation)`; `dpi = resources.dpi_scale() as f32`; `device = transform.multiply(scale(dpi))`; if `try_snap_pixel_exact(device, destination, source)` reports exact,
   `destination = snapped` and mode = NEAREST_NEIGHBOR (1 source pixel = 1 device pixel: byte-identical output); (f) `alpha = clamp(opacity, 0, 1) * current_opacity`; (g) one tile: `DrawTile(.., clip_to_core = false)`; several: each tile with `clip_to_core = true`.
6. **`DrawTile`** (C# 287 to 323): a tile without bitmap is skipped; `texture = pixel_rect_to_rect_d(tile.spec.texture)`; `core = intersect(pixel_rect_to_rect_d(tile.spec.core), source)`; empty core skips; `region = intersect(texture, source)`;
   `dest = map_to_destination(source, destination, region)`; `sourceRect = (region.x - texture.x, region.y - texture.y, region.right - texture.x, region.bottom - texture.y)` as `f32` (tile-local pixels); with `clip_to_core` the draw is wrapped in
   `PushAxisAlignedClip(map_to_destination(source, destination, core), ALIASED)` / `PopAxisAlignedClip`; the draw is `DrawBitmap(bitmap, dest, alpha, mode, sourceRect, None)`. The gutter pixels are drawn then clipped away so interpolation at tile edges uses the neighbour's real pixels.
7. **`draw_image_oriented`**: `push_transform(for_exif_orientation(o, destination))`, `draw_image(image, unoriented_rect(o, destination), ..)`, `pop_transform()` ALWAYS (C# `finally`), so an early return of `draw_image` still pops.
8. **Primitives**: `fill_rectangle` = `FillRectangle(rect, brush)`; `fill_rounded_rectangle` = `FillRoundedRectangle` with `radius_x = radius_y = radius as f32` (native in windows-rs, D-W8B3G-6; the C# used a raw vtable call); `draw_rectangle` = `DrawRectangle(rect, brush, stroke_width as f32, None)`;
   `draw_text` = `DrawTextLayout(Vector2 { X: origin.x as f32, Y: origin.y as f32 }, layout, brush, ENABLE_COLOR_FONT)` (emoji colour glyphs; ordinary text is identical to `NONE`).
9. **`try_read_pixels`** (C# 213 to 260): window surface (`has_swap_chain`) is `Ok(None)`; else `Flush`, `d2d::read_pixels(context, target, w, h)` (tight BGRA rows) into a new `PixelBuffer::allocate(w, h, Pbgra32)` row by row; every failure drops the half-built buffer and the staging bitmap.
   Must not be called while Direct2D has a draw open on the target: the C# calls it between `BeginDraw` and `EndDraw` after `Flush` (tests do), `read_pixels` documents the same.
10. **Inactive context.** C# throws `InvalidOperationException` when a draw call is made outside a frame. In Rust the context is only reachable inside the borrow of `begin_draw_context`, so the state cannot occur; the implementation uses `debug_assert!(self.active)` and,
    in release, skips the call. No `Err` is added (W8-12a rule: calls that cannot fail return `()`).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (matrix order): `System.Numerics` multiplies row vectors, `a * b` applies `a` FIRST. `push_transform` is `m * current` (the inner pushed transform is applied first, then the outer): `PushTransform_Nested_AppliesInnerFirstThenOuter` pins it. A mutant `current * m` must die.
- T2 (matrix fields to D2D): `D2D_MATRIX_3X2_F { M11, M12, M21, M22, Dx = M31, Dy = M32 }`; do not transpose. With `windows-numerics::Matrix3x2` the field names are `M11..M32` in the same row-major order.
- T3 (floats, item 4): rectangles are `f64` in `RectD` and `f32` in Direct2D; `Right`/`Bottom` are computed in `f64` then cast (`(x + width) as f32`), not `x as f32 + width as f32`. Rounding differences show up as 1-pixel seams in the tiled tests.
- T4 (opacity vs layers): opacity multiplies per call; do not use `PushLayer`. Overlapping shapes in one group differ from a layer (C# doc, accepted).
- T5 (shared brush): `PrepareBrush` must set BOTH colour and opacity on every call; a stale opacity from a previous call is the classic bug.
- T6 (`end` order): compute `balanced` first, then pop clips; `end` never touches opacity/transform stacks on the context. `end_draw_and_present` (12d) raises the unbalanced error AFTER presenting.
- T7 (skip, do not fail): an undrawable image (released, incomplete, older generation, foreign type) is skipped and counted, never an error; the compositor relies on it after a device loss.
- T8 (`DrawImageOriented` pop): the pop must run on every path; test with a skipped image (stack depth returns to 0).
- T9 (NaN, item 3): `Math.Clamp(NaN, 0, 1)` is NaN in .NET, and `f32::clamp(NaN, 0.0, 1.0)` is NaN too; do not "fix" it with `max/min` (which would return the bound).
- T10 (pixel-exact switch): the snap forces NEAREST_NEIGHBOR regardless of the requested mode; without it `HighQualityCubic` at 1:1 is not byte identical (the `OneToOne` theory rows catch it).
- T11 (`TryReadPixels` rows): the mapped pitch can exceed `width * 4`; `read_pixels` returns tight rows (11h trap); do not copy `pitch` bytes.
- T12 (integers, item 3): `skipped_image_draws` is `i64`; `clip_depth` is `i32` and cannot go negative (guarded pop).

## Safety rules (every `unsafe` block gets `// SAFETY:`)
- Verified in the windows 0.62.2 source: every Direct2D draw call this file makes is an `unsafe fn` taking raw pointers (`Clear(Option<*const D2D1_COLOR_F>)`, `FillRectangle(*const D2D_RECT_F, brush)`, `DrawRectangle`, `FillRoundedRectangle(*const D2D1_ROUNDED_RECT, ..)`,
  `PushAxisAlignedClip(*const D2D_RECT_F, mode)`, `PopAxisAlignedClip`, `SetTransform(*const Matrix3x2)`, `DrawBitmap(bitmap, Option<*const D2D_RECT_F>, opacity, mode, Option<*const D2D_RECT_F>, Option<*const Matrix4x4>)` of `ID2D1DeviceContext`,
  `DrawTextLayout(Vector2, layout, brush, options)` of `ID2D1RenderTarget`, `ID2D1SolidColorBrush::SetColor(*const D2D1_COLOR_F)`, `SetOpacity`, `Flush`). D-W8B3G-6 left them unwrapped on purpose. So this unit contains many small `unsafe` blocks, each with
  `// SAFETY:` saying: the pointer is to a local value that lives until the call returns; the rectangle/colour/matrix is fully initialised; the interface (`context`, `brush`, the tile bitmap) is a clone owned by the caller for the duration of the call; the call happens between
  `BeginDraw` and `EndDraw` of the same context (guaranteed by `active`). Group them in a few private helpers (`draw_bitmap`, `fill`, `set_transform`) instead of repeating the comment 20 times.
- COM lifetime: every interface used (`context`, `brush`, the tile `ID2D1Bitmap1`) is cloned out of `DeviceResources` / the tile for the duration of the call; the tile bitmap borrow (`GpuTile::with_bitmap`) must not call back into the same tile (RefCell panic, W8-12a note 20).
- Thread: UI thread only; `!Send`. The context is dropped with the surface.

## Error mapping to `RenderError`
`pop_clip` / `pop_opacity` / `pop_transform` return `RenderFault::InvalidOperation { message }` with the three verbatim messages; `try_read_pixels` failures are `Device(GfxError)`. Everything else cannot fail. `RenderFault` converts field by field (W8-12b).
