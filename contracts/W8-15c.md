## Semantics notes (each one is a C# behaviour the tests pin)
1. **Button defaults** (C# field initialisers): `content = ""`, `style = TextStyle::default()`, `padding = (8, 4)`, `border_thickness = 1`,
   `corner_radius = 2`, `is_enabled = true`, `is_hot = is_pressed = is_focused = is_checked = false`, `foreground = TEXT_BRIGHT`,
   `background = BUTTON`, `border_color = BORDER_STRONG`, `fixed_width = fixed_height = NaN`, `tool_tip = automation_name = ""`.
   Palette names come from `overlay::palette` (W8-15b): `BUTTON`, `BUTTON_HOVER`, `BUTTON_PRESSED`, `BORDER_STRONG`, `TEXT_BRIGHT`,
   `TEXT_MUTED`, `ACCENT_HOVER` (C# `DarkPalette.Get("Dark.AccentHover")` and `"Dark.TextMuted"`). If W8-15b names them differently, rename here.
2. **TextElement defaults**: `text = ""`, `style = TextStyle::default()`, `trimming = None`, `color = TEXT_BRIGHT`, `is_hit_test_visible = false`
   (set by the constructor), no layout, `layout_width = NaN`.
3. **Text and content changes** drop the layout at once, before the next measure (the C# test counts `Live == 0` right after `Text = "hello!"`).
   An equal value changes nothing (ordinal string equality).
4. **Button measure** (C# `MeasureCore`): `EnsureLayout` first (also when `fixed_width` is set and also when the content is empty), then
   `width = fixed_width` if not NaN, else `text.width + padding.horizontal + 2 * border_thickness`; height likewise with `text.height +
   padding.vertical + 2 * border_thickness`. The available width is not used for the text (one line, never trimmed or wrapped).
   The base clamps the result to `MaxWidth`.
5. **Text measure** (C# `MeasureCore`): reuse the layout if `layout` exists, `layout_owner == context.text_renderer_id`, and
   `layout_width == available.width` (IEEE `!=`, T5); otherwise drop, call `create_layout(text, style, available.width, trimming)`, record
   owner and width; return the layout size. The base clamps to `MaxWidth`.
6. **Render order** of the button (C# `RenderCore`): background fill (rounded if `corner_radius > 0`, else plain), border stroke (if
   `border_thickness > 0`, inset by half the thickness), then the text (only when a layout exists and the content is not empty): clip to
   `bounds`, text centred in `bounds`, colour `foreground` (enabled) or `TEXT_MUTED` (disabled), clip pop. The text is not drawn when the
   content is empty even though a layout was measured (T12).
7. **Text render order** (C# `TextElement.RenderCore`): nothing when there is no layout or the text is empty; else clip to `bounds`,
   `draw_text` at `(bounds.x, bounds.y)` with `color`, clip pop. No centring: the layout is drawn at the top-left of the bounds.
8. **Opacity** is applied by the base `render` (push/pop), not by the cores. Neither core pushes opacity itself.
9. **Background rule** (C# `RenderCore`, in order): `!is_enabled` -> `background`; `is_pressed || is_checked` -> `BUTTON_PRESSED`;
   `is_hot` -> `BUTTON_HOVER`; else `background`. A disabled button ignores hot and pressed (test case `enabled: false`).
10. **Focus border**: `is_focused` -> `ACCENT_HOVER`, else `border_color`. Stroke rect `(x + h, y + h, max(0, w - bt), max(0, h - bt))` with `h = bt / 2`.
11. **Click** (C# `Click()`): `&self`. Returns `false` without calling the sink when `!is_enabled`, `!is_visible` or `opacity <= 0`. Otherwise
    calls the sink with `self.id()` and returns `true`. C# `Click` has no other effect.
12. **Hit test** of both elements: the base rule (`is_visible && is_hit_test_visible && opacity > 0 && bounds.contains`). The button is
    hit-test visible by default (base default), the text is not.
13. **Release**: `release_resources` drops the lease (button: `drop_layout`; text: `invalidate`, which also forgets the owner and sets the width to NaN).
    C# `Dispose` of the lease happens in the same call. Rust drop of `Box<dyn TextLayout>` is the C# `Dispose`.

## Traps (the porter reads these before writing code)
- **T1 Layout identity is by renderer id, not by address.** C# `ReferenceEquals(_layoutOwner, renderer)`. A Rust `*const` of the renderer
  would go stale when a renderer is dropped and another one is allocated at the same address (ABA). Use `context.text_renderer_id` (O2).
  Store `Option<u64>`, never a reference or pointer.
- **T2 Failure leaves no layout.** C# disposes the old lease BEFORE `CreateLayout`; when `CreateLayout` throws (invalid font size,
  disposed renderer), `_layout` stays null and the owner and width are not updated. The next measure therefore retries. In Rust: set
  `self.layout = None` (drop) before calling `create_layout`, then `?`. Do not keep the old lease on failure. Test: `button_measure_failure_leaves_no_layout`.
- **T3 Button text is never trimmed or wrapped.** `create_layout(content, style, f64::INFINITY, TextTrimming::None)`. The width argument
  of C# `EnsureLayout` is computed in `MeasureCore` but unused: do not pass it on (a finite width would change the one-line layout).
  Do not compute it either (`unused_variables` in clippy).
- **T4 Style equality is NaN-aware (record equality).** C# `_style != value` on a `sealed record` compares `FontFamily` ordinally,
  `FontSizeDip` with `double.Equals` (NaN equals NaN, `0.0` equals `-0.0`) and `Bold`. The derived Rust `PartialEq` on `TextStyle` says
  NaN != NaN, so `style_same` compares the size with `f64_same` (W8-01a). Test: `text_element_style_with_nan_size_does_not_invalidate`.
- **T5 The width test in `TextElement` is plain IEEE `!=`.** C# `_layoutWidth != width` on `double` is IEEE (NaN re-measures every time).
  Do NOT use `f64_same` there. The owner test uses `==` on `u64`. (`layout_width` starts as NaN, so the first measure always creates.)
- **T6 Ordinal text equality.** C# `string.Equals(_text, value, Ordinal)`: byte equality of the UTF-8 strings is the same for valid text.
  Do not use `eq_ignore_ascii_case`, `to_lowercase` or a trimmed compare. Test: `text_element_same_text_different_case_invalidates`.
- **T7 `Click` gating order.** Check `!is_enabled` and `!is_visible` and `opacity <= 0` (C# `Opacity <= 0f`; a NaN opacity is already 0
  by the base setter) before calling the sink. A rejected click calls the sink zero times (the C# test counts `clicks`).
- **T8 Null is impossible.** C# `ArgumentNullException.ThrowIfNull(value)` on `Content`, `Style` and `Text`: a Rust `&str`/`TextStyle` cannot
  be null. Do not add a runtime check and do not port a null test (there is none in the C# suite for these elements).
- **T9 Background precedence.** Pressed and checked both give `BUTTON_PRESSED`; disabled wins over all (`enabled: false` gives `background`
  even when hot and pressed). A plain `fill_rectangle` is used only when `corner_radius <= 0` (NaN radius: `> 0` is false, so plain; keep the comparison
  as `corner_radius > 0.0`, not `!(corner_radius <= 0.0)`).
- **T10 Border inset uses `max(0, w - bt)`.** Negative sizes (a button with a zero or negative bounds) clamp to 0, never negative.
- **T11 Clip and opacity balance.** Every `push_clip` has its `pop_clip` in the same call, also when the text is skipped (the skip happens
  before the push). C# uses try/finally; in Rust there is no panic path in these cores, so a straight-line pair is enough.
- **T12 Empty content still measures.** `ensure_layout` runs even when `content` is empty (a zero-length layout), so the renderer request count
  matches C#. Render then draws nothing for the empty content. Test: `button_empty_content_still_measures_one_layout_and_draws_no_text`.
- **T13 Fixed size still measures.** `fixed_width` / `fixed_height` replace only the returned size; `ensure_layout` still runs first.
  Test: `button_fixed_size_wins_over_content` checks `Requests.len() == 1`.
- **T14 Manual `Debug`.** Never derive `Debug` on `ButtonElement` or `TextElement`: it fails on `Box<dyn TextLayout>`. The manual impl
  prints only plain fields and `layout.is_some()`.

## Open questions (each has a recommended default; the stub already follows the default)
- **O1 `measure` returns `Result`.** C# `Measure` cannot fail in the element, but `CreateLayout` throws on an invalid font size or a disposed
  renderer, which the Rust `TextRenderer` returns as `RenderError`. Recommended (used): `measure_core` and `measure`/`arrange` return
  `Result<_, RenderError>` and the error goes up to the host, which logs it (W8-15f). Alternative: swallow the error and draw no text
  (hides a real fault, rejected). Affects W8-15a's signatures; W8-15d/15e follow it.
- **O2 Layout owner by id.** Recommended (used): `OverlayLayoutContext.text_renderer_id: u64` assigned by the composition root (monotonic
  counter, `AtomicU64` in W8-09b). Alternative: pointer identity (ABA risk, T1). Needs the field in W8-15a.
- **O3 Click as a sink argument.** Recommended (used): `click(&self, on_clicked: &mut dyn FnMut(&str)) -> bool`. Alternative: a stored
  `Box<dyn FnMut>` handler (a `'static` closure that captures state; harder to test and to drop on release). The toolbar (W8-15e)
  routes by id, so the sink suits it.
- **O4 Shared fakes in `tests/overlay_fakes.rs`** included with `#[path]` by each test file. Alternative: a `tests/common/mod.rs`
  (the usual Cargo pattern). Recommended: one file, owned by 15c, because 15d and 15e are the next readers; the `#[path]` form avoids a new
  `tests/common` directory that another unit may also create.
- **O5 Element composition.** Recommended (used): `ElementBase` held by value and the trait `OverlayElement` with `base`/`base_mut`
  (composition, no `dyn` inheritance). Alternative: a `trait` with every property as a method (more boilerplate, the same behaviour).
- **O6 Plan edges.** The plan row lists only 15a and 15b. The transitive types of 12a, 01a and 01c are needed to compile. Recommended: the
  lead adds them as implicit edges; they are B1 and merge first. No behaviour depends on the choice.
