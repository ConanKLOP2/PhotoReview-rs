## Semantics

### AppLog (`misc::app_log`)
1. **Facade over one target.** `AppLog` forwards `info/warn/error/flush/shutdown/file_path` to its `instance` and reads `enabled` from it.
   `set_instance(None)` selects `DefaultFileLog` (C# `value ?? FileLog.Default`). `set_instance` does NOT count as an `Enabled` write.
2. **`set_enabled` counts every write** (C# `Interlocked.Increment` before the delegate), including a write of the value already set. The
   counter is `i32` with wrapping increments. `enabled_write_count()` starts at 0.
3. **`write_forced(write)`** (C# `WriteForced`): take the forced lock; `was = enabled()`; `set_enabled(true)` (counted); run `write`; on
   return, `flush()`; then restore `set_enabled(was)` (counted). Two counted writes per call. The restore lives in a drop guard, so a
   panic in `write` still restores and then propagates; the flush runs only when `write` returned. Writes outside the lock are not serialized.
4. **`error_forced(m, e)`** = `write_forced(|| self.error(m, Some(e)))`: the entry is persisted while logging was off, and the flag is back off.
5. **`shutdown`** delegates (FileLog: stop accepting, flush within its budget). `Enabled` is false afterwards (the target does that).
6. **`global()`** is a `OnceLock<AppLog>` created with `new(None)`. Tests never call it and never construct `DefaultFileLog`
   (that touches `%LOCALAPPDATA%`). Tests build `AppLog::new(Some(Arc::new(FileLog::new(temp_path, DEFAULT_MAX_LOG_BYTES)?)))`.
7. **`impl Log for AppLog`** makes the facade usable wherever W8 takes `&dyn Log` or `Arc<dyn Log>` (`TaskLogging`).

### BuildInfo (`misc::build_info`)
8. **`describe_parts`**: if `informational_version` is `None`, empty or whitespace only (C# `IsNullOrWhiteSpace`, Unicode whitespace), the result
   is `settings.version.unknown` and NOTHING else, even with a valid `build_time`.
9. **Split at the FIRST `'+'`** (`IndexOf('+')`): `version` = text before it (the whole text when there is no `'+'`), `commit` = text after it
   (`None` without `'+'`). `"+abc1234"` gives an empty version and commit `abc1234`.
10. **Parts** joined with `PART_SEPARATOR` (`" · "`): (a) `settings.version.number` with `version` (an empty version still produces the
    labelled part: `Version ` / `Phiên bản ` with the trailing space); (b) only when `parse_build_time(build_time)` succeeds,
    `settings.version.build` with `format_local_minute(utc, offset.offset_minutes_at(utc))`; (c) the commit, only when non-empty.
11. **`parse_build_time`** (`DateTimeOffset.TryParseExact`, `"yyyy-MM-dd HH:mm:ss zzz"`, invariant): exact shape, four-digit year, two-digit
    fields, real calendar dates (`2026-02-30` fails), signed `±hh:mm` offset. `None` input and any mismatch give `None`, which means "no build
    part", not "unknown". The written offset only locates the instant: the display uses the LOCAL offset at that instant (Trap 13).
12. **`format_local_minute`**: `"dd/MM/yyyy HH:mm"` of `utc + offset_minutes * 60`, proleptic Gregorian, computed with `div_euclid` /
    `rem_euclid` (negative instants before 1970 must not truncate toward zero). Pure arithmetic: no `chrono`, no OS time zone.
13. **`BuildStamp::version()`** = `informational_version.as_deref()` (C# `GetVersion`). `BuildStamp::describe` = `describe_parts` over its two fields.

### LaunchArguments (`misc::launch_args`)
14. **`normalize_one`** follows the six numbered steps in the stub's doc comment exactly (C# `NormalizeOne`). The result is the original `arg`
    whenever `arg` is not an existing folder after the quote repair (step 3 returns `arg`, not `candidate`).
15. **Quote repair**: only when `arg` has more than one UTF-16 unit and ends with `"`. The repaired candidate is used only when it exists.
16. **Trailing separators**: a folder path loses ALL trailing `\` and `/` (C# `TrimEnd('\\', '/')`), except that a drive root keeps them
    (step 5: `full.len_utf16() > root_len`). `"D:\"` stays `"D:\"`.
17. **`normalize`** maps every element in order and keeps the count (empty input gives an empty `Vec`).

### TaskLogging (`misc::task_logging`)
18. **`observe_end`**: `Faulted(e)` logs `log.error(context, Some(base_error(&*e)))`; `Completed` and `Canceled` write nothing (C#
    `OnlyOnFaulted`; `Canceled` is not a fault). The message is `context` verbatim.
19. **`base_error`** walks `source()` to the end and returns the last error (C# `GetBaseException`). An error with no source is its own base.
20. **`start_and_observe`** (C# `FireAndLog(Func<Task?>, context)`): run `start` inside `catch_unwind` (a panic counts as a `Failed` fault whose
    message is `panic_message(payload)`). `Ok(None)` is a no-op. `Ok(Some(rx))` goes to `observe_receiver`. `Err(Canceled)` is silent.
    `Err(Failed(e))` logs `log.error(context, Some(base_error(e)))` once.
21. **`observe_receiver`** spawns one background thread named `PhotoReview.TaskObserver` that calls `recv()` once and then `observe_end`. A
    sender dropped without sending is silent (no fault exists to report). A spawn failure is returned as `io::Error`: the caller logs it once with
    its context. The thread is only for rare fire-and-forget paths; hot paths call `observe_end` directly (Open question 5).
22. **The outcome is shared, not consumed**: `observe_end` takes `&TaskEnd`, so a caller that keeps the `TaskEnd` still sees the fault (C#
    `FireAndLog_FaultedTask_StillReportsTheFaultToAwaiters`).

## Traps
1. **Enabled write counter.** Every `set_enabled` increments, even for an unchanged value; `write_forced` adds two. A test asserting the
   count after `write_forced` expects `+2`. `set_instance` adds nothing (C# `Instance` setter does not touch the counter).
2. **Restore on panic.** The restore is a drop guard; a `catch_unwind` in the test sees the flag back off. A flush must not happen on a panic path.
3. **Lock poisoning.** A panic inside `write_forced` poisons `forced_lock`: take it with `lock().unwrap_or_else(PoisonError::into_inner)`
   (R0003). Never `unwrap()` a lock.
4. **Re-entrancy.** C# `lock` is re-entrant: a `write_forced` call made inside another one on the same thread enters without deadlock.
   `std::sync::Mutex` is not re-entrant. Implement a thread-local depth counter: depth 0 locks, a nested call on the owning thread skips the
   lock and only saves and restores the flag. Test `write_forced_nested_on_same_thread_does_not_deadlock` (bounded by the test harness).
5. **Default target.** `None` means the process default. Tests must never reach `DefaultFileLog` or `AppLog::global()`.
6. **Concurrent logging tests** use `std::thread::scope` with 8 workers and fixed counts (400 forced writes, 200 infos). No sleeps, no
   polling: `flush()` is the barrier.
7. **Version split** is at the FIRST `'+'`: `"2.0.41+1a2b3+x"` has commit `1a2b3+x`. Do not use `split_once` on the last `'+'`, and do not trim.
8. **Whitespace-only version** (`"   "`, `"\t"`) is unknown, like `None`; `""` too. A version that is not empty but has no commit (`"2.0.41+"`)
   has no commit part.
9. **Local time uses the instant's offset**, `offset_minutes_at(utc)`, never the offset written in the `BuildTime` string (C# `ToLocalTime`).
   Test with `FixedOffset(420)` and the string `"... +00:00"`: the minute is `+7h`.
10. **Quote repair and missing folders.** `"C:\x\"` (quote) with a missing `C:\x\` returns the original text with the quote, not the repaired one.
11. **8.3 short names.** CI temp paths may be `RUNNER~1`. `get_full_path` does not expand them, so compare the result with
    `get_full_path(temp.path())`, never with the `TempRoot` string the test built by hand (AGENTS.md, CI note).
12. **Dropped C# members.** `AsyncVoidJustification` (WPF event-handler text, scoped VSTHRD100 suppressions) has no Rust use: not ported,
    listed in PARITY as dropped. `ArgumentNullException` checks (`ThrowIfNull`) cannot occur for Rust references: no test, DIVERGENCE comment
    in `misc_task_logging.rs`.
13. **Years and offsets outside .NET's range.** `DateTimeOffset` accepts years 0001..9999 and offsets within +-14:00. The parser applies the
    same bounds. A local time that falls outside 0001..9999 makes C# `ToLocalTime` throw: Rust omits the build part instead (DIVERGENCE, test
    `describe_out_of_range_build_time_omits_the_build_part`). The exact `zzz` bounds are verified with `dotnet` (installed at
    `C:\Program Files\dotnet`) during the red-test step; the rule stays strict if that check is not possible (Open question 8).
14. **Trait objects across threads.** `observe_receiver` moves an `Arc<dyn Log>` into the thread; `Log: Send + Sync` is required. Never move a `&dyn Log`.
15. **Panic payload text.** `panic_message` returns the `&str`/`String` payload or a fixed fallback; the test panics with a `&'static str` and
    checks the text, not the `Debug` form.
16. **`None` is not `Some("")`** (MULTI-AGENT-PLAN section 7, item 8). `BuildStamp::version()` returns `Some("")` for an empty stored version,
    never `None`. `describe_parts` treats `Some("")` like `None` for the version (unknown), but `build_time = Some("")` only fails to parse
    (no build part), and `commit = Some("")` (text `"2.0.41+"`) is omitted by the non-empty rule. Tests pin all four shapes.
17. **Windows path shapes** (lesson of Wave 2): `normalize_one` must keep the NT prefix `\\?\` and the UNC root `\\server\share\` (the root
    length comes from `get_path_root`, not from counting separators). A lone `"` (length 1) is not a quote repair (step 2 needs length > 1).
