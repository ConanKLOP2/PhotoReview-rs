## `is_burst_scenario(key)`
Take the part before the FIRST `@` (the whole key if none). It is burst iff it has at least 2 chars, its first two chars equal `S3` or `S4` ignoring case (use `pr_core::text::eq_ignore_case` on the first two chars), and it is exactly 2 chars long or its third char is NOT an ASCII digit `0-9` (a non-ASCII digit such as `٣` does not block: `S3٣` is burst). Golden: `S3 `, `S3_`, `S3@`, `S4x`, `S4-`, `s3` true; `S34`, `S30`, `@S3`, `S`, `` (empty), `S2@S3` false.

## `nan_as_null_double_json(v)` / `nan_as_null_double_read`
Write: finite -> `crate::rules::fmt_double(v)`, else the text `null`. (Golden `json_double`: `10.0`->`10`, `-0`->`-0`, `1e-5`->`1E-05`, `1e17`->`1E+17`, `1e16`->`10000000000000000`, `NaN`/`±Infinity`->`null`.) Read: `Value::Null` -> `Some(NaN)`, a number -> `Some(f64)`, any other token -> `None`. The read side is never called by the app.

## `run(run_dir, rules_path)` — apply in THIS order
1. **Directory**: `!run_dir.is_dir()` -> `Err(PerfError::DirectoryNotFound(run_dir.display().to_string()))` (the message is the bare path as the caller gave it; also for a path that is a file).
2. **Find CSVs**: every FILE below `run_dir` at any depth (hidden/system files included; DESCEND through directory junctions and directory symlinks and COLLECT file symlinks: the link target decides (`fs::metadata`), because .NET 10 `Directory.EnumerateFiles(..., AllDirectories)` follows junctions (verified with a real .NET 10 harness in round 5; the earlier "do not follow" text was wrong). .NET has no cycle detection (it recurses until the path is too long); the port skips a directory already on the current descent chain: documented `// DIVERGENCE`) whose NAME (last component) matches `perf-*.csv` case-insensitively: at least 9 chars, first 5 chars `eq_ignore_case("perf-")`, last 4 chars `eq_ignore_case(".csv")` (`perf-.csv` and `PERF-C.CSV` match; `perf.csv`, `xperf-1.csv`, `perf-1.csv.bak`, `perf-1.txt` do not; `.NET` 10 has no 8.3 wildcard quirk, golden-checked). Skip a file when ANY directory component between `run_dir` and the file (and the file name itself) equals `warmup` ignoring case: `warmup/perf-w.csv` and `x/Warmup/perf-w.csv` are skipped, `warmup-y/perf-ok.csv` is not. Directory read errors are `Err(PerfError::Io)` (C# lets the `IOException` escape unwrapped).
   Sort the paths ascending by the path text compared as UTF-16 code units (`a.encode_utf16().cmp(b.encode_utf16())` on `path.to_string_lossy()`), i.e. `StringComparer.Ordinal`: NOT `Path::cmp`, NOT `str::cmp` (UTF-8 order differs for U+E000..U+FFFF vs supplementary chars: golden `file-order-utf16-not-utf8`), NOT case-insensitive (`B/` < `_/` < `a/` < `z/`: golden `file-order-is-ordinal-on-the-full-path`). The path of each file is `run_dir.join(relative)`.
   No file -> `Err(PerfError::InvalidOperation(format!("No perf-*.csv files found in {}", run_dir.display())))`. (This check comes BEFORE the rules file is read: golden `error-no-csv-wins-over-bad-rules`.)
3. **Rules**: `rules_path` `None` or empty -> `RulesConfig::default()`, else `RulesConfig::load(p)?` (errors propagate: `Io` for a missing file, `InvalidData("Invalid rules file ...")` for bad JSON).
4. **Per file, in sorted order**: `file = csv::read(&path)`, `analysis = nav::build(&file)`, `meta = RunFileMeta::load(&file)`. If `csv::read` fails with `PerfError::Io(e)`, return `Err(PerfError::InvalidData(format!("Could not analyze '{}': {e}", path.display())))` (the other two steps cannot fail).
   `mode` = the most frequent `mode` among `analysis.navs` where an empty mode counts as `"unknown"`: count in an `IndexMap` in nav order and pick the FIRST entry with the maximum count (ties -> the mode of the earliest nav; a manual loop with strict `>`; `Iterator::max_by_key` returns the LAST maximum); if the file has no navs: `meta.mode`, or `"unknown"` if that is empty.
   `key = GroupKey::new(meta.scenario, mode, meta.cond, meta.preload_workers)`. Maintain, all in FIRST-SEEN key order (`IndexMap<GroupKey, _>`): navs (append `analysis.navs`), preload items, paused sum, cancel sum, dispatcher ops (append), before-start sum, folder gens (append), startup runs (push `analysis.startup` only if it is not empty), metas (push), dropped sum (`+= file.dropped_rows`). A key is created even when the file has no navs (so a group with `count == 0` exists).
5. **Summaries**: for each key in first-seen order `s = GroupSummary::build(key, &navs)`; then set `s.preload_workers = s.key.preload_workers`; `s.dropped_rows`; `s.gc_time_percent = average_or_none(metas.map(gc_time_percent))` (mean of the present values, left-to-right sum / count, `None` if none present); `s.frame_time_p95_ms` likewise; `preload_items`, `preload_paused_count`, `preload_cancel_count`, `dispatcher_long_ops`, `dispatcher_long_ops_before_start_count`, `folder_gens`, `startup_runs` from the aggregates.
6. **Rules per group** (`evaluate_all_rules(rules, &s, &all_summaries)`), results in this exact order `[R-IO, R-DEC, R-UI, R-PRE, R-CONT, R-THREAD, R-GC, R-DISK, R-FOLDER]`:
   - `complete` = navs of `s` with `incomplete == false`; `source_miss` = complete navs whose `kind` CONTAINS (case-sensitive) `SourceMiss`; `decode_navs` = kind contains `SourceMiss` OR `InflightJoin`; `ram_hit` = contains `RamHit`; `disk_hit` = contains `DiskCacheHit`.
   - `ram_hit_final_p95` = `nearest_rank(sorted(final_visual_ms of ram_hit navs that have one), 95.0)`, NaN if none. `non_ram_hit_share_pct` = if `complete` non-empty `100.0 * (complete.len() - ram_hit.len()) as f64 / complete.len() as f64` (multiply first, then divide) else NaN. `is_burst = is_burst_scenario(&s.key.scenario)`.
   - `t_input_p95` = `Some(nearest_rank(sorted(t_input_ms of complete navs that have one), 95.0))` or `None`.
   - `dispatcher_count` = number of `s.dispatcher_long_ops` with `ms > rules.get("R-THREAD", "dispatcherLongOpMs", 16.0)`.
   - R-CONT: `siblings` = all summaries with the same `scenario`, `mode` AND `cond` as `s` and `preload_workers.is_some()` (this includes `s` itself). `low` = the sibling with the smallest `preload_workers`, `high` = the one with the largest (first on ties; ties cannot happen because keys are unique). `decode_low/high` = `average_decode_ms(group)` = mean of `t_decode_ms` over the group's navs that are complete, have kind containing `SourceMiss` or `InflightJoin`, and have a `t_decode_ms`; `None` if none. Pass `low.preload_workers` / `high.preload_workers`. No siblings -> all four arguments `None`. Different `cond` never compare (golden `worker-cells-not-pooled`); a single group compares with itself (equal workers -> N/A).
   - Call: `evaluate_r_io(cfg, &source_miss)`, `evaluate_r_dec(cfg, &decode_navs)`, `evaluate_r_ui(cfg, &ram_hit, ram_hit_final_p95, s.frame_time_p95_ms)`, `evaluate_r_pre(cfg, ram_hit_final_p95, non_ram_hit_share_pct, is_burst)`, `evaluate_r_cont(cfg, decode_low, decode_high, low_workers, high_workers)`, `evaluate_r_thread(cfg, dispatcher_count, t_input_p95)`, `evaluate_r_gc(cfg, s.gc_time_percent)`, `evaluate_r_disk(cfg, &disk_hit, &source_miss)`, `evaluate_r_folder(cfg, &s.folder_gens)`. (The evaluators take `&[NavRecord]`: clone the filtered navs into `Vec<NavRecord>`.)
7. **Order the groups**: stable sort by `key.scenario`, then `key.mode`, then `key.cond` (each by UTF-16 ordinal comparison as in step 2), then `key.preload_workers.unwrap_or(-1)` (numeric: workers 2 before 10; `None` ties with `-1`, keep first-seen order).
8. `summary_md_path = run_dir.join("summary.md")`, `summary_json_path = run_dir.join("summary.json")`, `csv_file_count = number of files found` (after the warmup filter). Call `report::write_markdown` then `report::write_json` (their `Io` errors propagate unwrapped). Return the result. Existing summary files are overwritten; the files are written AFTER the whole analysis succeeded.
Because step 2's sort and step 4's first-seen maps decide the order of `kind_counts`, `startup_runs` ties etc., the output depends on them (golden pins it).

## Golden `perf-analyze` (how to compare)
- `run` case: `files` maps a relative path (with `/`) to a text, or `{"content": text, "bom": true}`, or `{"raw_hex": ...}`; create the parent directories and write them under a `TempRoot`; `rules_json` (optional) is written to a file in a SECOND `TempRoot` and passed as `rules_path`; `missing_rules: true` passes `second_root/nope.json`; `missing_dir: true` runs on `root/does-not-exist`. If the case has `error`: `type` is `InvalidOperationException` -> `PerfError::InvalidOperation` with message equal to `message` after replacing `<RUNDIR>` by the run directory text; `DirectoryNotFoundException` -> `DirectoryNotFound` (message = `<RUNDIR>\does-not-exist`); `InvalidDataException` -> `InvalidData` whose message starts with `Invalid rules file '<second_root>\rules.json': ` (only the prefix; the rest is a .NET text); `FileNotFoundException` -> `PerfError::Io` with `ErrorKind::NotFound`. Otherwise compare `csv_file_count`, `groups` (`key_string, scenario, mode, cond, workers, count, incomplete, dropped_rows, gc_time_percent, frame_time_p95_ms`, `rules` = `[{rule, triggered, evidence, note}]`, null <-> `None`/NaN) and the two files: `std::fs::read_to_string(result.summary_md_path) == summary_md`, same for json (CRLF and all).
- The runs rely on the parent of the TempRoot not ending in `-warm`/`-cold-*` (true for `%TEMP%\pr-rs-tests`) and on a case-insensitive file system (Windows; the repo is Windows-only).
- `burst`: `is_burst_scenario(key) == is_burst`. `json_double`: `text` parsed like in W1-18's `fmt` cases -> `nan_as_null_double_json(v) == json`.
