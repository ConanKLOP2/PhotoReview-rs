## Semantics notes (C# is the spec; the render trait contract is W8-12a notes 9 to 13)
1. **Creation.** `create_window_surface(0, _)` is `Err(InvalidArgument { param: "hwnd", message: "A window handle is required." })`. The surface builds one `D2dDrawContext::new(resources.clone())` at creation. Offscreen: WARP unless `use_hardware`;
   the stored `SurfaceOptions` is `{ prefer_warp: !use_hardware, allow_tearing: false, max_frame_latency: 1 }`.
2. **`resize`** (C# 83 to 100): `Err(Disposed { object: "PhotoReview.Shell.Rendering.D2DRenderSurface" })` first; while a frame is open `Err(InvalidOperation "Resize is not allowed between BeginDraw and EndDrawAndPresent.")`;
   `DeviceResources::resize`: `Resized` is done; `BuffersFailed(hr)` with `is_device_lost(hr)` calls `recreate_device()` (size and DPI were already stored, so the new device is built at the NEW size); any other `hr` is
   `Err(Device { hresult: hr, operation: "IDXGISwapChain::ResizeBuffers" })`. An `Err` from `resize` itself (target creation failed) is returned as is.
3. **`begin_draw_context`** (C# 105 to 117): disposed check; a frame already open is `Err(InvalidOperation "BeginDraw was already called; call EndDrawAndPresent first.")`; `drawing = true`; `ID2D1DeviceContext::BeginDraw()`; `D2dDrawContext::begin()`; return the context.
4. **`end_draw_and_present`** (C# 119 to 153), ORDER IS THE SPEC: disposed check; not drawing is `Err(InvalidOperation "EndDrawAndPresent without BeginDraw.")`; `drawing = false`; `balanced = draw_context.end()`; time `DeviceResources::end_draw()`
   into `last_end_draw`; `classify_end_draw`: `DeviceLost` is `recreate_device()` and result `DeviceRecreated`; `Failed` is result `Failed` (no recreate, generation unchanged, NOT an `Err`); `Continue` is `self.present()`.
   Only AFTER that, `!balanced` is `Err(InvalidOperation "Unbalanced PushClip/PopClip or PushOpacity/PopOpacity in the frame.")`: the frame was shown and the surface works again.
5. **`present`** (C# 202 to 226): `last_present = 0`; no swap chain returns `Presented` (offscreen, no hook call); `sync_interval = if options.allow_tearing || immediate_present { 0 } else { 1 }`; time `DeviceResources::present(sync)` into `last_present`;
   `gfx::dxgi::classify_present`: `Occluded` returns `Occluded` (checked FIRST: `DXGI_STATUS_OCCLUDED` 0x087A0001 is a success code); `DeviceLost` is `recreate_device()` and `DeviceRecreated`; `Failed` is `Failed`; else `Presented`.
   The present flags are always 0: `DXGI_PRESENT_ALLOW_TEARING` is not used (C# comment line 210: needs `IDXGIFactory5`, "v1"); `allow_tearing` therefore only means sync 0 (open question 3).
6. **`recreate_device`** (C# 190 to 194): `DeviceResources::recreate()?` then every handler in subscription order, synchronously. A handler is `FnMut()` and cannot re-enter the surface (it would need `&mut`); the 12g cache handler captures an `Rc` of its own state.
   Handler ids are `u64` from a counter starting at 1, never reused; `unsubscribe` of an unknown id is a no-op. If `recreate` fails the handlers are NOT called and the error is returned.
7. **`wait_for_next_frame`** (C# 159 to 170): disposed check; handle 0 (offscreen) returns `Ok(true)`; else `WaitForSingleObjectEx(handle, max(0, timeout) as u32, alertable = true)` through `gfx::extras::wait_for_handle`, `true` only when signaled (`WAIT_OBJECT_0`).
   The message loop (W8-13) normally waits on `frame_latency_wait_handle()` itself; this method is for callers without a loop.
8. **Thread rule.** C# `ThrowIfInvalidThreadOrDisposed` compares the managed thread id. The Rust type is `!Send` (it holds `PhantomData<*const ()>`), so a cross-thread call cannot compile and the check has no twin; the C# test half
   `crossThread` of `Misuse_IsRejected` is dropped (recorded as Different-by-construction in PARITY). The disposed check stays.
9. **`dispose`**: idempotent; sets `disposed`, calls `DeviceResources::dispose()` (the cache's `Rc` clone stays valid, device getters then report `Disposed`). `Drop` calls it. Calling any method after `dispose` is `Err(Disposed)`
   except the numeric getters and `dispose`.
10. **Diagnostics.** `last_end_draw` / `last_present` use `std::time::Instant` (C# `Stopwatch` ticks); `PHOTOREVIEW_RS_FRAME_LOG` (W8-16a) reads them. The R0001 `EndDraw` stall (300 to 510 ms on the unattended laptop) is inside `end_draw()`, not `present`.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (result vs error): `Failed` for an `EndDraw`/`Present` failure is an `Ok(PresentResult::Failed)`, only the unbalanced stack, disposed, and misuse are `Err`. A mutant turning `Failed` into `Err` must fail `end_draw_other_failure_returns_failed`.
- T2 (order of the unbalanced error): it is raised AFTER present and after recreate; a test checks that the frame was presented (`last_present` set, offscreen: contents readable) and a following frame draws.
- T3 (device loss in three places): `resize`, `end_draw` and `present` each recreate. `end_draw` and `present` have fault-injection tests (the hooks); a device loss inside `ResizeBuffers` cannot be forced reliably, so that branch is
  checked by reading (`is_device_lost(hr)` selects `recreate_device`, otherwise `Err(Device)`) plus the `gfx::com::is_device_lost` tests of W8-11f.
- T4 (`DXGI_STATUS_OCCLUDED` is positive): never test `hr < 0` before the occluded check (`classify_present` handles it; the surface must call it, not re-implement).
- T5 (sync interval): `0` when `allow_tearing || immediate_present`; otherwise `1`. A swapped default (0) hides the vblank pacing and shows up only as tearing; `sync_interval_selection` pins it.
- T6 (handlers): subscription order, synchronous, after the new device exists; an `unsubscribe` of an unknown id does nothing; ids never reused.
- T7 (the draw context borrow): `begin_draw_context` returns `&mut D2dDrawContext` tied to `&mut self`; do not store the reference. The context holds an `Rc<DeviceResources>` clone, NOT a reference to the surface (C# held the surface).
- T8 (swap chain flags, D-W8B3G-3): the C# production values; do not copy the R0001 spike's `FLIP_SEQUENTIAL` / flags 0. W8-12j owns experiments.
- T9 (stall): a window `Present(1)` of the first frame may block 250 to 500 ms on a real GPU; the shell sets `immediate_present` until the first image frame is shown. Do not "fix" it here.
- T10 (exceptions to Result, item 9): disposed, already-drawing, not-drawing, resize-while-drawing, unbalanced are five distinct `InvalidOperation` messages (verbatim); keep them separate.

## Safety rules
- Almost no `unsafe`: every FFI call is behind `DeviceResources` / `gfx`, except `ID2D1DeviceContext::BeginDraw()` (called here, in `begin_draw_context`), which is an `unsafe fn` in windows 0.62.2 (no arguments). Its block says `// SAFETY: the context is owned by the shared
  DeviceResources and alive; the previous frame was ended (drawing == false); the target is attached`. The `WaitForSingleObjectEx` call is behind `gfx::extras::wait_for_handle`.
- COM lifetimes: the surface owns an `Rc<DeviceResources>`; the draw context owns another; the cache owns another. The last drop disposes; `dispose()` on the surface disposes eagerly (the C# behaviour).
- Reentrancy: handlers are called while `&mut self` is held by `recreate_device`; they must not capture the surface (they cannot: it is not `Clone` and not shared).
- Thread affinity: UI thread; `!Send`.

## Error mapping to `RenderError`
`RenderFault` to `RenderError` field by field (W8-12b). The adapter additionally maps `PresentResult` 1:1 by discriminant. Messages are the verbatim C# strings quoted above (they feed the log).
