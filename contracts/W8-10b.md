## Semantics notes (cited by number in the stub)
1. **Save order and partial writes.** `apply_all` runs the rows in table order and stops at the first refusal; rows before it stay written in the
   settings clone (the dialog stays open, so this is invisible to the user). Inside a row: ImageTransition and TouchpadSwipe write their enable flag
   BEFORE validating the number (golden `apply-transition-refused-keeps-kind`, `apply-touchpad-refused-keeps-enabled`); Preload and the overlay row
   validate everything BEFORE the first write (golden `apply-preload-backward-bad-keeps-nothing`, `apply-overlay-toolbar-delay-bad`).
2. **ViewMode.** Index: Fit 0, FitWidth 1, FitHeight 2, ClickZoomLevel 3, Percent100 4, Percent200 and Percent400 5 (the 400 % item is gone; a stray
   400 % lands on the 200 % item). Any other index gives `Fit`.
3. **Anchors.** The combo items are in enum order (index == value). An index that is not a member (negative, > 2) gives the row fallback
   (`Centre` for row 1, `BottomThird` for row 2).
4. **Load clamps.** Only ToolbarOpacity is clamped on load (to 20..100). Every other number is shown as stored (golden `load-ClickZoomPercent-0`,
   `-m5`, `9999`), because the presenter (W8-10d) decides what the slider can show.
5. **InfoOverlayFontSize text** is `ToString(Invariant)` of the double (T13). The golden cases `load-InfoOverlayFontSize-*` fix the format.
6. **Rounding.** `Math.Round(double)` rounds half to even (T1): 2.5 gives 2, 3.5 gives 4, 54.5 gives 54, 55.5 gives 56. Opacity then clamps to 20..100.
7. **Font size.** Parse with `NumberStyles.Float` (T4). The value must be finite and within 8..24. The message has no focus.
8. **Context menu.** Load: `shown` = every item that is locked or not in `effective_hidden`; the locked items are always shown. Apply:
   `apply_hidden(settings, items whose id is not shown)`; `apply_hidden` drops locked ids (golden `apply-context-one-unticked`). Apply returns no
   refusal. The golden `EffectiveHiddenContextMenuItems` is the sorted effective set after apply.
9. **Shortcuts.** Load copies the raw text (no canonicalize). Read takes the text as typed (missing box = `""`; `MoveToFolder2` keeps the default).
   Canonicalize runs every one of the 27 boxes through `shortcuts::canonicalize`, and `MoveToFolder2` is copied from the existing settings.
10. **Actions.** Load writes the indented JSON. Apply: a JSON parse error or a validation error refuses with the same `actionsJson` message; the parsed
    list is assigned BEFORE validation, so a list that fails validation stays in the clone (golden `apply-actions-invalid-assigned-anyway`).
    The JSON `null` is the empty list (golden `apply-actions-null-literal`).
11. **ImageSortMode tag.** `Enum.TryParse<ImageSortMode>(tag)` with the .NET rules: surrounding whitespace is removed; the member NAME must match
    exactly (case-sensitive, no aliases, see T5); a number is accepted when it is a member value. Anything else gives `Name`. `None` gives `Name`.
12. **Trim.** `ExternalEditorPath.Trim()` is `str::trim` here: the Unicode White_Space set equals .NET `char.IsWhiteSpace` (both include U+0085, U+00A0,
    U+2000..U+200A, U+3000). Golden: `apply-editor-*` with U+0085, U+00A0 and U+200B (U+200B is NOT trimmed by either).
13. **Messages** (English catalog keys, `format_with` on the localizer, `{min}` and `{max}` as integers except the font size, see Q8):
    `dialog.settingsInvalid.clickZoomPercent` (min 10, max 800, no focus); `.arrowPanStepPercent` (1..100, ArrowPanStep);
    `.keyboardZoomStepPercent` (5..100, KeyboardZoomStep); `.imageTransitionMs` (40..400, ImageTransitionMs);
    `.touchpadSwipeDistance` (30..2400, TouchpadSwipeDistance); `.preloadForward` (1..500, PreloadForward); `.preloadBackward` (0..500,
    PreloadBackward); `.toolbarAutoHideDelay` (0..10000, no focus); `.infoOverlayAutoHideDelay` (0..10000, InfoOverlayAutoHideDelay);
    `.infoOverlayFontSize` (8..24, no focus); `.actionsJson` (no args, no focus). Bounds are the `pr_core::settings::app_settings` `MIN_*`/`MAX_*`
    constants and `perf_options::{MIN_PRELOAD_FORWARD_COUNT, MIN_PRELOAD_BACKWARD_COUNT, MAX_PRELOAD_COUNT}`.
14. **Index helpers need no "undefined" branch in Rust.** C# `Enum.IsDefined(x) ? x : fallback` cannot see an undefined value in the Rust enum. The
    stub's `index_to_anchor` uses `lenient_from_number` (defined members only). Undefined C# values are not in the golden (Q4).

## Traps (docs/MULTI-AGENT-PLAN.md section 7; the stub cites T-numbers)
- **T1 Banker's rounding.** `Math.Round(double)` is round-half-even: `f64::round_ties_even`, never `f64::round` (semantic 6). Mutant: `round()`.
- **T2 Double to int.** `(int)` truncates; the Rust `as i32` saturates. Only reachable with NaN or out-of-range values, which the slider cannot
  produce (Q9). Not in the golden.
- **T3 `int.TryParse(NumberStyles.Integer)`.** Whitespace is only U+0009 to U+000D and U+0020 (NOT U+00A0, NOT U+200B; Rust `trim()` trims U+00A0, so
  `trim()` is wrong here). One optional sign, ASCII digits, no thousands separator, no exponent, no fractional zeros (`12.0` refused), overflow
  refused. Golden `try-int-*` (33 texts x 5 bounds).
- **T4 `double.TryParse(NumberStyles.Float, Invariant)`.** Same whitespace rule; sign; decimal point (`8.`, `.5` accepted); exponent; the symbols
  `NaN` and `Infinity` parse (then refused by `IsFinite`); `1e400` parses to infinity (refused). `12,5` refused. Golden `try-double-*`.
- **T5 `Enum.TryParse` is not `parse_lenient_text`.** The Rust helper accepts aliases (`PortraitFirst`, `Size`) and ignores case; the C# call does
  neither. Do not reuse `parse_lenient_text`. Golden: `apply-sort-tag-PortraitFirst` and `apply-sort-tag-Size` give `Name`.
- **T6 `Enum.IsDefined`.** Rust has no undefined member; `lenient_from_number` is the analogue (semantic 14).
- **T7 Refusal stops the pass.** See semantic 1. The golden `apply_all` cases check the partial state, not only the message.
- **T8 Assign before validate.** The actions list is assigned after a successful parse and before validation (semantic 10).
- **T9 Shortcut accessors.** By name in Rust: an unknown name must never reach them (the table is fixed). `MoveToFolder2` is not in the 27 and is
  copied from `existing` on canonicalize.
- **T10 Row order.** `bindings()` order is the Save order; the golden `tables.bindings_in_order` is the check. Do not sort.
- **T11 ImageCacheRamPercent has no Load.** The C# `null` load is a no-op; do not write `ramCachePercent` on load.
- **T12 Trim.** See semantic 12.
- **T13 `double.ToString(Invariant)`.** Shortest round-trip digits; fixed notation in the usual range, `E+xx`/`E-xx` outside. `12.0` gives `12`,
  `12.5` gives `12.5`. The exact exponent thresholds are golden-checked (`double-text-*`, `load-InfoOverlayFontSize-*`). If a threshold disagrees,
  escalate (Q10); do not guess.
- **T14 Null and empty.** `SortModeTag` `None` gives `Name`, `Some("")` gives `Name` too (both refuse the parse). `ExternalEditorPath` `""` stays `""`.
- **T15 Message arguments.** Integer bounds are `LocValue::Int`; the font size bounds are doubles (Q8). No grouping separator in any of them.
- **T16 No literal UI text** (D-W8-4): messages come from the localizer; the tests may spell the English text.
- **T17 Percent400.** Maps to index 5 and back to Percent200 (semantic 2).
- **T18 Locked context-menu items.** Always shown on load, never hidden by apply (semantic 8).
- **T19 Flags.** `exif_info_fields` and `title_bar_fields` are copied whole; the golden uses the flag bit values (`load-exif-fields-*`).
- **T20 DecoderBackend LibRaw.** C# loads LibRaw as index 0 and applies index 0 as Wpf. Kept identical (golden `load-DecoderBackend-LibRaw`,
  `apply-decoder-index-0`); see Q6.
- **T21 Overflow.** `try_int` refuses values outside `i32` (golden `2147483648`); no arithmetic on user values in this unit.
