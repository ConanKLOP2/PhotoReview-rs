## Traps
- Synchronous on the UI thread, no `async`; a modal prompt is a blocking `DialogService` call and must not run while a `RefCell` borrow of anything is held.
- An unknown id never shows a dialog; a launch failure of an EXPECTED kind never throws; an UNEXPECTED one must not be hidden.
- `add_external_editor` keeps the default: a new editor appended to a non-empty list is NOT the default.
- The legacy path alone (no list) is materialised BEFORE the append, so the legacy editor keeps its place and its default role (test `AddExternalEditor_WhenOnlyTheLegacyPathExists_...`).
- `ExternalEditorBug` stays the only `Err` of these methods; `add`/`choose` return a plain `ChangeSet` (nothing in them can propagate).

   806	    {
   807	        var shown = _compare.SelectedPath ?? _presenter.CurrentPresentedPath ?? _catalog.Current?.Path;
   808	        if (string.IsNullOrEmpty(shown)) return;
