## Semantics (C# is the spec)
### The trampoline (`WndProcThunk.ShellWindowWndProc`, C# 40-83; D-W8B3H-12)
1. **Cookie.** `make_cookie(target)` boxes the `Rc<dyn WindowTarget>` (`Box::into_raw(Box::new(target))`, a thin pointer) and returns it as `isize` (never 0). `free_cookie` reconstructs and drops the box. The target is `ShellWindowInner`, which owns its own cookie and frees it in `free_self` (idempotent via `cookie.replace(0)`).
2. **`shell_window_proc(hwnd, message, wparam, lparam)`** runs entirely under `pending_panic::guarded(LRESULT(0), ..)`. `WM_NCCREATE`: `lparam` is a `*const CREATESTRUCTW`; `cookie = lpCreateParams as isize`; `0` -> return `LRESULT(0)` (creation fails, C# "no owner"); else `SetWindowLongPtrW(hwnd, GWLP_USERDATA, cookie)`.
   Any other message: `GetWindowLongPtrW(hwnd, GWLP_USERDATA)`; `0` -> `DefWindowProcW` (messages before `WM_NCCREATE` such as `WM_GETMINMAXINFO`, and after `WM_NCDESTROY`).
3. With a cookie: `let target: Rc<dyn WindowTarget> = (*cookie_ptr).clone()` (CLONE FIRST: the target may free its own cookie in `on_native_destroyed`); `result = target.process_message(..)`; if `message == WM_NCDESTROY`: `SetWindowLongPtrW(GWLP_USERDATA, 0)` then `target.on_native_destroyed()`; return `result`.
4. **Panic guard.** Rust 2024 aborts when a panic unwinds out of `extern "system"`. `guarded` catches it, stores the payload (first wins) and the procedure returns `0` WITHOUT calling `DefWindowProc` (C# 79: `DefWindowProc(WM_CLOSE)` would destroy a window whose `Closing` handler had not decided; `WM_NCCREATE` returning 0 cancels creation).
   The owner resumes the panic after the native call returns: `MessageLoop` after `DispatchMessage` (13c), `ShellWindow::create` after `CreateWindowEx`, `close` after `SendMessage`, `dispose` after `DestroyWindow`, `show_command` after `ShowWindow`, `apply_initial_size` after `SetWindowPos` (all call `rethrow_pending()`).

### `ShellWindow::create` and the public API (C# 56-249)
5. `ensure_class_registered()?`; `cookie = make_cookie(inner.clone())`; `create_window_ex(0, CLASS_NAME, options.title, WS_OVERLAPPEDWINDOW, CW_USEDEFAULT x4, parent 0, menu 0, get_module_handle(), cookie)`. On `Err`: read the error FIRST, `free_self()`, `rethrow_pending()` (a captured panic wins over the Win32 error), then
   `Err(Win32 { operation: "CreateWindowEx (shell window) failed", .. })`. On success `rethrow_pending()`, `apply_initial_size()`, `last_raised_client_size = client_size_dip()`.
6. `ensure_class_registered`: once per process (`Mutex<bool>`, only success remembered); `style = 0`, `lpfnWndProc = Some(shell_window_proc)`, `hInstance`, `hIcon = icons::load_big(0)`, `hIconSm = icons::load_small(0)`, `lpszClassName = CLASS_NAME`; `hCursor` and `hbrBackground` stay 0 as in C# (the procedure sets the cursor on `WM_SETCURSOR` and returns 1 for `WM_ERASEBKGND`).
   `Err(Win32 "RegisterClassEx (shell window) failed")`.
7. `apply_initial_size` (C# 319-336): `rect = (0, 0, to_pixels(width_dip, scale), to_pixels(height_dip, scale))` with `scale = dpi / 96.0` (the dpi was read in `WM_NCCREATE`). `if size_is_outer || adjust_window_rect_ex_for_dpi(&mut rect, WS_OVERLAPPEDWINDOW, false, 0, dpi).is_ok()` { `set_window_pos(hwnd, 0, 0, 0, width, height, SWP_NOMOVE | SWP_NOZORDER | SWP_NOACTIVATE)`; `rethrow_pending()` }
   (when the adjust call fails and the size is not outer the window keeps its default size, exactly as C#). Then `get_client_rect`; on success store `client_width_px`/`client_height_px`.
8. `to_pixels(dip, scale)` = `(dip * scale).round_ties_even()` as `i32` (C# `Math.Round` default is banker's rounding, `(int)` cast; Rust's `as` saturates and maps NaN to 0 where C# x64 gives `int.MinValue`: documented, not reproduced).
9. **Events** (`EventList<H>`, D-W8B3H-12): ids from 1; `raise` iterates a snapshot of the slot ids, takes each handler out for the call (no `RefCell` borrow held), puts it back, drops it if it was removed while running; a handler added while raising is not called in that raise; a panicking handler is put back and the panic propagates (C# multicast: the exception leaves the subscription alone).
   `Closing` handlers get `&mut CancelEventArgs` (13f raises them). `subscribe(event, handler)` returns the id; `unsubscribe` removes from whichever list owns the id.
10. **`invalidate`** (C# 139-149): `render_requested || destroyed` -> return; else `render_requested = true` and `frame_subscription = Some(frame_clock.subscribe(handler))` where the handler is a `Weak<ShellWindowInner>` upgrade calling `on_frame(tick)` (a strong `Rc` in the clock would keep the window alive). `on_frame`: unsubscribe `frame_subscription`; `render_requested = false`; destroyed -> return; `render_count += 1`; raise `Render`.
    Net effect (test): any number of `invalidate` calls before the next frame produce ONE `Render`, and the clock is not armed afterwards.
11. `set_title`: destroyed -> `Ok(())`; `dialog_native::user32::set_window_text(hwnd, title)`; `Err(Win32 "SetWindowText failed")`. `set_cursor`: store; `if !destroyed && (has_pointer_capture() || is_pointer_over_client())` -> `user32::set_cursor(cursor_handle(cursor))`. `cursor_handle`: `load_system_cursor(IDC_ARROW | IDC_SIZEALL | IDC_WAIT)`, each loaded once (`OnceLock`), a failure gives 0 (no cursor change).
12. `capture_pointer`: `!destroyed` -> `set_capture(hwnd)`. `release_pointer`: `has_pointer_capture()` -> `release_capture()`. `has_pointer_capture`: `hwnd != 0 && native::get_capture() == hwnd`. `screen_to_client_dip(p)`: `Point { x: round_ties_even(p.x) as i32, y: .. }`; `!destroyed` -> `screen_to_client(hwnd, &mut point)`; `PointD { x: point.x / scale, y: point.y / scale }`.
13. `close`: destroyed -> return; `send_message(hwnd, WM_CLOSE, 0, 0)` then `rethrow_pending()`. `show(activate)` = `show_command(activate ? SW_SHOWNORMAL : SW_SHOWNOACTIVATE)`; `show_command(c)` = `show_window(hwnd, c)` then `rethrow_pending()`. `set_surface_ready` stores. `is_loaded` = `created && !destroyed && surface_ready`.
14. `dispose` (C# 238-249; also `Drop`): `hwnd != 0 && !destroyed` -> `destroy_window(hwnd)` (an error is ignored) then `rethrow_pending()`; always `free_self()`. In `Drop` the rethrow is skipped when `std::thread::panicking()` (a double panic aborts).
15. **Lifecycle arms**: `on_nc_create(hwnd, ..)`: `hwnd` stored, `dpi = get_dpi_for_window(hwnd)` (0 -> 96), return `def_window_proc(..)`. `on_create`: `created = true`, `icons::apply(hwnd, dpi)`, 0. `on_destroy` (`WM_DESTROY`): `destroyed = true`; `is_active = false`; if `get_capture() == hwnd` `release_capture()`; if `render_requested` { clear it, unsubscribe the frame subscription }; raise `Closed`; return 0.
    `WM_NCDESTROY`: `def_window_proc`; the trampoline then calls `on_native_destroyed` = `free_self`.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (GWLP_USERDATA trampoline): clone the `Rc` before calling the target; clear the slot BEFORE `on_native_destroyed`; a message after `WM_NCDESTROY` finds 0 and goes to `DefWindowProc` (never a dangling cookie). The cookie is freed exactly once (creation failure path, `WM_NCDESTROY`, `dispose` all call the idempotent `free_self`).
- T2 (UI-thread affinity): the C# `VerifyAccess` becomes the `!Send` of `ShellWindow` (an `Rc`); `ShellWindowInner` is only reachable through the cookie on the creating thread (a window belongs to its creating thread, the OS delivers messages there).
- T3 (message pump re-entrancy): `process_message` is re-entered by `SendMessage` from inside handlers (e.g. a handler calls `set_title`, `close`); every field is `Cell`/`RefCell` and no `RefCell` borrow is held across a call that can re-enter (handlers, events, the OS). The handler list is cloned before iteration (13f).
- T4 (FFI panic guard): see 4. A test panics inside a target and checks the OS got `0`, the panic resumes at the owner, the process did not abort.
- T5 (WM_QUIT): a window never posts `WM_QUIT` itself (the app's `Closed` handler calls `MessageLoop::quit`, as in the leak test).
- T6: `WS_OVERLAPPEDWINDOW` etc. are the `win32::messages` constants (the C# `WindowMessages` names); `SWP_*` flags combine with `|`; `CW_USEDEFAULT` is `user32::CW_USEDEFAULT` (-2147483648 as `i32`).
- T7: class name `PhotoReviewRs.Shell.Window` in the class and the call must match (a typo gives `ERROR_CANNOT_FIND_WND_CLASS`, error 1407): one `const`.
- T8: `Weak` in the frame handler (10); `Drop` does not leak the clock subscription (a test counts clock subscribers after dispose).
- T9: integer conversions: `lpCreateParams` is a pointer-sized value (`as isize`, not `as i32`).

## Safety rules (`// SAFETY:` per block)
`shell_window_proc`: (a) reading `CREATESTRUCTW` from `lparam` (valid for `WM_NCCREATE` for the duration of the call, per the Win32 contract; null-check first); (b) dereferencing the cookie (a `Box<Rc<dyn WindowTarget>>` created by `make_cookie` and freed only after the slot was cleared); (c) `SetWindowLongPtrW/GetWindowLongPtrW` (plain integers, wrappers).
`make_cookie`/`free_cookie`: `Box::into_raw` / `Box::from_raw` pair. `create`: `create_window_ex` (`param` = the cookie our procedure expects), `register_class_ex` (class name vector outlives the call). `close`: `send_message(hwnd, WM_CLOSE, 0, 0)` (no pointers). Every call that passes `&mut Rect`/`&mut Point` uses the safe wrappers.
