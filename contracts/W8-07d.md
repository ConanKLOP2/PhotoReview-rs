## Semantics notes
1. **`run_action`** (lines 68 to 116): `catalog.count() == 0` -> Done(false); settings read at use time (`get_settings().actions`); index out of range -> Done(false); `operation` not in `{Move, Copy, Recycle}` -> status
   `status.actionInvalidOperation(name)` and Done(false) (the C# `Enum.IsDefined`; Rust enums are closed, so this arm exists only if pr-core's `FileOperationType` keeps an invalid value: check; otherwise port as N/A with a comment);
   Recycle with `refuse_recycle_without_bin(compare.or(current))` -> Done(false); `permanent_prompt` and `group_prompt` computed with the 07c helpers; the generic confirmation (`action.confirm && dialog_service && !permanent && !group`)
   with the R7-4 re-check (folder, busy, target still in the catalog); Recycle -> core (destination ignored); else empty `source` -> Done(false); blank destination -> status `status.actionNoDestination(name)`, Done(false); core.
2. **`execute_core`** (lines 278 to 330): `source_index = catalog.index_of(source)`; `is_remove = Move || Recycle`; remove only: `clock.stop_for_action()` then `preload.cancel()`; `folder_gen = clock.current_folder()` (AFTER the bump) stored as
   `last_action_folder_gen`; `previous_path = path_at(source_index - 1)` when remove and `source_index > 0`; remove only: `next = catalog.remove(source)`; `sink.on_catalog_changed(Some(source))`; for a capture
   `sink.evict_cached_paths(members other than source, OrdinalIgnoreCase)`; `next >= 0` -> `sink.present(next)` and `present = Running` (INV-3: BEFORE the I/O, no waiting), else status `AllImagesProcessed`.
   The job on `WorkerLane::FileAction`: `executor.execute(&FileActionRequest{ source, operation, destination, allow_permanent_delete }, &CancelToken::none())` or `execute_group` for a capture; a panic -> `ExecOutcome::Panicked(describe)`.
   A Copy does NOT stop reads, cancel preload, change the catalog or re-present (tests `Copy_DoesNotStopReadsOrCancelPreload`, `Move_StillStopsReadsAndCancelsPreload`).
3. **`on_executed`** in this order (lines 329 to 522): `succeeded` and `source_removed` from the result (group: `members.any(completed) && operation in {Move, Recycle}`).
   (a) **Late completion** (`!is_folder_current(folder_gen)`): group -> `undo.register_group(result)` (also the completed members of a part-way failed Delete) and, when `succeeded`, a late status
   (`status.lateMoveUndoable` for Move with an entry destination; Recycle: `lateDeletedPartlyPermanently` when some completed members were permanent and some not, `lateDeletedPermanently` when all completed were permanent, else `lateRecycleUndoable`);
   single -> succeeded: `report_late_completion`; failed Move with `source_removed`: `status.moveUnverified`; a failed group Recycle with `processed > 0` completed members -> `status.lateGroupPartiallyProcessed(name, processed, total)`;
   always Done(false); NO catalog change, NO restore, NO session write. (b) **Success**: `undo.register`/`register_group`; remove and `source_index >= 0` -> `remember_move_position(source, previous_path, group)`;
   `sink.update_session_path(current path or source)`; partner files skipped -> park a `PartnerMissing` tail on the present (status `status.groupPartnerMissing`, prefixed by `AllImagesProcessed + " "` when a remove emptied the catalog), else catalog empty ->
   `AllImagesProcessed` (remove) or `ActionCompleted` (copy), else Copy -> `status.copiedTo(file name of the destination)`; a Move/Recycle with others left writes NO status (test `RunAction_MoveWithOthersRemaining_WritesNoStatusAtAll`). Done(true) (after the tail, if any).
   (c) **Unverified Move** (F3: failed, single, `source_removed`): park `UnverifiedMove`; the entry is NOT restored; no undo. (d) **Failure**: group -> `register_group` (the members already in the bin get Ctrl+Z); remove and `source_index >= 0`:
   single -> `catalog.restore(source, source_index)`; group -> `restore_members(available, source_index, group, settings.raw_support_enabled)` where `available` = all image paths when `members` is empty, else members whose source is an image path of the group and
   (`!state_known || source_exists`), then `sink.on_catalog_changed(None)`; then park `Failure` (status `ActionFailed(name, error)`; for Recycle with no completed member also the `dialog.recycleFailed.*` error). (e) **Executor panic**: if the action had succeeded
   (bookkeeping failed) -> log, park `CompletedAfterBookkeepingFailure`; else log, restore ONLY when remove, `source_index >= 0` and the folder is still current, park `ExecutorThrew` (status `ActionFailed(name, describe)`, recycle dialog).
   (f) `Canceled` -> no restore, no status, `Done(Canceled)`. (g) **finally**: `sink.notify_navigation_state_changed()` once per core, on every path that ends it (also when parked, at the time the tail ends).
4. **Parked tails / `on_present_finished`.** Each C# `await presentTask` becomes: if `present` is `Finished`, run the tail now; if `Running`, park it (`ParkedTail`), `on_present_finished` runs it; `None` -> run now. A faulted present is logged
   (`log.error("Present after failed file action threw")`) and never replaces the action's own error text. Every tail first checks `clock.is_folder_current(folder_gen)` (R08): if not, it writes NO session path and NO status and returns Done(false) (or the C# value).
5. **`report_late_completion`** (lines 599 to 617): `rejected` -> nothing; else `undo.register(result)`; Move with a destination -> `lateMoveUndoable(fileName, parent directory of destination)`; Recycle permanent -> `lateDeletedPermanently`; Recycle -> `lateRecycleUndoable`; Copy silent.
   All through `sink.show_late_action_status` (the sink may drop it).
6. **Move positions** (`undo.rs`): `remember_move_position` clears the map at 256 entries, stores under `ignore_case_key(source)` and, for a capture, under every member path. `take_move_position` removes the source and every member of its group.
   `insert_restored_move`: `PreviousPath == None` -> index 0; predecessor still listed -> `index_of(prev) + 1`; else `sorted_insert_index` (first index whose file name is NOT less under the natural comparer); restored paths non-empty -> `restore_members(paths, index, group, raw_enabled)` else `restore(source, index)`.
7. **`undo_last`** (lines 620 to 721): no undo service -> `Done(Undone(None))`; `folder_gen` BEFORE the call; the job is `undo_service.lock().undo_last()` on `WorkerLane::FileAction`. `on_undone`: **failed** -> if the folder is current and `restored_paths` non-empty and the source is in the current folder:
   restore the in-folder members (`insert_restored_move(.., keep_position = true)`), `on_catalog_changed(None)`; catalog was empty -> `present(max(current_index, 0))` and park `FailedPartialPresented`; then `update_session_path(current.or(source))`, `notify_navigation_state_changed`;
   then (folder still current) status `error_message.or(status.nothingToUndo)`. **Succeeded**: folder not current -> return the result untouched; `restores_outside_folder(result, current_folder)` (07e) -> `take_move_position`, and only if the SOURCE is in the folder: `on_catalog_changed(None)` + `update_session_path(source)` (the caller reloads);
   else Recycle in its folder -> `insert_restored_move`, `on_catalog_changed(None)`, catalog was empty -> `present(index_of(reload_path_after_undo.or(source)) or max(current_index,0))` and park `RecyclePresented`, else `preload.preload_around(max(current_index, 0))` (fire and forget; the `RunHandle` is dropped); `update_session_path`;
   else Move in its folder -> `insert_restored_move`, `on_catalog_changed(None)`, `idx = index_of(source)`, `idx >= 0` -> `present(idx)` and park `MovePresented`, then (folder current) `update_session_path(source)`. Finally `error_message` non-empty -> status, and `notify_navigation_state_changed`.

## Traps checklist (concrete)
- **INV-3**: `present(next)` is called BEFORE the executor job is submitted and nothing waits for it; nothing may re-present after the action (F-07).
- **INV-5**: after the I/O, every write into the catalog, the session or the status line requires `is_folder_current(folder_gen)` where `folder_gen` was read AFTER `stop_for_action` (D-02). The restore on the executor-panic path is gated, the restore on the normal failure path is NOT gated by the
  folder (it is gated by `late completion` returning earlier): keep exactly the C# structure.
- **INV-6** (caller side): the result of a part-way failed group Delete is registered for undo BEFORE the catalog is restored; `allow_permanent` flows from 07c unchanged.
- **Never restore a source that no longer exists**: unverified Move (`source_removed`) keeps it out of the catalog; the group restore filters by `source_exists`/`state_known`.
- **Status ordering (RV-A09)**: the failure/partner-missing/Moved-to statuses are written after the present finished, otherwise the presenter's "Ready" overwrites them.
- A cancelled executor/undo (`Canceled`) is NOT a failure: no status, no restore, `Done(Canceled)`; the `finally` (`notify_navigation_state_changed`) still runs.
- `sorted_insert_index` compares FILE NAMES with the injected natural comparer, `Some(a)`/`Some(b)`; do not use `str::cmp`.
- `UndoService` lock: recover poisoning with `PoisonError::into_inner`; never hold the lock while calling the sink (the lock is held only inside the worker job).
- The `RunHandle` returned by `preload_around` is dropped without waiting (C# `FireAndLog`).
- Paths: `ignore_case_key`/`eq_ignore_case` from `pr_core::text`; `get_file_name`, `get_directory_name` from `pr_core::text::dotnet_path`.
- No `async`, no `block_on`, no `unsafe`, no `windows` crate.
