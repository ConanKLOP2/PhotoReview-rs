- Later PowerShell staging proposal: accept explicit C# checkout path; verify source DLL against pinned SHA-256; verify package zip before extraction if used; copy only verified DLLs into Rust `native/x64/`; hash destination again; fail on missing pin, mismatch, unexpected architecture, or partial copy.
