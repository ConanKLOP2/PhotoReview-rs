- Semantics notes (from the contract writer; each one is a C# behaviour a Rust test checks):
  1. **Identity and ids.** `ElementBase::new(id)` panics on an empty id (C# `ArgumentException.ThrowIfNullOrEmpty`). Ids are compared
     ordinally (`==` on `str`). Uniqueness across the tree is NOT checked here (`OverlayHost`, W8-15f, does it).
  2. **Visibility and opacity.** `is_visible` defaults to `true`. `opacity` defaults to `1.0`. The setter maps NaN to `0.0` and
     clamps to `0.0..=1.0` (trap T3). `OpacityTarget` is the same setter.
  3. **Measure.** Collapsed (`!is_visible`): store and return `(0, 0)` as `desired_size`. Otherwise `w0 = max(0, min(available.width -
     margin.horizontal, max_width))`, `h0 = max(0, available.height - margin.vertical)`, `content = measure_core((w0, h0))`, and the result
     is `(min(content.width, max_width) + margin.horizontal, content.height + margin.vertical)`, stored as `desired_size`.
  4. **ArrangeIn.** `slot` includes the margin. Collapsed: `bounds = (slot.x, slot.y, 0, 0)`, and `arrange_children` is NOT called. Otherwise:
     `inner = slot` minus margin (`innerX = slot.x + margin.left`, `innerW = max(0, slot.width - margin.horizontal)`, same for Y and H);
     `desiredW = max(0, desired.width - margin.horizontal)`, `desiredH = max(0, desired.height - margin.vertical)`;
     `width = Stretch ? min(innerW, max_width) : min(desiredW, innerW)`; `height = VStretch ? innerH : min(desiredH, innerH)`;
     `x = Right ? innerX + innerW - width : Center ? innerX + (innerW - width)/2 : innerX` (C# switch, same for Y with Bottom/Center/Top);
     `bounds = (x, y, width, height)`; then `arrange_children`.
  5. **Arrange (host surface).** `arrange(ctx)` = `measure(ctx.client, ctx)` then `arrange_in((0, 0, ctx.client.width, ctx.client.height), ctx)`.
  6. **Render.** Collapsed or `opacity <= 0`: return (no push). Otherwise `push_opacity(opacity)`, `render_core(dc)`, `pop_opacity()`. The pop
     always follows the push (no early return in between). A child of a layer pushes its own opacity inside the layer's push.
  7. **HitTest.** `is_visible && is_hit_test_visible && opacity > 0 && bounds.contains(point)`. A collapsed element never hits, even at
     its zero-size bounds; `is_hit_test_visible = false` (the `TextElement` default) passes clicks through.
  8. **LayerElement.** `new(id)`: hit-test visible. `add` appends and returns `&mut self`. `measure_core`: measures each child (collapsed
     children too) with the same `available`, stores each child's desired size, returns `(max width, max height)` starting at `(0, 0)`.
     `arrange_children`: each child (collapsed too) is `arrange_in(self.bounds(), ctx)`. `render_core`: children in insertion order.
     `find_at`: `None` if the layer is hidden, not hit-test visible, `opacity <= 0`, or `bounds` does not contain the point; else the first
     `Some` from the children in REVERSE order (topmost first). The layer itself is never the answer. `find(id)`: self if the id matches,
     else the first match depth-first in insertion order. `release_resources`: forwards to every child.
  9. **OverlayModel defaults.** `font_size = 12`, `exif_font_size = 11` (the C# initialisers, not zero); every flag `false`; every string `""`.
     `exif_font_size` is stored, not computed from `font_size` (C# stores both).
  10. **OverlayLayoutContext.** A plain value: `new(client, dpi_scale, text)` stores the three fields. Layout never reads `dpi_scale`
      (C# doc of `OverlayElement`): a test changes `dpi_scale` and checks identical bounds.

- Traps checklist (MULTI-AGENT-PLAN section 7 items 1, 3, 4, 8 and 9 apply; the items below are specific to this unit):
  - **T1 NaN and -0 equality.** C# `record struct`/`record` equality uses `double.Equals`: NaN equals NaN, `0.0` equals `-0.0`. Every
    struct holding `f64` (`OverlayThickness`, `OverlayModel`) implements `PartialEq` by hand with `f64_same` (from `input::primitives`) for
    each `f64` field. A derived `PartialEq` would make a NaN margin unequal to itself.
  - **T2 Math.Min/Math.Max propagate NaN.** Rust `f64::min`/`max` ignore a NaN operand. In `measure` and `arrange_in` use the .NET order:
    a helper `if a.is_nan() || b.is_nan() { f64::NAN } else if a <= b { a } else { b }` for min, and the mirror for max. Example: `measure`
    with `available.width = NaN` must give a `desired_size.width` of NaN (C#: `Math.Min(NaN, max)` = NaN, `Math.Max(0, NaN)` = NaN), not the
    finite `max_width`. `LayerElement::measure_core` uses the same max (a NaN child width makes the layer's width NaN).
  - **T3 Opacity setter.** `NaN -> 0.0` first (C# `float.IsNaN(value) ? 0f : Math.Clamp(value, 0f, 1f)`). Clamp in the `Math.Clamp` order:
    `if value < 0.0 { 0.0 } else if value > 1.0 { 1.0 } else { value }`, so `-0.0` stays `-0.0` (do not use `f32::clamp`: it is equivalent
    here, but keep the order visible in the code). `set_opacity(5.0)` gives `1.0`; `set_opacity(-1.0)` gives `0.0`.
  - **T4 Collapsed bounds.** The collapsed `arrange_in` sets `bounds` to `(slot.x, slot.y, 0, 0)`, NOT to `RectD::default()` (which is at the
    origin). The Layer test "hidden child" depends on the slot origin. Children of a collapsed element are not arranged, so their `bounds`
    keep the values of the last visible arrange (C# semantics; do not "fix" it).
  - **T5 Desired size of a collapsed element.** `measure` stores `SizeD::default()` (0, 0) and returns it; `arrange_in` ignores the
    desired size when collapsed. A collapsed child contributes 0 to its parent's `measure_core` max.
  - **T6 Layer measure is the max over all children.** Collapsed children count with size 0 (they do not lower the max, they add nothing).
    Empty layer: `(0, 0)`.
  - **T7 Layer `find_at` never returns the layer.** An empty cell is click-through: `find_at` on the layer with no child under the point
    returns `None`, even when the point is inside `bounds`. The C# `Layer_EmptySpaceIsClickThrough` test checks it. The base `hit_test` of
    the layer (used by the host through `OverlayElement`) still counts the layer as hit; only `find_at` excludes it. Do not "unify" them.
  - **T8 Model defaults are not zeros.** `OverlayModel::default()` has `font_size = 12.0` and `exif_font_size = 11.0`. `#[derive(Default)]`
    would give `0.0` and is FORBIDDEN here; write the `Default` impl by hand.
  - **T9 Module placement.** `PointD`, `RectD`, `SizeD` stay in `input::primitives` (01a), and `DrawContext`/`TextRenderer` stay in
    `services::render` (12a). Do not re-declare them in `overlay`. `OpacityTarget` and `OverlayAnimator` live in `contracts.rs` (15b uses
    them from there; 15b does not redeclare `IOpacityTarget`).
