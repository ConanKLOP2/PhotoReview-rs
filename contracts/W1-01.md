## Semantics notes

* Numeric values are persisted in config.json and journal lines. They are exactly the C# values, which for every enum are `0..n-1` in
  declaration order. Never renumber, reorder or insert.
* `[JsonAlias]` in C# is `#[alias("...")]` in the macro and surfaces as `LenientEnum::aliases()`. The complete alias list is:
  `ImageSortMode::Name` has `PortraitFirst`; `SizeDescending` has `Size`; `InitialViewMode::Percent100` has `100%`, `Percent200` has `200%`,
  `Percent400` has `400%`, `FitWidth` has `fit-width`, `FitHeight` has `fit-height`, `ClickZoomLevel` has `click-zoom`;
  `FileOperationType::Recycle` has `Delete`. No other member has an alias. Aliases are READ-only spellings.
* What gets WRITTEN (`json_text`): the member name, except `InitialViewMode` where `Fit` is `Fit`, `Percent100` is `100%`, `Percent200` is `200%`,
  `Percent400` is `400%`; `FitWidth`, `FitHeight`, `ClickZoomLevel` are written as their names (NOT the `fit-width` aliases).
* `Default::default()` is C# `default(T)`, the zero member, which is not always the AppSettings default: `ImageSortMode::default()` is
  `Name` but the setting defaults to `Default` (value 3); `DecoderBackend::default()` is `Wpf` but the setting defaults to `WicDirect`;
  `LoadingMode::default()` is `Fast` but the setting defaults to `Preview`; `ScalingQuality::default()` is `Linear`, the setting
  `HighQuality`; `KeyboardZoomAnchor::default()` is `Pointer`, the setting `ViewportCentre`; `KineticGlideSmoothing::default()` is `Off`,
  the setting `Predict`. Those setting defaults belong to the AppSettings unit; do not add them here.
* `uses_explorer_order(mode)`: `true` for `Name`, `SizeDescending`, `SizeAscending`; `false` for `Default`, `NameAscending`,
  `NameDescending` (C#: `mode is not (Default or NameAscending or NameDescending)`). Note `Name` is a different mode from `NameAscending`
  even though they sort the same way.
* `DecoderBackend::LibRaw` exists and has value 3 (internal-only; the settings normalizer resets it, not this unit).
* `JournalState::Dismissed` (3) is part of the persisted set.
