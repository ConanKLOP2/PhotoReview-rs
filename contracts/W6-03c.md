## Required behavior

- Start one asynchronous accept loop; process one client at a time. Retry listener errors after 500 ms, and log failures.
- Read no more than `MaxMessageBytes + 1`; require a complete framed request within the default five-second read timeout.
  Malformed, oversized, incomplete, invalid UTF-8, path-invalid, or nonexistent-path requests receive `ERR\n` (when a
  reply remains possible), do not call the path callback, and do not terminate the listener loop.
- Valid requests are decoded with `ForwardedPathProtocol`, checked by the injected existence predicate (production:
  file or directory exists), passed to the callback exactly once, and answered `OK\n`.
- Dispose cancels and joins the loop so no new requests are accepted afterward. Dispose is idempotent; expected shutdown
  cancellation is not logged as an operational failure.
- The native server pipe rejects remote clients in addition to applying the current-user-only DACL (C# `PipeOptions.CurrentUserOnly`).
- Path callback failures reject that request and the loop remains serviceable. Keep any reply write bounded by the same
  request deadline and handle disconnect/IO errors without crashing the process.

## Concurrency and safety

- Native tests require Windows named pipes. Every test uses a unique pipe name and a bounded wait; do not poll with fixed
  sleeps. Use synchronization signals and timeouts. The C# test helper's `WithTimeout` bounds waits; Rust tests need an
  equivalent explicit timeout. A stalled-client case must close its own pipe client during cleanup.
- No test deletes files or interacts with the Recycle Bin. Inject `path_exists` and use fakes for path acceptance;
  the integration cases that verify OS pipe behavior use only test pipes.
- Mutation expectations: frame completion, `MaxMessageBytes + 1` bound, timeout cancellation, path-exists gate, callback
  invocation, `OK`/`ERR` response, accept-loop continuation after malformed input, 500 ms retry, and cancellation/join
  on dispose.
- Gates: `cargo fmt --all --check`; `cargo clippy -p pr-platform-win --all-targets -- -D warnings`;
  pure tests by default and native tests ignored with a reason. Final integration uses workspace gates.
