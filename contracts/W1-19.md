## Columns of a row (what the writer puts where)
`nav` = navigation id (or folder generation for `Folder*` events), `path_id`, then the numeric payload arguments in declaration order in `a`, `b`, `c`, `d` (bool as 0/1), remaining string arguments joined with `;` in `text`. A numeric view that is empty/garbage/non-finite is `None` (W1-16). `ms` below always means milliseconds; a time between two QPC readings is `file.qpc_to_ms(later - earlier)`.

## `build(file)` — one pass, then three post steps (apply in this order)
State: `by_nav: IndexMap<i64, Vec<PerfRow>>` (first-appearance order), `key_inputs`, `folder_rows`, `presented_global` (all `Presented` rows, any nav), `startup_anchor: Option<PerfRow>`.

0. `first_relevant_qpc` = the minimum `qpc_ticks` over rows with `event == "ShowStart"` OR (`event == "Folder"` AND `text == "start"`); `None` if there are none. (Case-sensitive: `START`, `FolderStart`, `showstart` do not count. The minimum over the whole file, not the first in file order.)
1. For each row in FILE order, by `event` (exact, case-sensitive match):
   - `KeyInput` -> `key_inputs.push(row)`; next row.
   - `PreloadItem` -> `PreloadItemRow { slot: a_num.unwrap_or(0.0) as i32, path_id: row.path_id, queue_wait_ms: b_num or 0, kind: row.text, ms: c_num or 0 }`; next. (`as i32` on f64 truncates toward zero and saturates, exactly like .NET 9+: `3.9`->3, `-1.5`->-1, `1e10`->2147483647. The row's `nav` column is ignored; a PreloadItem never creates a nav.)
   - `PreloadPaused` / `PreloadCancel` -> count++; next.
   - `DispatcherLongOp` -> if `first_relevant_qpc` is `Some(t)` and `row.qpc_ticks < t` (strictly): `dispatcher_long_ops_before_start_count += 1`; next. Otherwise push `DispatcherLongOpRow { ms: a_num or 0, priority, name }` where `text.split_once(';')` gives `(priority, name)` (`"a;b;c"` -> `("a","b;c")`; `";x"` -> `("","x")`; no `;` -> `(text, "")`; `""` -> `("","")`); next.
   - `Folder` -> `folder_rows.push(row)`; next.
   - `Startup` -> if `a_num` is `Some(v)` and `startup` has no key `row.text`: `startup.insert(text, v)` and, if `startup_anchor` is still `None`, `startup_anchor = Some(row)` (so the anchor is the first ACCEPTED Startup row; rows with an empty/non-finite `a`, and repeated phases, are skipped); next.
   - any other event falls through: if `event == "Presented"` push to `presented_global`; then `if let Some(id) = row.nav_id() && id > 0` push the row to `by_nav[id]` (create the entry on first sight). Rows with nav `0`, negative, empty, `abc` are dropped here, nav `" 5 "`/`"007"`/`"+9"` are ids 5/7/9. NOTE: events the builder knows nothing about (`FolderInfo`, `JoinStart`, `Weird`, ...) still land in `by_nav` and can become `ordered[0]` (see t0 below).
2. `build_folder_summaries` (below).
3. If `startup_anchor` is `Some(anchor)` (its `a_num` is `Some(anchor_ms)`) and `presented_global` is not empty: `fp` = the Presented row with the smallest `qpc_ticks` (first in file order on ties; `min_by_key` returns the first minimum); `startup["firstPresented"] = anchor_ms + file.qpc_to_ms(fp.qpc_ticks - anchor.qpc_ticks)` (addition in that order; may be negative or replace an existing `firstPresented` entry in place).
4. `key_input_index = KeyInputIndex::new(&key_inputs)`; for each `(id, rows)` of `by_nav` in insertion order push `build_nav_record(file, id, rows, &index)`.

### `build_folder_summaries`
Group `folder_rows` by the RAW `nav` text (ordinal; groups in first-appearance order). For each group: `generation = parse_integer_i64(key)`, else skip the group (`"x"`, `""`). `"02"` and `"2"` are two groups with the same `generation` 2 (two summaries). Inside a group sort by `qpc_ticks` STABLY, then:
- `t1_catalog_ready_ms` = `a_num` of the first row with `text == "catalogReady"`;
- the first row whose text is `explorerApplied`, `explorerFallback` or `explorerIgnored` gives `t3_ms = a_num` and `t3_phase = text` (`""` if none; the phase is kept even when `a` is empty);
- `start` = first row with `text == "start"`; if present, `fp` = the Presented row of `presented_global` with the smallest `qpc_ticks` that is `>= start.qpc_ticks` (an equal timestamp counts; first on ties); `t2_ms = qpc_to_ms(fp.qpc - start.qpc)`; no start or no such Presented -> `None`.
Any other `text` (`scanned`, `START`) is ignored.

### `build_nav_record(file, id, rows, index)`
`ordered` = rows sorted STABLY by `qpc_ticks` (file order breaks ties; `slice::sort_by_key` is stable, `sort_unstable*` is wrong). `rec = NavRecord { nav: id, ..Default }` (incomplete = true). `show_start` = first row of `ordered` with `event == "ShowStart"`. `t0` = `show_start.qpc_ticks` if any, else `ordered[0].qpc_ticks` (whatever event that is).
If there is a `show_start`: `rec.mode = show_start.text`; `m = index.nearest_at_or_before(show_start.thread, show_start.qpc_ticks)`; if `m` exists and `qpc_to_ms(show_start.qpc - m.qpc) > 500.0` (strictly; exactly 500.0 matches) then `m = None`; if `m`: `t_input_ms = m.a_num()` (may be `None`), `t_pre_ms = Some(qpc_to_ms(show_start.qpc - m.qpc))`, `t0 = m.qpc_ticks`. A second ShowStart of the same nav is ignored.
Then walk `ordered` with `pending_render: Option<f64> = None`, `first_presented_seen = false`, per event (exact match, others ignored):

| event | effect (every `row.a_num()` assignment OVERWRITES, also with `None`) |
|---|---|
| `Stat` | `t_stat_ms = a_num` |
| `Lookup` | `lookup_result = text` |
| `ThumbEnd` | `if text != "unknown" \|\| t_thumb_ms.is_none() { t_thumb_ms = a_num }` (specific source beats `unknown`; a later `unknown` never overwrites an existing value; an `unknown` with empty `a` leaves `None`, so the NEXT `unknown` can still fill it) |
| `JoinEnd` | `t_join_ms = a_num` |
| `DiskCacheRead` | `t_disk_ms = a_num` |
| `SourceRead` | `t_read_ms = a_num` |
| `Decode` | `t_decode_ms = a_num` (NOT reduced by the read time: PA-01) |
| `Verify` | `t_verify_ms = a_num` |
| `Assign` | `t_assign_ms = a_num` |
| `Rendered` | `pending_render = a_num` |
| `Presented` | `if text == "thumbnail" { has_thumbnail = true }`; the first Presented row sets `first_visual_ms = Some(qpc_to_ms(row.qpc - t0))` (any text); `if text` is `final` or `compare`: `final_visual_ms = Some(qpc_to_ms(row.qpc - t0))` (a later one overwrites), `t_render_ms = pending_render` (overwrites, so a second `final` after the first erases it with `None`), `incomplete = false`; finally ALWAYS `pending_render = None`. Other texts (`other`) only count as first presented. |
| `PostEnd` | `post_ms[text] = a_num.unwrap_or(0.0)` (insert-or-replace keeps the first position) |
| `RenderedFrame` | `t_render_frame_ms = a_num` (assigned directly, it arrives after `Presented`) |

Finally `rec.kind = classify_kind(&rec)`.

### `KeyInputIndex`
`new(key_inputs)`: bucket by `thread`, each bucket sorted stably by `qpc_ticks`. `nearest_at_or_before(thread, q)`: in that thread's bucket find the greatest `qpc_ticks <= q`; if several rows share that timestamp return the FIRST of them (file order); `None` if the thread has no bucket or no row at or before `q`. (Binary search: `partition_point` twice; a linear scan gives the same answer and is fine for the golden, but the 10 000-nav benchmark should stay fast.)

### `classify_kind(nav)`
`base` = by exact (case-sensitive) `lookup_result`: `"ramHit"` -> `RamHit`; `"inflight"` -> `InflightJoin`; `"miss"` -> `DiskCacheHit` if `t_disk_ms.is_some()`, else `SourceMiss` if `t_decode_ms.is_some()`, else `InflightJoin`; anything else (including `""`, `"RamHit"`, `"RAMHIT"`) -> `Unknown`. Result = `format!("Thumbnail+{base}")` if `has_thumbnail`, else `base` (so `Thumbnail+Unknown` exists).

## Golden `perf-nav` (how to compare)
`build` case: write nothing to disk: `build(&csv::parse_text(Path::new("perf-x.csv"), &case["content"]))`. Compare in order: `navs` (array of objects with the 21 keys `nav mode t_input t_pre t_stat lookup_result t_thumb has_thumbnail t_join t_disk t_read t_decode t_verify t_assign t_render t_render_frame post_ms first_visual final_visual incomplete kind`; `post_ms` and `startup` are ordered `[key, value]` pairs; JSON `null` <-> `None`; doubles must be EXACTLY equal — all arithmetic is `f64`, so a mismatch is a real order-of-operations bug), `preload_items`, `preload_paused_count`, `preload_cancel_count`, `folder_gens` (keys `gen t1 t2 t3 t3_phase`), `dispatcher_long_ops`, `dispatcher_long_ops_before_start_count`, `startup`. `classify` case: build a default `NavRecord` with the 4 inputs and compare `result`.
Quirks pinned by hand-made cases: `t0-without-showstart` (a `FolderInfo` row is `ordered[0]`), `keyinput-window` (500.0 ms matches, 500.01 does not, other thread, tie, key input after the show start, empty `a`, second ShowStart), `thumb-variants`, `presented-variants` (second `final` erases `t_render_ms`), `field-overwrites` (null overwrite, repeated PostEnd, unknown/lower-case events), `nav-ids`, `folder-variants`, `dispatcher-without-start`, `dispatcher-threshold-is-min`, `preload`, `startup*`, `unsorted-and-ties`, `mode-text`.

## Traps checklist (docs/MULTI-AGENT-PLAN.md §7)
3 (`as i32` saturates in Rust like .NET 9+, but never use `as` on a user value that must be range-checked: nav ids are `i64` from `parse_integer_i64`), 8 (empty `a` is `None`, `unwrap_or(0.0)` only where C# writes `?? 0`; `mode` stays `""` not `None`), 10 (`IndexMap` for `by_nav`, `post_ms`, `startup`; groups by first appearance), stable sorts (`sort_by_key`), `min_by_key` returns the first minimum (matches C# `MinBy`), no `HashMap` iteration in any output order.
