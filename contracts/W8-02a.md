## Semantics (C# is the spec)
1. **`build`.** `hidden = context_menu::effective_hidden(settings)` (the `Settings` item is never hidden). Context for the visibility rule:
   `ContextMenuContext { has_photo: has_image && can_copy_path }`. Walk `context_menu::compute(&hidden, ctx, None).entries` in order:
   an entry with an item goes to `top_level_item`; an entry without one becomes `separator("Separator.{group}")`. The first error stops the build.
2. **Separator.** `separator(id)`: kind Separator, text `""`, `is_enabled` false, `is_checked` false, no shortcut, no children, no automation name.
   Top-level id `"Separator.<group>"` (group = `ContextMenuEntry.group`, the table group, not a position); inside the Zoom submenu `"Separator.Zoom.<group>"`.
3. **Top level (`top_level_item`).** Every row is a Command with `is_enabled` true, `is_checked` false, no children, unless noted.
   Id = `ContextMenuItemId::name()` (`"Undo"`, `"MoveToRecycleBin"`, ...). Text and automation name are `pr_l10n::tr` calls with the key of
   the table; the shortcut is a `settings.shortcuts` field:
   | id | text (`tr::`) | automation (`tr::..._automation_name`) | shortcut field |
   |---|---|---|---|
   | Undo | `main_menu_undo` | `main_menu_undo_automation_name` | none |
   | MoveToRecycleBin | `main_menu_recycle` | `main_menu_recycle_automation_name` | `send_to_recycle_bin` |
   | Fit | `main_menu_click_zoom_level_fit` | `main_menu_click_zoom_level_fit_automation_name` | `toggle_fit` |
   | ZoomToLevel | `main_menu_zoom_to_level(click_zoom_percent)` | `main_menu_zoom_to_level_automation_name(click_zoom_percent)` | `click_zoom` |
   | ZoomSubmenu | `main_menu_zoom` | `main_menu_zoom_automation_name` | none; **Submenu**, children from `zoom_children`, `is_enabled` true |
   | Refresh | `main_menu_refresh` | `main_menu_refresh_automation_name` | `refresh` |
   | OpenFolder | `main_menu_open_folder` | `main_menu_open_folder_automation_name` | none |
   | NextFolder | `main_menu_next_folder` | `main_menu_next_folder_automation_name` | `next_folder` |
   | PreviousFolder | `main_menu_previous_folder` | `main_menu_previous_folder_automation_name` | `previous_folder` |
   | ExternalEditor | `main_menu_open_in_external_editor` | `main_menu_open_in_external_editor_automation_name` | none |
   | CopyFileName | `main_menu_copy_file_name` | `main_menu_copy_file_name_automation_name` | none |
   | CopyFullPath | `main_menu_copy_full_path` | `main_menu_copy_full_path_automation_name` | none |
   | Settings | `main_menu_settings` | `main_menu_settings_automation_name` | none |
   Any other id: `Err(NotTopLevel(id))`.
4. **Zoom children (`zoom_children`).** `context_menu::compute(hidden, menu_ctx, Some(ZoomSubmenu)).entries` in order:
   - Item `ZoomFitWidth` / `ZoomFitWidth2` / `ZoomFitHeight`: Command, id = the item name, text `main_menu_zoom_fit_width` /
     `main_menu_zoom_fit_width2` / `main_menu_zoom_fit_height` (+ `_automation_name`), shortcut `fit_width` / `fit_width2` / `fit_height`.
   - Item `ZoomPresets`: for each `p` in `zoom_rules::PRESET_PERCENTS` (50, 70, 100, 150, 200, 300, 400) a **Toggle** with id `"Zoom.Preset.{p}"`,
     text `main_menu_click_zoom_level_preset(p)`, automation `main_menu_click_zoom_level_preset_automation_name(p)`,
     `is_checked = p == settings.click_zoom_percent`, enabled, no shortcut. Then a Command `"Zoom.Custom"`, text
     `main_menu_click_zoom_level_custom` (+ `_automation_name`), no shortcut, enabled.
   - Item `ZoomLevelOptions`: Toggle `"Zoom.AlsoSetClickLevel"`, text `main_menu_zoom_also_set_click_level` (+ `_automation_name`),
     `is_checked = settings.set_zoom_also_sets_click_level`; then Command `"Zoom.SetCurrentAsClickLevel"`, text
     `main_menu_zoom_set_current_as_click_level` (+ `_automation_name`), `is_enabled = zoom_rules::calculate_click_level_from_effective_zoom(context.effective_zoom).is_some()`.
   - Entry without item: `separator("Separator.Zoom.<group>")`.
   - Any other item: `Err(NotZoomChild(item))`.
   Children of a Toggle or Command are empty; `ZoomPresets` produces seven Toggles, one Command, in that order.
5. **Preset text** is `tr::main_menu_click_zoom_level_preset(p)` (English "50%"); numbers in ids are plain decimal (`i32` Display, invariant).
6. **Flags that do not change the menu.** `can_undo`, `is_fit`, `can_open_in_external_editor` and `is_compare_visible` are ignored by `build`
   (WPF behaviour: Undo and External Editor are always enabled, the click-level rule depends only on `effective_zoom`). Copy items depend
   only on `has_image && can_copy_path` through `compute`.
7. **Shortcut text** comes from the `settings.shortcuts` field of the table; the Zoom submenu row and the Zoom presets have none.
8. **`build_tools_menu(has_images)`** (`BuildToolsMenu`): six Commands, no shortcut, in this order, with `is_enabled`:
   `"Tools.Recovery"` (`main_tools_recovery`), `"Tools.Diagnostics"` (`main_tools_diagnostics`), `"Tools.Benchmark"` (`main_tools_benchmark`),
   `"Tools.ClearCache"` (`main_tools_clear_cache`), `"Tools.RemoveNumberedDuplicates"` (`main_tools_remove_numbered_duplicates`, enabled = has_images),
   `"Tools.RemoveOriginalDuplicates"` (`main_tools_remove_original_duplicates`, enabled = has_images). Automation names `main_tools_*_automation_name()`.
9. **`command(id, text, shortcut, automation, is_enabled)`.** `shortcut` is `None` when it is empty or all whitespace
   (`string.IsNullOrWhiteSpace`); a non-empty shortcut is copied byte for byte (no trim, C# keeps `" D5 "`). Kind Command, checked false, no children.
10. **Errors.** Only the two `MenuBuildError` cases. `compute(None)` yields top-level ids only and `compute(Some(ZoomSubmenu))` yields children
    only, so the errors cannot happen for the level asked for; they are kept because C# throws there.
11. **No clock, no I/O, no logging, no globals.** Texts come from `pr_l10n::tr` (D-W8-4); no English literal in production code.
    Tests set the ambient localizer with `Localizer::set_current(built_in_english_localizer())` under a serial lock (the pattern of
    `pr-l10n/tests/generated_tr.rs`) and restore it.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- Item 1 (ordinal comparison): none here, but `ContextMenuItemId::name()` is the stored and compared form; compare ids with `==` on the enum.
- Item 3 (arithmetic): `percent` is `i32`; no overflow path. Do not write `p as i64` tricks.
- Item 4 (rounding): the zoom rounding is in `zoom_rules` (W8-01d), not here; `effective_zoom` is compared only through it.
- Item 8 (`null` against `""`): `shortcut_text` is `None` for `""` and for `"   "`, but `Some("D3")` stays `Some("D3")`.
  Trap: `str::trim().is_empty()` and `char::is_whitespace` (Unicode White_Space) agree with .NET `IsWhiteSpace` for NBSP and
  U+0085; U+001C..U+001F are NOT white space in .NET (golden case `shortcut_blank_and_padded`, NextFolder `"\u001c"` stays `Some`).
- Item 10 (order): `compute` order decides the output; `HashSet` is only a membership test, never iterated for output.
- Operator trap: `Zoom.SetCurrentAsClickLevel` enabled is `calculate(...).is_some()`, not `effective_zoom.is_some()` (a NaN zoom is
  "Fit" through `zoom_rules`, and a zoom of 0.004 is a valid level clamped to 10).
- `click_zoom_percent` is the value for the ZoomToLevel text and the preset check. A custom value (123) matches no preset.
- The ZoomToLevel shortcut is `click_zoom`, the Fit shortcut is `toggle_fit`, not `fit_width` (three different shortcuts look alike).
- ContextMenuBuildContext `has_image` and `can_copy_path` are ANDed only for Copy visibility: `has_image` alone does not show Copy.

## Open questions (each with the recommended option taken in this draft)
1. **`build` returns `Result`** (recommended). C# throws `InvalidOperationException` on the two impossible cases. Alternative: infallible
   build with `unreachable!()`, which panics on user-visible code paths. Taken: `Result`, mapped by the caller to a failed menu.
2. **Texts through `pr_l10n::tr` directly** (recommended, D-W8-4). Alternative: a `MenuTexts` trait injected by the composition root (the D13
   pattern). Taken: direct calls, because the golden pins English through the ambient localizer like the C# `Tr` does.
3. **`PRESET_PERCENTS` as `&'static [i32]`** (recommended) instead of `[i32; 7]` or a function: it matches the C# `IReadOnlyList<int>`
   and allows `.iter()` without a copy. W8-01d must use this exact name and type.

   replaced by hand-written expectations from the C# test file (as P-37 did for `cli-process`), and this unit is recorded as F, not G.
