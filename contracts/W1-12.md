- Semantics notes (concurrency; ADR docs/adr/R0003-concurrency.md "Cancellation and staleness" and "Shared state"):
  1. **Representation:** three `std::sync::atomic::AtomicI64` fields (already declared). `i64`, not `u64`, to keep the C# `long` signatures; increments WRAP on
     overflow exactly like `Interlocked.Increment` (use `fetch_add(1, SeqCst).wrapping_add(1)` for the returned new value; plain `+ 1` would panic in debug builds at `i64::MAX`).
  2. **Ordering:** `Ordering::SeqCst` for every load and read-modify-write (R0003: "atomics with SeqCst unless the contract justifies weaker"). No weaker ordering is justified here
     (the value is the synchronization point between a UI thread and decode/IO threads).
  3. **`next_*` returns the NEW value** (after the increment), as `Interlocked.Increment` does: the first call on a fresh clock returns 1, not 0.
  4. **`is_*_current(g)`** is a SeqCst load compared with `g` (equality, not `>=`): a token from the future is not current either.
  5. **`stop_for_action`** performs THREE separate increments in the order navigation, folder, interaction. It is deliberately NOT one atomic step and NOT under a lock
     (the C# comment: callers run on the UI thread and consumers only compare tokens). Do not add a mutex or a combined counter.
  6. **No locks, no `unsafe`, no `Arc` inside**: callers wrap the clock in `Arc` themselves. `GenerationClock` must be `Send + Sync` (automatic with atomics).
  7. The three counters are independent: advancing one never touches another except in `stop_for_action`.
- Traps checklist: §7 item 3 (overflow: wrapping increment instead of debug panic). R0003: never hold a lock across I/O (there is no lock here).

## Open questions
- R0003 says "Generations are `AtomicU64` counters"; this port uses `AtomicI64` to match the C# `long` API (constructor accepts negative initial values, wraps instead of panicking).
  A later unit that stores a generation in a `u64` field must convert deliberately. Lead: confirm `i64` is acceptable, or change the stub before the WU starts.
