## Semantics (C# is the spec)
1. **`new`**: `Rc::new_cyclic` (so `this` exists for the frame hook), every flag false / zero, `options = options.unwrap_or_default()`. It registers the object with `window.add_message_handler(Rc::clone(&this))`; the registration APPENDS to the handler chain, so the main window must construct the bars BEFORE `ShellInput` (the earlier handler sees the mouse first, and a zoomed image's box covers the bars). Cross-unit assumption on **W8-13g/13i/14c**: `RegisterScrollBars` runs before `RegisterInput`, as C# `RegisterFeatures` does. The window holds the bars (handler list) so the bars hold the window by `Weak` (D-W8B4V-7); when the window is gone every query answers "nothing" and `current_layout()` is `ScrollBarLayout::none()`.
2. **`ScrollBarOptions::default()`**: `ScrollBarMetrics::default()`, `repeat_timing = Rc::new(scrollbar_native::repeat_timing)`, `track_mouse_leave = Rc::new(scrollbar_native::track_mouse_leave)`, `ticks_per_second = qpc_frequency()`. The thickness (10) must equal `ViewportControllerOptions::scroll_bar_thickness` (both are the `DarkScrollBars.xaml` value); the main window passes ONE source for both (cross-unit assumption on W8-13g).
3. **`current_layout`**: `compute(client, &viewport.layout(), viewport.horizontal_offset(), viewport.vertical_offset(), &options.metrics)` with `client` the window's DIP client size converted to `pr_app::SizeD` (the host contract still returns its interim twin, D-W8B4V-1). The layout is recomputed on every call (cheap, pure); nothing is cached, so a resize, zoom or scroll is visible at once (`Resize_ReflowsTheBars...`).
4. **`hit_test`** (public) = `hit_test_in(&current_layout(), point)`. `hit_test_in`: when `is_compare_visible()` AND `scrollbar_geometry::inside(compare::layout::panel(client), point)` -> `ScrollBarPart::None` (the compare panel, 8 DIP margin and canvas background, is drawn over `ImageScroll` and covers the bars; only the strips outside the margin remain); else `scrollbar_geometry::hit_test(layout, point)`. `inside` is the HALF-OPEN helper (not `RectD::contains`): at the 1000x600 rig the panel is `(8, 8, 984, 584)`, so `x = 992` is outside it (-> `TrackAfter`), `x = 991` inside.
5. **`hovered_thumb_axis`**: `None` when dragging, paging, or the pointer is not inside the window; else `hit_test_in(layout, pointer) == Thumb` -> `axis_at(layout, pointer)`; otherwise `None`. It is recomputed from the CURRENT layout, so a thumb that scrolls under a stationary pointer becomes hovered (`HoverFollowsTheThumb...`). While the track is held (paging) a thumb that arrives under the pointer is NOT hovered until release (16g test).
6. **`to_dip`** (pub(super), used by 16g): `scale = normalized_dpi(window.dpi_scale())`; `PointD { x: pixel_x as f64 / scale, y: pixel_y as f64 / scale }`; `(0, 0)` when the window is gone. `normalized_dpi` keeps `0.25..=16` and maps NaN / out of range to 1.0 (so a broken DPI never divides by 0).
7. **`is_over_page_region(layout, point)`**: `wanted = if page_direction < 0 { TrackBefore } else { TrackAfter }`; `hit_test_in(layout, point) == wanted && axis_at(layout, point) == Some(page_axis)`.
8. **State accessors**: `is_dragging` / `is_paging` read the flags; `drawn_frames` the counter. All fields are `Cell`/`RefCell` (the handler can be re-entered by a nested `SendMessage`, D-W8B3H-6); no borrow is held across a call into the window, the viewport or a callback (D-W8B4V-9).
9. **`set_pointer_for_tests(point, inside)`** sets `pointer` and `pointer_inside` (what the first lines of `on_move` do); it exists only so the hover rule is testable in 16f; documented `#[doc(hidden)]`, precedent `PixelBuffer::unallocated_for_tests`.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (arithmetic): pixel to DIP is an `i32 as f64` division, never an integer division; a negative pixel coordinate (a drag outside the window with capture) is valid.
- T2 (`Weak` window, D-W8B4V-7): no strong `Rc<dyn ShellWindowApi>` is stored; the constructor takes `&Rc<..>` and downgrades. A test drops the window and checks the object frees (strong count of the bars goes to 1 held by the test).
- T3 (half-open vs closed): `scrollbar_geometry::inside` for the compare occlusion, as C# `ScrollBarGeometry.Inside`; do not use `RectD::contains`.
- T4 (colour constants): `from_argb` divides each channel by 255.0 in `f32`; `TRACK` must equal `palette::get("Dark.ScrollTrack").unwrap()` (a test).
- T5 (type twins): `window.client_size_dip()` returns the host `SizeD`; convert field by field into `pr_app` `SizeD` in ONE private helper (`client_size`).
- T6 (init order): `Rc::new_cyclic` closure must not call the window or the viewport (no upgrade of `this` yet).
