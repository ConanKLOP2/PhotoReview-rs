- Semantics notes:
  1. **Queued commands** (`run_action`, `recycle`, move/copy-to). `submit_queued` stores `QueuedFileCommand { kind, epoch = folder_load_epoch }` under a ticket and calls `file_action_gate.run_queued(move |turn| inbox.send(GateTurn { ticket, turn }))`.
     `Rejected` (an exclusive holder exists): the record is removed, nothing else happens (C# result false). `StartedNow`: the event was sent inside the call; the inbox is drained at once so the C# "prefix runs synchronously" holds.
     `Queued`: the gate posts the successor when the predecessor's turn ends; the event arrives later.
  2. **`on_gate_turn`** = C# `WaitForQueuedTurnAsync(epoch)` (590): `epoch != folder_load_epoch` -> the turn finishes and the command is dropped (R02); a pending Explorer order parks the command (`Deferred::FileTurn`, the turn stored in the record);
     after the wait the epoch is compared AGAIN (`resume` re-checks) and then `run_queued_command` runs the controller entry with `compare().selected_path()` and `catalog.current().path` read NOW.
  3. **Turn lifetime (INV-4).** `Pending` -> the turn moves to `active_gate_turn`; `Done(..)` -> it finishes AFTER the recorded sink calls were replayed (`apply_sink_actions`) and after `on_present_finished` was delivered; the gate therefore covers
     the catalog update that follows the I/O. A panic drops the turn (releases the gate). `GateTurn::finish` is called exactly once per accepted command.
  4. **Undo.** `undo()` = `run_exclusive`: a held gate makes it a silent no-op (OC14). With the turn: `UndoContext { undo_epoch = folder_load_epoch, current_folder = session folder }`, `undo_last`. On `Done(Undone(result))`, `finish_undo`:
     `restores_outside_folder(result, current_folder)` -> `reload_path_after_undo(result)`, `folder = parent directory` (non-empty) -> `open_folder_core(folder, Some(reload_path), Some(undo_epoch), UndoReopen { error_message })`, and the turn is
     released by `finish_open` (the gate stays held until the reopen finished, as C#); otherwise the turn finishes now. The reopen is dropped by `required_epoch` when the user opened another folder meanwhile (R09).
  5. **Viewer commands** apply the returned `ViewerUpdate` through `apply_viewer_update` (08a). `toggle_fit` passes `(0.0, 0.0)` (C# `ResetFit()` defaults); `zoom_actual_size` is a no-op without images.
  6. **`toggle_info_overlay`** order: flip in an edit copy (installed as the override so readers see it), overlay refresh, `notify_exif_line_changed`, THEN `commit_edit`; on `Err` log `Could not save the info overlay setting` and keep the value for the session.
  7. **`refresh_view`**: see the stub doc; `ViewRefreshOutcome { scaling_changed, resolution }`; the log line uses the invariant culture and the `0.####` format (up to 4 decimals, no trailing zeros).
  8. **External editor**: `can_open_in_external_editor` = path not blank and `has_images`. No path configured -> `show_settings_at(SettingsTarget::ExternalEditor)` and stop. The file path priority is shared with the copy commands:
     compare selection, else the presenter's presented path, else the catalog current path (`current_file_path`). `file_system.file_exists` false -> error dialog `dialog.externalEditor.fileMissing {fileName}` under the title `dialog.externalEditor.failedTitle`.
     `Expected` failures show the failure text under the same title; `Unexpected` is returned as `Err(ExternalEditorBug)` with NO dialog. The production launcher does not use a shell and passes the file path as ONE argument.
  9. **Clipboard**: status `status.copiedFileName {fileName}` / `status.copiedFullPath {path}` on success, `status.clipboardCopyFailed` on failure; the default clipboard reports "unavailable" (`UnavailableClipboardService`), so the failure text shows and the real clipboard is never touched.
  10. **Folder picker / benchmark start folder**: `session.folder` when a session exists (an EMPTY session folder stays empty, the C# null-coalescing operator tests for null only), else the directory of the catalog current path, else nothing.
  11. **Duplicates**: `remove_duplicates` = `run_exclusive`; the turn is kept in `duplicate_gate_turn` until `Done` / `Canceled`; `clear_cache` is NOT gated (as C#); `defer_close_for_file_action` = false without a held gate, else `cancel_duplicate_check()` then true.
