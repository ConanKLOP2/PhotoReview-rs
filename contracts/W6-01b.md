# W6-01b: Explorer window selection policy

- Color: 🔴 | Porter: **sonnet** (failure routing, cancellation, resource release) | C# spec baseline: `d92d6aae`
- Rust crate: `pr-platform-win`
- C# source (baseline): `src/PhotoReview.Platform.Windows/Explorer/ExplorerWindowSelector.cs`
- C# tests (baseline): `tests/PhotoReview.Integration.Tests/ExplorerWindowSelectorTests.cs`

## Scope and behavior

Port `ExplorerWindowSelector.Select` and `TryCanonicalizeLocation` as a policy module independent of live COM. Walk the supplied window iterator lazily, release each obtained window exactly once even on early return/cancellation, and never request later windows after the first available result. Skip unusable/non-file locations and locations that do not identify the requested folder. Try all matching windows until one returns Available; if all matching views fail, return the first failure. Cancellation is terminal. An iterator `MoveNext` error is logged and ends the walk while preserving the first already-observed matching failure; without one, return NoMatchingWindow. Unexpected location/read errors follow the baseline status and reason formatting.

Canonicalize only absolute file URLs using URI local-path decoding, then the existing `ExplorerSnapshotValidator` path canonicalization and `same_path` semantics. Do not treat arbitrary schemes or shell namespace locations as filesystem folders.

## Dependencies and file ownership

- Depends on W2-09 `ExplorerSnapshotValidator` (`canonicalize_folder`/`same_path`), W1-07 explorer snapshot/status/reason types, `ILog`, and W6-01a window abstractions.
- Own only the selector module and its focused tests. Do not edit shared explorer types/reasons or the provider/service module.

## Hang guard and mutation expectations

- Tests are synchronous and bounded; do not add sleeps, polling, or a real Explorer dependency.
- Time-box `cargo-mutants` to selector-owned code. Mutations that stop releasing a window, change lazy early-exit, accept a non-file URL, lose the first failure, or ignore cancellation must be killed by the named tests. Note any surviving equivalent mutation explicitly.
