## Semantics (C# is the spec)
Texts `text_fn(tr::<snake_case>)` (D-W8B5-802), pattern D-W8B5-803. `context` = `self.context.context()`; presenter calls: `context.presenter().borrow()/borrow_mut()` for the call only, text-producing ones inside `with_field_context` (D-W8B5-710), never across a `context` write (D-W8B5-706).
1. **`key()`** `"General"`.
2. **`declare`** (ids follow the declaration order; the golden fixes them):
   | # | group title | controls in order |
   |---|---|---|
   | 1 | `settings_group_language` (the id of the group box is stored as `language_group`) | `language` = combo(`settings_language_label`, None, 0).control; buttons(true, [`settings_language_open_folder`, `settings_language_reload`, `settings_language_export`]) -> `open_folder`, `reload`, `export`; note(`settings_language_hint`, true) |
   | 2 | `settings_nav_general` | `sort_mode` = combo(`settings_sort_mode_label`, [`enum_image_sort_mode_name`, `_name_ascending`, `_name_descending`, `_size_descending`, `_size_ascending`, `_default`] (prefix `enum_image_sort_mode`), 0).control; note(`settings_sort_mode_hint`, true); `view_mode` = combo(`settings_view_mode_label`, [`enum_initial_view_mode_fit`, `enum_initial_view_mode_fit_width`, `enum_initial_view_mode_fit_height`, `enum_initial_view_mode_click_zoom_level`, the literal `"100%"`, the literal `"200%"`], 0).control; `instance_mode` = combo(`settings_instance_mode_label`, [`enum_instance_mode_single_window`, `enum_instance_mode_per_folder`], 0).control; note(`settings_instance_mode_hint`, true) |
   | 3 | `update_section_title` | buttons(false, [`update_check_button`, `update_open_page_button`]) -> `check_update`, `open_update_page`; `update_status` = text(None); note(`update_hint`, false) |
   | 4 | `settings_shell_group` | `shell_status` = text(None); buttons(false, [`settings_shell_add`, `settings_shell_remove`]) -> `shell_add`, `shell_remove`; note(`settings_shell_hint`, false) |
3. **`attach(context)`**: store; `set_visible(open_update_page, false)`; `load_languages(None)`; `refresh_shell_status()` (that order).
4. **`load(state)`**: `set_combo_index(view_mode, state.view_mode_index)`; `set_combo_index(instance_mode, state.instance_mode_index)`; `set_combo_index(sort_mode, i)` with `i` = the position of `state.sort_mode_tag` in `SORT_TAGS` (ordinal, case sensitive) or `0` for `None` or an unknown tag (C# `Math.Max(0, Array.IndexOf(..))`). The language combo is NOT touched by `load` (only by `attach` and the reload button).
5. **`collect(state)`**: `view_mode_index`, `instance_mode_index` from the combos; `sort = combo_index(sort_mode)`; `state.sort_mode_tag = if 0 <= sort < 6 { Some(SORT_TAGS[sort]) } else { None }` (`get`, no indexing); `language = combo_index(language)`; `state.selected_language_code = languages.get(language).map(|l| l.code.clone())` when `language >= 0`, else `None`.
6. **`load_languages(current_code: Option<&str>)`**: `loaded = with_field_context(|c| presenter.borrow().load_languages(current_code, c))`. `None` (no localization service) -> `set_visible(language_group, false)` and return (the list stays as it was). `Some((options, index))` -> `self.languages = options`; `set_combo_items(language, &display_names, index.map_or(-1, |i| i as i32))`.
7. **`on_command(id, n)`**: `n != BN_CLICKED` -> `false`. Then, in this order, the first that matches (all return `true`; none matches: `false`):
   - `open_folder`: only if `presenter.borrow().has_localization()`: `request = presenter.borrow().prepare_languages_folder()` (borrow released) then `context.run_explorer(&request)`.
   - `reload`: `reload_translations()` (below).
   - `export`: `export_translation()` (below).
   - `check_update`: only if `context.is_enabled(check_update)`: `start_update_check()`.
   - `open_update_page`: `failure = with_field_context(|c| presenter.borrow().open_update_page(&mut |url| context.open_url(url), c))`; `Some(text)` -> `set_update_status(&text)`.
   - `shell_add` / `shell_remove`: `status = with_field_context(|c| presenter.borrow().change_shell_registration(true / false, c))`; `show_shell_status(status)`.
8. **`reload_translations()`**: `reloaded = presenter.borrow().reload_translations()`; `None` -> return; `code = selected_language().map(|l| l.code)`; `load_languages(code.as_deref())`; `context.show_warning(&tr::dialog_reload_translations_title(), &reloaded.message)` (shown whether or not there were problems, as the C#). **`export_translation()`**: no localization service -> return; `(request, error) = presenter.borrow().export_translation(selected_language().as_ref())`; `Some(error)` -> `show_warning(&tr::dialog_export_translation_failed_title(), &error)` and return; `Some(request)` -> `context.run_explorer(&request)`. **`selected_language()`**: the entry at `combo_index(language)` when `0 <= index < languages.len()`, else `None`.
9. **`start_update_check()`** (D-W8B5-809), in this order: `set_enabled(check_update, false)`; `set_visible(open_update_page, false)`; `set_update_status(&tr::update_check_checking())`; `job = presenter.borrow_mut().begin_update_check(context.version().as_deref())`; `post = context.ui_post()`; clone the ids and `update_status_text`; `started = (self.runner)(Box::new(move || { let completed = job.run(); post.post(Box::new(move |ctx| { ... })) }))`. The posted action, on the UI thread (a private `fn apply_update_result(ctx, completed, ids, text)` so it can post itself again): `let Ok(mut presenter) = ctx.presenter().try_borrow_mut() else { ctx.post_to_ui(<the same action over the same data>); return; }` (NEVER `borrow_mut`: the action is delivered by the message pump, which also runs inside the nested modal loops of the frame, for example while a warning box is open during Save or Import, when the frame may hold the presenter; a panic there would take the UI thread down; the re-post makes it run on a later pump turn, and `apply_update_result` clones nothing it cannot move: `completed`, the ids and the `Arc` are all `Send`); then `display = with_field_context(|c| presenter.finish_update_check(completed, c))` and the borrow is dropped before any `ctx` write; `None` (cancelled / dialog closed) -> return with no control change; `Some(d)` -> store `d.status_text` into the shared text, `ctx.set_text(update_status, &d.status_text)`, `ctx.relayout()`, `ctx.set_visible(open_update_page, d.show_open_page())`, `ctx.set_enabled(check_update, true)`. `started == false` -> `set_update_status(&tr::update_status_failed_bad_response())` and `set_enabled(check_update, true)`.
10. **`set_update_status(text)`**: store `text` in the shared `update_status_text`, `set_text(update_status, text)`, `relayout()`.
11. **`refresh_shell_status()`**: `status = with_field_context(|c| presenter.borrow().refresh_shell_status(c))`; `show_shell_status(status)`. **`show_shell_status(status)`**: `self.shell = Some(status.clone())`; `set_text(shell_status, &status.text)`; if `status.add_label` is `Some(label)` -> `set_text(shell_add, &label)`; `set_enabled(shell_add, status.add_enabled)`; `set_enabled(shell_remove, status.remove_enabled)`; `relayout()`.
12. **`on_language_changed()`**: `set_text(update_status, &copy of update_status_text)` (the result keeps its text; nothing re-translates it); if `self.shell.is_some()` -> `refresh_shell_status()`.
13. **`new()`** builds the production runner: `Rc::new(|job| match std::thread::Builder::new().name("settings-update-check".to_owned()).spawn(job) { Ok(_) => true, Err(e) => { AppLog::global().error("Update check thread failed to start", Some(&e)); false } })`. **`with_background_runner(runner)`** is the test constructor. The `Arc<Mutex<String>>` lock ignores poison (`unwrap_or_else(PoisonError::into_inner)`).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T5-like re-entrancy (D-W8B5-706): the posted action runs from the host's message pump, never inside a page method, BUT the pump also runs inside the frame's nested modal loops while the frame may hold the presenter: the action therefore uses `try_borrow_mut` and re-posts itself when busy (R0003: no panic on the UI thread); the code that starts the job releases its `borrow_mut` before `(runner)(..)`.
- T8 (null vs empty): `language_group` is the id returned by the first `page.group(..)`; `selected_language_code` is `None` when nothing is selected, never `Some("")`; `load_languages(None)` (no preferred code) differs from `Some("")`.
- T9: the C# `async`/`await` and `PostToUi` are the runner plus `ui_post`; the closed-dialog case is `finish_update_check` returning `None` (the frame cancels the token on close).
- T10 (order): the `on_command` chain order and the declaration order; the three call orders of `attach`, `start_update_check`, `show_shell_status` are asserted by call lists.
- D-W8-4: the two combo items `"100%"` and `"200%"` are the only literals (C# has them as literals).
- R0003: `get(i)` for every list access; no `unwrap`/`expect`; the thread spawn failure is handled; a `Mutex` poison is ignored.
