## Semantics (C# is the spec)
1. **Dialog units**: `scale_dlu_x(u, avg) = u.wrapping_mul(avg).wrapping_add(2) / 4`, `scale_dlu_y(u, line) = u.wrapping_mul(line).wrapping_add(4) / 8` (`/` truncates toward zero, as C#: `-5 * 6 + 2 = -28 / 4 = -7`, `-1 * 15 + 4 = -11 / 8 = -1`). `average_char_width(x) = max(1, (x / 26 + 1) / 2)`. `dx`/`dy`/`line_height` read `MetricsState`.
2. **Fonts**: `create_fonts` follows the C# steps. `dialog_native::user32::non_client_metrics_for_dpi(dpi)` -> `Ok(m)` with `m.lfMessageFont.lfHeight != 0` -> that `LOGFONTW` is the body description; otherwise `fallback_log_font(dpi)`. `fallback_font_height(dpi) = -((9.0_f64 * dpi as f64 / 72.0).round_ties_even() as i32)` (96 -> -12, 100 -> -12, 108 -> -14, 120 -> -15, 144 -> -18, 192 -> -24). `header_font_height(h) = h.wrapping_mul(14) / 10` (-12 -> -16, -9 -> -12, -16 -> -22). `fallback_log_font` copies "Segoe UI" as UTF-16 into `lfFaceName` (31 units + NUL room). `body = create_font_indirect(..)`, a `0` handle is returned as is (not an error; `WM_SETFONT` with 0 keeps the system font).
3. **`apply_fonts`**: the C# order: create the new fonts, send `WM_SETFONT` to the dialog, then to each child (header font for `header_control_ids()` when it exists), THEN delete the previous fonts, then `measure_units`. `header_control_ids()` is read ONCE per call (a `HashSet` or a sorted `Vec`; order is not observable). The children list is cloned before the loop (a `WM_SETFONT` handler may register a child).
4. **`measure_units`**: as C#; a failing `get_dc` or `get_text_extent_point32` leaves the previous units. The old font is restored before `release_dc`.
5. **`on_dpi_changed`** and **`on_dpi_changed_message`** as the stub docs; `new_dpi = low_word(wparam as isize) as u32` (`shell_input::native::low_word` takes an `isize` and returns `i32`; `Wparam` is `usize`; or an equal one-line mask on the `usize`); the `RECT` is read once into a local.
6. **Registry and `item`**: `children` and `child_hosts` are `RefCell<Vec<Hwnd>>`; `register_child` pushes under a short borrow, then sends `WM_SETFONT` with no borrow held. `item(id)` does `get_dlg_item(hwnd, id)` then, while `0`, each host of a SNAPSHOT of `child_hosts`.
7. **Helpers**: `place`, `set_list_item_height` (`LB_SETITEMHEIGHT` = `control_constants::LB_SETITEMHEIGHT`, `lparam = max(1, h) as isize`), `set_item_text`, `get_text` (`get_window_text_length(hwnd) <= 0` -> `""`, else `get_window_text`), `show_item`, `measure_*`, `button_width` (collects the widths of `get_item_text(id)` with `measure_text_width(text, 0)`), `place_button_row` (`button_row_positions` + `place` each + `button_row_total`), `button_row_width`, `window_size_for_client`, `resize_client`, `current_client_size`, `run_layout`: as the stub docs. `button_row_positions(.., count = 0, ..)` returns an empty `Vec`; `button_row_total(0, w, gap) = -gap` (as C#); no panic for `count` larger than `i32::MAX` (cast with `as i32`, wrapping).
8. **`initial_frame`** as the doc (min then max, in that order). `work_area(None, w, h) = (0, 0, w, h)`. `place_initially` obtains `owner_rect` from `get_window_rect(owner)` only when `owner != 0` and the call succeeds.
9. **`on_size` / `on_get_min_max_info`** as the docs; the min size is written with `ptMinTrackSize.x = frame.0`, `.y = frame.1`.
10. **`impl ListDialogBase for NativeDialog`**: one line each, delegating (`measure_text_width(text)` -> `self.measure_text_width(text, 0)`; `place_button_row` drops the return value). Inside the impl, call the inherent method with `NativeDialog::name(self, ..)` or `self.name(..)` (inherent wins); do not recurse into the trait.
11. **No `unwrap`/`expect`/`panic!`**; `i32` arithmetic is `wrapping_*` as D-W8B5-312 says.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T3 (arithmetic): every `*` and `+` of units, widths, positions is `wrapping_*`; `/` on `i32` truncates like C# (also for negative values: the golden has `units = -5`); `count as i32` for the row.
- T4 (rounding): `round_ties_even` for `Math.Round`, never `f64::round` (the golden/hand rows 100 dpi -> 12.5 -> 12 and 108 dpi -> 13.5 -> 14 separate the two).
- T8 (null vs empty): `get_text` of an empty or absent control is `""`.
- T10 (order): create fonts -> set fonts -> delete old fonts; `ShellIcons.Apply` before `ApplyFonts` in `on_dpi_changed`; `layout_controls` BEFORE `invalidate_rect`; min-then-max in `initial_frame`.
- Handles (R0003): the fonts are deleted only by `apply_fonts` (old ones) and `cleanup` (18k); `get_dc` is always paired with `release_dc` on every path (including the early return after a failed measure).
- Re-entrancy: `run_layout` calls the content hook with no borrow held; the hook calls `place`/`item` which borrow `child_hosts` shortly.

## Safety rules (`// SAFETY:` per `unsafe` block)
`on_dpi_changed_message` reads the `RECT` behind `lparam` (valid for the message, copied); `on_get_min_max_info` writes the `MINMAXINFO` behind `lparam` (valid, single writer); `set_list_item_height` is `send_message` with an integer pair (`LB_SETITEMHEIGHT` carries no pointer, may reuse `controls::basic::send_int` if it is `pub(super)`-reachable, else `send_message` with the comment); `WM_SETFONT` likewise (HFONT value, no pointer deref by the caller). `size_of`/`offset_of` assertions as D-W8B5-311.

|---|---|
| `SystemParametersInfoForDpi` returns false | `Err` -> `fallback_log_font(dpi)` |
| `CreateFontIndirect` returns 0 | handle `0` kept, no error |
| `GetDC` returns 0 | `line_height` (height), `0` (width), nothing (units) |
