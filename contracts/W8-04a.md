## Semantics
1. **`build`** (`LanguageOptions.Build`): first entry is `code = AUTO_CODE` ("auto") with the label of `settings.language.auto` (`text.get("settings.language.auto")`).
   Then one entry per language, in the GIVEN order (no sorting here: `discover_languages` sorts). Label: `native_name` when `native_name.trim()` is not empty, else `code`.
   If `is_user_provided`: `text.format("settings.language.userProvided", &[LocArg::new("name", label)])` (the `{name}` value is inserted literally; braces in it are not re-read).
   `entry.code` is the language code as given (not lower-cased).
2. **`index_of`**: `None` or blank (`trim().is_empty()`) value -> `auto`; otherwise `value.trim()`. Match the FIRST entry whose `code` equals it with `eq_ignore_case`. No match -> `None`.
3. **`to_setting`**: a selected entry -> `"auto"` (the `AUTO_CODE` constant) when `is_auto()`, else its `code` (as stored). No selection -> `current` returned UNCHANGED (no trim) when it is non-blank; `None` or blank -> `"auto"`.
4. **`LanguageOption::is_auto`**: `eq_ignore_case(code, AUTO_CODE)` (C# `OrdinalIgnoreCase`). Only the entry built at position 0 is "auto" in practice; a language whose code is `Auto` is also auto (golden `auto-looking-code-is-the-auto-entry`).
5. **`has_problems`**: `!warnings.is_empty()`.
6. **`message`** (`TranslationProblems.Message`):
   - no warnings -> `text.get("dialog.reloadTranslations.ok")`;
   - otherwise `details` = the first `MAX_LISTED` (15) warnings, each `"• " + warning`, joined with `"\n"`;
     when `warnings.len() > 15`, append `"\n"` + `text.format("dialog.reloadTranslations.more", &[LocArg::new("count", remaining)])` where `remaining = len - 15`;
   - result = `text.format_plural("dialog.reloadTranslations.problems", len, &[LocArg::new("count", len), LocArg::new("details", details)])`.
     `format_plural` picks `.one` only for count 1 (English-style plural rule of the catalog); `{count}` must be an ARGUMENT as well (the selector does not inject it).
   - the total count is used for the plural and for `{count}`, never the number of listed items.
7. **`source::text(key)`**: `pr_l10n::localizer::Localizer::current().get(key)`; unknown key -> the key itself (`Localizer::get` already does this).
8. **`LocalizationService::new`**: builds `LanguageLoader::new(file_system, paths.shipped_dir, Some(paths.user_languages_dir.clone()))`. No file is read in `new`.
   `requested_language` starts as `"auto"`, `mode` as `None`.
9. **`load(language)`** (`LocalizationService.Load`): `loader.load(language, Some(&installed_ui_culture))`. The installed culture is passed explicitly: never `current_ui_culture()`
   (C# uses `CultureInfo.InstalledUICulture`, not the current one). Then `Pseudo` -> `create_pseudo(&l)`, `Keys` -> `create_show_keys(&l)`, `None` -> `l` unchanged.
   Touches no global state: the result is NOT published.
10. **`parse_mode(args)`** (`ParseMode`): `--i18n-keys` present as an element (OrdinalIgnoreCase, exact element) -> `Keys`; else `--i18n-pseudo` present -> `Pseudo`; else `None`.
    Keys wins over pseudo. Elements are compared whole: `" --i18n-keys"` and `"--i18n-keys-x"` do not match.
11. **`apply(language, localizer)`** in this order (the order matters for the logs only):
    a. `requested_language` = `"auto"` when `language` is `None` or blank (`trim().is_empty()`), else `language.to_owned()` (not trimmed);
    b. for each `localizer.warnings()` entry, `log.warn(&format!("i18n: {w}"))`;
    c. culture code = `"en"` when `mode == Pseudo`, else `localizer.code()`; `cultures.lookup(code)`: `Some(c)` -> `pr_l10n::loader::set_current_ui_culture(c)`; `None` -> unchanged;
    d. `Localizer::set_current(localizer)` (same `Arc`: `Arc::ptr_eq` must hold afterwards).
    The culture of a KEYS-mode localizer is the localizer's own code (C# does the same), not `en`.
12. **`switch(language)`** = `let l = Arc::new(self.load(language)); self.apply(language, l)`.
13. **`reload()`**: `language = requested_language.clone()`, `l = self.load(Some(&language))`, `apply(Some(&language), Arc::new(l))`, returns the warnings of `l` (a clone, `Vec<String>`).
    Reload uses the REQUESTED language, never a value the caller passes.
14. **`resolve_code(language)`**: `loader.resolve(language, Some(&installed_ui_culture))`; an unknown code gives `en`; `auto` follows the installed culture (never in a golden).
15. **`discover_languages`**: `loader.discover_languages()`.
16. **`set_mode`** takes effect at the next `load`; it does not re-publish the current localizer.

## Traps (docs/MULTI-AGENT-PLAN.md section 7 plus this unit)
- **T1 Machine culture.** `auto` resolves through the installed UI culture, which differs per machine. Goldens never contain `auto` (the input files obey this). Tests for `auto` use an injected culture.
- **T2 Matching by `eq_ignore_case`, not `to_lowercase`.** `"AUTO"`, `"Auto"` and `"VI"` match the auto entry or `vi`. `index_of` trims its input before matching; `to_setting` never trims.
- **T3 Trim rules differ.** `index_of` and the blank test trim; `to_setting` returns `current` untrimmed; `apply` stores `language` untrimmed; `resolve_code(" vi ")` gives `en` (golden `resolve-padded-code-is-not-trimmed-to-en`).
- **T4 `Some("")` vs `None`.** Both mean `auto` in `apply`, `index_of`, `to_setting`; `resolve_code` treats blank the same way (`code.trim().is_empty()` in the loader).
- **T5 Plural selector vs `{count}`.** `format_plural` needs `count` (selector) AND the `count` argument. The "more" line uses the remaining count, not the total (golden `eighteen-warnings-*`: `more` = 3).
- **T6 Placeholders in values.** A warning or a native name containing `{count}` or `{0}` is inserted literally (golden `placeholder-text-in-warning-is-not-reparsed-en`, `user-native-name-with-braces-is-a-value`).
- **T7 Pseudo culture.** `apply` uses `en` for `Pseudo` even when `localizer.code()` is the pseudo code; `Keys` does NOT (it uses the localizer's code).
- **T8 Failed culture lookup keeps the current culture.** Not an error, not a log line (C# catches `CultureNotFoundException` silently).
- **T9 Warnings are logged on every apply**, including the `reload` path, with the `i18n: ` prefix.
- **T10 Ambient vs explicit.** `message` takes the localizer explicitly; `source::text` reads the ambient one; neither changes the other. The golden sets the ambient localizer before `message`.
- **T11 No `unwrap`/`expect`** in `service.rs` (AGENTS.md: the service touches files). `load` never fails: problems are warnings.
- **T12 `Arc` identity.** `apply` publishes the SAME `Arc` it was given.
- **T13 Debug.** `LocalizationService` has a hand-written `Debug` (the `dyn` fields have none); `LanguageOption`, `TranslatorMode`, `LocalizationPaths` derive it.
- **T14 Sorting.** `build` keeps input order; sorting belongs to `LanguageLoader::discover_languages` (already ported, native-name collation).

## Open questions (each with the recommended option)
1. **Production culture lookup and installed culture.** The `CultureLookup` trait and `installed_ui_culture` are injected. Recommended: the platform layer (`pr-platform-win`, the unit that wraps `GetLocaleInfoEx`, expected in the 11-series) implements `CultureLookup` and reads the installed UI culture once at startup; this unit does not depend on Windows. Alternative: a pure table of known codes, rejected because a table drifts from .NET.
2. **`message` takes an explicit `&Localizer`.** Recommended (done). Alternative: read `Localizer::current()` as C# `Tr.*` does; rejected because it makes the golden depend on global state.
3. **`index_of` returns `Option<usize>`** (not `-1`). Recommended (done, idiomatic). The golden records `-1` as `null` in its output; the test maps it.
4. **`apply` takes `Arc<Localizer>`** (so the identity check holds). Recommended (done).
5. **`DefaultThreadCurrentUICulture`** dropped and logged as `Different`. Recommended. Alternative: a thread-local culture, not needed by any unit so far.
6. **Language-switch notification** lives in the shell, not in `LocalizationSource`. Recommended. The change is one subscription to `on_current_changed`, owned by the window-host unit (W8-13).
7. **`parse_mode` is an associated function of `LocalizationService`** (C# static). Recommended (done); a free function would also fit, no caller depends on the choice.
