## Semantics (C# is the spec)
1. **Texts** are the ambient language read at call time (`pr_l10n::tr::*`); the item list is built once in `new` (D-W8B5-508). The combo entries are `tr::enum_file_operation_move()`, `_copy()`, `_recycle()` in this order = `operation_to_index` 0, 1, 2. No literals.
2. **Item styles** as the doc comment of `build_items` (it lists every control; `ComboBoxControl::DEFAULT_STYLE` = `CBS_DROPDOWNLIST | CBS_HASSTRINGS | WS_TABSTOP | WS_VSCROLL`; the list box is single-selection owner-draw fixed with strings; the check box is `BS_AUTOCHECKBOX | BS_MULTILINE`). `golden` compares class, id, text, style and ex style of all 18 items.
3. **Borrow discipline (D-W8B5-504).** The presenter lives in a `RefCell`. Every method reads the controls it needs FIRST (`current_fields`, selected indices, texts), then `borrow_mut()` for exactly one presenter call, then drops the borrow, then writes controls / opens dialogs. `show_warning`, the file dialogs and `ZoomPromptDialog` are modal loops: they never run under a borrow. A `try_borrow_mut` failure (cannot happen on the UI thread without a nested presenter call) is treated as "nothing to do".
4. **`on_selection_changed`** order: `save_current` (redraws the list only when the presenter says it changed a row), then read the selected index, map it to a `RowId` with `presenter.row_id(index as usize)` (negative or out of range: `None`), `presenter.open(id)`; `None` leaves the fields untouched (the C# `if (fields is null) return;`); `Some(form)` sets name, shortcut, destination, the check state and the combo selection (`form.operation_index`).
5. **`fill_list` / `refresh_list`**: `fill_list` remembers `LB_GETTOPINDEX`, clears, adds every name, restores the top index when `0 < top < count`. `refresh_list` remembers the selected index, `fill_list`, re-selects it (`select_single`) when it is still in `0..count`. `select_index(i)` = `select_single` then `on_selection_changed`.
6. **Add** = `save_current`, `presenter.add(&Localizer::current())`, `fill_list`, `select_index(index of the new row)` (find it with `row_id(i) == Some(id)`). **Remove**: no selection or out of range -> nothing; `next = presenter.remove(row, index)`; `fill_list`; `Some(n)` -> `select_index(n)`; `None` -> clear name, shortcut, destination, uncheck "confirm" (the operation combo keeps its value, as in the C#).
7. **Import**: described on `import_actions` (the doc comment is the spec). The filter text is `FileFilterText::parse(tr::dialog_file_filter_json_or_all())`; the dialog title is `tr::action_profiles_import()`; no initial folder. **Export**: filter `dialog_file_filter_json`, default extension `Some("json")`, suggested name `Some("photoreview-actions.json")`. A file dialog `Err` is logged (`AppLog::global().error("File dialog failed", Some(&hresult))`) and treated as a cancel (D-W8B5-514, the rule of D-W8B5-2).
8. **Apply**: `on_ok` as its doc comment. The presenter's `apply` message is shown as is (it already contains the localized reason; the destination-escape text names the action).
9. **List rows**: `list_item_text` returns `(name, shortcut)` for a row in range (badge `None` for an EMPTY shortcut only; a blank `" "` still gets a badge, golden rows "No key" and "Blank key"); anything else the base answer. Row height `line_height + dy(5)` (`apply_layout`).
10. **Layout** (the doc comment of `layout_plan` is the spec; worked example below). The pure `layout_plan` never touches a window: every measure goes through `&dyn DialogMeasure`.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- 3 (arithmetic): wrapping layout maths; `left_width` uses `max` then `min` (never `i32::clamp`); `/` truncates (negative `(fh - line_height) / 2` cannot occur here).
- 8 (None vs empty): `row_text_of` badge `None` only for `""`; `FileFilterText::parse("")` is `[]`; `files = None` means "no import / export", not "cancelled".
- 9 (exception to Result): file dialog `Err` -> log + cancel; `try_import` / `try_export` already return the localized text.
- 10 (order): the combo order Move, Copy, Recycle is the presenter's `operation_to_index`; the list order is the presenter's order.
- T-re-entrancy (D-W8B4I-1 / D-W8B5-504): `set_item_text` on an edit sends `EN_CHANGE` to the dialog; `on_command` ignores it (not `BN_CLICKED` / `LBN_SELCHANGE`), so no borrow is needed there, but nothing may hold the presenter borrow across a control write.
- T-modal-in-modal: the dialog can be opened over the Settings dialog; it uses `dialog.hwnd()` as the owner of its warnings and file dialogs (never the shell window).
- T-panic (R0003): no `unwrap`/`expect`; `LB_GETTOPINDEX` / `LB_SETTOPINDEX` are integer-only `send_message` calls, each with a SAFETY comment.
