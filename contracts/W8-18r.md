## Semantics (C# is the spec)
1. **Texts** are the ambient language at call time (`pr_l10n::tr::*`), the item list is built once in `new` (D-W8B5-508); names and descriptions of profiles come from `BenchmarkProfileItem::{name, description}(&Localizer::current())`. No literals.
2. **Constructor.** `BenchmarkContent::new` takes the optional pieces out of `&mut options`; `pictures_folder` override or `pictures_folder()` is passed to `BenchmarkPresenter::initial_folder(initial_folder, &pictures)`. `scan` and `save` go to `BenchmarkPresenter::new(session_factory, scan, save)` (`None` = presenter defaults). The `ui` argument of the C# constructor is dropped (D-W8B5-505).
3. **`on_initialized`** exactly as the doc comment of the hook (order matters: the window handle is published to workers first; the grid is configured before the columns are added; the tooltips and the language subscription come last; `texts_applied` is set at the very end).
4. **`SyncRows` / sort.** `display_order(count, column, direction, compare)`: identity when `column < 0 || direction == 0`; else the indices sorted by `compare`, ties by index, ascending when `direction == 1`, otherwise the full order reversed INCLUDING the tie-break (the C# negates the comparison). `compare_rows`: column 4 compares sample counts, 5..8 compare p50 / p95 / p99 / max with the .NET `double.CompareTo` rule (NaN first), every other column (and any number outside 0..9, clamped) compares the displayed cell text with the culture comparer. `next_sort`: `(column, 1)` unless the same column is already ascending, then `(column, 2)`. `sort_by` also tells the base class the new arrow (`set_list_view_sort`). The grid is rebuilt from scratch on every `sync_rows`; the selected row is kept by its source index (`row_param`).
5. **Language change.** The handler registered with `on_current_changed` runs on whatever thread called `set_current`: it only posts `WM_BENCHMARK_LANGUAGE` (the stored window handle, `0` -> nothing). The window handles it in `on_window_message`; `on_language_changed` is a no-op for a closed window and re-applies every caption listed in the doc comment, then asks the presenter to repaint (`notify_language_changed`), invalidates the profile list and re-runs the layout.
6. **Close.** `on_closed`: unsubscribe, publish handle `0`, cancel the run in flight through the presenter (`try_borrow_mut` then `close()`). `dispose()` is the same cancel without the window.
7. **Layout** is `layout_plan` + `apply_layout`; the doc comment of `layout_plan` is the spec, including the order of the calls (profile list item height BEFORE its placement; the bottom button row right before the results grid). `status_height` records the height given to the status line; `run::DialogView::set_status` re-runs the layout only when a new text needs a different height. `column_widths` runs only when the grid window exists. Not resizable below `minimum_client_size` (the base class enforces it through `WM_GETMINMAXINFO`).
8. **`culture_compare`**: `CompareStringEx(LOCALE_NAME_USER_DEFAULT, 0, a, b)` with UTF-16 lengths; `CSTR_LESS_THAN` / `CSTR_EQUAL` / `CSTR_GREATER_THAN` map to `Less` / `Equal` / `Greater`; a `0` answer falls back to `pr_core::text::cmp_ignore_case`, then `a.cmp(b)` (D-W8B5-509: .NET 10 on Windows may use ICU for `CompareInfo.Compare`; the two orders agree for the first-letter-different words the tests use; a `Different` note).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- 1 (string compare): the text columns use the culture comparer, NOT `to_lowercase` / ordinal; the test passes an ordinal comparer only to be machine independent.
- 3 (arithmetic): wrapping `i32` layout maths, truncating `/`, `max` then `min` for clamps; `flex * 2 / 3` is integer division.
- 4 (rounding / formatting): none here (the cells are formatted by `BenchmarkResultRow::cell_texts`, W8-10h).
- 8 (None vs empty): `initial_folder: Some("")` is a folder (the box shows an empty text); only `None` means "Pictures". `profile_badge` is `None` out of range, never `""`.
- 10 (order): the profile list order is `pr_bench::profiles::all()` order; the grid order is the presenter's row order unless sorted.
- T-re-entrancy (D-W8B4I-1 / D-W8B5-504): no `RefCell` borrow (presenter, sort cell, language cell) is held across an OS call or a hook; `sync_rows` copies the cells out under a short `borrow()` and then talks to the list view; the view the presenter writes to never reads the presenter.
- T-threads (R0003, D-W8B3H-4): the language handler runs on any thread and only posts a message (the stored handle is an `AtomicIsize`); nothing else in this unit is `Send`; the dialog must not be touched from the wake function.
- T-leaks: the language subscription and the handle cell are released in `on_closed`; the presenter token is cancelled; the tooltip provider holds the presenter `Rc`, not the content (no cycle).
- T-panic (R0003): no `unwrap`/`expect`; `SHGetKnownFolderPath` and `CompareStringEx` are the only new `unsafe` calls, each with a SAFETY comment; the `CoTaskMemFree` of the folder string runs on every path.
