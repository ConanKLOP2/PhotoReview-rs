## Semantics notes (the stubs cite these numbers)
1. **Order and separators (`format_exif`).** Parts in this order: FileName, DateTaken, ModifiedDate, Dimensions (with the raw preview part right after it), Camera, Lens, Iso, FocalLength, Aperture, ShutterSpeed. Joined with `SEPARATOR` (U+00B7 between single spaces). No parts gives "".
2. **Value gating.** Each part needs its flag in `fields` (`contains`) and a value:
   - FileName: `!is_blank(file_name)`, shown verbatim (not trimmed).
   - DateTaken: `exif.date_taken` is `Some`: `"Taken: " + format_date_time(...)` (key `exif.dateTaken`).
   - Dimensions: `width > 0 && height > 0`: `exif.dimensions` with `{width}`/`{height}` as `LocValue::Int`.
   - Camera: `camera_text(make, model)` is `Some`.
   - Lens: `exif.lens_model` is `Some`, even `""` (C# `is {} lens`; golden `format-empty-lens-part` gives `IMG_1234.jpg · `).
   - Iso: `iso` is `Some(v)` with `v > 0`: `exif.iso`.
   - FocalLength: `focal_length` with `value() > 0.0`: `exif.focalLength` with `format_custom_fixed(value, 1)`.
   - Aperture: `f_number` with `value() > 0.0`: `exif.aperture` with `format_custom_fixed(value, 1)`.
   - ShutterSpeed: `shutter_text(exposure_time)` is `Some`.
3. **Overall contract.** `format_exif` never fails and never shows a placeholder. An empty result is "" (the golden `format-none-fields`).
4. **ModifiedDate and raw preview.** ModifiedDate: flag and `modified_local` `Some(local)`: `"Modified: " + format_date_time(local)` (key `exif.modified`), placed right after DateTaken. The value is NOT converted here (Semantics 9). Raw preview: flag Dimensions and `raw_preview_width > 0 && raw_preview_height > 0`: `overlay.rawPreview` with `{width}`/`{height}`, right after the dimensions part. When absent the line is byte-identical to the line without it (golden `format-raw-preview-zero-height`).
5. **`format_date_time`.** `ctx.dates.general(date)`; when that is `None`, `ctx.dates.invariant_general(date)`. Only `None` (out of range) falls back (T6). Used by DateTaken, ModifiedDate and the title bar.
6. **`camera_text`** (inputs are not trimmed; Some(...) keeps the original text):
   - model blank: make blank gives `None`, otherwise `Some(make)`.
   - make blank (model not blank): `Some(model)`.
   - `starts_with_ignore_case(model, make)`: `Some(model)`.
   - `space` = byte index of the first `' '` in make (ordinal); `makeWord` = `make[..space]` when `space > 0`, else `make`.
   - `starts_with_ignore_case(model, makeWord)`: `Some(model)`.
   - otherwise `Some(make + " " + model)`.
   Examples: ("Canon", "Canon EOS R5") gives the model; ("NIKON CORPORATION", "NIKON Z 6_2") gives the model; (" Canon", "Canon X") gives " Canon Canon X" (leading space: `space` is 0, so the whole make is compared).
7. **`shutter_text`.** `None` unless `numerator > 0 && denominator > 0` (`value()` is not used here, T4).
   - `numerator == 1 && denominator > 1`: `exif.shutterFraction` with `{denominator}` as `LocValue::UInt`.
   - `seconds = value()`. When `seconds < 0.5`: `reciprocal = 1 / seconds`, `denom = round_half_away_from_zero(reciprocal)`. If `seconds >= 0.1 && |reciprocal - denom| > denom * 0.01`, `exif.shutterSeconds` with `format_custom_fixed(seconds, 2)`; otherwise `exif.shutterFraction` with `denom` printed as an integer.
   - `seconds >= 0.5`: `exif.shutterSeconds` with `format_custom_fixed(seconds, 1)`.
   Golden examples: (1,250) "1/250 s", (3,10) "0.3 s", (4,10) "0.4 s", (1,2) "1/2 s", (101,1000) "1/10 s" (reciprocal 9.90 is within 0.1 of 10, so the fraction form wins), (4,100) "1/25 s" (seconds below 0.1 always use the fraction form).
8. **Status numbers and plurals.** Every "position" is `index + 1` with `wrapping_add(1)` (T21). `no_supported_images_but_subfolders(count)` is the plural group: `Localizer::format_plural_with("status.noSupportedImagesButSubfolders", i64::from(count), &[LocArg::new("count", LocValue::Int(i64::from(count)))], ctx.numbers)`. The base key is a string literal because `pr_l10n::keys` has only `_ONE`/`_OTHER` constants.
9. **Local time (caller's job).** The formatter never converts a time zone (T7). `modified_local` is the local wall clock that the caller already computed (C# `ToLocalTime()`). The oracle builds that value with `DateTimeKind.Local`, so the C# `ToLocalTime()` inside the formatter is the identity and the golden does not depend on the machine time zone. Who computes the conversion is open question Q2.
10. **Null messages.** `action_failed(name, None)` and `copied_to(None)` render their `{message}` / `{fileName}` as "" (`LocValue::Null`; `Some("")` also gives ""). C# `string?` null and "" are equal in the rendered text, but a `None` in Rust stays `Option::None` in the signature (T9).
11. **Title bar (`format_title_bar`).** Parts in this order: FolderName; FolderPath (not blank); IndexCount (`index` is `Some` and `count` is `Some(c)` with `c > 0`: `status.position` with `index + 1`); FileName (not blank); FileSize (`length` is `Some`: `format_file_size`, T15); Dimensions (as in Semantics 2); ModifiedDate (flag and `modified_local` `Some`: "Modified: " + format_date_time, as Semantics 4); DateTaken (`exif.date_taken` `Some`: same text as Semantics 2); Camera (`camera_text`); Lens; Iso; FocalLength; Aperture; ShutterSpeed (same rules as Semantics 2). FolderName is `get_file_name(trim_ending_directory_separator(folder))`; an empty name falls back to the folder path itself (T13). Joined with `SEPARATOR`; "" when nothing is shown. A blank folder path gives no FolderName/FolderPath part.
12. **Reload path (`choose_reload_path`).** `candidate = presented_path` if it is `Some` (even `""`, T19), else `entry_path`; `None` gives `None`. If `!raw_enabled` and `group` is `Some(g)` and `eq_ignore_case(candidate, g.raw_path())`, return `Some(g.jpeg_path())`. Otherwise return the candidate. `pair_mode` is not used (C# `_ = pairMode`).

## Traps (docs/MULTI-AGENT-PLAN.md section 7; the stubs cite these ids)
- **T1 .NET custom numeric formats.** `ToString("0")`, `"0.#"`, `"0.##"` on a `double` (`format_custom_fixed`). Output: digits rounded to `max_decimals` digits after the point (away from zero on the decimal digits, the .NET behaviour; `f64::round` is the same rule; do NOT use `round_ties_even` or `format!("{:.N}")` without checking the golden), trailing zeros dropped, the point is `numbers.decimal_separator`, the sign is `numbers.negative_sign`. Golden cases that pin it: 1.25 (`(5,4)` shutter), 0.96 (`(96,100)`), 0.45, 1024-based sizes (`format-status` file_size rows), 4294967295 seconds. If the golden disagrees after two attempts, escalate (see the header).
- **T2 Shutter thresholds.** The `< 0.5` split, the `>= 0.1` lower bound for decimals, and the tolerance `> denom * 0.01` (strict). Mutants: `>` vs `>=` in each.
- **T3 ISO.** `iso > 0` only (no upper bound here: `ExifSummary::create` already limits it). Golden `format-negative-iso`, `format-zero-values`.
- **T4 focal length and aperture use `value() > 0.0`**, where `value()` is `0.0` for denominator 0. Shutter uses `numerator > 0 && denominator > 0`, not `value()`. Golden `format-zero-values`.
- **T5 Denominators are integers.** Print `u32` through `LocValue::UInt` (`1/4294967295 s` stays exact, no float). Golden `shutter-1-4294967295`.
- **T6 Date fallback.** Only `DateText::general` returning `None` falls back to `invariant_general`. The fallback is the only path for a bad date; no other error is caught. Golden `format-date-year-1`, `format-date-1850-th-TH`.
- **T7 Wall clock.** `DateTimeUtc` is a wall clock (not a UTC instant). Never apply a time zone in this module.
- **T8 `StartsWith(OrdinalIgnoreCase)`.** Use `starts_with_ignore_case` (per char `pr_core::text::ordinal_upper`). Not `str::starts_with`, not `to_lowercase`, not `eq_ignore_ascii_case`. Golden `camera-*` rows with `'Canon '`, `' Canon'`, `'ARABIC'`, `'東京カメラ'`.
- **T9 Null, empty and blank.** C# `is {} x` accepts `""` (lens, `format-empty-lens-part`); C# `IsNullOrWhiteSpace` rejects `"   "` (file name, folder path). `camera_text` returns `None` for blank parts, and a blank model returns the make unchanged. Keep `Option::None` and `Some("")` apart.
- **T10 Raw preview** needs both sides > 0 and sits under the Dimensions flag. Absent: the line is unchanged.
- **T11 Unknown dimensions.** `width <= 0 || height <= 0` hides the Dimensions part (negative counts as unknown; golden `format-blank-file-name` has width -1).
- **T12 No literal UI text** in pure code (D-W8-4). The only literals are `SEPARATOR` and the `" "` join in `camera_text`, which C# also has as literals. Tests may spell the expected English text.
- **T13 Folder name.** Use `pr_core::text::dotnet_path::{trim_ending_directory_separator, get_file_name}` (W2-00 golden `dotnet-path` covers them). Drive root `D:\` gives the root text; UNC root `\\server\share\` gives `share`; trailing space stays in the name (golden `title-bar` `trailing-space-name`).
- **T14 IndexCount** needs `count > 0`; `count == 0` hides it even with an index (golden `index-count-zero-count`).
- **T15 FileSize.** Any `Some(len)` shows; negative counts as 0: `"0 byte"` (golden `file-size-negative`).
- **T16 `format_file_size`.** `value = max(0, bytes) as f64` (C# `(double)` conversion, rounding for `i64::MAX` is the same). Loop `while value >= 1024 && unit < 3`. Unit 0 uses `"0"`, others `"0.##"` (T1). Units `unit.size.byte|kilobyte|megabyte|gigabyte`.
- **T17 Hash fragment.** `None` gives `compare.hash.off`, `Some(true)` `compare.hash.same`, `Some(false)` `compare.hash.different`, `compare_hash_unknown` gives `compare.hash.unknown`.
- **T18 Sibling boundary.** `direction > 0` gives `.last`; zero and negative give `.first` (golden `sibling_folder_boundary` with 0).
- **T19 Reload path `??`.** C# `??` only coalesces `null`: `Some("")` is kept. The RAW-off rule compares with `eq_ignore_case` (`OrdinalIgnoreCase`), not `==`, not `to_lowercase`.
- **T20 Plurals.** Never reimplement the one/other choice; call `Localizer::format_plural_with` (count 1 is "one", other counts "other"). Golden `no_supported_images_but_subfolders` counts 0, 1, 2, 12.
- **T21 Overflow.** C# `int` arithmetic is unchecked: `index + 1` with `i32::MAX` gives `-2147483648`. Use `wrapping_add(1)` (a debug build would otherwise panic). Golden `format-status` `index_only` with 2147483647 gives `-2147483648/10`. No other arithmetic on user values is in this unit.
- **T22 N0 (`compare_size_suffix`).** Digits grouped in threes with `group_separator` (invariant ","), the sign from `negative_sign`: `-5` gives `-5`, `1048576` gives `1,048,576` (vi-VN: `1.048.576`). Grouping size 3 only (Q1).
- **T23 Integers in args** (index, count, width, height, bytes, denominators) go through `LocValue::Int`/`UInt`: no grouping for `ToString()` without a format. Golden `index_only` with 1000/12345 in vi-VN gives `1001/12345`.
- **T24 Placeholder names.** `LocArg::new(name, ...)` with the placeholder text exactly as in `assets/languages/en.json` (`fileName`, `leftName`, `hashText`, `denominator`, ...). A wrong name leaves `{name}` in the output and fails the golden.

## Open questions (each has the recommended default; the lead decides)
- **Q1 Group separator for N0.** `pr_l10n::NumberCulture` has no `NumberGroupSeparator`.
  - A (default, used in the stubs): a `group_separator` field in `FormatContext`. No change to `pr-l10n`. Grouping size is fixed at 3, which is right for every culture the golden uses.
  - B: add `group_separator` (and group sizes) to `NumberCulture`. Cleaner, but changes a W1-11 type in a lead-owned crate. Needed anyway for the Windows culture lookup (D10).
  - Recommendation: A now, B with the Windows culture unit. After B, the `group_separator` field goes away.
- **Q2 Local time conversion.** `ToLocalTime()` needs the OS time zone, which `pr-core` cannot do (D16, P-05).
  - A (default): the caller (presenter, W8-08d / W8-07g) converts with a local-time source trait implemented in `pr_platform_win`. This unit stays pure.
  - B: pass a `LocalTimeSource` into the formatter. Adds a trait argument to every formatter call.
  - Recommendation: A. The golden already passes local wall clocks (Semantics 9).
- **Q3 `DateText` production implementation.** The C# `"g"` format is culture-specific.
  - A (default): a Windows adapter in `pr_platform_win` (`GetDateFormatEx` plus `GetTimeFormatEx` in the display locale), built with the host unit. Tests use the recorded golden texts.
  - B: a pure Rust table of the common patterns. Simpler, but misses the calendars the golden covers (`th-TH`).
  - Recommendation: A.
- **Q4 Empty lens part.** C# shows an empty part for `LensModel == ""` (`is {} lens`), which can only come from unsanitized input (`ExifSummary::create` drops blanks). Default: keep the C# behaviour (golden `format-empty-lens-part`); the production path never produces it.
- **Q5 Vietnamese golden.** The `vi` cases need `assets/languages/vi.json` at test time (already in the repo). If the lead wants English only, drop the `vi` cases from the golden inputs and the Rust harness keeps the English path.
