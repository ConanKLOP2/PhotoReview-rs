## Semantics (C# is the spec)
Every formula is in the doc comment of its stub function; this section gives the worked examples (hand-computed from the C#, `S(scale, v) = max(1, round_ties_even(v * scale))`) that the pure tests must contain, and the GDI order.
1. **`check_layout`.** (a) check box, `width 120, height 20, scale 1.0, enabled, checked, not hot, focused, text_height 15, text_width 60`: `box_size 13`, `box_left 0`, `box_top 3`, `border_key Dark.Accent`, `fill_key Dark.Accent`, `mark = Some((Dark.TextStrong, 2, [(3, 10), (5, 12), (10, 7)]))`, `dot None`, `text_rect (19, 0, 120, 20)`, `text_flags 0x8024` (`DT_VCENTER 4 | DT_SINGLELINE 0x20 | DT_END_ELLIPSIS 0x8000`), `focus_rect = Some((18, 1, 81, 18))` (`shown = min(101, 60) = 60`, `text_top = (20 - 15) / 2 = 2`, `right = min(120, 19 + 60 + 2) = 81`, `bottom = min(20, 2 + 15 + 1) = 18`). (b) radio, `scale 1.5, width 120, height 20, enabled, checked, hot, text_height 22`: `box_size 20`, `box_top 0` (`(20 - 20) / 2`), `border_key Dark.Accent`, `fill_key Dark.Input`, `dot = Some((Dark.Accent, 6))` (`round_ties_even(5.6) = 6`), `mark None`, `text_rect (29, 0, 120, 20)`. (c) left text, multiline, `width 120, height 40, scale 1.0, text_height 15`: `box_left 107`, `box_top 1` (`(15 - 13) / 2`), `text_rect (0, 0, 101, 40)`, `text_flags 0x10` (`DT_WORDBREAK`), unchecked enabled: `border_key Dark.BorderStrong`, `fill_key Dark.Input`. (d) disabled checked: `border_key Dark.TextFaint`, check box `fill_key Dark.Input` (the fill is the accent only when checked AND enabled), mark key `Dark.TextFaint`, `text_key Dark.TextMuted`, no focus rectangle. (e) the border key priority: disabled, then checked, then hot, else strong. The C# truncating division `(height - box) / 2` of a negative value is clamped by `max(0, ..)`.
2. **`combo_layout`.** `width 200, height 24, scale 1.0, enabled, focused, not dropped`: `arrow_width 24`, `text_rect (6, 1, 176, 23)`, `arrow_points [(183, 10), (187, 15), (191, 10)]`, `arrow_pen_width 2`, `focus_rect Some((3, 3, 176, 21))`, `border_key Dark.Accent`. `width 200, height 36, scale 1.5, enabled, not focused`: `arrow_width 36`, `text_rect (9, 1, 164, 35)`, `arrow_points [(175, 15), (181, 22), (187, 15)]`, `focus_rect None`, `border_key Dark.BorderStrong`. Border key priority: disabled `Dark.Border`, focused or dropped `Dark.Accent`, hot `Dark.TextMuted`, else strong. A dropped combo has no focus rectangle.
3. **`progress_fill_width`.** `(200, 0, 0, 100, 40) = Some(80)`; `(101, 1, 0, 100, 50) = Some(50)` (`(101 - 2) * 0.5 = 49.5` rounds to even `50`); `(200, 0, 0, 0, 5) = None`; `(200, 1, 10, 20, 25) = Some(198)` (fraction clamped to 1); `(200, 1, 0, 100, -5) = Some(0)`.
4. **`tick_xs`** (all `scale 1.0`): `(10, 210, 11, 0, 10, auto, None)` = `[10, 30, 50, 70, 90, 110, 129, 149, 169, 189, 209]` (`span 199`, step 1); `(10, 110, 101, 0, 100, auto, None)` = `[10, 17, 24, 31, 38, 45, 52, 59, 65, 72, 79, 86, 93, 100, 107, 109]` (`span 99`, `step = ceil(6 / 0.99) = 7`, and the extra last tick at `10 + 99 = 109` because `100 % 7 != 0`); `(10, 110, 5, 0, 100, not auto, Some([10, 50, 90]))` = `[10, 20, 60, 99, 109]`; `(0, 100, 4, 0, 3, not auto, None)` = `[0, 0, 0, 99]` (a missing inner table gives `min`); `count 1`, `max <= min` or `no_ticks` give `[]`.
5. **`trackbar_layout`.** `channel (10, 12, 210, 20)`, `thumb (90, 5, 102, 27)`, `height 40`, `scale 1.0`, enabled, not hot, ticks off: `channel.rect (10, 14, 210, 18)` key `Dark.BorderStrong`; `filled.rect (10, 14, 96, 18)` key `Dark.Accent`; `thumb.key Dark.Accent`, `thumb_border_key Dark.TextSoft`. A thumb centre left of the channel start gives an empty `filled` rectangle (`(10, 14, 10, 18)`) and a centre right of the end is clamped to the channel end: no `clamp` that panics when `left > right`. Hot enabled thumb `Dark.AccentHover`; disabled: channel `Dark.Border`, filled `Dark.TextFaint`, thumb `Dark.TextFaint`, outline `Dark.Border`, tick key `Dark.TextFaint`. Tick rectangles: `top = thumb.bottom + S(1)`, `bottom = min(height, top + S(4))`, width 1.
6. **`border_thickness`** (`metric(45, d) = 2 * d / 96`, `metric(5, d) = d / 96`): `(0, 0x200, 96) = (2, true)`; `(0, 0x200, 144) = (3, true)`; `dpi 48` is raised to 96; `(0, 0x20000, 96) = (1, false)`; `(0x800000, 0, 96) = (1, false)`; `(0xC00000, 0, 96) = (0, false)` (a caption contains `WS_DLGFRAME`); `(0x800000 | 0x400000, 0, 96) = (0, false)`; `(0, 0, 96) = (0, false)`; the client edge wins over the border style; the minimum is 2 for a client edge and 1 for the others even when the metric is 0.
7. **`border_layers`** (`width 100, height 24`): `edge 2, client_edge` = `[{0, outer}, {1, inner}]`; `edge 3, client_edge` = insets 0, 1, 2; `edge 1` or `edge 2` without client edge = `[{0, outer}]`; `edge 0` or negative = `[]`. `paint_border` fills each layer as a 1 px `frame` of `(inset, inset, width - inset, height - inset)`; the inner colour is `LVM_GETBKCOLOR` of a list view, `Dark.Surface` of a progress bar, else `Dark.Input`.
8. **`group_box_layout`**: `(300, 100, 1.0, text_height 15, text_width 40, has_text)` = `frame (0, 7, 300, 100)`, `patch (5, 0, 51, 15)`, `text_rect (8, 0, 48, 15)`, flags `0x8020`; `(30, 100, 1.5, 22, 80, true)` = `frame (0, 11, 30, 100)`, `patch (8, 0, 26, 22)`, `text_rect (12, 0, 22, 22)` (the text is clipped to `width - left - 2 * pad = 10`); `has_text = false` = frame only; `hide_accel` adds `0x100000`.
9. **`etched_shape`**: `(0x10, 100, 24) = Line(0, 12, 100, 13)`; `(0x11, 100, 24) = Line(50, 0, 51, 24)`; `(0x12, ..)` and any other type `Frame(0, 0, 100, 24)`.
10. **`header_filler_rects`**: `client (0, 0, 300, 24)`, `last (0, 0, 200, 24)` = `[(200, 0, 300, 24), (200, 23, 300, 24)]`; `last.right >= client.right` = `None`.
11. **GDI order of the draw functions** (each is the C# method line by line): pen and brush are created, selected, used, selected back and deleted around each `Ellipse` / `Polyline` / `RoundRect`; the text is drawn after the shapes; the focus rectangle last. The mark of the check box and the chevron of the combo box are `polyline` with a pen of the width from the layout. `draw_progress` reads `PBM_GETRANGE` twice (`wParam 1` = low, `wParam 0` = high) and `PBM_GETPOS`. `draw_trackbar` reads the channel and thumb rectangles through a pointer to a local `RECT`, and for non-auto ticks copies `count - 2` values from the pointer of `TBM_GETPTICS` (null -> `None`).

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (GDI leaks): every pen, brush and the selected objects are restored and deleted on every path (guards); the native test counts `GR_GDIOBJECTS` over 50 paints of every widget.
- T2 (panics): no `Ord::clamp` on values that can be unordered (`trackbar_layout`, `progress_fill_width`): use `max(..).min(..)`; no slice indexing without `get` (the inner tick table); no division by zero (`count - 1`, `max - min` are checked first); no `as` that can wrap silently on a float (saturating).
- T3 (rounding): `Math.Round` of a `double` is to even: `round_ties_even`, never `round`; `(int)Math.Ceiling` is `ceil` then a saturating cast; `Math.Round((double)i * (max - min) / (count - 1))` multiplies first.
- T4 (integer arithmetic): the C# unchecked `int` wraps; use `wrapping_sub` / `wrapping_add` / `wrapping_mul` where the inputs are control values (`position - low`, `value - min`, `max - min`, `width - 2 * inset`); coordinates stay `i32`. The tick loop is `(0..count).step_by(step)` (a `+=` on `i32` can overflow for a huge `count`), and `step` is a saturating `as i32` of `ceil(..)`, converted with `usize::try_from(step).unwrap_or(1)` (a fallback, never `unwrap`).
- T5 (pointer from the OS): the `TBM_GETPTICS` pointer belongs to the control and is invalid after the next change: copy at once, read at most `count - 2` values, never keep it.
- T6 (focus rectangles and `GetFocus`): the combo box and the trackbar compare `get_focus() == hwnd`; the check box uses `BST_FOCUS` of `BM_GETSTATE`; do not mix.
- T7: no `unwrap` / `expect` / `panic` outside tests.

## Safety rules (`// SAFETY:` per `unsafe` block)
`send_message` with a pointer to a local `RECT` (`TBM_GETCHANNELRECT`, `TBM_GETTHUMBRECT`, `HDM_GETITEMRECT`): "the pointer is to a live local `RECT`, the control fills at most `sizeof(RECT)` bytes during the call"; `TBM_GETPTICS`: "the answer is a pointer into the control's own array of `count - 2` `i32`, valid until the control changes; it is copied before any other message is sent"; integer-only messages: "value parameters".

## Error mapping
| C# | Rust |
|---|---|
| `GetClientRect` / `GetWindowRect` fail | nothing is drawn (`paint_border`, `paint_header_filler`) |
| `HDM_GETITEMRECT` answers 0 | nothing is drawn |
| `ComboBoxControl.TextAt` for a bad index | the wrapper returns `""` |
| `Math.Clamp` | `max(..).min(..)` |
