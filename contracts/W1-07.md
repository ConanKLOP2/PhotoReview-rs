- Semantics notes:
  1. **Extensions** compare OrdinalIgnoreCase through `pr_core::text::eq_ignore_case` (not `to_lowercase`). The extension is taken with `get_extension`
     (= .NET `Path.GetExtension`, see its doc and golden field `extension`). Notable consequences pinned by the golden: `".jpg"` (a file literally named
     `.jpg`) IS supported; `"photo."` has no extension; `"a.jpg "` (trailing space) is NOT supported; `"photo.jpg\0"` is NOT supported; a directory
     named `dir.jpg` does not leak (`"C:\\dir.jpg\\file"` has no extension); `':'` is not a separator (`"C:file.jpg"` -> `.jpg`).
  2. **`is_supported_with_raw`**: false if `path.trim().is_empty()` (whitespace-only or empty); then false if the extension is empty; then true if in
     `SUPPORTED_EXTENSIONS`; else `raw_enabled && ext in RAW_EXTENSIONS`. `is_supported(p)` == `is_supported_with_raw(p, false)`. `is_raw_path` does NOT
     do the whitespace check (it only tests the extension), `is_raw_path("")` is false.
  3. **The three extension lists are exact sets**: `.nrw`, `.pef` are NOT RAW here. `JPEG_EXTENSIONS` = `.jpg`, `.jpeg` only (no `.tif`/`.png`).
  4. **CatalogEntry.path** is never blank: `new` and `with_path` return `Err(ArgumentError::BlankPath { param_name: "path" })` for `""` and for
     whitespace-only text (`path.trim().is_empty()`; Rust `trim` uses the same White_Space set as .NET `IsWhiteSpace`). The path is stored as given
     (not trimmed). Other fields start `None`.
  5. **CatalogEntry.matches**: needs BOTH `length` and `last_write_utc` to be `Some` and equal to the stat. `None` never matches.
  6. **with_metadata** compares the OLD `(length, last_write_utc)` with the NEW ones to compute `unchanged`; supplied (`Some`) dimensions always win; omitted ones
     survive only if unchanged. `capture_group` and `path` are copied. The method takes `&self` and returns a new entry (C# record `with`).
  7. **CatalogEntry equality** is derived (`PartialEq, Eq`): `path` compared exactly (case-SENSITIVE, like C# string `==`); `capture_group` uses
     `CaptureGroup`'s own case-insensitive equality.
  8. **CaptureGroup**: constructor validation order jpeg, raw, xmp; `Some("")` or `Some("  ")` xmp is an ERROR (not "no sidecar"). `paths()` is
     `[jpeg, raw]` or `[jpeg, raw, xmp]`; `image_paths()` is always the first two. `get_representative_path`: PreferJpeg -> jpeg, PreferRaw -> raw,
     Separate -> `Err(ArgumentError::OutOfRange { param_name: "mode" })`. Equality: the three paths with `crate::text::eq_ignore_case` (an `Option` xmp
     equals only an `Option` xmp, `None == None`). `Hash` must agree with `Eq`: hash the `ignore_case_key` strings (xmp as `Option<String>`).
  9. **ExplorerReason**: `format(code, details)` replaces every `'|'` in the code and in each detail by `'/'`, then joins with `'|'`; with no
     details there is no separator at all. `parse` = `split('|')`: first piece code, rest details (empty pieces kept). Constant VALUES are persisted/compared by
     other layers: copy them exactly.
  10. **LatestExplorerSnapshot** replaces `Task<ExplorerViewSnapshot>` with `ExplorerQueryHandle` (a write-once `OnceLock` cell, ADR R0003: no async). `current()`
     returns `Some` only when the handle was completed with a snapshot. Pending, failed, canceled or unset => `None`. `set` replaces the previous handle.
     Recover poisoned locks with `unwrap_or_else(PoisonError::into_inner)`; never hold the mutex while calling `handle.snapshot()` (clone the handle out first).
