- Semantics notes:
  1. **SlowLinkSourceReader.** `open_source(path, priority, buffer_size)` calls `inner.open_source(path, priority, buffer_size)?` with the SAME three
     arguments (golden: `inner_path`, `inner_priority`, `inner_buffer_size`; C# default buffer 1 MiB is the caller's `1_048_576` in Rust), exactly
     once. An inner error is returned unchanged and the limiter is not touched (cases `inner-open-failure-*`). Then: `bandwidth == None` returns the
     inner stream itself (no wrapper); `Some(l)` returns `Box::new(ThrottledReadStream::new(stream, Arc::clone(l)))`. `priority` is NOT used for
     pacing (priority-blind: viewer and preload draw from the same bucket; golden `*-preload-priority-*`). Byte content, seek positions and
     `Length` are those of the inner stream (golden `op_results`, `final_position`, `final_length`).
  2. **Shared limiter.** Several readers (and `SlowLinkFileSystem`) are built from clones of ONE `Arc<SharedBandwidthLimiter>`; the decorator must
     keep the `Arc`, never copy limiter state. The throttling itself (token bucket, `Consume`, chunking, the 1 ms minimum sleep, seek/length
     delegation, `Write` => `NotSupported`) belongs to W7-02a; this unit only chooses whether to wrap.
  3. **Constructor null check.** C# `ArgumentNullException` for a null `inner` has no Rust twin (the type is non-null). No test.
  4. **BenchmarkRecycleBin switch.** `is_real_bin_opt_in(v)` is true only for `Some("1")`: ordinal compare, no trim, no case folding, no
     `true`/`yes`, `"01"`, `"11"`, `" 1"`, `"1 "` and `""` are all false (golden `env-*` cases, all 10 spellings). `use_real_bin()` reads the
     process environment with `std::env::var_os`; a non-Unicode value counts as unset (C# can hold lone surrogates; no case). `create` =
     `create_with(use_real_bin(), real_bin)`.
  5. **`create_with`.** `true` => calls the factory exactly once and returns THAT `Arc` (golden `factory_calls`, `returned_factory_instance`;
     test with `Arc::ptr_eq`). `false` => never calls the factory (golden `factory_calls: 0`) and returns a new `TempCopyDeleter`.
  6. **TempCopyDeleter members** (golden `default-deleter-members`): `can_recycle` => true for any path; `fits_in_recycle_bin` => true for any
     path and size (0 and `u64::MAX`); `delete_permanently` => `Err(io::ErrorKind::Unsupported)` (C# `NotSupportedException`); `try_restore` =>
     `Ok(false)` (never `Ok(true)`, never an error).
  7. **`send_to_recycle_bin` = .NET `File.Delete(path)`.** Not `std::fs::remove_file`. Golden `delete-*` cases fix the outcomes
     (`outcome` is the C# exception type; Rust maps `DirectoryNotFoundException` => `NotFound`, `UnauthorizedAccessException` =>
     `PermissionDenied`, `ArgumentException` => `InvalidInput`; any other value in the golden is a contract bug: report it, do not guess):
     existing file => deleted, `Ok`; missing file inside an EXISTING folder => `Ok`, nothing happens (no `NotFound`); missing folder => `NotFound`;
     path is a directory => `PermissionDenied` and the directory stays; read-only file => `PermissionDenied` and the file stays (Rust's
     `remove_file` deletes read-only files on current toolchains, so check `metadata.permissions().readonly()` first); empty path => `InvalidInput`;
     path below a regular file => `NotFound`. Suggested shape: empty => `InvalidInput`; `symlink_metadata`: `NotFound` => `Ok` when the parent
     (an empty parent means the current folder) `is_dir()`, else `NotFound`; other errors returned; directory or read-only => `PermissionDenied`;
     else `remove_file`. Error text: any; only the kind is compared.

   either way).

   clock/sleeper that would let the two timing tests become deterministic), only `open_source` and the two timing tests change. Preferred: W7-02a
   offers an injectable sleeper so no timing test is needed here.
