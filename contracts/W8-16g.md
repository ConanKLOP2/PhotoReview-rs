## Semantics (C# is the spec)
### Messages
1. **`try_handle`**: the table above. `Some(0)` is "handled" (C# `result = 0, true`); `None` is "not handled". `WM_LBUTTONDBLCLK` is treated as a press (the window class has no `CS_DBLCLKS`, but a client may send it). Right / middle / X buttons are never touched. The wheel and touchpad messages are NOT handled (`ShellInput`, W8-14b).
2. **Coordinates**: `lparam` low / high word as SIGNED 16-bit pixels (a client coordinate can be negative while the pointer is captured outside the window), then `to_dip` (16f).
3. **`on_left_down(px, py)`**: `point = to_dip`, `layout = current_layout()`, `part = hit_test_in(layout, point)`; `ScrollBarPart::None` -> `false` (nothing changes, no `on_press`). Else: `pointer = point`, `pointer_inside = true`; `end_interaction(false)` (a previous press whose release was lost); `on_press()` if present (stops a kinetic glide; once per press taken, also for `Background` / `Corner`); then by part: `Thumb` with an axis -> `dragging = true`, `drag_axis`, `drag_grab = box.along(point) - box.thumb_start()`, `window.capture_pointer()`, `window.invalidate()`; `TrackBefore` / `TrackAfter` with an axis -> `page_axis`, `page_direction = -1 / +1`, `paging = true`, `page_region_active = true`, `capture_pointer()`, `page_once()`, `next_repeat_ticks = viewport.timestamp() + milliseconds_to_ticks(repeat_timing().0)`, `hook_frames()`, `invalidate()`; `Background` and `Corner` do nothing more. Returns `true` ALWAYS for a non-`None` part (every left press on a bar or the corner is swallowed).
4. **`on_move(px, py)`**: `hover_before = hovered_thumb_axis()`; `pointer = point`, `pointer_inside = true`; `!tracking && window.hwnd() != 0` -> `tracking = true`, `track_mouse_leave(hwnd)` (ONCE per entry; the flag clears in `on_leave`); `dragging` -> `drag_to(point)`, return; `paging` -> `over = is_over_page_region(current_layout, point)`; entering the region while it was inactive restarts the delay (`next_repeat_ticks = timestamp + delay`, no immediate page); `page_region_active = over`; return; otherwise `invalidate()` when `hovered_thumb_axis() != hover_before`.
5. **`on_left_up`**: not dragging and not paging -> `false`; else `end_interaction(true)` -> `true`. **`on_leave`** (`WM_MOUSELEAVE`): `tracking = false`; `had_hover = hovered_thumb_axis().is_some()`; `pointer_inside = false`; invalidate if `had_hover`. **`WM_CAPTURECHANGED`**: `end_interaction(false)` (the capture is already gone; do not release again). **`WM_CANCELMODE`**: `end_interaction(true)`.
6. **`end_interaction(release_capture)`**: `was_active = dragging || paging`; clear `dragging`, `paging`, `page_region_active`; `unhook_frames()`; `!was_active` -> return (no invalidate); else release the pointer only when `release_capture && window.has_pointer_capture()`, then `invalidate()`.

### Drag and paging
7. **`drag_to(point)`**: `box = current_layout().box_for(drag_axis)`; `!box.visible` -> return (the layout changed mid-drag, e.g. Fit); `offset = offset_for_thumb_start(&box, box.along(point) - drag_grab)` (clamped `0..=max_offset` by the geometry); `apply_axis_offset(axis, offset)`. The geometry is read fresh on every move (`TheDragFollowsWhateverLayoutChangesDuringIt`).
8. **`apply_axis_offset(axis, offset)`**: reads BOTH current offsets, replaces the dragged axis, `viewport.scroll_to(h, v)`, `viewport.update_layout()` (synchronous, so the next geometry query and the next frame see it), `window.invalidate()`.
9. **`page_once`**: `box = current_layout().box_for(page_axis)`; invisible -> return; `current` = that axis's offset; `apply_axis_offset(axis, current + page_direction * box.viewport_length)` (a full viewport; the clamp makes the last page short).
10. **`on_frame`** (the render-frame hook, delivered by the viewport controller's frame subscription): `!paging` -> `unhook_frames()`, return; `now = viewport.timestamp()`; `!page_region_active || now < next_repeat_ticks` -> return; `!is_over_page_region(current_layout, pointer)` -> `page_region_active = false`, return (the thumb arrived under the pointer: the WPF `RepeatButton` disappears); else `page_once()` and `next_repeat_ticks = now + milliseconds_to_ticks(repeat_timing().1)`. `milliseconds_to_ticks(ms) = max(0, ms) * ticks_per_second / 1000` in `i64` with `saturating_mul`.
11. **Frame hook**: `hook_frames` registers ONE `viewport.hook_render_frame(Box::new(move |_| weak.upgrade().map(|b| b.on_frame())))` and stores the id (no second hook while `frame_hook` is `Some`); `unhook_frames` takes the id and calls `viewport.unhook_render_frame(id)`. `on_frame` may call `unhook_frames` from inside the delivery (the controller supports it).

### Painting
12. **`draw(context)`**: `layout = current_layout()`; `!layout.any_visible()` -> `Ok(())` (nothing drawn, `drawn_frames` unchanged). `drawn_frames += 1`. Compare NOT visible -> `draw_bars(context, &layout)`. Compare visible: `client`, `panel = compare::layout::panel(client)`, `right = (panel.right(), 0, max(0, client.w - panel.right()), client.h)`, `bottom = (0, panel.bottom(), client.w, max(0, client.h - panel.bottom()))`; for each strip with `width > 0 && height > 0` (right first): `push_clip(strip)`, `draw_bars`, `pop_clip()` (always popped, also on error; the `RenderError` is returned after).
13. **`draw_bars`**: `hovered = hovered_thumb_axis()` ONCE; `draw_box(vertical)`, `draw_box(horizontal)`, then, when `has_corner`, `fill_rectangle(corner, TRACK)`. **`draw_box`**: invisible -> nothing; `fill_rectangle(bar, TRACK)`; no thumb -> stop; `pressed = dragging && drag_axis == box.axis`; colour `THUMB_PRESSED` if pressed, else `THUMB_HOVER` if `hovered == Some(box.axis)`, else `THUMB`; `fill_rounded_rectangle(thumb, options.metrics.thumb_radius, colour)`. Order of recorded fills at the rig: vertical bar, horizontal bar, corner, then the two rounded thumbs are recorded in the separate `Rounded` list in vertical, horizontal order (the recording context keeps two lists, as the C# `FillRecorder`).
14. **`dispose`**: idempotent; `dragging = paging = false`, `unhook_frames()`; does NOT release the capture (the window is closing). `Drop` calls it.

## Traps checklist (docs/MULTI-AGENT-PLAN.md section 7)
- T1 (INV / swallow rule): a left press that hits any part but `None` returns `Some(0)` — if it leaked to `ShellInput` the image under the 3000 px box would start a pan (the C# no-bars rig shows this). `Background` and `Corner` press = `on_press` + swallow, nothing else.
- T2 (re-entrancy, D-W8B3H-6 / D-W8B4V-9): `try_handle` can be re-entered through `SendMessage` made by `capture_pointer` / `release_pointer` (the OS sends `WM_CAPTURECHANGED` synchronously to the window that LOSES the capture, possibly this one). Keep the C# order exactly: `end_interaction(false)` first, THEN set the flags, THEN `capture_pointer()`; hold no `RefCell` borrow across window / viewport / callback calls. A test with a fake window whose `capture_pointer` re-dispatches `WM_CAPTURECHANGED` documents the observed behaviour (open question 5).
- T3 (signed words, section 7 item 3): `signed_low_word(lparam) = (lparam & 0xFFFF) as u16 as i16 as i32`, `signed_high_word(lparam) = ((lparam >> 16) & 0xFFFF) as u16 as i16 as i32`; `lparam` is `isize` (negative values and the 64-bit sign extension must not change the words).
- T4 (ticks): `repeat_timing` is in ms, `viewport.timestamp()` in QPC ticks (`ticks_per_second` of the options); never mix with keep-warm ticks.
- T5 (frame hook leak): every path out of paging (`on_left_up`, `WM_CAPTURECHANGED`, `WM_CANCELMODE`, new press, `dispose`) unhooks; the clock subscriber count returns to 0 (tests).
- T6 (`f64` `along`/offset): `offset_for_thumb_start` returns NaN for a NaN `thumb_start` (documented in 16e); a NaN pointer cannot come from integer words, so no guard is added.
- T7 (draw/pop balance): same as 16b T2 for the two strips.
