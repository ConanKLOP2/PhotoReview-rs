## Semantics (C# as implemented is the spec)

Atomic catalog rekey preserves order, index, metadata and current item; bump StructuralVersion once. Resolve collision among mapped and unmapped image members before any mutation. XMP-only key is not indexed. Cache key path replacement keeps size/mtime/mode/box; eviction also drops original-dimension cache for old path.

## Traps checklist

- Preserve OrdinalIgnoreCase path comparisons while retaining the user's exact stored spelling and original extension. Do not use locale casing.
- No `unwrap`/`expect`/`panic!` or indexing that can panic on UI-thread or user-data paths. C# async methods map to blocking worker jobs and UI events under R0003; view models mutate and return a `ChangeSet`.
- Keep journal and session formats byte compatible; no new journal operation kind. The C# design's unconfirmed items are resolved by code at `7eaee2a2` (contracts/README.md, Wave 9 sync (FEAT-RENAME)).
- Native work confines `unsafe` to `pr-platform-win` with a `// SAFETY:` comment per block; never touch the user's real Recycle Bin.

## Safety rules

Use fake file systems for failures and recovery. Real OS cases own temp paths and clean only their own items. Do not hold a view-model borrow across native modal loops or worker completion.
