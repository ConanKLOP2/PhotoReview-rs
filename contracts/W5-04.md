- Semantics notes (the C# `Read`, step by step; C# names in backticks):
  1. **`can_read`.** `extension` equals ".nef" under OrdinalIgnoreCase (`pr_core::text::eq_ignore_case`: ".NEF", ".Nef" accepted; "nef", ".nefx", ".nef " not), at least 4 bytes, and the first four
     are `49 49 2A 00` or `4D 4D 00 2A`. Nothing else is looked at (an `IIRO` ORF or `IIU\0` RW2 head is rejected only because the four bytes differ).
  2. **Header.** `source.length() < 16` => `InvalidData`. Read bytes 0..16 (one 16-byte read), `try_read_header` on them: `None` (neither `II` nor `MM`) or `magic != 42` => `InvalidData`.
     `ifd0_offset` is a `u32` kept as such for `compute_exif_block` and widened to `i64` for the queue.
  3. **State.** `orientation = 1`, `previews: Vec`, `pending: VecDeque<i64>` seeded with `ifd0_offset`, `visited: HashSet<i64>` (membership only, never iterated), `maker_note_offset: Option<i64>`,
     `ifd_count = 0`, `ifd0_width/height`, `raw_area: i64 = 0`, `sensor_width/height`, `crop_width/height`, `exif_pixel_width/height` (all 0).
  4. **Loop** `while let Some(..) = pending.pop_front()` AND `ifd_count < MAX_IFD_COUNT` (the cap is tested BEFORE the pop: when it is reached, the rest of the queue is dropped unread). Per iteration:
     `cancel.check()` (=> `Canceled`); `ifd_offset <= 0` or already in `visited` => `continue` WITHOUT counting (a skipped pointer does not use up the 64); read the entries
     (`read_ifd_entries` => entries + `next_ifd_offset`); `is_ifd0 = ifd_count == 0` (the first IFD that was actually read, even if it turned out empty); `ifd_count += 1`;
     `(width, height) = read_image_size`; `sub_file_type = read_tag_value(0x00FE).unwrap_or(0) as u32` (TRUNCATING cast, C# `(uint)long`: 4294967294 => bit 0 clear => raw; 4294967295 => bit 0 set);
     `compression = read_tag_value(0x0103).unwrap_or(1)` (i64).
  5. **IFD0 only.** Orientation = `read_tag_value(0x0112)` if in 1..=8 (first 0x0112 entry only; an out-of-range first entry keeps 1 even if a later entry is valid; any integer field type works);
     remember `ifd0_width/height`. An orientation in a SubIFD or a chained IFD is ignored.
  6. **SubIFDs (0x014A).** Every value of `read_tag_unsigned_array(entry, max_items = 64)` is pushed to the BACK of `pending` NOW, i.e. before the next-IFD pointer of this IFD (step 11).
     Consequence (golden `queue-order-subifds-before-next-ifd`): SubIFDs of IFD n are read before the IFD that n chains to.
  7. **Exif IFD (0x8769).** If the entry exists and `read_tag_unsigned` gives `Some(o)` with `o > 0`: read that IFD's entries (next pointer ignored); for each entry with tag 0x927C and `count > 4`
     (any field type; `count`, not byte size) do `maker_note_offset.get_or_insert(value_or_offset as i64)` (FIRST one in the whole file wins, across IFDs; later notes are ignored even if the first is garbage).
     Then, if `exif_pixel_width == 0` and `try_read_exif_pixel_dimensions(o)` is `Some((w, h))`: store both (a width-only Exif IFD leaves 0, so a later complete one still counts).
     This runs for every read IFD (IFD0, SubIFDs, chained), so reads happen even for reduced previews.
  8. **Preview or raw?** `is_preview = false`.
     (a) `try_read_jpeg_interchange` (0x0201/0x0202 present, `is_range_in_file`, length >= 4 and SOI) => `(pw, ph) = (width, height)` (the IFD's declared size, 0 if none);
         `reconcile_jpeg_size(offset, length, &mut pw, &mut ph)` (only when both > 0: the JPEG's own SOF size wins if readable; non-I/O budget exhaustion keeps the declared size);
         `add_preview(offset, length, pw, ph)`; `is_preview = true`.
     (b) else if `compression == 6 || compression == 7` AND `try_read_single_strip` AND `try_read_lossy_frame(strip)` gives `Some((w, h))` => `add_preview(strip_offset, strip_length, w, h)` with the PROBED size
         (never the declared one); `is_preview = true`. The conditions are evaluated in this order and short-circuit (no strip read for compression 1 or 5; lossless SOF3, 12-bit, SOF9 and truncated data are not previews).
     (c) Raw candidate: `area = width as i64 * height as i64`; if `!is_preview && sub_file_type & 1 == 0 && area > raw_area` then `raw_area = area`, `sensor_* = width/height`, and
         `(crop_width, crop_height) = try_read_default_crop_size(entries).unwrap_or((0, 0))` (the crop is RESET to 0 when this raw IFD has none: it always belongs to the winning raw IFD).
         Strict `>`: equal areas keep the first; an IFD with a 0 dimension never wins.
  9. **Chain.** If `next_ifd_offset > 0` push it to the back of `pending` (after the SubIFDs of step 6). `read_ifd_entries` already returns 0 for a next pointer < 8 or > length - 6.
  10. **After the loop.** If `sensor_width == 0` use `ifd0_width/height` (so a file with only a reduced 160x120 IFD0 reports 160x120). If `maker_note_offset` is `Some(o)` with `o > 0`:
      `parse_nikon_maker_note_preview(o)` (step 12). Then `(sensor_width, sensor_height) = choose_active_sensor_size(sensor, crop, exif)`. Then, ONLY IF `crop_width == 0 && exif_pixel_width == 0`
      (testing the raw crop/Exif values, not whether `choose_active_sensor_size` accepted them: a crop or Exif size larger than the raw IFD is rejected by the chooser yet still blocks this step;
      goldens `crop-ignored-because-larger-than-raw-still-blocks-...`): `try_read_full_size_jpeg_frame(previews, sensor_width, sensor_height)` and, if it finds one, the sensor size becomes the frame size (step 13).
  11. **Result.** `RawContainerInfo { format: Nef, sensor_width, sensor_height, orientation, previews, exif_blocks: vec![compute_exif_block(source, little_endian, ifd0_offset as i64)] }`.
      Exactly one Exif block (offset 0, `is_tiff_header` true, `ifd_is_exif` false); `compute_exif_block` itself swallows a non-I/O `InvalidData`.
  12. **`parse_nikon_maker_note_preview(o)`.** Return `Ok(())` silently when `o < 8` or `o > length - 18`. Read 18 bytes at `o` (COPY them: the next read invalidates the slice). Require bytes 0..6 = `"Nikon\0"`
      (case-sensitive) and byte 6 == 2 (version; 0, 1, 3, 255 are ignored: type-1 notes have no embedded TIFF header). The embedded TIFF header is bytes 10..18; `try_read_header` must succeed with
      `magic == 42` (its byte order is the NOTE's, independent of the file's). `tiff_base = o + 10`. Read the note IFD at `tiff_base + ifd_offset` with the note's byte order; entry 0x0011 => `read_tag_unsigned` =
      `preview_ifd_offset` (else return); read the entries of the IFD at `tiff_base + preview_ifd_offset`; `read_tag_value(0x0201)` = start and `read_tag_value(0x0202)` = length (both required);
      `abs = tiff_base + start`. Require `is_range_in_file(abs, length, file_len)` AND the two bytes at `abs` == `FF D8`; then `add_preview(abs, length, 0, 0)` (size unknown, resolved later by the selector).
      Note: NO "length >= 4" rule here (unlike `try_read_jpeg_interchange`): a 2-byte `FFD8` range is listed, and a 1-byte range at the very last byte makes the 2-byte SOI read fail with `InvalidData`
      (propagated out of `read`; goldens `maker-note-preview-length-one-at-last-byte-throws-on-soi-probe`, `...-length-two-at-end-is-listed`). Dedup by offset happens in `add_preview`.
  13. **`try_read_full_size_jpeg_frame(previews, raw_w, raw_h)`.** `raw_w <= 0 || raw_h <= 0` => `None`. Candidates = the 4 previews with the largest `length` (STABLE sort by length descending, ties keep list order;
      `.iter().enumerate()` + `sort_by_key(Reverse)` on a copy, then `take(4)`). For each: `(w, h) = (preview.width, preview.height)`; if either is <= 0, read the frame with
      `preview_selector::try_read_jpeg_frame`: `Err` with `is_io_failure()` => propagate; any other `Err` (budget) => skip this preview; `Ok(None)` => skip; `Ok(Some(f))` => `(w, h) = (f.width, f.height)`
      (BOTH replaced, also when only one was missing; the declared half is discarded). `margin_x = raw_w - w`, `margin_y = raw_h - h`; skip unless `0 <= margin <= MAX_MASKED_MARGIN (256)` on both axes
      (so a frame LARGER than the raw IFD never matches, and 256 matches while 257 does not). `area = w as i64 * h as i64`; strict `>` best: the first examined wins an equal area. Result is the best (w, h) or `None`.
      A preview that already has declared sizes is NOT read (golden `jpg-from-raw-declared-sizes-used-without-reading-frames`).
  14. **`add_preview`.** If any listed preview has the same `offset` do nothing (even if length/size differ); else push `{ index: previews.len(), offset, length, kind: Jpeg, width, height,
      color_space: Unknown, header_resolved: false }`. Preview order = discovery order: IFD previews in queue order, then the MakerNote preview.
