# W6-05: Windows platform primitives

- Color: 🟢 | Small platform adapters | C# spec baseline: `d92d6aae`
- Rust crate: `pr-platform-win`
- C# sources: `PhotoReview.Platform.Windows/WindowsMemoryProbe.cs`, `WindowsNaturalComparer.cs`, `WindowsDarkTitleBar.cs`, `WindowsLiveOperationRegistry.cs`
- C# test twins: `PhotoReview.Integration.Tests/MemoryHeadroomTests.cs`, `PlatformPrimitivesTests.cs`, `WindowsNaturalComparerTests.cs`, `WindowsLiveOperationRegistryTests.cs`, `LibraryImportInteropTests.cs`

## Scope and behavior

1. `WindowsMemoryProbe` implements `pr_core::abstractions::MemoryProbe` using `GlobalMemoryStatusEx`. Report load percent and available physical bytes. If the API fails, log its Win32 error and return `None`; headroom evaluation remains the existing pure policy in `pr-imaging` and fails closed.
2. `WindowsNaturalComparer` implements `NaturalComparer` using `StrCmpLogicalW`; compare nulls as C# does and break native ties with ordinal-ignore-case comparison. Fall back to `ManagedNaturalComparer` when `shlwapi.dll` is missing or the entry point is missing; propagate other loader failures like C#.
3. `WindowsDarkTitleBar` accepts only a raw HWND. Try DWM dark-mode attributes 20 then 19, and caption COLORREF attribute 35. A zero HWND, unsupported HRESULT, missing DLL, or missing entry point returns false; propagate other loader failures like C#. Do not add WPF dependencies.
4. `WindowsLiveOperationRegistry` implements `LiveOperationRegistry` with a nonsignaled manual-reset named event. Name exactly `Local\\<prefix>_LiveOp_<UPPERCASE SHA256 HEX(UTF8("liveop|<current user SID>|<operation id>"))>`. `Begin` returns an RAII marker; every opened handle is closed. Preserve C# error behavior: empty id is a caller error; creation failures log and return a no-op marker; access denied while checking means live; IO/argument check failures log and return false.

## Verification

- Pure tests run by default: headroom boundaries through existing `pr-imaging` tests; null ordering and injectable comparer policy where practical; deterministic event-name digest tests without querying real user markers.
- Win32 smoke/integration tests are `#[ignore = "native: ..."]`, bounded, use unique event prefixes, and never touch the Recycle Bin or user files.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, and `cargo test --workspace --locked` are required on the final PR head.

## Parity constraints

- Do not change the `Local\\PhotoReview_LiveOp_...` identity when using the default prefix: old and Rust builds must observe the same live operation.
- Do not replace native natural sorting with the managed comparer except for the two documented missing-library cases.
- Do not add an intentional product behavior difference without an ADR and a `Different` parity row.
