## Semantics (C# is the spec)
1. **`RectD.Contains` and `RectD` (W8-01a code; this unit tests it)**: closed on all sides with the C# formula
   `p.x >= x && p.x - width <= x && p.y >= y && p.y - height <= y` (not `p.x <= x + width`, the rounding differs). A negative width or
   height contains no point. Tests: the hand-written edge and corner cases (origins -5, 0, 10.5; sizes 0, 0.5, 20; probes on the edges)
   with the expected answer written by hand. If a grid point disagrees with the closed-interval rule, check the C# formula first, not the test.
2. **`ReviewCommandType.IgnoresAutoRepeat`** is membership in the 14-element set of Semantics list in "New tests". Navigation, zoom, `Skip`,
   `ToggleFit`, `FitWidth`, `FitWidth2`, `FitHeight`, `ExitFullscreen` and `Close` keep repeating (false).
3. **`ReviewCommand` constructors**: C# positional record defaults are `ActionIndex = -1`, `ForcePicker = false`. `new(kind)` and every
   constant use `-1`. `action(i)` sets `action_index = i` (`force_picker` false). `move_to_folder(f)` and `copy_to_folder(f)` set
   `force_picker = f` (`action_index` stays -1). Record equality: all three fields.
4. **`FrameTick` equality**: C# `readonly record struct` equality uses `EqualityComparer<double>.Default` for `RenderingTimeMs` (`f64_same`: NaN equals
   NaN, `0.0` equals `-0.0`), `timestamp` and `timing` by value (`Option<DisplayTiming>` derives `PartialEq`).
5. **`IFrameClock`**: `Frame += h` is `subscribe`, returning an id; `Frame -= h` is `unsubscribe(id)`; `RequestFrame()` is `request_frame`. The
   trait is single-threaded (UI thread, no `Send`). The raising rule is the clock's (W8-13a). An unknown id to `unsubscribe` is a no-op (C#
   `-=` on a missing delegate is a no-op).
6. **`ViewportOperationVersion`**: `Current` starts at 0. `next_version` increments first and returns the new value (C# `++Current`), so the
   first call returns 1. The increment wraps (`wrapping_add`): C# `long` is unchecked by default. Single-threaded.
7. **`IImageSurface` mapping** (33 C# members to Rust):
   - `YieldToRenderAsync()` (`Task`) becomes `yield_to_render(continuation)` (D-W8-2). The continuation runs on the UI thread at Render priority,
     never inline inside the call. The caller (W8-05g/h) keeps its state behind `Rc<RefCell<..>>` or in the controller.
   - `RenderingTime(EventArgs e)` is not a trait member. The platform extracts it from the render event args and passes the value to the
     `RenderFrameHandler` as `Option<i64>` (TimeSpan ticks, 100 ns). `None` when the args have no frame time.
   - `HookRenderFrame(EventHandler)` / `UnhookRenderFrame(EventHandler)`: C# matches the delegate by reference. Rust returns a `RenderHookId` from hook
     and takes it in unhook. Unknown id is a no-op.
   - `DragThreshold`, `(double Horizontal, double Vertical)`: `(f64, f64)` in that order.
   - `SourceSize`, `(double Width, double Height)?`: `Option<SizeD>`.
   - `DisplayTiming` (a getter that starts the clock): `display_timing(&mut self)`.
   - `ScrollTo`: two calls, horizontal first, then vertical (the C# order matters for the scroll-changed events).
8. **`WheelMessageSource` decoding**:
   - `delta(w_param)`: `((w_param >> 16) & 0xFFFF) as u16 as i16 as i32`. The mask is required: with an `i64` arithmetic shift, a sign-extended
     `IntPtr` keeps high bits. Values: `(0xFFF4 << 16) | 8` gives -12; `120 << 16` gives 120.
   - `screen_point(l_param)`: `x = (l & 0xFFFF) as u16 as i16`, `y = ((l >> 16) & 0xFFFF) as u16 as i16`, both as `f64` in `PointD`.
     Monitors left of or above the primary give negative values.
   - `Current()` (Win32 `GetCurrentInputMessageSource`, returns `Touchpad` or `Unknown`, and `Unknown` on `EntryPointNotFoundException`) is
     **not here**. It needs `unsafe` (`pr-platform-win`, W8-14a). That unit returns a plain `bool` (touchpad or not) and maps it to
     `WheelDeviceHint`. This keeps `input::wheel_message` free of a dependency on `input::touchpad_gestures` (W8-05e owns `WheelDeviceHint`).
9. **No clock, no I/O, no logging, no `unsafe`, no `windows` crate** in any of the five files (AGENTS.md / WAVE-8-PLAN layering rule).

## Traps (checklist)
- `ReviewCommand::default()` does not exist on purpose: C# `default(ReviewCommand)` has `ActionIndex == 0`, the constructor has `-1`.
- `next` is not a valid method name here (clippy). Use `next_version`.
- `IntPtr` arithmetic: mask after shifting, or sign-extended `wParam` values give wrong deltas.
- Equality of `FrameTick` must treat NaN as equal (`f64_same`), not derived `PartialEq` on `f64`.
- The `ReviewCommandType` values are C# ordinals; any reorder breaks the 14-element test and the shortcut tables of W8-05c/d.
- Do not put `WheelDeviceHint` into `wheel_message.rs`: it lives in `touchpad_gestures.rs` (W8-05e).

## Open questions (each with the recommended default; lead decides, see D-W8 notes)
1. **Two extra modules** (`operation_version`, `wheel_message`) are not in the plan's row target list (`primitives, frame_clock, surface,
   review_command`). Recommended: accept them. The alternative (fold them into `frame_clock`/`surface`) is worse: `frame_clock` is then a
   grab bag, and `wheel_message` would sit beside `FrameClock` for no reason.
2. **`WheelDeviceHint` mapping** happens in W8-14a (platform), not here. Recommended: as written. The plan could instead move `WheelDeviceHint` to
   05a, but it is a 13-line enum that belongs with the touchpad gesture logic (05e).
3. **`FrameClock` takes `&mut self`** for `subscribe`/`unsubscribe`/`request_frame`. W8-13a may need interior mutability (`RefCell`) if two
   owners hold the clock. Recommended: keep `&mut self` here; 13a decides and the trait changes then.
4. **`yield_to_render(continuation: Box<dyn FnOnce()>)`**: the shape the B2 coordinators (05g/05h) rely on. The continuation may need to
   reach the controller, so 05g/05h must decide how state is shared (`Rc<RefCell<..>>`). Recommended: keep the boxed continuation; 05g decides.
5. **`RenderFrameHandler` argument** is `Option<i64>` (TimeSpan ticks), not `Option<Duration>`: `Duration` is unsigned and C# `TimeSpan` can be
   negative. Recommended: as written.
6. **No `Default` for `ReviewCommand`** (Semantics 3 / Traps). If a caller needs C# `default(ReviewCommand)`, it can build it explicitly
   (`kind: Fullscreen, action_index: 0, force_picker: false`). Recommended: no `Default` impl.
7. **PARITY id `X-input-core`** instead of `C-05`/`C-06` (the plan's ids are taken by other rows). Recommended: as written; lead confirms.
