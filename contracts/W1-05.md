## Semantics notes

* Values (C# type): `ImageCacheCapacityBytes` 16 GiB = 17179869184 (`long`), `ImageCacheRamPercent` 50, `MaxImageCacheRamPercent` 90, `MinImageCacheRamPercent` 1,
  `MemoryReserveBytes` 2 GiB = 2147483648 (`long`), `PreloadWorkerCount` 8, `MaxPreloadWorkerCount` 64, `PreloadMemoryLoadLimit` 0.90 (`double`),
  `PreviewDiskCacheCapacityBytes` 4 GiB = 4294967296 (`long`), `UseSourceBytesCache` false, `SourceBytesCapacityBytes` 16 GiB (`long`), `PreloadForwardCount` 32,
  `PreloadBackwardCount` 8, `MinPreloadForwardCount` 1, `MinPreloadBackwardCount` 0, `MaxPreloadCount` 500.
* These are plain data. Unlike the other units there is nothing to port besides the tests; the golden exists because a mistyped constant (a wrong power of two) is
  invisible to the compiler and only shows up as a wrong memory budget.
* Do not add helper functions (clamping, RAM budget): those are `SettingsNormalizer` and `RamBudgetPolicy`, other units.
