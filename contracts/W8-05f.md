## Semantics (C# is the spec; line numbers are C# lines)
1. **Velocity (16-69).** `add(time, x, y)` writes at `next`, advances `next` mod 32; `count` saturates at 32. `velocity()`: fewer than two
   samples gives `(0, 0)`. `newest` is the last written sample. Walk back `i = 1..count` and keep going while `newest_time - time[index] <= 80`
   (an age of exactly 80 is inside). `span = newest_time - time[oldest]`. `oldest == newest` or `span < 8` gives `(0, 0)` (a span of exactly 8
   measures). Result `((x[newest] - x[oldest]) / span, (y[newest] - y[oldest]) / span)`.
2. **Scroll bounds (73-77).** `max_horizontal = Math.Max(0, extent_width - viewport_width)` with .NET NaN rules (trap 1).
3. **Start (133-146).** `vx = clamp(-finite(px) * 0.65, -8, 8)`, same for y. If `sqrt(vx*vx + vy*vy) < 0.1`, call `stop()` and return false, so a
   glide in progress is ended by a slow release. Otherwise store, active, true. The sign flip is intentional (the view moves against the drag).
4. **Stop (148-153).** Velocities `+0.0`, inactive.
5. **AddImpulse (162-167).** Each axis: `clamp(v + finite(s), -8, 8)`. Active becomes true even for `(0, 0)`. NOT damped: the Q-R40 factor is
   only in `start`.
6. **Step (173-188).** Inactive: return the inputs unchanged. `dt = clamp(finite(elapsed), 0, 100)` (negative and NaN become 0).
   `decay = exp(-dt / 325)`, `travel = 325 * (1 - decay)`. `horizontal = advance(h, vx, travel, max_h)` and `vertical` likewise, both from the
   PRE-step velocities. Then `vx = hit_x ? 0 : vx * decay` (X first, then Y). `|vx| < 0.02` gives `+0`; same for y. Both zero gives inactive.
   **Advance (190-197):** `target = finite(offset) + velocity * travel`; `clamped = clamp(target, 0, max)`; `hit = velocity != 0 && clamped != target`.
7. **KeyboardPan.StepPixels (224-225).** `Math.Min(viewport_width, viewport_height) * fraction` (NaN propagates, trap 1).
8. **KeyboardPan.Step (227-239).** `max = dx != 0 ? max_h : max_v`. `max <= 0.5` gives `NotScrollable` (NaN is false, so NaN continues).
   `current = dx != 0 ? h : v`. `step = StepPixels(vw, vh, fraction) * (dx + dy)`, where `dx + dy` is an `int` (wrapping, trap 4).
   `target = clamp(current + step, 0, max)`. `|target - current| < 0.5` gives `AtEdge` with the inputs returned. Otherwise `Panned`, writing the
   target to the axis picked by `dx != 0` (horizontal), else vertical. The other axis keeps its input.
9. **IsZoomed (242).** `max_h > 0.5 || max_v > 0.5`.
10. **ImpulseVelocity (254-262).** Per axis: `step == 0` gives `+0` (also for `-0.0`); else `copysign(|step| / 325 + 0.02, step)`.
11. **ConsumesKey (270-275).** `Panned` gives true. Default (`navigates_at_edge == false`): true iff `IsZoomed(bounds)`. With `navigates_at_edge`:
    `result == AtEdge && is_repeat`.
12. **GlideFrameClock.Start (312-318).** Mode becomes the given mode if `ticks_per_ms > 0`, else `Off` (NaN gives Off). Resets only `started`
    and `anchored`. `last_rendering_ms`, `last_index`, `anchor_vblank`, `anchor_period` keep their values (C# does not reset them).
13. **GlideFrameClock.Advance (324-361).** `e = rendering - last_rendering`. First call (not started): mark started, `last_rendering = rendering`,
    anchor if mode != Off and timing has `refresh_period > 0`, return 0.
    If mode != Off and timing has `refresh_period > 0`: when anchored and `|period - anchor_period| <= 0.02 * anchor_period`, compute
    `index = round_ties_even((next_vblank(now) - anchor_vblank) / period)`. If `e > 0`, set `last_rendering = rendering`. If
    `index <= last_index`, return 0. Else `advanced = (index - last_index) * period / ticks_per_ms`, `last_index = index`, return advanced.
    Otherwise (not anchored, or period changed) anchor, then fall through to the rendering branch.
    Else if mode != Off (timing lost): `anchored = false`.
    Then: if `e` is NaN or `<= 0`, return 0; else `last_rendering = rendering`, return `e`.
14. **Anchor / NextVBlank (363-376).** `anchor`: anchored, `anchor_vblank = next_vblank(now)`, `anchor_period = period`, `last_index = 0`.
    `next_vblank`: `target = now + (long)(1.0 * ticks_per_ms)` (wrapping add, truncating cast). `periods = ceil((target - last_vblank) / period)`,
    where the subtraction is wrapping `i64` and then converted to `f64`. Result `last_vblank + (long)(max(0, periods) * period)`.

## Traps (write these into the tests; each one is a mutant the verifier will try)
1. **.NET NaN and clamp rules (D-W8-5f-2).** `Math.Max(0, NaN)` is NaN (`f64::max` gives 0). `Math.Clamp` with a NaN bound never panics
   (`f64::clamp` does). Tests: a NaN extent gives NaN `max_horizontal`; `keyboard_pan_step` with a NaN scroll range does not panic and pans.
2. **Ties-to-even (D-W8-5f-3).** `Math.Round(double)` in `advance` and in the test helpers `Period`/`At` is banker's rounding: use
   `f64::round_ties_even`, not `round()`. A test with an exact half-refresh index must fail under `round()`.
3. **Negative zero.** `start(-0.0, ...)` and `ImpulseVelocity` of `-0.0` give `+0`. `stop` gives `+0`. Golden outputs carry `-0` as the string
   `"-0"`, so the golden comparator checks `to_bits()`, not `==`. Mutant: normalise with `abs` or `+ 0.0`.
4. **Integer arithmetic.** Tick math is C# `long`: `wrapping_add` / `wrapping_sub` (no debug panic), `as i64` for the `(long)` casts.
   `dx + dy` is `i32` with `wrapping_add`.
5. **Clippy: `!(e > 0)`.** Write `e.is_nan() || e <= 0.0` (clippy `neg_cmp_op_on_partial_ord` fires on the literal form). Mutant: `e <= 0.0`
   alone lets NaN through.
6. **`start` below the threshold stops the glide** (C# calls `Stop()`), it does not just return false. Test: a slow release while active
   gives inactive with `+0` velocity.
7. **Edge test uses the target before clamping, and the other axis keeps going.** Test: `reaching_an_edge_stops_that_axis_only`.
8. **`start` does not reset the glide-clock grid** (`restart keeps...` golden, and `Predict_TimingLostThenRecovered...`).
9. **Axis choice follows `dx != 0`**, not the larger component: `keyboard_pan_step(1, 1, ...)` moves horizontally by `2 * pixels`.
10. **`ConsumesKey` default is zoom-based, not result-based**: `AtEdge` at zoom is consumed. Mutant: `result == Panned` only.
11. **Ring buffer order.** Newest is `(next + 31) % 32`; `oldest` is found by walking back and stopping at the first sample older than 80 ms.
    Mutant: take `time[0]` as the oldest.
12. **`ScrollBounds` equality with NaN.** `PartialEq` on NaN fields is false (C# record equality says true). No test compares a
    `ScrollBounds` containing NaN with `==`.
13. **Repeated rendering time.** `e == 0` gives 0 and does not move `last_rendering`. Mutant: step by 0 and move the anchor.
14. **Exp.** `f64::exp` and .NET `Math.Exp` both call the UCRT on Windows; the golden compares bit-exact. A one-ulp difference is written as
    a `// DIVERGENCE:` comment with the value, not hidden by a tolerance (O3).
