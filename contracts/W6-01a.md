## Scope and behavior

Port the shell32 declarations, GUID/constants, typed `IShellWindows` access, and the owned COM wrapper types. Match the baseline's reference-transfer rules: `ShellWindowsSource` owns and releases its `IShellWindows` pointer once; each yielded `ShellWebBrowser` owns the `IDispatch` reference; `LocationUrl` temporarily acquires `IWebBrowserApp`, frees its BSTR, and releases the queried interface; `AcquireUnknown` adds exactly one reference for the caller. `Windows` is lazy, checks disposal, calls `get_Count` then `Item`, skips a null dispatch pointer, and propagates HRESULT failures through `ShellCom.Check`.

Use the explicit SDK vtable slot indices and ABI layouts from the baseline. Keep this layer independent of query policy and service scheduling. Do not use reflection, `dynamic`, `Marshal.GetDelegateForFunctionPointer`, or a managed Shell.Application automation object. Every unsafe block needs a `// SAFETY:` explanation.

## Dependencies and file ownership

- Depends on W0-02 `ShellCom` (CoCreateInstance/HRESULT handling) and W6-01d's typed view consumer; W6-01d depends on this unit. `ExplorerOrderProvider`, snapshot types, and reason codes are already in `pr-core`.
- Own only the COM interop module and its unit/integration test file. Do not edit crate root/module exports or shared test fixtures without lead coordination.

## Tests and safeguards

- Port all eight named `ShellWindows_*`/`ShellWindow_*` tests above and the relevant fake-vtable cases in `ExplorerNativeViewTests`: `Window_WithoutIServiceProvider_IsNativeViewUnavailable`, `Window_BrowserServiceFails_ReportsQueryService`, `Window_AsksTheTopLevelBrowserServiceForIShellBrowser`, `Window_ActiveShellViewFails_ReportsIt`, `Window_ViewWithoutIFolderView2_ReportsIt`, and the interface/reference assertions exercised by those cases. If the Rust split relocates a baseline case to W6-01d, keep the test ownership there and avoid duplicate tests.
- Keep ABI tests deterministic and fake-backed. Any real Windows smoke test must be `#[ignore = "native: ..."]`; it must not close windows, modify user shell state, or use a user's folders as writable fixtures.
- Hang guard: no unbounded COM calls in default tests. A native smoke test must have an external CI timeout and a bounded caller timeout; do not add fixed-delay polling.
- Mutation expectations: time-box `cargo-mutants` to this unit. Mutations to slot numbers, GUIDs, HRESULT checks, AddRef/Release, BSTR freeing, and disposed-pointer guards must be killed by focused tests; document any surviving ABI-specific mutant with why the fake harness cannot distinguish it.
