## Semantics

1. The icon does **not** exist in `assets/` at HEAD (`assets/SYNC-MANIFEST.txt` lists languages only). W8-20a's `build.rs` says to sync C# `src/PhotoReview.App/Assets/PhotoReview.ico` to `assets/PhotoReviewRs.ico`; until then emit its documented warning, but R1 must fail the resource gate. `crates/pr-platform-win/src/win32/shell.manifest` exists and is the single manifest source. Keep `RT_MANIFEST` id 1, `RT_GROUP_ICON` id 32512 and icon images per `crates/pr-shell/build_support/res_writer.rs`.
2. Workflow sets `PHOTOREVIEW_RS_VERSION` from a validated `vX.Y.Z` tag without `v`; local fallback is `0.0.0-dev`. Release mode rejects fallback. Do not use workspace package version (`Cargo.toml` is `0.1.0`). Numeric `VS_FIXEDFILEINFO` is `(X,Y,Z,0)`, each component checked `<=65535`. `dwSignature=0xFEEF04BD`, `dwStrucVersion=0x00010000`, file/product MS = `(X<<16)|Y`, LS = `(Z<<16)|0`, `dwFileType=VFT_APP`; fixed flags mask and OS values require implementation validation against Windows SDK headers.
3. `VS_VERSIONINFO` is little endian and 4-byte aligned: `wLength`, `wValueLength`, `wType`, UTF-16 NUL key, padding, `VS_FIXEDFILEINFO`, child `StringFileInfo` / `StringTable` / `String`, then `VarFileInfo` / `Translation`. Proposed language/codepage is `040904B0` (en-US/UTF-16). Strings: `CompanyName`, `FileDescription`, `ProductName`, `ProductVersion`, `FileVersion`, `OriginalFilename=PhotoReviewRs.exe`, `LegalCopyright`. Pick project-owned literal values only after reviewing the actual copyright/license text; no invented copyright year. `ProductVersion` and `FileVersion` equal `X.Y.Z`. `RT_VERSION` id 1 is emitted only for a release version if D-W10release-3 accepts the changed policy.
4. Extend the pure `.res` writer test to assert resource boundaries, alignment and exact UTF-16 strings. `exe_resources` must enumerate id 16, parse fixed and string values and assert the tag, original filename, manifest and icon on the linked exe. The Properties dialog/SmartScreen display is a manual Windows check, not implied by the parser.

## Traps and open questions

- P-47 and D-W8B6-53 (`contracts/README.md`) chose no version resource as the safe W8 default. Recommend adding it **only when R1 ships**, with an ADR and updated `X-exe-versioninfo`; keeping the default would leave Windows Properties without a product version.
- Exact `VS_VERSIONINFO` length conventions, `VS_FIXEDFILEINFO` flags/OS values and SmartScreen treatment are **not verified** from SDK docs in this task; verify against `winver.h` and a PE resource reader before implementation. No optional stub is written, so `cargo check` behavior is unchanged.
