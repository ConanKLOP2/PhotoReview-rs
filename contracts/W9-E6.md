Downstream: W9-E9 (the controller parses the same ids).

## Traps
- The editor entry kind is `Toggle` (checked = default), not `Command`; the submenu root is enabled even without an image; only the editor rows follow `has_image`.
- The default is `effective_default` (an unknown stored id = the FIRST editor), and only that row carries `settings.shortcuts.open_in_default_editor`, only when non-blank.
- Editor ids are used verbatim in the command id (`ExternalEditor.Open.<id>`): ids can contain dots; the controller strips the prefix, never splits.
- Do not sort; the submenu follows the declaration order; an editor removed from the list changes no other id.
