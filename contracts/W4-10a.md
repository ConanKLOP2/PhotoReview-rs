## Semantics notes
1. **Constructor.** `capacity = ram_budget::clamp_source_bytes_to_physical_memory(capacity_bytes, physical_memory_bytes)`
   (C#: `min(min(req, (long)(phys*0.5)), (long)(phys*0.2))`, `phys <= 0` => `req`), stored as `capacity_bytes`, then
   `BoundedLruCache::new(capacity, |b| b.len() as i64)`; its `InvalidCapacity` becomes `ArgumentOutOfRange { param_name: "capacity" }`.
   `source_reader: None` => `Arc::new(PhysicalSourceReader)`.
2. **Keys.** Whole file (`create_key`): `full = get_full_path(path)` (`PathError::Argument` => `Argument { "path" }`, `TooLong` =>
   `Io(io::Error::from_raw_os_error(206))`, ERROR_FILENAME_EXCED_RANGE, the same mapping as W2-14 `physical::path_error`), then `PhysicalFileSystem.get_file_stat(full)` (exactly `new FileInfo(full)`: no link
   following, a directory or missing file is `None`) => `None` is `Io(NotFound, "Could not find file '{full}'.")`; key
   `(full, len, last_write_utc.ticks(), 0, len)` (`len` as `i64`, saturating). Range (`create_range_key`): `full` + the caller's
   numbers, no file access. Equality is ORDINAL on the path (trap 1).
3. **`get_or_read_range` order (golden `argument-check-order`).** (a) `path` empty or all `char::is_whitespace` => `Argument { "path" }`
   (`ThrowIfNullOrWhiteSpace`; Rust `char::is_whitespace` is the Unicode White_Space set, the same characters as .NET
   `char.IsWhiteSpace`). Only `get_or_read_range` has this check: `get_full_path` alone rejects only empty / U+0020-only / NUL, so
   `get_or_read("\t")` is a `NotFound` stat failure and `evict("\t")` / `try_get_range("\t", ..)` succeed; (b) `length < 0` => `ArgumentOutOfRange { "length" }`; (c) `offset < 0 || count < 0 || offset > length ||
   count > length - offset` => `{ "offset" }` (one param name for all four; `length - offset` cannot overflow after the first checks);
   (d) `count > ARRAY_MAX_LENGTH` => `{ "count" }`; (e) build the range key (may fail on a NUL path even with count 0); (f) `count == 0`
   => `Ok(empty)` without opening; (g) `!can_cache_range(count)` => `read_and_cache(key, 0, 0, priority, publish = false)` directly:
   no in-flight entry, no dedup, no publish, `BeforePublish` never runs; (h) otherwise `get_or_read_key`.
4. **`get_or_read_key`.** `key.count > ARRAY_MAX_LENGTH` => `ArgumentOutOfRange { "key" }` (a > 2 GB whole file); cache hit => return
   it (refreshes LRU recency); else run `AfterCacheMiss`, read `generation` and `path_version` (`path_versions[ignore_case_key(path)]`,
   default 0) WITHOUT the gate, then get-or-insert the in-flight entry under the `in_flight` mutex (a new entry stores THIS caller's
   generation / version / priority), release the mutex, and `entry.result.get_or_init(|| cache.try_get(key) or read_and_cache(key,
   entry.generation, entry.path_version, entry.priority, true))`. Always (also on error or panic: a drop guard) remove the map entry
   ONLY if it is still the same `Arc` (`Arc::ptr_eq`, C# `TryRemove(KeyValuePair)`). Return the stored result (clone: `Arc` bytes or
   the shared error). Joiners block in `get_or_init` (std `OnceLock` blocks concurrent initializers: C# `ExecutionAndPublication`).
5. **`read_and_cache`.** (1) record `thread::current().id()`; (2) `reader.open_source(Path::new(&key.path), priority,
   SOURCE_READ_BUFFER_SIZE)?`; (3) `stream.seek(End(0))` != `source_length` => localized `io::ErrorKind::Other`, English
   `"File changed while reading: {path}"`, text `tr::err_io_file_changed_while_reading(path)`; (4) allocate `count` bytes (trap 6);
   (5) `seek(Start(offset))`; (6) read loop until full: `Ok(0)` => localized `UnexpectedEof`, English `"Unexpected EOF while reading
   {path}"`, text `tr::err_io_unexpected_eof(path)`; `Interrupted` => retry; other errors propagate; (7) `AfterRead` hook; (8) re-stat
   `full` (missing => `NotFound`); length or ticks differ from the key => the localized "file changed" error again; (9) `publish ==
   false` => return; (10) under `publish_gate`: if `generation == self.generation` and `path_version == path_versions[key]` then
   `BeforePublish` hook, `cache.set(key, bytes)`; (11) return the bytes even when not published. The stream lives until the end of the
   function (C# `using var`).
6. **`try_get_range`.** `offset < 0 || count <= 0 || offset > length || count > length - offset` => `Ok(None)` (no key, no throw);
   else build the key (may `Err` on a bad path) and `cache.try_get` (refreshes recency; golden `try-get-range-hit-refreshes-lru`).
7. **`try_prefetch`.** `create_key` (errors propagate); `!can_cache(key.source_length)` => `Ok(false)` with nothing opened; else
   `get_or_read_key(key, Preload)?` and `Ok(true)` (also when the bytes were already cached).
8. **`clear`.** Under the gate: `path_versions.clear()`, then `generation.fetch_add(1)` (wraps like `Interlocked.Increment`), then
   `cache.clear()`. Order matters (RV-I16): versions cleared BEFORE the bump.
9. **`evict`.** `full = get_full_path(path)?` (no trimming, no stat); under the gate: if `path_versions.len() >= 4096` and `full` is not
   tracked => `path_versions.clear()` + generation bump and `full` is NOT inserted; else version `+1` (insert 1; wrapping);
   then `cache.remove_where(|k| eq_ignore_case(&k.path, &full))`. In-flight entries are left alone (their read finishes, returns
   bytes, does not publish).
10. **Sizes.** `current_size` counts `max(1, len)` per entry (a zero-byte file costs 1: golden `zero-byte-file-...`). A whole-file key and
    the range `(0, len)` with the same ticks are the SAME key (golden `whole-file-key-equals-the-full-range-key`).
11. **Policy.** `SourceBytesCachePolicy::new(cache)` stores it; `cache()` returns it. No other behaviour.
12. **`SourceBytesError` text (Rust-only, never compared with C#).** `Display`: `Io(e)` is transparent (`e`'s own `Display`, i.e. the
    English .NET message such as `"File changed while reading: {path}"`); `Argument { p }` => `"Invalid argument. (Parameter '{p}')"`;
    `ArgumentOutOfRange { p }` => `"Specified argument was out of the range of valid values. (Parameter '{p}')"`. `source()`: `Io(e)` =>
    `e.source()` (transparent, so an error-chain printer does not print the message twice); the argument variants => `None`.
    `io_kind()`: `Io(e)` => `Some(e.kind())`, else `None`. Localization lives on the inner `io::Error` (match the variant, trap 7).

## Traps checklist
§7 items 1 (OrdinalIgnoreCase for versions and evict only), 3 (`i64`/`i32` limits, wrapping counters), 5 (ticks), 7 (`GetFullPath`),
8 (`Ok(None)` vs error), 9 (each C# exception type is its own variant / io kind). INV-2 (clear/evict invalidate in-flight work),
INV-8 (shared sequential open through `SourceReader`, never `File::open`). Specific traps:
1. **Key equality is ordinal, invalidation is ignore-case.** Do NOT key `RangeKey` with `path_key`: `Case.bin` then `CASE.BIN` are two
   entries and two disk reads (golden `keys-are-ordinal-but-evict-is-ignore-case`, `try-get-range-misses-without-reading` last step);
   `evict("case.bin")` removes both.
2. **The in-flight entry's captured values belong to its creator** (C# closure), not to the waiter that runs the initializer; store them in
   the entry. Using the waiter's own snapshot lets an evict that happened between creation and init slip through.
3. **Double-check inside the initializer** (`cache.try_get` before reading): a late caller that missed the cache before the winner
   published must share the winner's `Arc` (test `LateReaderAfterPublish...`: one open).
4. **Never hold a std `Mutex` while calling a hook or the reader** except the publish gate around `BeforePublish` (as C#). Clone the
   `Option<TestHook>` out of its mutex, drop the guard, then call it: hooks call `evict`, `clear` and the `set_*_for_tests` setters.
   Lock order is `publish_gate -> path_versions -> LRU`; `in_flight` is never held with any other lock. `remove_where`'s predicate must
   not call back into the cache.
5. **Hooks capturing the cache** create an `Arc` cycle; tests reset the hook (`None`) or capture a `Weak`.
6. **Allocation without a copy and without `unsafe`.** Build `let mut buf: Arc<[u8]> = std::iter::repeat_n(0u8, n).collect();` (one
   allocation for a `TrustedLen` iterator) and fill it through `Arc::get_mut` (always unique here; handle `None` with an error, no
   `unwrap`). Do NOT read into a `Vec` and `Arc::from(vec)` (a second full copy of every RAW file). Do the length check BEFORE allocating
   (test `CountAtArrayMaxLength`: a 2 GB range must fail on the length check, not allocate).
7. **Errors are shared, not recreated.** A failed shared read returns the same `Arc<io::Error>` to every waiter; `is_localized`/`describe`
   take `&*arc`. Do not cache failures: the in-flight entry is removed after the attempt, the LRU never sees them.
8. **`count == 0`** returns an empty array AFTER key creation; the C# `[]` is a shared singleton, so the golden omits `same_as` for empty
   results (any empty `Arc` is fine).
9. **`can_cache(negative)` is `true`** (C# has no lower bound there); `can_cache_range(-1)` is `false`.
10. **`Read::read_exact` is not allowed** for the loop: its EOF error has the wrong message and is not localized.
11. **C# `Debug.Assert(SynchronizationContext.Current is null)`** has no Rust twin (no UI-thread marker in pr-core); keep the doc warning.
12. **MSRV.** The workspace `rust-version` is 1.85 and clippy's `incompatible_msrv` is on: no std API newer than 1.85
    (e.g. `io::ErrorKind::InvalidFilename` is 1.87; `iter::repeat_n` 1.82 and `File::set_modified` 1.75 are fine).
13. **Path conversion.** `get_full_path` takes `&str`: use `path.to_string_lossy()` (same lossy rule as `pr_core::text::path_key`).

- Expected values worked out by hand (the oracle run is the authority): `argument-check-order` => `path`, `length`, `offset`,

## Open questions
1. **pr-imaging -> pr-l10n dependency.** C# localizes the two read errors inside the cache. Recommended (used by this contract): add
   `pr-l10n` to pr-imaging (`pr-l10n` depends only on `pr-core`, no cycle). Alternative: return plain `io::Error`s and localize in
   each consumer (W4-14 etc.), which duplicates the mapping and breaks the golden's `localized` field. The W4 drafts disagree:
   W4-01a says "this crate does NOT depend on pr-l10n" (caller localizes), W4-12c avoids the dependency with an injected
   `UserText = Arc<dyn Fn() -> String + Send + Sync>` closure. A cache cannot defer to its caller here (the error is created deep
   inside a shared read and replayed to every waiter), so the injected-closure variant would need a `Texts` seam passed to `new`.
   The lead states the crate-level rule once for all W4 units.
2. **Physical memory as a parameter** (`new(capacity, physical_memory_bytes, reader)`) instead of C# calling
   `RamBudgetPolicy.GetPhysicalMemoryBytes()` itself. Recommended: keep (tests become machine-independent; the composition root
   passes `ram_budget::get_physical_memory_bytes(&source)`). Alternative: take `&dyn PhysicalMemorySource` (W4-07a trait).
3. **Test seams as `pub` + `#[doc(hidden)]`** (like `session::writer::set_after_drain_for_tests`) vs. a `test-seams` cargo feature.
   Recommended: `pub` + `doc(hidden)` (integration tests in `crates/pr-imaging/tests` need them; zero cost when `None`).
4. **Zeroed vs uninitialized buffer.** C# uses `GC.AllocateUninitializedArray`; safe Rust zeroes (about 1 ms per 100 MB). Recommended:
   accept; an `unsafe` uninitialized buffer is not allowed outside `pr-platform-win`. Revisit only if W7 benchmarks show it.
5. **Temp-file tests are not `#[ignore]`d** (fast, self-cleaning `TempRoot`, like `pr_core::abstractions::source_reader`'s own test).
   Only the exclusive-lock prefetch test is `#[cfg(windows)]`. Lead confirms.
6. **Allocation failure.** C# `GC.AllocateUninitializedArray` throws a catchable `OutOfMemoryException` (consumers fall back);
   Rust's `collect::<Arc<[u8]>>()` aborts the process on allocation failure. Cached reads are bounded by the capacity (<= 20 % of
   RAM), but the uncacheable-range bypass (`count > capacity`, up to 2 GB) is not. Recommended: accept for W4 (no stable fallible
   `Arc<[u8]>` allocation; `Vec::try_reserve_exact` + `Arc::from` would cost the second copy trap 6 forbids) and record it as a
   known divergence in PARITY I-10; revisit with W4-07b `MemoryHeadroom` admission if the bypass is ever used for multi-GB ranges.
7. **`SourceBytesError` and `io::Error` consumers.** C# consumers catch `IOException` around `GetOrRead`. No `From<SourceBytesError> for
   io::Error` is provided (the shared `Arc<io::Error>` cannot be unwrapped without losing the localized payload or cloning it).
   Consumers (W4-14, W4-10b, W5) match the enum. Lead confirms or asks for a conversion that rebuilds the error with
   `pr_l10n::template::localize_io`.
