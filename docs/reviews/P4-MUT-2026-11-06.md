## Follow-up 2026-11-10 (task 3B part 1, branch fix/p395-viewer-state): viewer_state.rs 323:35, 711:24, 715:35 removed by refactor

Owner decision 3B: remove the redundant guards instead of proving them. Production change in `crates/pr-app/src/viewmodels/viewer_state.rs` only:

* `fit_zoom`: `if fit.is_finite() && fit > 0.0 { fit } else { 0.0 }` is now `if fit.is_finite() { fit } else { 0.0 }`. Past the two `usable` guards both limits are finite and `> 1.0`, both sources are `> 0` and the DPI is normalised into `{1.0} u [0.25, 16.0]`, so `fit` is a positive normal number or `+inf` (overflow); never NaN, `+-0` or negative.
* `fit_axis_zoom`: the guard `source <= 0 || !limit.is_finite() || limit <= 1.0` and the result guard are replaced by `u32::try_from(source)` (a negative source, private-domain only, still gives `0.0`), `if limit > 1.0` (NaN and `-inf` fail it; `+inf` yields `+inf` below) and `if fit.is_finite()`. Source 0 yields `+inf`, so `0.0`.

Equivalence, class reasoning: the result is `0.0` unless the quotient is finite; for every finite quotient the old guard's extra `fit > 0.0` was true (see the domain above), and a NaN or infinite quotient was `0.0` before and after. `-0.0` limit/DPI/limits: `-0.0 > 1.0` is false so `0.0`, as before; a `-0.0` or NaN `fit` cannot arise. The two sites are therefore identical for every input.

Executed proof: new test `fit_zoom_and_fit_axis_zoom_are_bit_identical_to_the_pre_refactor_guards_over_ieee_special_values` in `crates/pr-app/tests/mut3_viewer_state_whole_domain.rs` runs verbatim copies of the OLD functions against the real new ones, comparing `to_bits()` of `fit_width_zoom`, `fit_height_zoom` and `fit_zoom` over every limit exponent with edge mantissas, NaN (with payloads), `+-inf`, `+-0`, subnormals, `f64::MAX` and negatives, sources `i32::MIN..=i32::MAX` edges, and 24 DPI classes (more than 100,000 states, including mixed axes). The existing golden tests (`viewer_state_golden`) and the rest of `cargo test -p pr-app --locked` pass unchanged.

Mutation (own target dir, `tools/dev/mutants.sh pr-app ... -F fit_zoom -F fit_axis_zoom`, preflight 80 tests executed): tested 31 / total 31, caught 31, missed 0, unviable 0, timeouts 0. The mutants at the old sites no longer exist (the `fit > 0.0` comparison and the `source <= 0 ||` operand are gone); the remaining `> 1.0` mutants (719:18 in `fit_axis_zoom`) are caught. An earlier run on the shared default target dir reported false MISSED results (build 33 s + test 0 s) and was discarded; only the run with a private `TEMP` is evidence.
