# P2: native decoders, bench and WinHTTP transport, open survivors of N4 under OWNER RULE B (strict reading)

Rule B as applied here (P-391, closed 2026-11-05): a mutant is closed only if it was caught, unviable, or proven equivalent BY A RUN over the WHOLE domain in which mutant and original differ, or over every input class. A sampled or random differential, a bounded sequence length or a reading of the code closes nothing and is reported `run-supported, open`. A timeout is never a catch.

Vocabulary of the fate column:

* KILLED: a test fails under the mutant (named). The test passes on the original.
* PROVEN-E: the test passes under the mutant and enumerates the divergent domain value by value (or settles it by an arithmetic fact that the test itself executes).
* PROVEN-C: the test passes under the mutant and enumerates the divergent STATE class by class (every value of every local the differing evaluation and its continuation read). The one step that is not a run is that the continuation reads nothing else; the owner may reject that step, then these rows count as run-supported. They are listed separately in the totals for that reason.
* RUN-SUPPORTED, open: the test passes under the mutant on a bounded part of the domain; open under rule B.
* OPEN: nothing but reading, or not runnable here.
