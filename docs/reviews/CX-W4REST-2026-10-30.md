## Method

Read AGENTS mutation rules 126-140, LESSONS 1-74, the latest CX-MUTW4,
CX-IMAGING2 and CX-IMAGING3 reports and the six authoritative Wave 4 PARITY
rows before choosing new selections. Prior selections remain separate evidence.
Normal target is `target`; mutation target is `target-mut`; outputs are
`mut-out-w4rest-GROUP/mutants.out`. A single cargo-mutants process runs at a
time, with `--baseline skip --timeout 90 -j 1`, function regex chunks and an
outer 1200-second guard. No normal cargo test runs in target-mut.
Builds use `CARGO_INCREMENTAL=0`, `CARGO_PROFILE_DEV_DEBUG=line-tables-only`
and two build jobs. Per-run RUSTFLAGS markers rebuild the copied golden helper.
Runtime configuration uses `PHOTOREVIEW_RS_ISOLATE_CONFIG=1` and
`PHOTOREVIEW_RS_DATA_ROOT=<worktree>/target/w4rest-data`.
No real Recycle Bin, C# app data or user configuration is accessed.

Native DLLs were staged with `powershell -NoProfile -ExecutionPolicy Bypass
-File tools/dev/stage-native.ps1`; LibRaw and TurboJPEG hashes match C#
`7eaee2a2`. Command-local safe.directory entries cover this worktree and the
read-only C# checkout; global Git configuration was not changed.
C# `WicDirectDecoder.cs` at `7eaee2a2` confirms the blank-path guard before
source open. New tests live only in the two `tests/w4_mutation_killers3.rs`
files; they use TempRoot/fakes and contain no sleeps or timing assertions.
