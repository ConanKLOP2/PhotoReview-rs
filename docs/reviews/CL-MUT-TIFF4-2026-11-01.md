## Equivalent survivors (7)

- `78:38 > -> >=` (`ifd_offset + 2 + clamped*12 > len`): on equality the clamp `(len - ifd_offset - 2) / 12` returns the same count.
- `172:18 || -> &&` (`size == 0 || count == 0 || max_u32 == 0`): size 0 yields no items (`read_unsigned` is `None` for unknown types), count 0 gives `n = 0`; both end in an empty list anyway.
- `215:25 > -> >=` (`exif_pointer > 0`): pointer 0 reads the IFD at offset 0, which `read_ifd_entries` rejects (`< 8`), contributing `(0, 0)`.
- `355:19 < -> >` (`span.len() < 16`): a read of 16 bytes inside the source returns exactly 16, and a shorter span would still decode to a rejected ratio.
- `362:16`, `362:27`, `362:38` (`hn == 0 || hd == 0 || vn == 0 || vd == 0`, each `||` -> `&&`): any single zero already makes `hn*vd == vn*hd` false, and zeros in a pair are caught by the remaining terms.
