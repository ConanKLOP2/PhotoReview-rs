## P-320 nested EN_CHANGE during load (test only)
- New native test `crates/pr-platform-win/tests/settings_reentrancy_native.rs` (`#[ignore = "native: needs desktop"]`): a real Settings window with an `EchoPage` that mirrors the Shortcuts page (`load` = `set_text` then `refresh`; `on_command(EN_CHANGE)` = `refresh`; `refresh` reads the box and borrows the presenter) plus six probe pages. Defaults -> `load_all` -> `page.load` raises a nested `EN_CHANGE` inside the page's `&mut` borrow. Asserts exactly one `refresh()` and no `BorrowMutError`; a user edit refreshes exactly once.
- No production change: the test passes on current master code, so there is no bug.
- Sensitivity check: with BOTH the `view.loading` early return and the `try_borrow_mut` guard removed from `handle_command`, the test fails with `RefCell already borrowed`. Note the two guards are redundant for this case: `try_borrow_mut` alone is enough (D-W8B5-805); removing only `loading` leaves the test green.
- Ran: `cargo test -p pr-platform-win --test settings_reentrancy_native -- --ignored` (1 passed).
