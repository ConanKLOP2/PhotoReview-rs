Reproof selectors were listed first and each selected exactly two identities:

```text
-F 'app_settings.rs:(1166:47:.*\*=|1176:46:.*-=).*json::Parser.*skip_ws'
-F 'app_settings.rs:(1295:34:.*-=|1339:34:.*\*=).*json::Parser.*parse_string'
-F 'app_settings.rs:(1487:9:.*json::is_decimal_literal.*with.true|1496:28:.*with.\+.in.json::is_decimal_literal)'
```

- `1166 *=`: `true//éé` makes cursor multiplication exceed the UTF-8 input
  boundary promptly. An earlier ASCII-followed input spun and timed out.
- `1176 -=`: `/*  */true` returns into whitespace; after skipping it the
  parser sees the closing `*` as a value, rejecting valid input promptly.
  The initial empty block comment instead revisited the opening delimiter.
- `1295 -=`: `"\u0041"` sends the hex decoder back onto the backslash and
  rejects valid input, rather than revisiting an ordinary escape indefinitely.
- `1339 *=`: `"é"` moves the cursor inside a UTF-8 character and panics,
  rather than spinning on an ASCII character.
- `1179 *=`: multiplying the block-comment scan cursor by one leaves it
  stationary. Any ordinary body character loops forever. The 90-second timeout
  is retained honestly; no timing-dependent killer or production hook was added.

The two earlier equivalents were rerun and remain observable MISSED, with the
same public-boundary proofs as JSON2:

- `1487:9 return true`: the only caller of the private decimal predicate is
  `to_f64`, followed by Rust `str::parse::<f64>()` and a finite filter. The
  predicate accepts the same finite decimal syntax. Rust's additional named
  nonfinite spellings cannot escape the filter; exact C# named specials are
  already handled before the predicate. No returned value changes.
- `1496:28 - -> +`: unsigned inputs have `int_start=0`, so both expressions
  are identical. For signed inputs this only relaxes the no-integer-digit
  rejection. Valid signed fractions still pass; malformed sign-only, dot-only
  or exponent-only inputs fail the subsequent float parser. The intermediate
  digit count is private and no finite result changes.
