## Test changes

`crates/pr-platform-win/tests/w8_setui_killers.rs` imports the existing 11 pure layout killers into one binary and adds two deterministic tests:

- Nested group visibility: skips preceding non-group elements, searches descendants, rejects unknown IDs and non-group IDs, preserves sibling and parent visibility, and can update a child under a hidden parent.
- Flatten: asserts every descendant in exact preorder, including descendants of a hidden group, with checks before, inside and after nested groups.

Tests use builder values and fake surfaces only; no file timestamps, clocks, sleeps, registry, real config or Recycle Bin. No timing-related test was added, so the conditional 20-repeat timing gate does not apply. C# baseline `7eaee2a2:src/PhotoReview.Shell.Win32/Dialogs/SettingsUi/SettingsPageBuilder.cs` was read only; group placement arithmetic at lines 76-106 agrees with the existing layout assertions.
