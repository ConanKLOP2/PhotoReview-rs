## (a) Rule 1 of `aggregate_group_verdict` (N3 mutant 412:26 and its three siblings)

Removed: the first `if` (undo, `Move`, all member verdicts in `{CanRetry, AlreadyDone}`, contains `CanRetry` => `CanRetry`). The function is a pure function of `entry.op_type`, `entry.undo`, the member verdicts, and (rule 3) the source status of `NotRecycled` members; no caller invariant is involved. Why it is redundant: rules 2, 3 and 4 each require every verdict to be outside `CanRetry` (sets without `CanRetry`), so none matches a group that contains `CanRetry`; the next rule (old 5, now 4: all in `{AlreadyDone, CanRetry}` and contains `CanRetry` => `CanRetry`) then returns the same value as rule 1 for every input rule 1 accepts.

Test: `recovery_check::tests::aggregate_group_verdict_is_identical_with_and_without_the_undo_move_rule_for_every_member_combination` (inline unit test, calls the private function directly). Reference restated independently from the documented rules, with a switch that puts the old rule 1 back. For every case the test asserts production == reference without rule 1 AND reference with rule 1 == reference without. Domain: 3 ops (`Move`, `Copy`, `Recycle` are all the values of `FileOperationType`) x 3 undo values (`None`, `Some(false)`, `Some(true)`) x every ordered group of 1 to 3 members over all 44 (verdict, source status) pairs (11 verdicts x 4 statuses), every ordered group of 4 verdicts (status `Exists`), and every non-empty set of verdicts (2047) with a uniform status for each of the 4 statuses (the function only reads `all`/`contains` of verdicts plus statuses of `NotRecycled` members, so a set plus statuses covers longer groups). Over 700 000 groups; the rule-1 domain (undo Move, only `CanRetry`/`AlreadyDone`, one `CanRetry`) is reached and asserted to give `CanRetry`. Result before removal: pass. ## (b) `Exists` guard in `check_group_member` (N3 mutants 327:24 true/false, 328:25, 327:51, 328:65)

Removed: the match guard `single.source.current_size == Some(member.size) && single.source.current_last_write_utc == Some(member.last_write_utc.value)` and the dead arm `Exists => Conflict`. Now `Exists => AlreadyDone`. Why it is redundant: `single` is produced a few lines above by `self.check(&single_entry)` with `size`, `last_write_utc` taken from the member; for a non-group entry `check_path(source, size, last_write, compare_last_write: true)` returns `Exists` only when `i64::try_from(stat.length) == Ok(recorded_size)` and `stat.last_write_utc == recorded`, and then stores `current_size = Some(length)` and `current_last_write_utc = Some(stat.last_write_utc)`. So `Exists` already implies both comparisons are true. This is a property of the callee in the same file (not of a caller), and it holds for any path including a case-only twin because `Exists` is built in only one place.

Test: `crates/pr-core/tests/p393b_group_member_exists_guard.rs`, `undo_recycle_member_verdict_depends_only_on_the_source_status_for_every_size_and_write_time`. A stub `FileSystem` returns a chosen stat or `Missing` or an `Err`. Cross product: recorded size {i64::MIN, -1, 0, 1, 10, 11, 4096, i64::MAX-1, i64::MAX} x recorded write ticks {0, 1, STAMP-1, STAMP, STAMP+1, MAX-1, MAX} x permanent {false, true} x stat outcomes (missing, unreadable, every pair of length {0, 1, 9, 10, 11, 4096, i64::MAX-1, i64::MAX, i64::MAX+1, u64::MAX-1, u64::MAX} x the same 7 write ticks, and the exact match). Asserts the source status equals the spec of `check_path` (size AND write time), and the member verdict equals the model with no guard (`Exists` => `AlreadyDone`, `Missing` => `RecycleUnverifiable`, `Changed`/`Unreadable` => `Unknown`), never `Conflict`, and that the entry is the group entry.
