## Traps found in this run (each one made earlier numbers wrong)
1. **Inline tests need `--lib`.** First shard (`--test host_main_window_core` only): `priority_slot -> 0/1` and `TimerEntry::eq` looked MISSED/TIMEOUT; they are pinned by the in-crate tests (`core::tests`, `registry_tests`). Fixed with `--cargo-arg --lib`.
2. **`--lib` twice = false CAUGHT.** Passing `--lib` as both `--cargo-arg` and `--cargo-test-arg` made `cargo test` fail with "the argument '--lib' cannot be used multiple times"; with `--baseline skip` all 74 mutants of that run were reported caught with no test run. That run (`mut-out-D`) was discarded; every number below comes from logs that show `running N tests` (N = 274/275 lib + 29 core, up to 16 binaries in the second pass), none contains `no tests/golden above`.
3. **Stale test exes after the preflight.** A preflight in the shared target dir left test exes that the first mutant reused unmutated (`priority_slot -> 0` survived there but fails in 0.7 s when run by hand). Fix: preflight in a separate target dir, `MUT_PREFLIGHT=0` for the mutants run (the touch then precedes the copy).
4. **Full `--no-run` build is the cost.** Without `--cargo-arg --test=<bin>` cargo-mutants compiled ~100 test binaries per mutant (5-10 min on this loaded machine, 300 s test timeouts); with it 1-2 min.
