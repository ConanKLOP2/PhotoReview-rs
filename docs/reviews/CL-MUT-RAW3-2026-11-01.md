## Method

`cargo mutants -p pr-imaging-raw --baseline skip --timeout 300 -j 1`, `CARGO_TARGET_DIR=<worktree>/target-mut`, `CARGO_PROFILE_DEV_DEBUG=0`, `CARGO_PROFILE_TEST_DEBUG=0`, `PHOTOREVIEW_GOLDEN_ROOT` set, isolated data root, sources touched before each run. Test arguments: `--test <bins> -- --include-ignored --test-threads=1 --skip golden --skip corpus`, so a golden-only catch cannot count. Each run had a preflight (`running N tests`, N > 0, exit 0) and the mutant logs show `running N tests`. One cargo-mutants at a time. I did not use `tools/dev/mutants.sh` itself: it has no `-F` filter pass-through and no `--skip`; its flags and environment were replicated by hand in a scratch script. A reused target dir holds the last mutant's build: after the CR2 run an unmutated test failed until the sources were touched (the known trap in `tools/dev/docs/mutants.md`), so every run touched the sources first.
