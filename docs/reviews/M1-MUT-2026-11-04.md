### layout.rs (7, all equivalent, none killable by a test)

| Mutant | Why equivalent |
|---|---|
| `layout.rs:77:16` `> -> >=` in `wpf_double::greater_than` | equal values are `are_close`, so `value1 >= value2 && !are_close` is false exactly when `>` was false there |
| `layout.rs:96:10` `> -> >=` in `net_max` | `a == b` returns in the branch above, so `a > b` and `a >= b` agree on every value that reaches the line |
| `layout.rs:108:10` `< -> <=` in `net_min` | same reasoning |
| `layout.rs:349:15` `< -> <=` in `arrange_length` (`length < unclipped`) | on equality it assigns the same value |

| `layout.rs:349:15` `< -> ==` in `arrange_length` (`length < unclipped`) | equivalent in practice, argued and searched, not proven: `slot = net_max(measured, viewport) >= measured = net_min(unclipped, max)`, and `unclipped <= max` except for one ulp of rounding in `natural * (box / natural)`.
