## New tests and survivor dispositions

New file: `crates/pr-core/tests/w2_json_killers.rs`. Tests directly assert duplicate
property lookup, signed integer bounds/grammar and the serde adapter's token kinds.
They are deterministic, have no sleeps or clock/mtime inputs, and use no files.

- `app_settings.rs:1444:21`, guard `allow_plus -> true`: typed golden input passes
  through the parser, which rejects a leading plus before conversion. The public
  DOM can also be constructed directly. A new assertion requires number token
  `+42` to fail, while string token `"+42"` converts to 42.
- `1453:18`, `> -> ==` and `> -> >=`; `1454:42`, `+ -> -` and `+ -> *`:
  equivalent at the public integer conversion boundary. The affected magnitudes
  are at least `u64::MAX - 1`, beyond both signed output ranges. Removing the
  small clamp still leaves a monotonically growing nonnegative magnitude, bounded
  by saturating i128 arithmetic; negating it remains outside i64. The private
  intermediate i128 value is never exposed. All variants still return `None`.
