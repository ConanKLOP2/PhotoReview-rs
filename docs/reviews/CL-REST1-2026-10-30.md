## Method

`cargo mutants -p pr-platform-win --baseline skip --timeout 90 --build-timeout 600 -j 1 --file ... --cargo-arg=--test=<binary>...`, own `target-mut`, `PHOTOREVIEW_RS_ISOLATE_CONFIG=1`, `PHOTOREVIEW_RS_DATA_ROOT` in the worktree. The windowing run used `-- -- --include-ignored --test-threads=1` (hidden windows only, never shown); the first argument group after `--` goes to `cargo test`, so the test-binary flags need the second `--`. Popup menu native tests (`TrackPopupMenuEx` shows a real menu) were NOT run, per the no-GUI rule.

Two runs were discarded as false (kept only as local logs, not committed):
- startup group with `--cargo-arg=--lib`: the unrelated lib test `size_minimized_matches_the_csharp_golden` fails inside the cargo-mutants temp copy (no `tests/golden` above `pr-test-support`), so all 84 "caught" were fake. Rerun without `--lib`.
- windowing group with a single `--`: cargo rejected `--include-ignored` (`error: unexpected argument`), so everything was "caught" by the build error. Rerun with `-- --`.
