Scope: decide every cargo-mutants mutant of 10 source files with hand-written, non-golden tests only. No production code changed.
Base `origin/master` 56423e22, branch `test/mut-presenters`. New tests (9 files, 47 tests):
`crates/pr-app/tests/mut_presenters_m4_{actions_row,combo_rows,killers,numeric_rows,profiles,recovery_killers,scrollbar_killers,zoom}.rs`

## How it was run (and where it differs from `tools/dev/mutants.sh`)

* cargo-mutants with `--baseline skip --timeout 90` (zoom_detail 200) `-j 1`, 10 mutants per chunk, 3000 s budget per chunk, non-golden tests
  (`--skip golden_`, so no mutant counts as caught through golden data), own preflight (the unmutated command must run tests and exit 0),
  one cargo target dir per lane under `C:\Users\PC\Projects\target-mut-presenters-*` (outside the worktree), `CARGO_BUILD_JOBS=2`.
* DEVIATION: the runs used a small Python harness (`lane.py`, kept outside the repo in `C:\Users\PC\Projects\tmp-mut-presenters`) that calls
  `cargo mutants` with the same arguments as `mutants.sh`, instead of `tools/dev/mutants.sh` itself. Reasons: it lists the mutants once, runs them in
  chunks, resumes, and records each mutant by `file:line:col` in a `summary.json`. The libtest flags were passed after `--` (`--skip golden_`, and
  `--include-ignored --test-threads=1` for the pr-core file with `physical_access_denied_source` skipped), so the false-"caught" trap of
  AUDIT-MUTATION-FLAG-2026-10-30 does not apply (every preflight that gated a run executed tests).
* A timeout is never counted as caught. No mutant in this evidence ended in a timeout (0 everywhere).
* Preflight failures seen in intermediate runs (R1, R2, and the compare/zoom/settings_field_map jobs of lane F) were a harness fault, not a test
  fault: the reused lane target dir held artifacts of the last mutant of the previous job (stale mtimes, the trap described in `mutants.sh`). The
  harness now touches the crate sources before each job; the affected jobs were rerun (lanes F3, F4) and their preflights passed.
* First-pass "caught" verdicts were produced with the test set that existed then. They were not rerun with the final test set (the final set is a
  superset, so a caught mutant stays caught); only survivors were rerun, with the final test set.
* "Equivalent" below is a proof by reading and case analysis, not a run (a surviving mutant cannot be proven equivalent by running tests; the three
  `recovery_check.rs` ones were rerun on the final tests and survive, as predicted).
