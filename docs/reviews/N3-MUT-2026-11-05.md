## How it was run

`tools/dev/mutants.sh -j 1` itself (not a private harness), `TEMP` pointed at `C:\Users\PC\Projects\target-mut2-presenters-proofs-mut` so the
cargo target dir is outside the worktree, `CARGO_BUILD_JOBS=2`, `MUT_TIMEOUT=200`. Each batch was selected with `-F`, so only the
mutants in scope ran; each batch's preflight executed tests (68, 11, 11, 11, 2). Tests are selected with `--tests` (the new files, plus the
existing zoom tests for the zoom batch), so no mutant is caught through golden data. A timeout is never counted as caught: the one timeout
(below) was rerun through the harness with a filter and ended caught.

What "proven equivalent by run" means here. A surviving mutant is equivalent on a domain when a test that compares the function with an
independent model (or with a digest of the unmutated outputs, bit for bit) passes under the mutant on that whole domain. The domain is stated
per test. Evidence that the tests can fail: in the same batches the neighbouring non-equivalent mutants were caught by them
(`inside` `>` to `==`/`<`, `cs_min` `<` to `==`/`>` and `||` to `&&`, `try_double` guard 260:14 to `true`, `format_size` `>` to `==`/`<`,
recovery_check 327:24 guard to `false`).

## Open

None of the 46 mutants is left undecided. Limits that remain, stated plainly:

* The `cs_min` proof is a differential digest over a large sampled domain of the f64 line (13 classes cartesian, plus 1 million random
  layouts), not an enumeration of all 2^64 inputs.
* 450:30 is proven over the operation sequences listed, not over thread interleavings.
* 412:26: `PartiallyPermanentlyDeleted` and a few verdict multisets are not reachable from the fixture (Rule 1 does not involve them).
* Proposal text (no production change was made): drop the dead `e` branch of `dotnet_double_text`, the redundant rule 1 of
  `aggregate_group_verdict`, the redundant `Exists` guard in `check_group_member`, and make `cs_min` take already-sanitized operands, which
  would remove these 11 equivalents; or expose a `pub(crate)` test seam for the `CompletionInbox` waiter so that no `inbox_` test needs a
  60 s hang guard.
