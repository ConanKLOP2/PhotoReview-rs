# CL-W6RERUN: re-run of the W6 platform native mutation groups with the corrected flag form, 2026-10-30

Context: [AUDIT-MUTATION-FLAG-2026-10-30](AUDIT-MUTATION-FLAG-2026-10-30.md). The W6 and CL-P01 runs used a libtest-flag form that
cargo rejects, so `--baseline skip` counted every mutant as caught. Worktree `cl-w6rerun`, branch `feat/cl-w6rerun`, crate
`pr-platform-win`. Recycle Bin: no test and no mutant touches the real bin; the only registry write is a throw-away key
`HKCU\Software\PhotoReviewRsW6RerunScratch-<pid>` created and deleted by one killer. No window was opened.

## Command form

`cargo mutants -p pr-platform-win --baseline skip --timeout 300 -j 1 --file ... -F "<regex>" --cargo-arg=--test=<binary> [...]
--cargo-test-arg=-- --cargo-test-arg=--include-ignored --cargo-test-arg=--test-threads=1`, `CARGO_TARGET_DIR=<worktree>/target-mut`,
`CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0`. Test binaries are chosen with `--cargo-arg=--test=<binary>` (it applies to the build
and to the test step, so only those binaries are built and run) and the libtest flags follow a real `--`. `tools/dev/mutants.sh --native`
was not used: it hard-codes `--timeout 90` and builds every test binary of the crate for every mutant.

Preflight (unmutated, same binaries, `-- --include-ignored --test-threads=1`): exit 0 and N > 0 tests for every binary (14, 17, 2, 13, 18,
6, 6, 37, 21, 3 tests). The per-mutant logs (`mutants.out/log/*.log`) contain `running N tests` lines (2, 3, 6, 13, 14, 17, 18, 21, 37), so
tests really ran and a failing test is what "caught" means here. A first attempt with the default debug profile ended in a rustc crash
(`STATUS_STACK_BUFFER_OVERRUN` while compiling an unrelated test target on the loaded machine); that output was discarded and the run was
repeated with the settings above. A second false start (an extra `--cargo-test-arg=--test` form that built all ~150 test binaries per
mutant, about 50 s per mutant) was stopped after 8 mutants and replaced by the form above.

## New killers (`crates/pr-platform-win/tests/w6_rerun_killers.rs`, 6 tests, 1 ignored native)

Each of the 7 killable mutants was applied by hand to the source and run against only this binary: all 7 failed as required, the source
was restored with `git checkout` (the cargo-mutants runs above were not repeated for the new tests). No sleep; the private test pipe has a
per-process unique name (never the application pipe); waits are deadlines of 300 ms or a 4 s channel guard.
`cargo test -p pr-platform-win --test w6_rerun_killers -- --include-ignored --test-threads=1` passes 6/6; `cargo fmt` and
`cargo clippy -p pr-platform-win --test w6_rerun_killers --locked -- -D warnings` are clean.
