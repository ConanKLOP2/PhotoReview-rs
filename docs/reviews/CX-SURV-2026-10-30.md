## JSON: eight stationary cursor loops remain unresolved

Fresh --list in `target/surv-json-list.json` confirms all eight identities.
All replace `+= 1` with `*= 1`; the replacement leaves the cursor unchanged
for every usize value and cannot overflow. While the loop condition is true,
the next iteration reads the same immutable byte, so it remains true forever.
If the condition is false, the mutated statement is never reached and cannot
change the result. These loops have no injected reader, clock, callback or
cancellation observation on which an external assertion can run.

| Source coordinate | Example that reaches the loop | Unchanging condition |
|---|---|---|
| app_settings.rs:1146:26 skip_plain_ws | ` true` | Same whitespace byte at pos 0 |
| app_settings.rs:1179:53 skip_ws | `/*x*/true` | Same non-closing comment body byte at pos 2 |
| app_settings.rs:1228:34 parse_number | `1` | Same integer digit at pos 0 |
| app_settings.rs:1239:30 parse_number | `0.1` | Same fractional digit at pos 2 |
| app_settings.rs:1251:30 parse_number | `0e1` | Same exponent digit at pos 2 |
| app_settings.rs:1494:15 is_decimal_literal | String conversion of `1` | Same integer digit at i 0 |
| app_settings.rs:1501:19 is_decimal_literal | String conversion of `.1` | Same fractional digit at i 1 |
| app_settings.rs:1516:19 is_decimal_literal | String conversion of `0e1` | Same exponent digit at i 2 |

The inputs above are static witnesses, not newly executed mutated tests.
Reordering inputs or using UTF-8 cannot move a cursor multiplied by one.
Inputs that bypass the affected loop cannot distinguish this mutation.
A child-process watchdog could fail a parent assertion after a time limit;
it would remain a timing-dependent hang detection. Instrumenting the loop
with a progress/step observer would change production solely for mutation,
which this lane prohibits unless a real bug is exposed. No production bug
was exposed. Therefore no false assertion-only killer or copied parser was
added, and no eight redundant 90-second hangs were launched.

This is an unresolved constraint, not an equivalence proof or caught verdict.
