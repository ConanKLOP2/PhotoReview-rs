# N4: native image decoders, RAW readers, bench presenter and WinHTTP transport, mutation under OWNER RULE B

Rule B as applied here: a mutant is closed only if it was caught, unviable, or proven equivalent BY A RUN (a test that passes under the mutant on the WHOLE domain in which mutant and original differ, or a differential test). An equivalence argued only by reading the code stays OPEN. A timeout is never a catch: every timeout below was re-run through the harness against a new bounded killer (none was killed by hand). Where a run covers a bounded sub-domain only, the row says `run-supported` and counts as OPEN.
