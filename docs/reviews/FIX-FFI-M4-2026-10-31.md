# FIX-FFI-M4 (2026-10-31): safe functions that took any integer as a native pointer

Status: done in PR (lane `fix-ffi-m4`). Source: ST-FFI-LIBS M4 and the deferred FIX-FFI-HARDENING item.

## Problem

Safe `pub fn`s let any caller turn an arbitrary integer into a native `tjhandle`, or skip the pinned-version gate before
native memory is read or written. They had no production caller (grep over the whole workspace: only the crates' own
integration tests, which sit in separate crates, so `pub(crate)` is not usable; `unsafe fn` would add dozens of `unsafe`
blocks in tests).

## Choice (least churn)

Cargo feature `test-support` (default OFF) in `pr-turbojpeg` and `pr-libraw`; the items are
`#[cfg(any(test, feature = "test-support"))]`. Each crate lists itself in `[dev-dependencies]` with the feature
(`pr-libraw = { path = ".", features = ["test-support"] }`), so `cargo test`/`clippy --all-targets` enable it, and a normal
build of the crates (and of every dependent) does not. Same pattern as the existing `pr-platform-win` `test-support`.
No `unsafe` was added or removed; the unsafe lines and their `// SAFETY:` comments are unchanged.

## Functions removed from the default public API

pr-turbojpeg (`src/native.rs`): `TurboJpegHandle::from_raw`, `TurboJpegHandle::with_destroy`, `wrap_init_result`, and the
`Binding::Shared` variant (only they build it; the gate also avoids a dead-code warning).

pr-libraw (`src/native.rs`): `LibRawHandle::try_set_use_camera_wb_with`, `LibRawHandle::raw_structure_with` (production
`raw_structure` now calls a private `raw_structure_impl`), `LibRawHandle::read_data_i32`. `write_i32`/`read_i32` were trait
methods of the public `WhiteBalanceTarget` implemented on the real handle, so any safe caller could read/write the live
`libraw_data_t` without the pin gate. The impl moved to a private adapter `ProbeTarget`; the production
`try_set_use_camera_wb` goes through it, the trait stays public for the tests' fake block.

Not changed: `NativeOwner::new(usize, release)` stays public (its release is a safe closure; it is not a native call by
itself).
